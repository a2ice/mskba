# Каталог оформления MSKBA App

Копия принятого эталона 002-03, использующая **CSS и assets новой темы**.
Внешние картинки и Google Fonts заменены локальными файлами. Каталог показывает
все существовавшие в стенде состояния; это не реальная страница приложения.

Из корня `site`:

```sh
python3 -m http.server 8014 --bind 127.0.0.1 --directory resources/themes/mskba_app
```

Открыть http://127.0.0.1:8014/catalog/ . Docker не требуется.
`js/catalog.js` обслуживает только этот каталог: локальный поиск, учебную форму,
диалог и уведомление. Его нельзя подключать как бизнес-JavaScript страниц.
Vue-компоненты и работа с API появятся при реализации настоящих маршрутов.
