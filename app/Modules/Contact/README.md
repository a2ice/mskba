# Contact Module

Модуль хранит контактные каналы доменных сущностей и процессы их подтверждения.

Значение контакта нормализуется через `Domain\ValueObjects\ContactValue`. VO отвечает только за формат и каноническое строковое значение; проверки уникальности, прав доступа и workflow подтверждения остаются в application/use case слое.

Проверка контакта разделена на два потока:

- старт подтверждения выполняется через `ContactVerificationStrategy`, потому что доставка кода зависит от типа контакта и канала;
- подтверждение введенного кода выполняется через общий `ConfirmContactVerificationHandler`, потому что email/sms-like каналы используют одинаковые правила: pending-код, срок действия, лимит попыток и атомарное обновление контакта.
