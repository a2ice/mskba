# Venue

Модуль ограниченного контекста для баскетбольных площадок и доступа к ним.

## Ответственность

- Публичный список площадок и просмотр площадки.
- Список площадок в личном кабинете.
- Создание площадки подтвержденным пользователем.
- Редактирование регулярного расписания площадки в личном кабинете.
- Проверка доступа к площадке по membership-contract permissions.
- Bootstrap-доступ создателя только для площадок без действующего owner membership contract.
- `created_by_user_id` остается audit/source field.
- Связь площадки со структурированной `Location` через `location_id`.
- Fallback-адрес площадки в `raw_address`, если структурированная локация еще не заведена.

## Публичная страница площадки

Страница просмотра площадки развивается от визуального каркаса к реальным данным. `ShowVenueHandler` должен отдавать read-only DTO, пригодный для финальной страницы, даже если часть доменных модулей еще не реализована.

Уже реальные данные:

- базовые поля площадки;
- `Venue -> Location -> Address`;
- `Venue -> Location -> MetroStations -> MetroLine`.
- `Venue -> Media` для hero-изображения и галереи.
- `Venue -> Amenity` для публичного блока опций площадки.
- `Venue -> VenueSchedule -> VenueScheduleInterval` для регулярного расписания по дням недели.
- `Venue -> VenueReview -> User/Profile` для публичных отзывов и агрегированного рейтинга.

Пока заглушки в DTO/UI, которые заменяются по мере появления модулей:

- исключения расписания;
- бронирования;
- посты/лента площадки;
- создание и модерация отзывов.

Метро и адрес не должны возвращаться на старую схему прямых полей площадки. Для публичной страницы источник данных остается таким: `Venue -> Location -> Address` и `Venue -> Location -> MetroStations`.

## Структура

- `Domain`: бизнес-модели, enum, события, исключения, value object.
- `Application`: use case, DTO, application-сервисы и builders.
- `Infrastructure`: ACL, интеграции, service provider, factory.
- `Presentation`: HTTP-контроллеры, request-классы, resource-классы.
- `Tests`: feature- и unit-тесты модуля.
