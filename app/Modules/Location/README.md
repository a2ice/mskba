# Location

Контекст физической локации, структурированных адресов, канонической административной географии и метро.

`Location` используется как общий агрегат для площадок и других сущностей с физическим местом. `Address` сохраняет строковый provider/legacy snapshot города и nullable ссылки на канонические `City`/`District`; метро связывается с `Location` через общий справочник станций.

Yandex остаётся внешним источником подсказок и reverse geocoding, но не владельцем справочника: неизвестные города и районы не создаются автоматически. Канонические города/районы управляются отдельно и используются для фильтрации homepage discovery.
