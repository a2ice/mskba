# Contract

Модуль ограниченного контекста для контрактов и участников контрактов.

## Ответственность

- Список контрактов пользователя в личном кабинете.
- Просмотр деталей контракта пользователя.
- Membership contracts через `ContractMembership`.
- Relation contracts через `ContractRelation`.
- Snapshot фактических прав через `ContractPermission`.
- Текущая площадочная специализация доступа через `venue -> user` membership contracts.
- Целевая модель membership/relation contracts описана в `docs/specification/contracts.md`.

## Текущая область

В текущей кодовой базе контракты используются для выдачи пользователям membership-доступа к площадкам с разрешениями:

- `view`
- `edit`
- `edit.schedule`

Relation contracts для связей сущность-сущность заложены в схему, но прикладной ACL для событий, команд, компаний и других доменов пока не реализован полностью.

Значения `holder`, `provider`, `customer` не используются как универсальная ACL-модель. Они подходят только для контекстов, где relation type действительно описывает сервисный или заказной договор.
