# Contract

Модуль ограниченного контекста для контрактов и участников контрактов.

## Ответственность

- Список контрактов пользователя в личном кабинете.
- Просмотр деталей контракта пользователя.
- Участники контракта через `ContractParty`.
- Текущая площадочная специализация доступа через `VenueContract` и `VenueContractPermission`.
- Основа для будущего более общего механизма контрактов между разными типами сущностей.

## Текущая область

В текущей кодовой базе контракты используются для выдачи пользователям доступа к площадкам с разрешениями:

- `view`
- `edit`
- `edit.schedule`

Более широкая модель контрактов между разными сущностями является направлением будущего развития и пока не реализована полностью.
