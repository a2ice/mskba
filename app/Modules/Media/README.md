# Media

Модуль для файлов, привязанных к доменным сущностям через polymorphic-связь.

Первый потребитель - публичная страница площадки:

- hero-изображение;
- галерея площадки;
- будущие media-разделы в управлении площадкой.

`mediable_type` хранится через обязательный morph map:

- `profile` — профиль пользователя;
- `event` — мероприятие;
- `venue` и `venue_revision` — площадка и её редакция;
- `content_item` — материал;
- `team` — команда и её логотип.
