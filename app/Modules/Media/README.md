# Media

Модуль для файлов, привязанных к доменным сущностям через polymorphic-связь.

Первый потребитель - публичная страница площадки:

- hero-изображение;
- галерея площадки;
- будущие media-разделы в управлении площадкой.

`mediable_type` хранится через morph map. Для площадок используется alias `venue`.
