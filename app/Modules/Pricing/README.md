# Pricing

Модуль хранит управляемый прайс-каталог отдельно от будущего финансового контура.

Иерархия первой версии:

- `PricingCategory` — логическая группа услуг;
- `PricingService` — стабильный тип покупаемой услуги;
- `PricingVariant` — необязательный вариант услуги;
- `PricingPrice` — версия цены с периодом действия.

Цены хранятся в минимальных денежных единицах (`amount_minor`), для RUB — в копейках.
Смена цены создаёт новую запись и закрывает предыдущую, поэтому история не переписывается.

Актуальная цена для бизнес-кода получается через
`PricingPriceResolver::resolve($serviceCode, $variantCode = null)`.
Finance/Purchase слой должен фиксировать найденную цену в момент создания покупки, а не
читать её повторно после совершения операции.

Начальный каталог:

- `avatar_generation` — 100 ₽;
- `team_generation` — 100 ₽;
- `game_highlights_generation` — 100 ₽.

Категория для всех трёх услуг: `ai_generation`.
