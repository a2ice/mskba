# Rewards

Rewards — отдельный контекст управляемых бонусных вознаграждений.

Границы ответственности:

- Rewards хранит каталог: за что, кому и сколько полагается;
- конкретный `RewardMechanism` определяет право на награду по предметному событию;
- `RewardGrant` фиксирует неизменяемый снимок возникшего права;
- Finance остаётся единственным контуром, который фактически меняет баланс и пишет ledger.

## Механизмы

Реализованные механизмы регистрируются в `config/rewards.php`. Технический статус
«механизм реализован» вычисляется реестром, а `is_enabled` остаётся управляемой
бизнес-настройкой каталога.

Текущие механизмы:

- `referral_user_confirmed` — 300 ₽ bonus прямому пригласившему после подтверждения приглашённого;
- `referral_second_level_user_confirmed` — 100 ₽ bonus первоначальному пригласившему по цепочке A → B → C;
- `venue_first_approval` — 100 ₽ bonus автору новой площадки после первой успешной модерации.

Для реферальной цепочки используется явная атрибуция. Персональный вход имеет вид
`/r/{username}`: ссылка сохраняет pending attribution в сессии, а связь фиксируется
только на первом входе действительно нового пользователя. Старый аккаунт, self-referral
и циклическая цепочка не создают attribution.

## Выполнение

Подтверждение аккаунта публикует `UserAccountConfirmed` после commit. Успешная
модерация площадки уже публикует `ModerationRequestApproved`. Rewards слушает эти
события queued-listener'ами и передаёт их в `RewardEngine`.

`RewardEngine`:

1. проверяет активную запись каталога и зарегистрированный механизм;
2. определяет получателя;
3. создаёт `RewardGrant` с reward/version/amount/business fact;
4. проводит начисление только через Finance;
5. использует стабильный idempotency key `reward-grant-{id}`.

Повтор события или retry не удваивает баланс. Если grant уже возник, последующее
выключение правила не отменяет его: retry завершает сохранённое право по snapshot.

Изменение номинала, условий, получателя, момента начисления или параметров механизма
создаёт новую `RewardVersion`. Уже возникшие grants и проведённые операции не
пересчитываются.
