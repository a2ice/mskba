# Portal

Модуль содержит общепортальные механики, которые не принадлежат одному предметному разделу.

## Сводка сайта

`SiteSummaryService` формирует показатели для первого экрана и мобильной панели:

- игры и игровые тренировки, запланированные на текущий день по часовому поясу приложения;
- количество активных авторизованных пользователей online;
- количество всех активных посетителей online, включая гостей;
- общее количество незаблокированных и неудалённых аккаунтов.

На главной и в мобильной панели суточный показатель ведёт в журнал мероприятий с составным фильтром `games` (`game` + `game_training`) и датой текущего дня. Если игр сегодня нет, вместо счётчика отображается ссылка «Новая игра»; для гостя она сначала открывает авторизацию. В мобильной панели online отображается как `авторизованные/всего`, например `5/15 онлайн`. Общее число считается по уникальным browser fingerprint, поэтому несколько вкладок одного браузера учитываются как один посетитель, а разные браузеры или устройства — как разные посетители.

Суточный счётчик мероприятий и общее количество пользователей используют Laravel cache store. В штатном Docker runtime это Redis. Изменения `Event` и `User` инвалидируют соответствующие ключи после завершения транзакции.

Online presence хранится в Redis Sorted Set с общим окном активности: для авторизованных пользователей member — ID пользователя, для всех посетителей отдельный Sorted Set использует ID browser fingerprint; score — timestamp последней активности. Heartbeat и обычные web-запросы обновляют timestamp, а значения старше окна активности исключаются.

Административный список пользователей получает один актуальный snapshot пользовательского Sorted Set и сопоставляет его с загруженной страницей аккаунтов. Это позволяет показывать сводку online/total и последнюю активность каждой строки без отдельного Redis-запроса на пользователя.

Если Redis временно недоступен, presence возвращает `0`, а кешируемые SQL-счётчики пробуют вычислиться напрямую, поэтому сбой необязательной сводки не должен блокировать страницы.
