# Portal

Модуль содержит общепортальные механики, которые не принадлежат одному предметному разделу.

## Сводка сайта

`SiteSummaryService` формирует показатели для первого экрана и мобильной панели:

- игры и игровые тренировки, запланированные на текущий день по часовому поясу приложения;
- количество активных авторизованных пользователей online;
- общее количество незаблокированных и неудалённых аккаунтов.

Суточный счётчик мероприятий и общее количество пользователей используют Laravel cache store. В штатном Docker runtime это Redis. Изменения `Event` и `User` инвалидируют соответствующие ключи после завершения транзакции.

Online presence хранится в Redis Sorted Set: member — ID пользователя, score — timestamp последней активности. Heartbeat и обычные web-запросы обновляют timestamp, а значения старше окна активности исключаются. Один пользователь с несколькими вкладками учитывается один раз.

Если Redis временно недоступен, presence возвращает `0`, а кешируемые SQL-счётчики пробуют вычислиться напрямую, поэтому сбой необязательной сводки не должен блокировать страницы.
