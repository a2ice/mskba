# MSKBA — подготовка разработчика к собеседованию

> Учебный путеводитель **по реальному коду MSKBA**, а не отвлечённая шпаргалка. Срез: **13 октября 2026**, локальная ветка **dev**. Некоторые части заявки на изменение профиля и тредов на дату аудита **не закоммичены** — они отмечены отдельно. Не выдавай план за production.

## Как пользоваться

**Если до интервью 30 минут:** [экспресс-шпаргалка](14-cheatsheet.md) → [питч о проекте](01-product-and-stack.md) → [вопросы и ответы](13-interview-qa.md).

**Если есть 2–3 часа:** пройди маршрут [00 — подготовка](00-roadmap.md), затем главы 02–12, отвечая вслух на вопросы в конце каждой главы.

**Если нужен технический разбор:** переходи по ссылкам «В коде»; каждая ведёт к конкретной реализации. Код — источник истины; примеры из документации упрощены и могут опускать второстепенные проверки.

## Легенда достоверности

- **В коде:** проверен существующий класс, конфиг или тест.
- **Концепция:** общепринятый приём, иллюстративный SQL/PHP, не обязательно точная копия реализации.
- **WIP / локально:** присутствует среди незакоммиченных изменений ветки dev; пока нельзя утверждать, что это выпущено в production.
- **Не подтверждено:** не утверждать как личный проверенный результат (например, числа ускорения без бенчмарка).

Этот материал **не заменяет** [продуктовую документацию](../project.md) и [техническую спецификацию](../specification.md). Он переобъясняет имеющиеся решения языком собеседования.

**Ключевая формула ответа:** «Была бизнес-проблема X → мы выбрали Y вместо Z → защитили инвариант W → проверили тестом/измерением Q → знаем компромисс R».
