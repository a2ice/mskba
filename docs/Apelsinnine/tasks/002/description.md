# 002 - Проверка флоу регистрации нового пользователя

## Оригинальное описание

Проверить процесс регистрации - попробовать зарегистрироваться с уже существующим логином или никнеймом - проверка на другие нестандартные варианты: наличие пробелов в логине/пароле, длина минимальная/максимальная логина/пароля, повторная отправка формы, получение и корректная обработка и вывод этих ошибок: какое сообщение пользователь получает при ошибке - понятно ли

## Подробное описание

- Добавить план действия и кретериев приемки (чеклист) (DoD - definition of done)
- На всех устройствах - десктоп, планшет и смартфон (либо в эмуляции устройств в браузере (например Chrome))
