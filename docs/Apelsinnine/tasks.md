# Tasks

Список задач проекта. Каждая задача ведется отдельной папкой в `docs/tasks/{NNN}`.

Формат строки:

```markdown
- [ ] NNN - Название или краткое описание задачи
```

Статусы:

- `[ ]` - задача запланирована или ожидает старта.
- `[x]` - задача выполнена, закоммичена и вмержена в `main`.

Сокращения/маркеры:

- (DEV) - dev.mskba.ru
- (PROD) - mskba.ru
- (ST) - smoke test - проверка ключевой функциональности - работает ли корректно, без зависаний и прочих непредвиденных эффектов
- (FT) - functional test - функциональное тестирование, которое охватывает позитивные, негативные и граничные сценарии (не типичные ситуации на границах допустимых значений)
