# API для приложения: удаление аккаунта

`DELETE https://mskba.ru/api/v1/me`

**Авторизация:** HTTP `Authorization: Bearer <access_token>` (Sanctum). Нужно право токена `account:delete`. Оно включается в токены, выдаваемые новыми `POST /api/v1/auth/login` и `POST /api/v1/auth/register`. Со старым токеном без права следует перелогиниться.

**Тело:** не требуется. Метод удаляет **только** текущую identity; параметр `user_id` не принимается.

**Ответ HTTP 200:**
```json
{"deleted":true,"message":"Аккаунт удалён."}
```

Все токены canonical identity и её aliases отзываются; приложение обязано очистить локальный токен и профиль и перейти к гостевому состоянию. Вход удалённого пользователя больше невозможен.

**Ошибки:** `401` — отсутствует/недействителен Bearer; `403` — нет права `account:delete` или аккаунт заблокирован; `429` — слишком много запросов (5/мин).

Перед DELETE приложение должно показать собственный диалог «Вы уверены, что хотите удалить аккаунт?» с «Отмена» и «Да, удалить аккаунт». После успеха повторный DELETE со старым токеном получит `401`.

В базе используется только soft delete (включая связанные aliases), чтобы сохранить документы, историю бронирований, сообщений и финансовых операций. Восстановление возможно административно.
