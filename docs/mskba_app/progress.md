## Ключевые решения

1. Тема `mskba_app` самостоятельная, не наследует неперенесённые Blade-страницы из `mskba_dark`.
2. Дизайн-гайдлайн 1.0 — единый источник визуальных решений; новый CSS выносится отдельно, без изменения эталонного `design-system.css`.
3. Реальное меню строится из существующего `App\\Presentation\\Navigation\\MenuResolver` / `MainMenu`, без копирования пунктов в шаблон.
4. Header пока Blade partial; Vue/Inertia уже подключены в изолированный `/ui-preview` и Vue-попап работает с существующей Blade-оболочкой. Общий Vue layout ещё не принят.
5. Гостевая кнопка открывает Vue AuthDialog; GET `/login` и `/register` автоматически открывают нужный режим. Успешная авторизация и внешние провайдеры пока не проверены.
6. Новый локальный реестр — подробная декомпозиция внутри #139, а не новые глобальные номера `docs/tasks.md`.
