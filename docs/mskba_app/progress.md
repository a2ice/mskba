## Ключевые решения

1. Тема `mskba_app` самостоятельная, не наследует неперенесённые Blade-страницы из `mskba_dark`.
2. Дизайн-гайдлайн 1.0 — единый источник визуальных решений; новый CSS выносится отдельно, без изменения эталонного `design-system.css`.
3. Реальное меню строится из существующего `App\\Presentation\\Navigation\\MenuResolver` / `MainMenu`, без копирования пунктов в шаблон.
4. Header пока Blade partial, поскольку Vue/Inertia ещё не подключены; при появлении общего Vue layout решение о переносе принять отдельно.
5. Гостевая кнопка ведёт на имеющийся GET `/login`; модалка авторизации нового дизайна пока не реализована.
6. Новый локальный реестр — подробная декомпозиция внутри #139, а не новые глобальные номера `docs/tasks.md`.

## Ограничения и риски

- История локальной ветки `feature/139` значительно отличается от удалённой, поэтому операции синхронизации требуют предварительной проверки.
- `/events`, `/venues` и прочие ссылки могут показывать fallback, пока соответствующие экраны не перенесены.
- Эмуляция разрешений на скриншотах не заменяет проверку реального Telegram WebView или всего набора браузеров.
- Полного визуального контроля после последней CSS-правки пока нет.
