## Порядок работы

- Ближайший этап — визуальная приёмка юридических модалок [016](tasks/016/description.md) и отсутствия автофокуса [017](tasks/017/description.md) на localhost. Компактные мобильные токены [018](tasks/018/description.md) запланированы отдельно для согласования. Задача 015 уже принята. Этапы [012](tasks/012/description.md), [013](tasks/013/description.md) и [014](tasks/014/description.md) уже интегрированы локально. Доработку режима «Моим связям» и отдельных ролевых приглашений планировать следующей самостоятельной задачей. Остаются функциональный техдолг Wizard [010](tasks/010/description.md), review модалок [011](tasks/011/description.md) и header [002](tasks/002/description.md).
- Перед **каждым новым самостоятельным поручением**, даже небольшой правкой CSS/текста, добавить следующий свободный номер и `tasks/NNN/description.md`. Уточнения, тесты и исправления по приёмке существующей задачи остаются внутри неё.
- **Перед разработкой UI:** сверить каждый элемент с [принятым гайдлайном](../specification/ui-design-system.md), каталогом и уже реализованными общими компонентами; существующие использовать **строго по контракту**. Новый элемент, предназначенный для повторного использования, сначала согласовать с пользователем, затем добавить в гайдлайн/каталог и общую библиотеку, только после — в экран. См. [009](tasks/009/description.md) и [CaseRule15](../specification/agent-rules.md#caserule15---сверять-ui-с-гайдлайном-до-реализации-mskba-app).
- До отдельного явного распоряжения пользователя выполняем только локальные правки и согласованные локальные коммиты; GitHub push, PR, merge и deploy по этой работе не выполнять.
- Техническая зависимость 003 → 004 → 005/006; границы и порядок следующих задач уточняются перед реализацией.
- Новые этапы (аккаунт, игры, турниры, Telegram и другие экраны) добавлять по мере декомпозиции #139, не выдавая неописанное за выполненное.
- Статус задачи меняется после обновления `description.md` и `progress.md`. Для «Принято» нужна явная визуальная приёмка по [протоколу](../tasks/139/visual-review.md); коммит/merge фиксируются отдельно.
