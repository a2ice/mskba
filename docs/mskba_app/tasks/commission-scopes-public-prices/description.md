# Иерархия комиссий и отображение итоговой стоимости аренды

## Задача

В Filament «Контент → Комиссии» должна быть единая общая ставка MSKBA и таблица ставок по сущностям/действиям. Для отдельных сущностей ставка по умолчанию наследуется от общей; собственная ставка задаётся явным переключателем. **NULL — наследовать**, явная ставка **0% — нулевая комиссия**. Существующую комиссию «Площадки / Аренда» необходимо перенести в общую ставку без потери данных при миграции.

## UI и поведение

- Использовать стандартный Filament Table вместо Tailwind-классов, не попавших в сборку. Показать сущность, действие, настройку/наследование, эффективную ставку и версию.
- Изменять глобальную ставку в шапке страницы. Изменять ставку по действию через действие в строке и переключатель «Использовать собственную ставку».
- Разделы без подключенного денежного расчёта показывать как подготовленные, **не начислять** комиссию в ещё не существующих платёжных потоках.
- При публичном просмотре расписания площадки использовать комиссии, тарифные условия и наследование: общая → действие «Аренда» → площадка → зал.
- Показать цену *одного* интервала с комиссией. При выборе непрерывного диапазона запросить у сервера **итог за весь заказ**: одноразовая фиксированная комиссия начисляется один раз, скидки по длительности рассчитываются на весь диапазон. До подтверждения суммы не активировать бронирование.
- Источник FindSport хранит неизменённую цену поставщика; надбавка добавляется только в ответе сайта/бронирования.
- Стандартные контролы и стили действующей темы, без отдельного дизайна или новых нативных селектов.

## Проверка

- Общая ставка 10%, площадка и зал наследуют: для базовых 3250 ₽ ожидается 3575 ₽.
- Явное 0% для аренды отключает только комиссию MSKBA, наследование восстанавливает общую.
- Фиксированная комиссия при выборе двух получасовых слотов начисляется один раз на диапазон.
- Снимки старых коммерческих предложений не изменяются после изменения комиссии.
- Пилот FindSport не включает бронирование автоматически.
