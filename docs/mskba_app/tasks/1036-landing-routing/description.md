# #1036 — Маршрутизация SEO-посадочных каталога

DEV ONLY. #1069 merged 6f8329c, CI и checkpoints green; фактический dev deploy/Filament smoke не подтверждены.

- Выделен namespace /venues/collections/{slug}, например /venues/collections/rent/moscow. Причина: /venues/{alias}, /venues/{alias}/preview, /venues/{alias}/nearby-map и /venues/{venue}/courts/{court} уже заняты. Первые сегменты slug courts/preview/nearby-map зарезервированы; проверка при сохранении и разрешении. Page Builder поддерживает только одноуровневые URL. Старые ссылки не заменяются.
- Feature gate FEATURE_VENUE_CATALOG_LANDINGS по умолчанию false везде. Не включаем его при текущем релизе и не меняем окружение. Это внутренняя интеграция, не публикация. При включении только в тестах: активный ЧПУ предустанавливает критерии, явные GET-параметры переопределяют, затем существующая validation; точно совпавший обычный запрос → 302 на ЧПУ, дополнительные условия → обычный каталог либо другая активная конфигурация. Неизвестные параметры не совпадают; query не теряется при возврате к каталогу. Tracking allowlist сохраняется при перенаправлении, внешней отправки нет.
- Единый VenueController::index/ListVenuesHandler, гостевая видимость на посадочной, обычная выдача без совпадения неизменна. JSON fragment не перенаправляется, сохраняет контракт. Карта и пагинация используют те же фильтры. Никаких изменений booking/auth/DB.
- Переиспользован существующий H1 и PageSeoResolver для title/description/canonical; в обеих темах без новой композиции. Все посадочные принудительно noindex на данном этапе независимо от флагов Filament. Sitemap и robots не меняются. Полноценные HTML-блоки/FAQ/перелинковка и UI Studio — следующий этап, не включать feature gate до визуальной приёмки.
- UI Studio: Desktop Commander 25.11 вернул месячный лимит, доступ к checkout/preview не подтверждён. Не считаем CI визуальной приёмкой. После восстановления доступа подготовить изолированный specimen, проверить темы/ширины, принять ревизию, только затем включить на dev. Проверить также мобильный контекст/счётчик, legacy map/sort, JSON/pagination и безопасный HTML.
- Тесты: feature gate, черновик, точный match, SEO head, гостевые результаты/скрытая площадка, дополнительные условия, canonical/page 2, map/fragment, обе темы и совпадения маршрутов. CI и фактический deploy отдельно.

**Актуализация 26.11.2026:** по прямому указанию владельца общий флаг включён по умолчанию во всех средах после развёртывания конструктора. Явный false сохраняется как аварийное отключение. Визуальная приёмка теперь на активной странице dev; раннее ограничение gate off отменено. DEV ONLY для текущего merge; noindex и ограничения внешнего продвижения сохраняются.
