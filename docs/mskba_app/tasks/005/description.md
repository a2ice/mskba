**Статус:** Запланировано · **Зависит от:** 003–004.

- Вывести реальные мероприятия, площадки и контент через существующие серверные сервисы.
- Добавить осмысленные переходы, обработать пустые/ошибочные состояния.
- Сохранить локальный UI-гайдлайн и не копировать демонстрационные цифры/события из каталога.

## Критерии приёмки

Desktop/mobile реализация на реальных данных, согласованные сценарии и visual review, корректные ссылки и отсутствие регрессий.
