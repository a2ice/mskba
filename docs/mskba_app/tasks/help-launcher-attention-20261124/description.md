# MSKBA App — первое появление кнопки «Помощь ?» (24.11.2026)

## Принятое поведение
Общая кнопка контекстного FAQ в правом нижнем углу, выше мобильной навигации, не меняет положения или размера круга (desktop 50px, mobile 46px).

1. После события полной загрузки страницы выдерживается **2 секунды**.
2. Появляется исходный круглый значок `?` (короткая анимация входа).
3. Круг плавно расширяется **влево**, оставаясь закреплённым по правому краю. В ходе расширения надпись «Помощь» раскрывается **справа налево**. Раскрытое состояние: **«Помощь ?»**.
4. Расширенная кнопка остаётся примерно **0,5 секунды**.
5. Кнопка плавно сворачивается в исходный круглый `?` и остаётся в нём до конца просмотра страницы.

Весь цикл воспроизводится **один раз за полную загрузку страницы**. Клик открывает прежнее контекстное FAQ, без смены логики или URL. CSS-анимация `app-help-intro` длится 2,5 секунды, первое раскрытие начинается после короткого показа круга. Ширина pill рассчитывается JS по реальной ширине надписи при текущих шрифтах/размере экрана, без жёстко заданных пикселей.

## Доступность и надёжность
- Для пользователей с `prefers-reduced-motion: reduce` показывается обычный круг сразу, без скрытия и анимации.
- Клавиатурный фокус или клик прерывает анимацию, оставляя рабочий круг.
- Если JS недоступен, базовая кнопка видна сразу.
- Системные toast-уведомления остаются сверху; расположение плавающей кнопки не меняется.
- Новые стили относятся только к `mskba_app`; оформление light/dark не влияет на механику.

## Приёмка
1. Открыть https://mskba.ru/ и обновить страницу: сначала кнопка невидима, через ~2 секунды круг, затем «Помощь ?», пауза полсекунды, сворачивание.
2. Нажать на кнопку: прежнее окно FAQ с тремя вкладками открывается без изменений.
3. Проверить мобильную ширину: правый край не меняет позицию, плашка растёт влево над нижней навигацией.
4. Проверить светлую и тёмную темы; ни цвет, ни существующее поведение FAQ не меняются.
5. Включить уменьшение анимации на устройстве: круг должен отображаться сразу, без движения.
