# Задача №304 — комиссии MSKBA и коммерческих агентов

## Принцип
Комиссия не является частью базовой цены зала и не является тарифной скидкой. Итоговая цена для арендатора:

`venue_base_after_rules + mskba_fee + selected_agent_fee`

Обе комиссии вычисляются **от одинаковой базы** — стоимости после правил №303, без сложного процента. Цена площадки остаётся базой, надбавки отображаются отдельно. Без оплаты через MSKBA ни одна рассчитанная комиссия не считается выплаченной или полученной.

## Иерархия
- Глобальная комиссия MSKBA: модель `PortalCommissionPolicy`, superadmin. Отсутствие записи = 0.
- Площадка: `VenueCommissionPolicy`: наследовать глобальную (NULL), явно 0 (`none`), процент (`percent`), фиксированная сумма (`fixed`).
- Зал: `VenueCourtCommissionPolicy` с теми же вариантами наследования от площадки, затем от глобальной.
- Значения — basis points (1% = 100) либо integer minor units (копейки для RUB). Десятичный процент до 2 знаков, округление до копейки half-up. Фиксированная сумма хранит валюту; при несовпадении валют расчёт не допускается.
- Все новые правила по умолчанию = 0. **На staging не включаем тестовые ставки на реальные площадки автоматически.**

## Агент
- Агент — отдельное экономическое назначение `VenueCommissionAgent` (ссылка на активного подтверждённого пользователя), с собственной версией, ставкой и признаком активности. Экономическое назначение **не выдаёт права доступа в Filament или ЛК** и не создаётся автоматически для сотрудников.
- Площадка может иметь N агентов, но `VenueCommissionPolicy.selected_agent_id` указывает максимум на одного, чья ставка участвует в quote. Если не выбран никто, агентская комиссия 0. При деактивации выбранного агента назначение снимается. Если пользователь заблокирован, ставка не включается.
- В дальнейшем экономическое назначение связывается с агентским соглашением и платёжным контуром. Пока это конфигурация цены, не поручение на выплату или безусловное долговое обязательство.

## Где редактировать
В Filament → Площадки → редактирование:
- **Комиссии и агенты**: глобальная ставка, переопределение площадки, создание/изменение агентских ставок, выбор единственного активного комиссионного агента.
- **Переопределения комиссии по залам**: индивидуальное значение или наследование.
- До появления подтверждённой договорной схемы и отдельного permission операции доступны только подтверждённому супер-админу, фиксируются Auditable.
- Остальные права в ЛК площадки не меняются; в будущем управление комиссиями — отдельное делегируемое право, а не автоматический эффект прав сотрудника.

## Цена и отображения
- `VenueCommissionCalculator` вызывается **после** `VenueSlotPricing` и `VenuePricingRuleEvaluator`.
- Новый `VenueBookingQuote` содержит итоговую сумму, а snapshot версии 4 включает базу, стоимость после правил, комиссии MSKBA/агента, источники global/venue/court, ID/версии ставок и выбранного агента.
- Старые quote не меняются. Все будущие суммы заявок/оплат должны брать итог quote, а не заново прибавлять комиссии.
- Расшифровка есть в калькуляторе аренды MSKBA App, старой теме, JSON quote и предварительных просмотрах тарифов в Filament/ЛК. Во внешнем API не выдаём персональные данные агента, только суммы.
- Скидка уже относится к источнику `venue`; новые комиссии добавляются поверх суммы после скидки. Реальные settlement/net allocations появятся после утверждения расчётного контура.

## Числовые кейсы для приёмки (только тестовые значения)
1. Аренда 2 000 ₽, глобальная ставка MSKBA 10%, выбранный агент 5% → комиссия портала 200 ₽, агента 100 ₽, клиенту **2 300 ₽**.
2. Переопределение портала для площадки 8% → **2 260 ₽**; для зала 3% → **2 160 ₽**; явное 0 у зала → **2 100 ₽**. Ничего не дублируется.
3. Скидка 30% при двух часах: база 2 000 → после скидки 1 400 → MSKBA 10%=140, агент 5%=70 → **1 610 ₽**.
4. Из двух агентов 5% и 7% рассчитывается только назначенный; смена выбора не изменяет предыдущие quotes.
5. Фиксированная ставка 50 ₽ + 10 ₽ даёт **2 060 ₽**. Округление 105 коп. при 2,5% и 1,5% → 3 и 2 коп. комиссии.
6. Нулевые значения/наследование/деактивация агента/иностранный agent_id/попытка установить 101%/нет прав — проверяются тестами.
7. Проверка одинаковых значений в JSON quote, HTML расчёте и Filament «Проверить стоимость».
