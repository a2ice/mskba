# #1036 — Индексируемая пагинация каталога площадок

Связано с #1034, #1035 и #1036. Предыдущий PR #1042 merged в main (be7f7abcdf35f520949751381fab9396f1652b21); фактический production deploy и географические ID ещё не подтверждены. Этот PR готовится независимо, но выпускать последовательно после smoke предыдущего.

## UX и контракт
- Существующие порции по четыре карточки, IntersectionObserver, loader/retry и карта сохраняются.
- Под выдачей серверные ссылки «Предыдущая страница»/«Следующая страница» в имеющемся app-category__pagination и button secondary. Никаких новых CSS/компонентов. Работают без JS, при ошибке загрузки и в браузерах без IntersectionObserver. После автоматической подгрузки следующая ссылка обновляется, после последней порции удаляется.
- Параметры валидированных фильтров и сортировки сохраняются, page=1 опускается, fragment исключается. Карта без навигации порций. Dark theme уже рендерит полную выдачу; не меняем её поведение.
- Чистые URL /venues?page=N имеют собственный canonical и уникальный title для N>1. Для главной сохраняется существующий SEO title/canonical. Политика индексации фасетов, пустых и out-of-range URL — отдельный аудит, здесь не меняется.
- Без изменения запроса каталога, прав, booking, цен, маршрутов и БД.
