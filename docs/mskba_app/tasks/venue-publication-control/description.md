# Управление публикацией площадки

Дата: 15.11.2026. Пример для проверки: Площадка. Метро Академическая (ID 15).

## Три независимых состояния

- Модерация: подтверждён / не подтверждён / заблокирован.
- Состояние работы: работает / временно закрыта. Закрытие не удаляет площадку из каталога.
- Публикация: is_published = true/false, переключатель «Показывать на сайте» в Filament. Публична только подтверждённая И опубликованная площадка.

Миграция добавляет default(true), сохраняя прежнее поведение всех существующих записей. Площадку ID 15 скрывают вручную в Filament; не меняем конкретную запись автоматически.

## Filament и журнал

- В форме «Основное»: переключатель и tooltip; текст «Комментарий к статусу и публикации» с пояснением назначения (внутренний, не для публикации).
- В таблице статус публикации и фильтр «Опубликованные / Скрытые».
- Право редактирования — BACKOFFICE_ACCESS и BACKOFFICE_VENUE_MANAGE, проверка на уровне VenueBackofficeEditor и VenueResource; неподписанные запросы не изменяют значения.
- Существующий аудит Venue ведёт actor_id, timestamp, маршрут, old_values/new_values, включая is_published, status, status_info. Комментарий сохраняется при переходах статусов, если его явно не изменили. Внутренний текст не показывается на публичной странице.
- Изменение флага не сбрасывает подтверждение и не удаляет залы/контракты/историю.

## Публичность

- Исключаем скрытые из каталога/карты/поиска, API, nearby, sitemap, выбора площадок мероприятий, публичных профилей, карты главной и внешних источников.
- По прямому URL анонимный посетитель получает 404; superadmin/уполномоченный менеджер может просмотреть напрямую, но не видит скрытую площадку в общем каталоге.
- Существующий VenueSearchCacheObserver сбрасывает версию кеша после изменения модели, включая поиск confirmed_only.
- Гостевые страницы аренды и публичные данные доступности скрытых площадок закрыты, внутреннее управление остаётся.
- Возврат публикации выполняется без повторного одобрения модерации.
