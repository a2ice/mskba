# #1157 — Компоновка публичной страницы площадки и игровой зоны

[Issue #1157](https://github.com/a2ice/mskba/issues/1157). 27.11.2026. Только `dev`.

## Контракт

- Общая страница и подстраница зоны: «О площадке / О зале / О корте» раньше расписания, тот же порядок anchor-навигации. Сохранить игры, интересы, акции, удобства, режим работы и refresh-статусы.
- В общей странице — список зон (ссылка, тип, эффективное операционное состояние), в расписании вместо «Подробнее» — ссылка в названии зоны. Статус не зависит от времени суток, учитывает операционный статус площадки и зоны.
- На странице зоны H1 — ссылка на общую страницу, название зоны с заглавной буквы перед кратким описанием. Собственное описание имеет приоритет; если описания нет, выводится только название.
- Плашки по содержимому, flex-wrap, gap 10px, центрирование, существующая SVG-библиотека (`#ball`, `#sliders`, `#check`, `#currency-ruble`, `#calendar` и др.). Полезные характеристики, доступ и цены; неизвестные не показывать. Разметка и состояния колец/покрытия хранятся на уровне площадки, использовать на подстранице только при единственной зоне. Размеры берутся с зоны. Не менять модель хранения и бронирования.
- В «Площадки рядом» — общий поток адреса и дистанции, символ ⇿, отдельный доступный тултип и общая карта; см. [#1092](../1092-inline-nearby-distance/description.md).
- Применяем существующие локальные panel, typography, tokens, badge и SVG-примитивы [гайдлайна](../../../specification/ui-design-system.md). Изменение существующей компоновки MSKBA App, без нового общего UI Kit-примитива. Legacy-страница не меняется.

## Проверки

- Общая страница с одной/несколькими зонами, indoor/outdoor, активная/закрытая площадка/зона. Переходы по именам и H1, порядок секций и якорей.
- Собственное/унаследованное описание, название с кириллической строчной буквы, неполные данные; сохранение цен и удобств.
- Информационные часы без кнопок бронирования; активное бронирование, refresh-индикатор и ошибки.
- Длинный адрес на desktop/tablet/mobile, клавиатура и тултип, две точки карты. Светлая и тёмная палитры.
- Обновлены существующие тесты на границы секции расписания. Локальная сборка/визуальная приёмка не подтверждены из GitHub-коннектора; обязательны зелёный полный CI и проверка на dev. Не заявлять о production-деплое.
