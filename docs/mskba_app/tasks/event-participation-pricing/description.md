# Стоимость участия в мероприятии

- В общем визарде создания события и на странице редактирования после лимита участников: чекбокс «Платное мероприятие», общая стоимость и стоимость участия в рублях, редактируемый комментарий. При выключенном чекбоксе поля скрыты.
- По умолчанию сумма участия = общая сумма / лимит участников (если лимита нет — 10); округление до копеек. Ручная цена сохраняется при изменении лимита; кнопка «Рассчитать автоматически» возвращает авторасчёт.
- Персональный комментарий по умолчанию сохраняется только по явному чекбоксу. Уже созданные мероприятия сохраняют свой комментарий. Старые события по умолчанию бесплатные.
- На странице события отдельная строка под датой, одинаковая типографика: «Стоимость участия: … руб.» и доступное по клику/клавиатуре пояснение со знаком вопроса. Общая стоимость не публикуется. Публичная цена не меняет стоимость аренды.
- Счета, перечисления, возвраты и расчёт окончательной суммы по фактическим участникам — отдельная следующая задача; текущий комментарий только объясняет условия организатора.
- Приёмка: автоматическая сумма с лимитом и без, ручная сумма, изменение лимита, бесплатное мероприятие, персональные шаблоны двух аккаунтов, отображение и мобильный тултип.

## Комментарий к предварительному времени

Независимое поле `time_comment` в событии, собственный шаблон `default_event_time_comment` пользователя, возможность изменить и сохранить его по умолчанию. В визарде поле находится на шаге времени, доступно и при создании черновика без даты. Пояснение показывается рядом с установленной датой вместо отдельной строки, использует общий с ценой компонент, открывается по нажатию и закрывается повторным нажатием, кликом вне или Escape. У существующих событий без комментария используется системный текст. Дата и время имеют собственный статус «Дата и время предварительные» / «Дата и время подтверждены» (по умолчанию предварительные), управляемый организатором. Пустой комментарий не подменяется шаблоном и скрывает тултип; пустой персональный шаблон также допустим. При подготовке аренды из мероприятия чекбокс «Обновить и подтвердить дату и время мероприятия при подтверждении аренды» по умолчанию включён; его можно снять. Отправка заявки не меняет мероприятие. После подтверждения аренды с этим чекбоксом дата и время обновляются и подтверждаются только при сохранении исходной ревизии мероприятия; без чекбокса они не изменяются. Организатор может отдельно изменить дату, время и их статус, не меняя аренду. Отдельные новые статусы мероприятия и площадки не вводятся. UI-паттерн: [Tooltip и общие компоненты](../../../specification/ui-design-system.md).

## Что входит в оплату (GitHub #976)

В общем компоненте стоимости создания и редактирования отмеченные по умолчанию «Аренда зала» и «Организация», дополнительные «Инвентарь», «Вода», «Свой вариант» с названием. У каждой позиции необязательные цена (десятичная строка в рублях, включая ноль) и комментарий до 250 символов. JSON-поле Event скрыто при стандартной сериализации; публичный Blade-компонент явно выводит только названия и комментарии. Отсутствующий ввод при обновлении не изменяет состав; явный пустой выбор сохраняется. Старые мероприятия без данных не получают публичный состав задним числом. Указанные цены не влияют на общую стоимость, цену участия и аренду. UI: существующие field-group/form-control и check-label (см. UI Design System).
