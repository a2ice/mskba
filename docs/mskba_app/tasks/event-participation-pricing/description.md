# Стоимость участия в мероприятии

- В общем визарде создания события и на странице редактирования после лимита участников: чекбокс «Платное мероприятие», общая стоимость и стоимость участия в рублях, редактируемый комментарий. При выключенном чекбоксе поля скрыты.
- По умолчанию сумма участия = общая сумма / лимит участников (если лимита нет — 10); округление до копеек. Ручная цена сохраняется при изменении лимита; кнопка «Рассчитать автоматически» возвращает авторасчёт.
- Персональный комментарий по умолчанию сохраняется только по явному чекбоксу. Уже созданные мероприятия сохраняют свой комментарий. Старые события по умолчанию бесплатные.
- На странице события отдельная строка под датой, одинаковая типографика: «Стоимость участия: … руб.» и доступное по клику/клавиатуре пояснение со знаком вопроса. Общая стоимость не публикуется. Публичная цена не меняет стоимость аренды.
- Счета, перечисления, возвраты и расчёт окончательной суммы по фактическим участникам — отдельная следующая задача; текущий комментарий только объясняет условия организатора.
- Приёмка: автоматическая сумма с лимитом и без, ручная сумма, изменение лимита, бесплатное мероприятие, персональные шаблоны двух аккаунтов, отображение и мобильный тултип.
