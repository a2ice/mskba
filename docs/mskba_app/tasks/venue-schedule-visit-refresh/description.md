# Обновление расписания при посещении площадки

- Сохранён текущий дизайн расписания и плашки дней, существующая сетка и семантика времени/занятости. Добавлен компактный текстовый статус с role=status, без новой модали, отдельного интерфейса или изменённых цветов.
- При ожидании отображаются последние сохранённые данные и «Обновляем расписание…»; после результата заменяется только существующий server-rendered блок расписания. В случае ошибки остаются сохранённые данные с предупреждением.
- App: открытый попап бронирования не заменяется; карточки заново подключаются к существующему обработчику и синхронизируют календарь. Legacy: сохраняется узел открытого попапа и его обработчики; карточки открывают тот же попап.
- Reverb публикует только идентификатор площадки; резервный ограниченный опрос запрашивает локальный статус, не FindSport. Не меняем checkout, исходные правила валидации и семантику свободных слотов.
- DEV first. Ручная приёмка desktop/mobile и обеих тем с разрешённым источником, отключением Reverb, двумя вкладками и ошибкой провайдера ещё необходима. Desktop Commander недоступен из-за месячного лимита; CI не выдаётся за визуальную приёмку.

Инструкция активации и проверки: [задача 308](../../../tasks/308/visit-refresh-dev.md).
