# Task 342 — Географический фильтр каталога площадок

Продуктовый контракт: [Task 342](../../../tasks/342/description.md).

## UI Kit trace

- Фильтр расположен сразу после поиска и до остальных условий; общая GET-форма, существующий range-паттерн профиля игрока, стандартные кнопки.
- При явном выборе — общая геолокация, при отказе — native top-layer Modal 1.1 с predictive address и картой. Шапка без eyebrow, общий drag controller и 44px крестик; pointerdown/pointerup на backdrop. Подтверждение только после валидной точки. При отмене сохраняется исходное состояние.
- Радиус 1–10 км, начальный 3 км, согласно существующей логике nearby. Выбор не изменяет профиль. Карточки, список, карта и пагинация используют одну серверную выборку.
- Проверки: PHP regression, Vite build, desktop/mobile и обе темы; визуальная приёмка пока не выполнена.
