# Вознаграждения и подписи бонусов в интерфейсе

## Задача

Системные вознаграждения должны редактироваться внутри Filament, а не только в отдельном legacy-разделе. Список «Кешбэк: исключения» содержит только локальные переопределения: отсутствие записи у площадки означает наследование глобального правила.

## Контракт интерфейса

- Filament → Контент → Вознаграждения: механизм, статус, положительная сумма в бонусных рублях, условия, получатель, триггер, JSON-параметры и поле «Шаблон подписи». Действующее финансовое версионирование — через `RewardCatalogManager`, без обходных прямых записей в `reward_versions`.
- Filament → Контент → Акции: название, описание, CTA и переопределения по месту показа. Допускаются переменные `{amount}`, `{amount_number}`, `{currency}`, подставляются только из серверного resolver после применения переопределения конкретной площадки.
- Поле `Reward.amount_caption_template` — только подпись на публичных экранах, не часть финансовой версии, не изменяет права на начисление. Если шаблон не задан, используем «Кешбэк: {amount}» для аренды или «Бонус: {amount}» для остальных.
- Страница площадки и попап дневного расписания используют `amount_caption` resolver вместо жёстко написанной строки «Бонус за выполненное условие: N ₽». Шаблон может быть отдельным от текста акции.
- Промоплашка ниже галереи отделяется штатным вертикальным расстоянием 20 px; не трогать геометрию галереи, sticky-навигацию и мобильную сетку.
- Выплата реальными деньгами остаётся недоступной и выключенной. Раздел управления доступен только подтверждённому superadmin.

## Приёмка

1. В Filament видны «Вознаграждения», «Акции» и «Кешбэк: исключения» с пояснением пустого списка.
2. Смена шаблона подписи не увеличивает `reward_versions`. Смена суммы увеличивает и не переписывает предыдущие начисления.
3. При базе 100 ₽ и переопределении 200 ₽ в описании с `{amount}` и в подписи отображаются разные корректные суммы соответственно; при нуле/выключении предложение скрывается.
4. На странице площадки плашка не прилегает к галерее. В попапе слотов нет зашитого текста и дублирования суммы.
5. PHP/БД/JS тесты, CSS build, CI и dev-деплой. Production не трогать.
