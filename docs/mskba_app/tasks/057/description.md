# 057 — Спортивные аксессуары: групповые чекбоксы и стороны

## Цель и критерии приёмки
Налокотник, напульсник, наколенник — каждый один общий чекбокс; при выборе открывать модальное окно «Слева/Справа» и кнопку «Применить». Отмеченное отображать как (л), (п) или (л/п); возможность полного снятия и правильная синхронизация со старым character.attributes (`*_left/right`). Повязка на голову остаётся самостоятельной.

## Технические границы
Сохранить историю и API без дополнительных таблиц; диалоги по UI Kit и доступность клавиатуры.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
Зарегистрирована, ожидает приёмки предшествующих задач.
