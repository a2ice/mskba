# 057 — Спортивные аксессуары: групповые чекбоксы и стороны

## Цель и критерии приёмки
Налокотник, напульсник, наколенник — каждый один общий чекбокс; при выборе открывать модальное окно «Слева/Справа» и кнопку «Применить». Отмеченное отображать как (л), (п) или (л/п); возможность полного снятия и правильная синхронизация со старым character.attributes (`*_left/right`). Повязка на голову остаётся самостоятельной.

## Технические границы
Сохранить историю и API без дополнительных таблиц; диалоги по UI Kit и доступность клавиатуры.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
PR #508 прошёл CI и опубликован на `dev`; замечания визуальной приёмки по чекбоксам/попапу исправляются отдельным PR.

## Реализация 29.10.2026

- Вместо отдельных чекбоксов слева и справа для налокотника, напульсника и наколенника — по **одному общему чекбоксу**. При выборе нового аксессуара открывается native top-layer `<dialog>` по UI Kit с чекбоксами «Слева» / «Справа», кнопками «Отмена» и «Применить», закрытием через крестик или Escape. Настройки сохраняются только по «Применить» в попапе.
- Текущий выбор отображается после имени: `(л)`, `(п)`, `(л/п)`. Для уже выбранного типа доступна кнопка «Изменить», которая открывает тот же диалог с сохранёнными сторонами; отмена не меняет данные.
- Снятие единого чекбокса сразу убирает **обе** стороны. Повязка на голову остаётся обычным отдельным чекбоксом. Финальная кнопка «Применить» физической формы отправляет состояние как раньше.
- Backend, API, права и БД **не меняются**: hidden-поля формируют старые значения `character[attributes][]` (`elbow_left/right`, `wristband_left/right`, `knee_left/right`, `headband`). При повторном открытии UI разворачивает сохранённые значения; пустой массив снимает все аксессуары.
- Приёмка: каждый тип выбрать только слева/справа/на обеих сторонах, отменить попап, изменить ранее выбранное, полностью снять, сохранить и перезагрузить страницу, убедиться в сохранении. Проверить клавиатуру и мобильное окно.

## Правки по визуальной приёмке 29.10.2026

- Чекбоксы аксессуаров в форме и сторон в диалоге привести к **общему `.check-label` из `design-system.css`**: нативные контролы 20×20, accent через `var(--accent)`, min-height 44px, единое выравнивание по центру и 14px текст. Не использовать локальный коричневый accent и уменьшенные чекбоксы 17px.
- В диалоге убрать нижнюю «Отмена»; сохранение — только кнопкой «Применить», закрытие без сохранения — крестик в заголовке либо Esc.
- Ссылку «Изменить» по горизонтали оставить после названия/суффикса, а по вертикали центрировать в одной строке с чекбоксом: центрированный inline-flex с min-height 44px и line-height 20px.
- Сценарии выбора сторон, отмены и сохранения `character.attributes[]` сохранить без backend-правок.
