# MSKBA App 064 — генерация аватара и пользовательские логотипы

Дата: 30.10.2026. Основание: приёмка /account/participation/player.

## UX и контракт
- Три компактные карточки генерации. Иконка «?» у цены открывает диалог порядка списания, у бонусного баланса — существующий диалог пополнения. Дублирующее описание списания со страницы удалено.
- Фотографии лица — три кликабельных голубых кружка (анфас, слева, справа); по выбору видны имя файла и отметка. Требование анфас + один профиль остаётся серверным.
- Ниже фотографий: форма команды, кроссовки, логотип и спортивные аксессуары. Поля аксессуаров и кроссовок остаются связанными с формой физического профиля через атрибут form.
- Форма по умолчанию — первая команда пользователя, без команд — нейтральная. «Создать свою форму» открывает сообщение «в разработке» и восстанавливает исходный выбор.
- Логотип: без/с логотипом, затем логотип команды/свой. Собственный логотип выбирается из приватной галереи, загрузка по клику и drag-and-drop, удаление. Максимум три на пользователя, итоговые WebP до 500 px. Для генерации передаётся через уже поддерживаемую ссылку на последнее reference-изображение (не face reference).
- Сохранить действующие цены, списания, валидацию лиц и проверку членства команды.

## Приёмка
1. «Доступно генераций» не ломается на две строки в обычном десктопном макете.
2. Оба tooltip доступны по наведению и фокусу, по клику открывают правильные popup.
3. Перенесённые поля кроссовок и аксессуаров реально отправляются при сохранении и генерации.
4. Чужие логотипы нельзя получить, удалить или использовать. Четвёртая загрузка — 422.
5. WebP <=500px, приватный storage, собственный логотип доступен генератору через авторизованный signed reference и сохраняется в snapshot.
6. При отсутствии команд — нейтральная форма; выбор будущего конструктора возвращает безопасное значение.
7. CI+PostgreSQL → merge dev → подтверждённый SSH-deploy. Main/prod не изменять.

## Приёмка мобильного превью — 30.10.2026
- Сохранённое фото любого разрешения/ориентации вписывается через `object-fit: cover` в фиксированный круг `62–94px` без влияния на ширину/высоту карточки или соседних ракурсов.
- Размеры изображения отвязаны от intrinsic dimensions: абсолютное позиционирование внутри размерно ограниченного круга, круговая маска, корректное поведение iOS Safari.
- Проверять анфас, левый и правый профили на мобильной ширине, включая переключение заглушки на приватное фото. Ошибки загрузки отображаются непосредственно под соответствующим ракурсом.

## Дополнение к приёмке — выбор логотипа, 31.10.2026

На мобильном `/account/participation/player` упрощено управление логотипом на форме по существующему UI Kit (см. `docs/specification/ui-design-system.md`, «Обязательный цикл обновления UI Kit», checkbox `.check-label` и унифицированный dialog `.mskba-modal`):

- Единственный **нативный чекбокс «С логотипом»**, 20×20 px, touch target минимум 44 px. Дублирующие радиогруппы «без/с логотипом» и «логотип команды/свой» удалены **из UI**, backend-режим `team` остаётся совместим с прежними запросами, но новый UI использует `none/custom`.
- Пока чекбокс снят, строка выбора скрыта, генерация отправляет `generation_logo_mode=none`. При включении показывается **фиксированное превью 35×35 px**: собственный выбранный логотип из приватной галереи либо штатная `team-placeholder.webp`. `img` занимает `100% × 100%` контейнера с `object-fit: cover`, не растягивая строку из-за intrinsic dimensions.
- Рядом с превью всегда доступна кнопка **«Выбрать логотип»** (только при включённой галочке). Она открывает существующую приватную галерею «Мои логотипы», сохраняет загрузку/удаление и лимит 3; выбор сразу обновляет превью. При наличии сохранённого `generation_custom_logo_id` он восстанавливается после загрузки персонального списка; при удалении — возвращается заглушка.
- **Без выбранного логотипа** генерация в режиме `custom` останавливается до платного API-запроса с понятным сообщением. Выключение чекбокса не стирает выбранный файл: при повторном включении он восстанавливается.
- Попап «Мои логотипы» использует `mskba-modal`, общий `mskba-modal__header`, `app-profile__dialog-close` с крестиком **×**, `aria-label="Закрыть"`, Escape и восстановление фокуса на кнопке выбора. Общий drag controller работает без отдельных CSS-override. Body — `mskba-modal__body mskba-scroll`; не изменяется серверный API.
- Добавлены PHP-контрактные проверки разметки/стилей и Node-тесты безопасных same-origin URL для приватного превью.

Критерии: проверить iPhone 390/360 px и desktop; пробелы, переносы, tap targets, чекбокс, заглушку, выбор/загрузку/удаление, крестик и Escape, восстановление ранее выбранного логотипа. CI → `dev`, production не изменять.
