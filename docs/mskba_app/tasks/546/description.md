# 546 — UI-гайдлайн баннеров и страниц лиг

Дополнение к #541 и #544, согласовано после выкладки на dev.

## Принятое оформление
- Общий ритм 20px для самостоятельных плашек; не складывать margin контейнера и вложенного editor.
- Все горизонтальные строки (иконки, кнопки, фильтры, чипы) — \`align-items:center\`, контроль высоты кнопок минимум 44px.
- Базовые токены дизайн-системы MSKBA: \`--surface\`, \`--surface-raised\`, \`--line\`, \`--control-line\`, \`--text\`, \`--muted\`, \`--accent\`, \`--radius-card\`, \`--radius-control\`.
- В редакторе короткие привычные названия и понятные действия; без технических деталей про хранение исходников и параметры кадрирования.
- У владельца лиги навигация между её баннером и баннерами сезонов — отдельная плашка, кнопки с активным состоянием.
- В современном ЛК баннер пользователя управляется на странице «Профиль» рядом с настройками аватара.
- Предпросмотр восстанавливает применённый кроп при открытии и не прыгает после сохранения.
- Для удаления используется встроенная строка подтверждения с кнопками «Удалить / Отмена» — без системного \`confirm\`.

## Регрессии
- Проверить существующие лого, аватары и галереи: редактор изменяет только \`banner\`.
- Проверить публичные карточки лиг, каталог, страницы сезонов, хлебные крошки.
- Фильтры и кнопка «Найти» не разъезжаются по вертикали.
- Управление из Filament, публичных форм и личного кабинета; отсутствие доступа даёт 403.
- Мобильная ширина 390px: нет горизонтального скролла, управление жестами и slider не сбивает layout.
- CI зелёный, затем dev deployment и пользовательская приёмка. Production не затрагивать.
