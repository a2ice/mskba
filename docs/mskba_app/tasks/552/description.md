# MSKBA — Реестр контрактов и вкладки управления

## Сценарии
- В карточке пользователя отображаются все его контракты.
- В карточках площадки, команды, лиги, сезона, турнира и мероприятия доступна вкладка «Контракты».
- В общем разделе «Контракты» работают фильтры по сущности, пользователю и статусу.
- В редакторе можно указать название, дату окончания, комментарий, основание изменения и допустимые полномочия.
- История изменений сохраняется отдельно.
- В публичной части при назначении контракта можно указать дату окончания и комментарий.

## UI/UX
- Соблюдать вертикальные отступы между плашками и секциями.
- Выравнивать текст, ссылки и статусы внутри строк таблиц по вертикали.
- Использовать знакомые подписи полей без технических кодов.
- Не показывать служебные значения в заголовках и пояснениях.
- Контракты, требующие отдельной процедуры передачи владения, не отзывать обычным редактированием.

## Проверка
- Глобальные права бэк-офиса независимы от публичных контрактов.
- Назначения без конечной даты не ограничиваются временем.
- Делегирование со сроком не дольше срока полномочий назначающего.
- Сохраняется история изменений и основание.
- Проверить тесты, сборку и миграции до слияния.
