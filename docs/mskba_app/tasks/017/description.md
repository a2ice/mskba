# 017 — Отказ от автофокуса в полях авторизации

**Дата:** 2026-10-09 · **Ветка:** feature/139 · **Статус:** Реализовано локально; на визуальной приёмке.

## Запрос
При открытии попапа входа, регистрации, восстановления и при переключении режимов убрать автоматическую постановку фокуса в первое поле. Она вызывает ненужное выпадающее автозаполнение и открывает виртуальную клавиатуру на мобильных.

## Реализация
- [x] Описать задачу до начала изменений.
- [x] Фокус при открытии/переключении направлять на программно фокусируемый заголовок диалога, не на поле; не ломать навигацию по Tab, trap focus нативного showModal и возврат фокуса после закрытия.
- [x] Проверить мобильную и desktop регистрацию; не допустить автоматического открытия подсказок или клавиатуры.
- [x] Регрессия. Документы / статус.

В рамках этой задачи не менять поведение сохранения введённых данных и автозаполнение после явного клика пользователя.

**Git:** локально, без commit/push/PR/merge/deploy до отдельного запроса.

## Результат

- Вместо первого `input` программно фокусируем заголовок h2 (`tabindex=-1`) при showModal и смене режимов login/register/restore.
- Нативный focus trap, перемещение Tab и возврат фокуса при закрытии сохранены; автофокус на поле по **ошибке валидации** остаётся намеренно, это отдельный UX-контракт Wizard.
- Chromium подтвердил стартовый focus === H2 на мобильной регистрации 320/440 и десктопе 768/1440; переключение режимов login/restore/register при ширине 375 также PASS. Всплывающие подсказки автозаполнения не вызываются программным фокусом.
