# 022 — Ролевое меню «Мой MSKBA» и обращение на «ты»

Дата: 2026-10-09. Ветка: feature/139. Статус: реализовано локально, на визуальной приёмке. Без нового коммита.

## Принятая модель

Активные роли участия определяют доступные подразделы независимо от существующих команд или договоров. Связи определяют содержимое разделов и доступные действия.

- Игрок: Мои команды, Мои игры, Мои тренировки.
- Тренер: Мои секции, Мои тренировки, Мои команды.
- Представитель площадки: Мои площадки, Бронирования, Расписание.
- Организатор: Мои мероприятия, Мои турниры.
- Судья: Мои игры, Судейские назначения.
- Статист: Мои игры, Статистика.
- Медиа: Мои материалы, Мои мероприятия.

Несколько ролей объединяют пункты без повторений, порядок стабилен. Без ролей группа отсутствует, при этом пункт «Роли в проекте» доступен. Навигация не является системой выдачи permissions.

## Реализация

В app-only AccountMenu используются активные participation roles канонического пользователя. Группа отображается через native details/summary по уже принятому UI паттерну, открывается на дочерней странице и управляется вручную. Для девяти ещё не разработанных экранов добавлены app-only GET маршруты с информативным заголовком и подзаголовком. mskba_dark продолжает работать по прежним правилам. Кошелёк расположен непосредственно перед Настройками. UI-тексты на «ты» по CaseRule18; юридические согласия не изменены.
