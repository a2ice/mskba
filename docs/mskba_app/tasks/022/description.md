# 022 — Ролевые группы sidebar аккаунта и обращение на «ты»

Дата: 2026-10-09; актуализация 2026-10-10. Тема: **mskba_app**. Статус: реализовано, ожидает визуальной приёмки на Dev.

## Актуальное поведение (заменяет прежнюю общую группу «Мой MSKBA»)

У каждой **активной роли участия** пользователя в sidebar появляется **отдельная раскрывающаяся группа с названием роли из `UserParticipationRoleEnum::label()`**. При отсутствии активных ролей таких групп нет, пункт «Роли в проекте» остаётся. Модель 0/1/2+ ссылок внутри общей группы «Мой MSKBA» от 2026-10-10 **отменена**: `AdaptiveMenuGroup` удалён, ссылок или группы «Мой MSKBA» больше нет.

Матрица подразделов в `app/Presentation/Navigation/Menus/AccountMenu.php` (перед последним пунктом «Параметры»):

- **Игрок:** Мои команды / Мои игры / Мои тренировки.
- **Тренер:** Мои секции (если фича включена) / Мои тренировки / Мои команды.
- **Судья:** Мои игры / Судейские назначения.
- **Представитель площадки:** Мои площадки / Бронирования / Расписание.
- **Медиа:** Мои материалы / Мои мероприятия.
- **Статист:** Мои игры / Статистика.
- **Организатор мероприятий:** Мои мероприятия / Мои турниры.

Каждая группа **всегда заканчивается ссылкой «Параметры»** на `account.participation-role` c соответствующим `{role}`. Это ровно тот же маршрут, что у шестерёнки активной роли в `/account/roles`. На маршруте параметров активной становится **только группа соответствующей роли**, сама ссылка «Параметры» подсвечивается акцентным текстом, а базовый пункт «Роли в проекте» не помечается активным. На вложенных ролевых страницах группа открывается нативным `details[open]`; пользователь также может вручную свернуть/развернуть её.

Пункты внутри групп визуально компактнее обычных ссылок sidebar (13px, высота от 34px); текущий пункт имеет акцентный цвет **без цветной фоновой плашки или рамки**. Навигация keyboard/focus-visible сохраняется. В мобильном sidebar родительский аккордеон раскрывается, когда текущий маршрут находится внутри ролевой группы.

## Данные, права и взаимодействие

`AccountMenu` читает активные роли канонического пользователя через `participationRoles()`. Создание роли сразу создаёт группу, отключение удаляет её. Существующие команды/площадки и договоры определяют содержание и разрешённые действия внутри разделов, **но не сам факт присутствия группы**. Все проверки разрешений в контроллерах/handlers остаются без изменений; навигация не выдаёт прав. Одинаковые маршруты (например, «Мои игры» для игрока, судьи и статиста) осознанно повторяются в разных ролевых группах; **между группами дедупликации нет**, внутри группы дубли исключаются.

`account-roles.js` после AJAX PATCH по-прежнему загружает серверную разметку аккаунта и заменяет sidebar целиком; матрица ролей не дублируется в JS. Мобильное состояние общего аккордеона сохраняется. `mskba_dark`, системные роли, onboarding, toggle cooldown и API не меняются. Общие ссылки (Обзор, Профиль, Роли в проекте, Уведомления, Контакты, Кошелёк, Настройки, Контракты, Выйти) остаются в существующем порядке. Обращение к пользователю на «ты» — CaseRule18; юридические тексты не редактируются.
