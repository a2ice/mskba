# Мероприятие до бронирования · информационная предзаявка, чат и ревизии

## Назначение
Мероприятие создаётся до оформления аренды. Предзаявка показывает интерес организатора к площадке, но не блокирует временной интервал и не создаёт обязательств. Уполномоченный представитель площадки может предложить оформить заявку; только согласие организатора с актуальной ценой превращает её в обычный процесс бронирования.

## Интерфейс и гайдлайн
- Эталон темы: **Filament → Дизайн → Темы оформления → UI Kit / Гайдлайн**, существующие поверхности \`.panel\`, кнопки \`.button.primary/.secondary\`, \`.field-group\`, \`.select-control\`, \`.check-label\`; не создавать дублирующие одноразовые UI-компоненты.
- Для страниц новой темы используется \`theme::layouts.app\` или \`theme::layouts.account\`; всё содержимое размещается в \`section > .container\`, границы контейнера совпадают с общим сайтом.
- Новые экраны: \`events/booking-quote\`, \`events/interest-thread\`, \`events/edit\`, \`venues/event-interests\`. Предварительный интерес и реальная заявка различаются текстовым статусом, не только цветом.
- На публичных исторических страницах \`events.show\` и \`events.game-show\` действует разрешённый read-only fallback прежней темы до их нативного переноса. Страница ревизии показывает прежние площадку/время с перечёркиванием и новые значения раздельно.
- Адаптив: стандартная шкала 4–64 px; responsive в пределах общих контейнеров, кнопки не перекрывают поля; клавиатурные focus и click сохраняются.

## Данные, доступ и безопасность
- Время предзаявки не учитывается как занятое и не резервируется в БД.
- \`rental.interests.view\` позволяет видеть и вести переписку, \`rental.interests.propose-booking\` позволяет представителю площадки предложить аренду. Заявку создаёт только организатор после серверного quote. Сотрудник не получает от этого права на платежи.
- В заявке сохраняются \`event_venue_interest_id\` и \`interest_booking_initiator\`. Общий чат продолжает существовать при привязке аренды.
- Отдельная аренда без предзаявки проходит прежним маршрутом.
- Пересчёт цены всегда серверный. Процентные и персональные скидки — отдельная будущая задача.
