# #1084 — Расстояние и карта соседней площадки

[Issue #1084](https://github.com/a2ice/mskba/issues/1084) · DEV ONLY.

## Контракт

- Шаблон mskba_app, «Площадки рядом», режимы «Все» и «Похожие», страница площадки и зала: исходный контракт расстояния от названия родительской площадки заменён уточнением [#1092](https://github.com/a2ice/mskba/issues/1092): `(N,N км)` в строке адреса, полное название в подсказке без обрезки. Использовать текущую карточку и семантические стили без изменений Core UI Kit.
- Общий `map-dialog` и фирменный `venuePlacemark`: при открытии адреса соседней карточки сразу две площадки (исходная и выбранная), станции метро выбранной площадки как прежде, автоматические общие границы. Исходный pin находится вне коллекции дополнительного nearby-поиска; уточнение [#1097](https://github.com/a2ice/mskba/issues/1097) — тёмно-коричневый маркер, без служебной подписи, только название.
- Опция «Показать площадки рядом», радиус и «Применить» продолжают работать относительно выбранной площадки; добавляются остальные результаты существующего поиска без дубля исходной. Отключение опции очищает лишь дополнительные точки и подбирает масштаб по оставшимся. Обычный каталог и карта основной площадки без нового reference-контекста.

## Приёмка

Проверить светлую/тёмную тему, desktop/mobile: подсказка с полным названием, оба режима подбора, страницу зала; две точки сразу, включение поиска, изменение радиуса, отсутствие дублей, выключение поиска, открытие другой карточки и основной карты. Сборка и CI до merge в dev. Локальная визуальная проверка недоступна через текущий GitHub-коннектор; не считать её выполненной.
