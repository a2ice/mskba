# 047 — Универсальный просмотр подписок и восстановление истёкших

**Задача:** приёмочные исправления универсального центра подписок MSKBA, 26.10.2026. **Процесс:** feature branch → PR → CI → dev.

## Список /account/subscriptions
- Каждая строка независимо от статуса и типа содержит универсальное действие **«Посмотреть»** вместо «Редактировать». Оно открывает отдельный диалог «Подписка» с типом, статусом, привязкой, условиями, сроком действия и настройками уведомлений.
- В общем списке больше **нет** действия «Подходящие площадки» и никакой плашки со словами «доступность брони ещё не проверена».
- Активные подписки сохраняют кнопки «Приостановить», «Отменить подписку»; приостановленные — «Возобновить», «Отменить подписку».
- Истёкшие получают **«Восстановить подписку»** вместо отмены. «Посмотреть» доступно всем статусам, включая архивные.

## Просмотр и редактирование
- В общем диалоге «Посмотреть» действия универсальные; у неархивных записей доступно «Редактировать», открывающее специализированный wizard игровой подписки.
- В редактировании игры на странице подтверждения размещён предварительный блок **«Подходящие площадки»**. Результат — лишь названия площадок со ссылками, без текста о проверке брони. Подбор выполняется по *сохранённым* настройкам, изменения в форме применятся после сохранения.
- Поля «Выбранная площадка» и «Исключённые площадки» используют theme-поля высотой 44px, радиус 12px, CSS-переменные MSKBA, доступную клавиатурную фокусировку и существующие списки вариантов.

## Продление и безопасность
- У `expired` (active + expires_at в прошлом) API `PATCH /account/play-intents/{id}/restore` продлевает ту же запись: flexible на 30 суток, regular на 90 суток. Первоначальные критерии, idempotency key, уведомления и приватность остаются неизменны. Запрос разрешён только владельцу; транзакция блокирует запись, исключая повторное продление параллельными запросами.
- Разовую подписку с истекшей датой нельзя восстановить без новой даты: действие ведёт в редактор для выбора новых дат, валидируемых сервером. Новая запись не создаётся.
- Preview совпавших площадок для истёкшей подписки выполняется без её активации. Она не попадает в публичные счётчики и уведомления, пока не восстановлена.
- Архивные cancelled/completed подписки только просматриваются, восстанавливать их этим API нельзя.

## Проверки
- PHP feature tests: регулярное и гибкое восстановление, повторный вызов, запрет чужого доступа, разовые даты, сохранение параметров и неизменность статуса при preview.
- JS/build проверка компонент, корректная разметка двух модалок; отсутствие прежнего предупреждения в списке/редакторе, результат продления обновляет фильтры и пагинацию.
- CI + RBAC Postgres зелёные, затем merge в dev и dev deploy. Production не меняем.
