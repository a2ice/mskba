# Аренда до полуночи: переход от слотов к расчёту

Дата: 15.11.2026. Сценарий: /venues/30-aktiviti-kholl, выбран конец 16 ноября 00:00 в календаре; на странице /venues/30/rental/quote появляется ошибочное сообщение о событии, а поле «Начало» обнуляется.

## Причина
VenueEventAvailability::assertAvailable используется событиями и системой аренды. Проверка isSameDay без учёта исключающей границы суток отвергает даже окончание аренды строго в 00:00 следующих суток. При импортированном FindSport дополнительно рабочее время хранится как 23:59 (ограничение HTML-time), что мешает настоящему окончанию в 00:00. Контроллер возвращает Blade при ошибке расчёта, не передавая введённые значения; old() не помогает без редиректа.

## Исправление
- Для аренды вводится явный разрешающий параметр allowEndAtMidnight в общем сервисе проверки; создание обычных мероприятий сохраняет прежние правила. Только ровно 00:00 следующего дня допустимо как исключающая граница [start,end). 00:30 и позже по-прежнему отклоняются.
- Если у зала есть активный импортированный снимок FindSport, его значение окончания 23:59 при проверке аренды до полуночи интерпретируется как 24:00 (только для сравнения). Действительно закрытые вручную залы не расширяются; фактические занятые слоты остаются недоступными.
- Флаг передаётся при расчёте аренды, создании заявки, проверке актуальности расчёта и поиске альтернативного времени для rental, чтобы заявка не отваливалась на следующем шаге.
- В ошибочной странице аренды сохраняются зал, выбранное начало и длительность. В успешном расчёте, если дата окончания другая, показывается и дата окончания.
- Минимальная длительность аренды по действующей политике (например, 60 минут) остаётся обязательной: одиночный слот 23:30–00:00 нельзя арендовать при минимуме 60 минут; интервал 23:00–00:00 — можно, если оба слота свободны.

## Приёмка
- 23:00–00:00, два свободных получасовых слота FindSport: корректная цена, расчёт, проверка актуальности, заявка.
- 23:30–00:00 при минимуме 60 минут: отказ по длительности, не по переходу даты.
- 23:30–00:30: отказ по границе суток.
- Тест ошибочной страницы проверяет восстановление введённого значения datetime-local.
- После CI и merge в dev проверить публичный сценарий. Production без отдельного разрешения.
