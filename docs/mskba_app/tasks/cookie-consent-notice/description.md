# Cookie notice & optional analytics — 2026-11-14

## Задача

Фиксированное уведомление по образцу пользователя, но строго на токенах действующей темы MSKBA:
не создавать отдельный визуальный дизайн. Удерживать содержимое в общем `.container` проекта
(ширина 1280px на десктопе, текущие адаптивные поля; фоновая полоса — на всю ширину экрана).
В старых темах используется их штатная ширина `.inner`. Не перекрывать работу сайта
модальным backdrop; мобильные кнопки переносятся в колонку.

## Поведение

- Первое посещение: отложенная аналитика, доступны явные «Только необходимые» и «Разрешить аналитику».
- POST `/cookie-consent`: CSRF, валидация состояния, HttpOnly/SameSite=Lax cookie на 365 дней.
- Серверный журнал сохраняет visitor UUID, пользователя (если есть), решение, версию, время, IP и user-agent.
  Плановая очистка доказательств старше 13 месяцев; обновление версии вновь открывает баннер.
- Яндекс Метрика (JS и noscript) не подключается без текущего opt-in;
  при изменении выбора полная перезагрузка страницы корректно применяет новые правила.
- «Настройки cookie» в футере позволяет отменить разрешение или изменить отказ.
  Необязательная аналитика не влияет на авторизацию, бронирования и другие сервисные функции.
- Единые подключение и поведение для `mskba_app`, legacy `mskba_dark`,
  `mskba_streetball` и `blank`. Без JS обычный POST формы остаётся рабочим.
