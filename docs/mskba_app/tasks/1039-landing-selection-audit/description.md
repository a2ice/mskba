## Распределение по округам — 27.11.2026

Расширена существующая ручная проверка сохранённых фильтров: по городской выборке подсчитываются площадки для каждого округа из справочника, включая нулевые. Показывается число непустых округов, число округов с 3+ площадками и до пяти наиболее наполненных. Некорректные или отсутствующие привязки учитываются отдельно; принадлежность не выводится из строки адреса. Только редактор с manage-content, только по нажатию кнопки, без дополнительных запросов на публичных страницах. Не создаёт/активирует посадочные и не изменяет географию. Число площадок не равно числу свободных слотов; 3+ — ориентир для редакционной проверки, не SEO-гарантия. DEV ONLY.
