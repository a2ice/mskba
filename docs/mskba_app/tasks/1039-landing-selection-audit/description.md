# #1039 — Проверка наполнения SEO-подборки

DEV ONLY. После #1102: не создавать гео-страницы автоматически. На dev по текущим фильтрам Москва = 4, САО = 1, Химки/Долгопрудный = 0; справочник Москвы содержит один округ (публичный GET, 26.11.2026, #1039).

В штатной странице редактирования Filament добавлена кнопка «Проверить выборку». Действие работает по сохранённой записи, не по несохранённым полям, с Gate manage-content. Стандартное persistent Notification без нового UI. Используем существующий ListVenuesHandler с гостевой видимостью и configuredRentalOnly, поэтому считаем площадки из каталога, а не все записи/залы/слоты. Для выбранного города также считаем выдачу без ограничения округа при сохранении остальных фильтров, число площадок без корректного district того же города, количество записей округов/районов справочника. Один дополнительный проход каталога только при выборе округа, по запросу редактора, не на публичных страницах. Нет изменения БД и автоматической активации/деактивации. Ориентир 3 площадки — редакционное предупреждение, не жёсткий SEO-порог. Не обещаем свободные слоты; отсутствие привязки к округу не означает ошибку адреса.

Тесты: точная выборка, city baseline, hidden, неверная/отсутствующая привязка, права, отсутствие изменения записи. Приёмка в Filament на сохранённой московской подборке; проверить 4/актуальное число, city baseline, справочник и предупреждения; визуальная проверка отдельно. Никаких изменений public UI, main, sitemap, robots, внешних сервисов или booking.
