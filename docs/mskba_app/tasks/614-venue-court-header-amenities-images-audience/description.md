# Площадки: типы зон, удобства, фотографии и аудитория

## Изменения

- В заголовке общей страницы тип игровой зоны определяется по всем `venue_courts.environment`: крытый зал, уличный корт либо оба типа одновременно. На подстранице — только тип выбранной зоны.
- На общей странице показываются только общие удобства площадки. На странице зала/корта — общие удобства плюс оснащение выбранной зоны. В верхней части не более семи бейджей, остальные раскрываются переходом «и другие» в раздел `#app-venue-about`, где отображается полный список.
- Ссылка «и другие» получила компактное оформление и видимый фокус для клавиатуры в `venue-detail.css`.
- Карточка каталога и попап главной карты используют фото площадки, если оно есть. Иначе берётся первое доступное фото из галереи залов/кортов в порядке сортировки зон. Никакого копирования или сохранения фото не выполняется. Одинаковая логика используется в `ListVenuesHandler` и `PublicVenueResource`.
- Блок «Площадкой интересуются» объединяет прямые подписки и пользователей, подходящих по условиям активного `PlayIntent`. При расчёте совпадения НЕ создаются новые подписки; подтверждение по конкретному пользователю требует проверки его записей в dev-БД. Не следует трактовать рекомендованных пользователей как прямых подписчиков.

## Приёмка

1. Школа с indoor + outdoor: общий заголовок комбинированный, выбранная зона имеет один тип.
2. Общая страница не показывает оснащение отдельных зон, на странице выбранной зоны показываются только относящиеся к ней удобства.
3. Первые семь бейджей отображаются наверху; ссылка «и другие» ведёт к полному списку.
4. Фото площадки имеет приоритет; при его отсутствии каталожная карточка и карта используют первое фото одного из залов/кортов.
5. Аудитория не меняется при просмотре и не создаёт новых записей без действия пользователя.
