# 344 — Предложить роль организатора при создании мероприятия

В общем quick-create wizard на финальном шаге, а также на стандартной странице создания показывается фирменный check-label «Добавить мне роль „Организатор мероприятий“» (по умолчанию выбран). Пользователь с активной ролью не видит чекбокс; гость видит его до входа. Единый Blade-парциал, выбор сохраняется при валидации и восстановлении визарда после авторизации (в том числе снятая галочка). Оба HTTP-входа валидируют optional boolean, отсутствие флага не меняет поведение других вызовов. CreateEventHandler внутри транзакции после успешного создания вызывает штатный UpdateUserParticipationRolesHandler::updateOne для канонического пользователя, если явно выбрано назначение и роли нет. Остальные роли и права на конкретное мероприятие не изменяются. Не назначать роль при неуспешном запросе; повтор запроса не создаёт дубликат.
Проверки: гостевой flow, имеющаяся роль, снятая галочка, валидация, сохранение существующих ролей и идемпотентность.
