# 004 — Application layout и общие UI-компоненты

**Статус:** Запланировано · **Зависит от:** 003.

## Цель

Создать переиспользуемую визуальную основу реальных экранов `mskba_app`: application layout, навигация и ключевые компоненты по принятому гайдлайну, не копируя разметку стенда.

## Планируемый объём

- Определить границы Vue layout и Blade shell, чтобы header и навигация не дублировались.
- Общие кнопки, ссылки, поля, карточки, состояния loading/empty/error и диалоги.
- Адаптивность, базовая доступность, согласованность с токенами и эталоном.
- Переиспользование компонентов на конкретном реальном экране вместо исключительно демонстрационного каталога.

## Критерии приёмки

У каждого компонента есть правило в гайдлайне, реальные варианты на странице и визуальная проверка desktop/mobile. Нет независимых расходящихся UI-систем.

## Текущий результат

Не реализовано. Header остаётся первым самостоятельным Blade partial, не общей библиотекой Vue-компонентов.
