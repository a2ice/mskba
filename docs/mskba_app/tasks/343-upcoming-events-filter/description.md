# 343 — Фильтр ближайших мероприятий в каталоге площадок

## Реализация и UX
В /venues после условий доступа показан чекбокс «Есть ближайшие мероприятия»; выбранный чекбокс раскрывает ползунок 1–14 дней (7 по умолчанию). Переиспользованы классы существующего range-контрола из player-profile-workspace.css и стандартный check-label. Фильтр применяется кнопкой «Применить», сохраняется при переключении режима карточки/список/карта, и при загрузке следующих страниц. Период означает от текущего момента до того же времени через N дней. Отбираются только публичные опубликованные события с началом в данном окне; приватные, черновики, отменённые и прошедшие исключаются. Общий ListVenuesHandler применяет whereHas до формирования DTO и пагинации.

## Проверки
Feature-регрессия проверяет границы периода, приватность и статусы; Laravel-валидация 1–14. Визуальный smoke desktop/mobile и комбинации с остальными фильтрами после деплоя. Не вводить параллельные стили range/checkbox.
