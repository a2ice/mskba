# Задача 309 — сохранение индивидуальных условий основного зала

## Симптом
После редактирования основного уличного корта школы №1794 настройки оплаты/записи/подтверждения/онлайн-бронирования могут возвращаться на «Наследовать от площадки».

## Решение
- Явное преобразование tri-state селектов inherit / yes / no при заполнении Filament и при Eloquent create/update.
- false означает «Бесплатно», «Свободный доступ», «Автоматически», «Запрещено», а null — именно «Наследовать».
- active/temporarily_closed остаются enum, inherit преобразуется в null.
- Проверять одинаковый flow для основного и дополнительного зала, без перезаписи соседнего.
- Изменения залов и политики инвалидируют поисковый кэш.

## UI Kit
Сохранить существующую модалку Filament без новых CSS, кнопок и пояснений. Следовать docs/specification/ui-design-system.md.

## Приёмка
Открыть школу №1794 → Основной уличный корт → вкладка «Доступ и бронирование» → изменить все четыре условия на явные. Сохранить и повторно открыть, затем перезагрузить страницу. Проверить согласованность с БД, публичной страницей и каталогом. Аналогично проверить дополнительный школьный зал и намеренный возврат к наследованию.
