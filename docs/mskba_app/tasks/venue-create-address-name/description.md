# Адрес и название при добавлении площадки — 14.11.2026

- При ручном вводе действующий address-suggest сбрасывает location.address_selected, координаты и структурированные поля. Сервер требует подтверждённый выбор, город, улицу, дом и координаты: свободный текст без выбора подсказки не сохраняется.
- После подсказки или reverse-geocode происходит событие address-suggest:selected с улицей и домом. Форма MSKBA App автоматически заполняет название как «Улица, дом».
- Название остаётся редактируемым. Введённое пользователем и восстановленное после ошибки значение не перезаписывается. При смене адреса автоматически предложенное название обновляется.
- Проверки: JavaScript автоимя и ручной ввод; PHP отклонение сохранения без подтверждённого выбора адреса.
- Права, модерация, геокодинг и вознаграждения не меняются.
