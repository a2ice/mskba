# #1160 — Рейтинг и отзывы площадок

[Issue #1160](https://github.com/a2ice/mskba/issues/1160). 27.11.2026. Только dev.

## Сценарий и интерфейс

- Селектор зон: «Вся площадка» в текущем значении общей страницы и первым пунктом списка. В списке зон галочка зелёная, крестик красный, статус читается текстом.
- Публичные страницы площадки и каждой зоны используют единый рейтинг и отзывы родительской площадки. Звезда и число выровнены по центру H1, число с одним десятичным знаком того же размера, заливка пропорциональна рейтингу. При отсутствии оценок — только контур.
- Клик по звезде и кнопке «Оценить площадку» открывает общий native dialog: целая оценка 1–5, начальная 5, штатный оранжевый range-паттерн, необязательный textarea до 3000 символов. После успешного сохранения — отдельный попап благодарности.
- «Отзывы» в якорной навигации и отдельной панели. До 10 записей на страницу, прокрутка до 250px, lazy по курсору, штатный оранжевый индикатор, ошибка с повтором. Аватар с учётом приватности, никнейм/логин (не email), звёзды и текст.
- Гость может читать опубликованные отзывы; создание/редактирование требует аккаунта. При создании и редактировании сервер проверяет блокировку аккаунта, публичность площадки и принадлежность записи канонической identity.
- Фильтр «Показывать мои отзывы» включает собственные ожидающие модерации записи. Редактирование возвращает отзыв на модерацию, сохраняется аудит.
- Новая оценка разрешена каждые пять минут на площадку и каноническую identity. Блокировка строки пользователя в транзакции предотвращает обход параллельными запросами. Оценка без текста публикуется сразу, оценка с комментарием после проверки, все правки — после повторной модерации. Среднее по опубликованным записям. Модерация: Filament → Площадки → редактирование → Отзывы, права BACKOFFICE_VENUE_MANAGE.
- Повторное использование существующих VenueReview, Auditable, UserPrivacyAccessService и общих UI-примитивов; миграция не нужна. Контракт [дизайн-системы](../../../specification/ui-design-system.md). Старый шаблон не меняется.

## Приёмка

- [ ] PHP feature-тесты: авторизация, 1–5, cooldown, фильтр, отсутствие утечки непубличного текста, ownership, аудит правок, cursor.
- [ ] Filament: модерация доступна только уполномоченным, публикация/снятие меняет публичный список и среднее; проверка изменений при повторной модерации.
- [ ] Визуал на общей странице и зоне: без оценок, 4.5 и 5.0, длинный H1, 360/390/768/1440, светлая/тёмная палитры, focus/keyboard, scroll 250px, >10 отзывов.
- [ ] Успешная отправка, ошибки, гость, фильтр своих, редактирование, повторная отправка через пять минут.
- [ ] Зелёный полный CI, merge только dev, автодеплой и проверка. UI Studio/живой браузер пока не проверены; не считать CI визуальной приёмкой.

## Уточнение #1163 — гостевой сценарий

Клик гостя по звезде или кнопке «Оценить площадку» открывает информационный диалог; «Войти» вызывает общий AuthDialog. Намерение хранится в sessionStorage до 15 минут, только в текущей вкладке, с локальным URL площадки/зоны. После успешной авторизации и обязательного онбординга восстанавливается исходная страница и автоматически открывается форма с оценкой 5, без отправки данных. Отмена авторизации очищает намерение. В отличие от автоматического добавления в избранное, оценка сохраняется только отдельным подтверждением пользователя. Используется обычный redirect общего AuthDialog для получения авторизованной Blade-разметки и нового CSRF. Серверный контроль не меняется. Приёмка: гость, отмена, вход, регистрация с онбордингом, возврат на зону, истечение срока, повторная загрузка страницы, отсутствие автоматической записи.
