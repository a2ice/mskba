# Штатный экран доступа к созданию в MSKBA App — 14.11.2026

- Проблема: ShowCreationPageAccess перехватывает гостевой GET /venues/create и отрисовывает theme::pages.creation-access; в MSKBA App отсутствует этот Blade, поэтому ThemeResolver выдавал «MSKBA App theme» (HTTP 200).
- Добавлен тематический шаблон с контейнером сайта, стандартной panel, CTA и CSS-токенами. Он универсален для остальных маршрутов создания и показывает требования для заблокированных / не имеющих доступа пользователей.
- Гость видит штатные вход и регистрацию через общий AuthDialog.vue, без дублирования механики. Действия передают точный локальный URL текущей страницы через data-auth-redirect, а middleware уже сохраняет url.intended в сессии. Авторизация и регистрация возвращают к исходной странице; при обязательном privacy-онбординге она сохраняется до завершения.
- Подтверждённость аккаунта для создания площадки не требуется; POST по-прежнему защищён auth и существующей проверкой блокировки.
- Regression: гостевой вход в теме app не показывает заглушку, сохраняет query URL и предлагает оба действия; неподтверждённый пользователь попадает в форму.
