## Данные
- Просмотры: одно учтённое публичное открытие материала на посетителя за 30 минут; гости/авторизованные, без известных роботов/превью/админских запросов, без выдуманной истории; лёгкий агрегат, не веб-аналитика.
- content в существующем Favorites: активная запись = лайк, счётчик активных добавлений, снятие/корзина/восстановление, общий header count, авторизация через AuthDialog; ЛК «Новости и материалы». Старые реакции и Telegram агрегаты сохраняются отдельно, не суммировать.
- Комментарии: UX отзывов площадки без звёзд; публичные только после модерации, автор видит свои/статус, редактирование/удаление, 10 на страницу, приватность имени/аватара, ограничения частоты, XSS, Filament модерация.
