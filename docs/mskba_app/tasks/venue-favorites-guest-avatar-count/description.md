# Venue hero: общий счётчик избранного и аватары интересующихся (23.11.2026)

## Запрос
На странице площадки обеих тем кнопка «В избранное» / «В избранном» всегда показывает в скобках число **активных добавлений именно этой площадки**, включая гостей как зрителей: «В избранное (N)» / «В избранном (N)». Не путать с количеством элементов в избранном текущего пользователя (счётчик сердца в header). Исключать удалённые в корзину записи.

При добавлении/удалении через кнопку или другие механизмы в том же окне немедленно обновлять надпись и число из существующего `favorites/toggle.count` и события `mskba:venue-favorite:updated`; при первоначальной загрузке использовать серверный счётчик и штатный `venue-statuses.counts`. Новые API, миграции, polling и персональные данные не нужны.

В блоке «Площадкой интересуются» визуально отдавать приоритет участникам, для которых доступно настоящее фото. Источник: основной аватар профиля, затем ранее привязанный Telegram/VK; эти публичные фото должны показываться в гостевом режиме так же, как авторизованному. Статус авторизации **не влияет** на доступ к аватару; действующее согласие `show_on_venue` на его показ сохраняется. Если пользователь запретил показ аватара для этой площадки, сохраняется штатная иконка профиля без раскрытия фото и игровых данных; добавление в избранное не считается согласием на распространение фото.

## Приёмка
- Гостевая карточка площадки: 0/2/много добавлений отображаются рядом с кнопкой; после add/remove 2→3→2 меняется текст без перезагрузки, независимо от количества в header.
- Оба шаблона (`mskba_app`, `mskba_dark`) используют одну разметку и `venue-favorite-main.js`.
- В списке интересов гости видят разрешённые аватары из Telegram/VK при отсутствии локального фото; скрытые пользователи показывают иконку, не фото; сортировка компактной ленты отдаёт приоритет видимым фото и не меняет список/счётчики в popup.
- PHP Feature + JS tests, CI, Codex Review, merge в `main`, успешный production deploy.

Существующий UI Kit не расширяется: используются штатные кнопки, бейдж/скобочный счётчик и avatar primitives.
