# Задача 608: мастерская формы

## Цель
Один Git-owned редактор формы для главной (Page Builder-owned точка входа), отдельной страницы /uniforms/workshop и профиля игрока. Сохранённые эскизы доступны по /account/uniforms.

## Дизайн и UX
Редактор содержит название формы, основной и дополнительный цвет, размеры XS–XXL и логотип (без него / логотип доступной команды / загруженный свой). Живой SVG-предпросмотр. Стандартный диалог .mskba-modal с drag handle, крестиком, ESC, затемнением и адаптивностью. Главная, её CSS и анимация игроков не изменяются.

## Процесс гостя
Сохранение требует входа/регистрации через общий попап. Черновик, включая логотип, временно хранится только в sessionStorage. После авторизации и онбординга производится POST; после подтверждения сервера открываются «Мои формы». При ошибке черновик сохраняется для повторного действия.

## Проекты
CRUD только владельцу (каноническая идентичность). Сервер проверяет, что командный логотип относится к доступной команде. Свой файл нормализуется до WebP 500px, хранится на private local disk и отдаётся только владельцу. Модель versioned и поддерживает soft delete. Заказ в производство пока не создаётся: только попап-заглушка.

## Приёмка
PHP tests, Vite build, DEV smoke, главная/профиль/отдельная страница, 1440–360px, гостевой вход, тесты доступа и логотипов. Не вливать в main до отдельного согласования.
