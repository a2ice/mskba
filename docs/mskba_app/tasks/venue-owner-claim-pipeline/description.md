# Единая карточка подтверждения в MSKBA App — 20.11.2026

- Канонический путь: /account/contracts/venues/{venue}; точка входа — принятое owner-приглашение.
- Стандартный layout личного кабинета и меню «Мои контракты → Площадки», без отдельной неготовой страницы.
- Попап «Контракт» в списке показывает текущий статус и переход к полной карточке.
- Состояния: требуется подтверждение, черновик, на рассмотрении, отклонена (можно подать снова), заблокирована (запрещено), подтверждено, контракт действует/не действует.
- Отдельно хранить и показывать модерацию площадки, не смешивать с подтверждением собственника.
- Формы с доступными подписями, private-файлами и общей историей сообщений.
- Ссылка на юридический документ в приглашении — оранжевая подчёркнутая, в отдельной вкладке.
