# #1092 — Компактное расстояние рядом с адресом

[Issue #1092](https://github.com/a2ice/mskba/issues/1092) · DEV ONLY. Уточняет [#1084](https://github.com/a2ice/mskba/issues/1084).

- В «Площадки рядом» mskba_app (Все / Похожие, страница площадки и зала) расстояние отображается рядом с адресом: `Флотская улица, 7с1 (4,8 км)`. Одна цифра после запятой. Отдельную строку и повторную иконку удалить.
- Подсказка: «Расстояние до площадки {полное название исходной площадки}». Native title для наведения, существующий делегированный tooltip для нажатия/тапа/клавиатуры; расстояние не открывает карту, адрес открывает её как прежде. Не разрывать число и единицу измерения; на узкой ширине допускается перенос длинного адреса. При отсутствии отображаемого адреса расстояние сохраняется.
- Используется существующий catalog-address и стили метаданных, опциональные параметры только из карточки nearby. Никаких изменений в Core UI Kit или JS карты: исходная и выбранная точки постоянны, остальные по переключателю.
- Приёмка после штатного CI/merge/dev-деплоя: светлая и тёмная тема, 1440/768/390/360; короткий/длинный адрес, название в подсказке не обрезано, тап и клавиатура, карта и переключатель работают, обычный каталог без расстояния. Визуальная проверка в текущем окружении не выполнена.

## Уточнение 27.11.2026

Расстояние располагается в общем текстовом потоке адреса после его последнего слова, отдельный интерактивный элемент тултипа сохраняется; префикс ⇿, значение и единица измерения не разрываются. Сам адрес остаётся отдельной клавиатурно доступной ссылкой на общую карту. Проверить перенос длинного адреса, две точки карты, тултип и обе темы.
