# MSKBA App — меню аккаунта, избранное и компактные аватары

## Изменения

- На гостевых страницах убрать только ссылку-сердце «Избранное» из главного header, сохранив функциональность добавления в избранное на карточках.
- В sidebar «Участие» всегда является группой и включает «Роли в проекте», у которых сохранены собственные дочерние пункты («Все роли» и индивидуальные роли). Добавлена рекурсивная отрисовка вложенных пунктов для десктопа и мобильной версии.
- «Мои формы» сразу после «Участие», вместо дискеты используется иконка майки.
- «Настройки» — группа с пунктами «Общие настройки», «Контакты» и «Кошелёк».
- На странице профиля основной аватар 112 → 56 px, эскизы сохранённых аватаров 76 → 38 px, уменьшены карточки и отступы. Поддержаны статический и JS-варианты отображения.

## Проверка

- Гость не видит `data-header-favorites`, авторизованный пользователь видит счётчик.
- Для пользователей с ролями и без них проверяются ссылки, активный пункт и вложенные группы.
- Проверить вложенность на компактном desktop sidebar и mobile, чтобы не было горизонтального переполнения.
- После загрузки нового аватара JS-превью и миниатюры остаются того же компактного размера.
- Только `mskba_app`; тема `mskba_dark` не изменяется.
