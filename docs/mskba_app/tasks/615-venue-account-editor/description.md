# MSKBA App — редактор площадки в личном кабинете

## Эталон и UI Kit
Основой служат `docs/specification/ui-design-system.md`, `player-profile-workspace.blade.php` (вкладки, поля, карточки) и `components.entity-banner-editor` (баннер как в профиле). Новый тип кнопок и собственные UI-токены не создаются. Функции ориентируются на Filament VenueResource и используют существующие серверные обработчики.

## Разделы
- **Основное:** название, тип, описания, теги, доступ/подтверждение бронирования. Алиас и модерационный статус read-only: backoffice-only. Рядом компонент баннера с обрезкой.
- **Адрес и метро:** структурированный адрес, координаты, метро и существующий Yandex AddressSuggest API.
- **Удобства:** характеристики и общие удобства; оснащение отдельных залов на вкладке зон.
- **Залы и корты:** перечень и ссылка на действующий специализированный редактор.
- **Расписание:** недельные интервалы и исключения по датам через существующий backend `UpdateVenueScheduleHandler`.
- **Фотографии:** загрузка, выбор основной, удаление через `VenueGalleryManager` с сохранением ревизий.
- **Контракты:** переход к контрактному менеджеру при наличии `venue.contracts.manage`.
- **Аренда:** отдельные пункты для аренды, тарифов, промокодов, коммерческих ролей с соответствующими правами. Комиссии остаются только в Filament.

Все вкладки остаются видимыми, а недоступные — disabled; прямые URL и операции проверяются сервером.
Разрешение `venue.edit` открывает основные разделы, `edit.schedule` — расписание; остальные права проверяются отдельно.
Суперадмин без контракта не получает публичный редактор по роли; ему предоставлен Filament. Bootstrap-создатель без контракта сохраняет доступ в период первоначального заполнения созданной площадки.

Сохранение подтверждённой площадки — только через `VenueRevision` и модерацию. Баннер — через `VenueBannerDraftManager`.

## Приёмка
1. Действующий контракт EDIT: вкладки, настоящая форма, сохранение черновика, crop баннера.
2. EDIT_SCHEDULE без EDIT: расписание доступно, редактирование основных данных закрыто.
3. Без контракта, истёкший контракт, SUPERADMIN без контракта: запрет публичного редактора.
4. Залы, фото, контракты и аренда: переходы к существующим проверенным endpoints; disabled без прав.
5. Desktop, tablet, mobile: sticky-tabs, клавиатура, focus-visible, отступы по UI Kit.
6. CI зелёный, деплой только dev до приёмки.
