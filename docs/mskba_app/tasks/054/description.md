# 054 — Физические параметры: телосложение, обувь, кнопки

## Цель и критерии приёмки
Убрать «Стройность» (сохранённое значение не терять и не использовать как дополнительный интерактивный ввод); телосложение: худощавое, нормальное (default), упитанное и остальные существующие доступные варианты по согласованному порядку; убрать опцию «Не указано». Обновить enum/валидацию/модель/пользовательские значения с совместимостью старых данных. «Обувь» → «Кроссовки», добавить основные цвета, «Сохранить физические данные» → «Применить».

## Технические границы
Сверить влияние телосложения на 2D prompt и legacy profile, миграцию не создавать без необходимости.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
Реализация внесена в рабочую ветку после приёмки 053. CI, merge и проверка публикации в dev ещё не завершены. Визуальная приёмка 054 не выполнена.

## Обратная совместимость и проверка

- Порядок селекта: Худощавое, Нормальное, Упитанное, Атлетичное, Мускулистое, Коренастое; без «Не указано». Старые null отображаются как нормальное, при сохранении физических данных нормализуются в normal без миграции.
- Legacy large остаётся в enum, отображается «Упитанное» и в AI описывается как fuller build.
- character.adiposity сохраняется в истории, но не влияет на UI, предпросмотр или генерацию.
- Цвета кроссовок сохраняются под прежним ключом character.shoes; список опций и валидация едины.
- Визуальная приёмка: пустой/старый профиль, смена телосложения, выбранный цвет, «Применить», повторная загрузка страницы, сохранение данных игры.
