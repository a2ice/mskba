# 657 — Специальные условия аренды

Запрос: персональные условия и PUBLIC/USER_BOUND купоны, управление в аккаунте,
серверный quote и безопасное отображение. Связанные задачи: 300 и 322.

UI preflight: [дизайн-система](../../../specification/ui-design-system.md),
существующая страница `venues/pricing-rules.blade.php`, примитивы `panel`,
`field-group`, `button primary/secondary`, `app-rental-pricing__form`,
`select-control`, `check-label`. Одноразовая композиция без новых CSS и модалок.

Статус: локальная реализация; визуальная проверка desktop/mobile и CI ожидаются.
Не считать PHPUnit подтверждением визуальной приёмки. Публикация запрещена.

Примечание UX: выбор получателя в аккаунте использует серверный поиск логинов
и список результатов; predictive-поиск остаётся отдельной доработкой.

Проверено: обе темы собираются в scratch-копии, 118 feature tests и 10 JS tests
прошли; PHP lint и diff check прошли. Полная сборка ожидает доступного
`swagger-ui-dist`. Визуальная приёмка и CI остаются обязательными.
