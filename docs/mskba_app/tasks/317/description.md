# 317 — Источник страницы в ссылке «Пригласить друга»

Связано с [основной задачей 317](../../../tasks/317/description.md).

## Изменение MSKBA App

В существующем попапе «Пригласить друга» на странице игрока реферальная ссылка теперь содержит дополнительный необязательный параметр `source_page` с текущим относительным путём (`request()->getPathInfo()`). Ссылка едина для копирования, Web Share и fallback `mailto:`; оформление и UX попапа не меняются.

## Проверка

- При открытии попапа с `/account/...` параметр `source_page` соответствует адресу страницы без query string.
- Скопированная и отправленная ссылка содержит тот же параметр.
- Сервер принимает только внутренний путь, сохраняет его после регистрации приглашённого и продолжает поддерживать прежние ссылки без параметра.
- Визуальную приёмку desktop/mobile выполнить на публичном dev после зелёного CI и автодеплоя.
