# Задача 607: открытие FAQ из компонентов Page Builder

## Проблема
На главной MSKBA не показывается контекстная панель «Действия», поэтому условно подключённая к ней модалка FAQ отсутствует. Кнопки «Подробнее» и «Как стать партнёром» в редакторе не должны зависеть от ранее удалённой Vue-вставки.

## Согласованное решение
- Использовать один штатный `dialog.mskba-modal.app-context-help-dialog` на всех страницах темы MSKBA App; не копировать HTML/CSS модалок в Page Builder.
- Сохранить единый гайдлайн: шапка с символом перетаскивания, крестиком, нативный modal top layer, blur backdrop, клавиатурное закрытие и адаптивная геометрия.
- Через разрешённые атрибуты `data-mskba-faq-section` и `data-mskba-faq-article` на кнопках редактора выбирать конкретную статью. Общий JS выполняет делегирование клика и запрос к существующему API FAQ.
- Продолжать удалять inline-JS и принудительно выставлять `type=button`. Поддерживать событие `mskba:faq:open` для будущих компонентов с собственным JavaScript.
- HTML/CSS/JS компонентов остаются в Filament; новая Vue-реализация не создаётся.

## Приёмка
- На главной одна FAQ-модалка, без дополнительной полосы контекстных действий.
- На странице «Площадки» та же модалка, не дублируется.
- Кнопки показывают нужную статью с корректной фокусировкой и закрытием.
- CSS и drag-контроллер переиспользуются из дизайн-системы.
- Есть тест публикации HTML редактора и санитайзера; запрет встроенных обработчиков сохранён.
