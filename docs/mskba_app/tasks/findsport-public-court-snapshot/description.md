# Task 308 / mskba_app — публичное отображение снимка FindSport на Basketpoint

## Цель
На изолированном dev показать реальные наблюдаемые интервалы занятости и цены залов Basketpoint непосредственно на странице площадки и соответствующего зала, используя **только сохранённый снимок** Task 307.

## UI-сценарий
1. Площадка с одним залом: в разделе «Расписание» страницы площадки появляется блок «Занятость и цены · FindSport» ниже рабочих часов.
2. Площадка с несколькими залами: блок доступен только на публичной странице конкретного связанного зала. У других залов контент не меняется.
3. Блок показывает идентификатор снимка, дату получения, предупреждение об устаревании TTL.
4. Даты — аккордеоны, внутри — карточки получасовых слотов со временем, статусом (занято / не отмечено занятым / недоступно / нет данных) и ценой за 30 минут в ₽, если она определена.
5. Без покрытия даты показываем «Нет данных», а не «Свободно»; при отсутствии snapshot сохраняем прежний интерфейс.
6. Существующие игры и мероприятия MSKBA остаются в разделе «Игры и мероприятия» и не заменяются внешними занятыми слотами.
7. Карточки внешнего расписания **read-only**: на них нет кнопки бронирования или оплаты, чтобы наблюдаемая цена не считалась подтверждённым предложением.
8. Desktop/mobile: адаптивная сетка 2–4 колонки, для узких экранов 1–2 колонки; оформление на токенах `--surface`, `--line`, `--text`, `--muted`, `--accent`, без нативных select.

## Технические ограничения
- Отдельный конфигурационный флаг `venue_integrations.findsport_public_snapshot_enabled`: по умолчанию true только на `APP_ENV=staging`, на production false.
- События и бронирования MSKBA не переписываются. Только read-only представление внешнего снимка, без сетевых запросов на публичной странице.
- Источник жёстко ограничен API FindSport playground #4805, тестовым режимом, одним связным залом.
- Для автосинхронизации, цен checkout и актуализации без ручного сохранения нужны следующие этапы Task 308–309.

## Проверка
- Пройти создание/сохранение снимка в Filament, открыть публичную страницу Basketpoint и конкретного зала.
- Сверить часы, цены, занятость и timestamp с сохранённым снимком.
- Проверить неизвестные даты за пределами недели, истечение TTL, мобильную сетку и отсутствие внешних бронирований среди мероприятий.
- Убедиться, что отключение feature flag возвращает прежнее расписание.
