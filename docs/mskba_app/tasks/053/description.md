# 053 — Навигация роли «Игрок» как у площадки; sticky-аватар

## Цель и критерии приёмки
Перенести стиль навигации площадки на вкладки игрока: неактивные ссылки без подложки, активная — серая с акцентным оранжевым текстом; при sticky у навигационной панели прямые верхние углы. Аватар остаётся sticky в рамках секции и находится на 15px ниже фактической нижней границы панели, включая анимацию шапки.

## Технические границы
UI, позиционирование и поведение scroll/resize/header-visibility. Не затрагивать данные профиля.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
Реализовано в рабочей ветке; ожидает зелёного CI, слияния в dev и визуальной приёмки.
