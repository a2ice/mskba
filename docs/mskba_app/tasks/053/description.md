# 053 — Навигация роли «Игрок» как у площадки; sticky-аватар

## Цель и критерии приёмки
Перенести стиль навигации площадки на вкладки игрока: неактивные ссылки без подложки, активная — серая с акцентным оранжевым текстом; при sticky у навигационной панели прямые верхние углы. Аватар остаётся sticky в рамках секции и находится на 15px ниже фактической нижней границы панели, включая анимацию шапки.
