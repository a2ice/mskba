# 658 — Ссылка на площадку в системном уведомлении о бонусе

Issue #926. Запрос от 21.11.2026: конкретизировать системные уведомления по мере выявления сценариев, начиная с успешной модерации площадки. Название площадки в тексте — ссылка на публичную карточку, новая вкладка. Сумма и CTA кошелька без изменений.

## Реализация и проверка

Rewards использует идентификатор площадки из business_fact_key; тело остаётся plain text, метаданные ссылки проверяет UserNotificationPresenter. Общий partial notification.body для системной переписки и старого центра. UI: существующий .app-messages__action, согласно [гайдлайну](../../../specification/ui-design-system.md), без новых CSS-примитивов. Регрессия в RewardMechanismPayoutTest: сумма, связь, текст, URL, target/rel и отклонение внешнего URL. История без новых метаданных не переписывается; toast и внешние каналы получают название в plain text. CI и визуальная проверка на dev/prod ещё не подтверждены.
