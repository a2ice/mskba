# MSKBA UI task 609 — открытие мастерской из текущей вкладки «Своя форма»

Проверка опубликованного Page Builder компонента #7 на DEV выявила перестроенную компоновку вкладки: внутри `.tab-content[data-tab-name="workshop"]` кнопка «Открыть мастерскую» теперь является `.tab-footer-actions > button.section-cta`.

Не меняем HTML/CSS/JS пользователя в Filament, арену, игроков и scroll director. Вместо этого в существующем Git-owned lazy bridge `uniforms/bootstrap.js` добавляется совместимый делегированный селектор кнопки; старый селектор и декларативный `data-mskba-open-workshop` остаются поддержаны.

Действие по клику запускает **тот же** `UniformModal` / `UniformWorkshop`, что и отдельная страница и профиль игрока. Диалог использует единые `.mskba-modal` стили, header drag affordance, top layer, крестик, ESC, mobile. Для новых компонентов предпочтительно использовать явный атрибут `data-mskba-open-workshop` и не привязываться к структуре вложенных контейнеров.

Приёмка: на главной переключиться «Своя форма», нажать CTA, увидеть SVG-эскиз и настройки; исходный скролл арены и высота секций не изменяются. Поддержать 1440 и 390 px, проверить отсутствие горизонтального overflow.
