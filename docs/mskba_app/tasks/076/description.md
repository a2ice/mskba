# 076 — Сезоны внутри административной карточки лиги

Дата: 31.10.2026. Изменение после ручной приёмки этапа лиг/сезонов/турниров (PR #540).

## Решение
- «Сезоны» убраны из основной навигации Filament.
- При редактировании **конкретной лиги** есть встроенный раздел «Сезоны» (Filament RelationManager).
- Внутри лиги можно просматривать и фильтровать принадлежащие ей сезоны, создавать, редактировать, архивировать и удалять их по прежним правилам.
- При создании `league_id` принудительно берётся из текущей лиги, не из формы. При изменении чужих сезонов — 404.
- Команды сезона выбираются только из состава данной лиги и только при отдельном разрешении управления командами сезона.
- Поля: название, статус, необязательные даты, описание и команды при наличии прав.
- Существующие страницы SeasonResource сохраняются для старых ссылок и обратной совместимости, но не показываются в меню. База/связи/история не меняются.
- Права на лиги и сезоны по-прежнему **раздельные**. Наличие доступа к лиге не открывает управление сезонами автоматически.

## Проверки
- Новый сезон находится внутри своей лиги; список других лиг не виден.
- Черновик/активный/архив, необязательные даты, связь с командами, сохранение истории.
- Создание/редактирование/архивирование/удаление разрешены только с соответствующими permissions.
- Direct URL старой страницы сезонов не появляется в меню и продолжает требовать разрешения.
- CI и dev deployment перед визуальной приёмкой.
- Production не затрагивать.
