# 337 — Просмотр занятости и шаг времени мероприятия

## Требования приёмки 20.11.2026

- Пустой список «Хочу здесь играть»: пояснение, две кнопки в footer с space-around и промежутком, мобильное перенесение без переполнения. С 25.11.2026 кнопка «Посмотреть занятость» заменена на избранное (PR #1075); см. [актуальные требования к избранному](../venue-interest-direct-favorites-20261123/description.md).
- В основной теме MSKBA оставшиеся входы в занятость на странице площадки используют существующий двухшаговый rental search и календарь девяти дней. Режим просмотра не создаёт бронь и не показывает CTA бронирования; зал по умолчанию любой, при явном выборе — только выбранный. Сохраняются вкладки залов и выделение диапазона.
- Шаг времени: московские дата и время (текущее московское время + минимальный срок до начала аренды из действующей политики площадки (или переопределение выбранного зала) + 10 минут на заполнение; округление вверх до целой минуты, с переходом даты через полночь), только после включения неотмеченного по умолчанию чекбокса «Указать желаемую дату». До включения поля скрыты и disabled, «Далее» создаёт черновик без даты. После включения нажатие «Далее» добавляет первый интервал даже без изменения подставленных значений; плюс добавляет интервалы вручную. Повторное отключение сбрасывает интервалы и исключает их из payload; восстановление после авторизации включает чекбокс только при сохранённых интервалах. Зал или корт остаётся независимым полем. Используются существующие Modal 1.1, поля, цвета и ссылка как в выборе площадки, плюс с доступным названием и tooltip.
- В классической теме и при выборе иной площадки в глобальном визарде сохраняется существующий inline просмотр; общий календарь пока привязан к контексту конкретной страницы площадки. Это ограничение требует отдельного расширения.
- Не изменять API брони, цену, контракты и роли.
- Проверки: JS regression assertions и CI; ручная приёмка мобильного и desktop после деплоя, включая пропуск выключенного шага, принятие предложенной даты и повторное отключение и сохранение поведения аренды.

UI reference: [MSKBA UI Design System](../../../specification/ui-design-system.md), Modal 1.1, Form Controls, существующий rental-time-first-wizard и UI Kit.
