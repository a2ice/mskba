# 548 — Дополнительные проверки UI Kit для баннеров и лиг

## Исходная точка
PR #547 (задача #546) уже реализовал согласованные поправки к вертикальным
отступам, редактору и текстам. Этот небольшой follow-up создаётся
**на dev после #547** и не меняет принятое расположение редактора в «Профиле»,
кнопки масштаба +/−, активные пункты навигации, встроенную строку
подтверждения удаления и связи лиги/сезона.

## Эталон
- `docs/specification/ui-design-system.md`: «Пространство и композиция»,
  «Адаптивный layout», «Компоненты и состояния».
- Filament → Дизайн → Темы оформления → UI Kit / Гайдлайн.
- Утверждённые примитивы `.panel`, `.button`, `.badge`,
  `.app-team-field`, SVG-спрайт Tabler `#ball`.
- Размеры по шкале 4/8/12/16/20/24/32 px; межкарточный ритм не менее 20px,
  внутри строки `align-items:center`, кликабельные зоны от 44px.

## Follow-up
- Лига и сезон: вместо платформенного баскетбольного эмодзи использовать
  уже существующий SVG-символ Tabler `#ball`; центрировать символ в заглушке
  32px / 48px и соблюдать вертикальную ось.
- Подтянуть оставшиеся несистемные gaps/padding в CSS каталога
  и редактора (18/22 → 20/24, внутри строк 8/12/16).
- Дополнить существующий редактор перемещением изображения стрелками
  при фокусе на превью, включая Shift для ускоренного шага.
- К существующему выбору файла добавить drop на ту же область с
  accent-состоянием. Предотвратить гонку между загрузкой сохранённого
  баннера и новым выбранным изображением.
- Оставить короткие пользовательские подписи из PR #547; типы/лимит
  файла видны только в подсказке upload.

## Приёмка
- Green CI с тестами публичных страниц и доступных контролов.
- После merge только dev; production не трогать.
- Визуальная проверка владельцем на desktop и mobile; отдельно
  проверить gaps между плашками, положение элементов внутри строк,
  hover/focus/disabled, загрузку перетаскиванием и стрелками.
