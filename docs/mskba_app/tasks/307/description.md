# Задача 307 — заголовок страницы игровой зоны

## Проблема
На отдельной странице зала рядом с заголовком площадки повторяется название выбранного зала, хотя оно уже показано в селекторе. Пример: «Школа №1794 · Школьный зал».

## UX / UI Kit
- Основной H1 на странице площадки и любой её зоны — только название площадки «Школа №1794».
- Текущее название зоны остаётся исключительно в штатном селекторе над заголовком.
- Не менять eyebrow «Школа: крытый зал / уличный корт», breadcrumbs и остальные блоки.
- Использовать существующий H1 `app-venue-title`, без добавления CSS, нового компонента или дублирующей кнопки.
- Применить гайдлайн `docs/specification/ui-design-system.md` и уже существующий MSKBA App layout.

## Приёмка
- Общая страница площадки: одно H1 «Школа №1794».
- Страница /venues/.../courts/...: то же H1 без повторного названия зала.
- Селектор отображает «Школьный зал» либо «Уличная площадка».
- Feature-тест и визуальная проверка desktop/mobile на DEV.
