# Регистрация: последовательный Enter и безопасное закрытие окна

**Дата:** 2026-11-18 · **Целевая среда:** production после зелёного CI.

## Замечания первичного UX-тестирования

1. В шаге ФИО Enter после фамилии отправлял мастер на следующий шаг, не переводя курсор на имя; после имени — аналогично, вместо отчества.
2. Клик в свободной области вне регистрационного попапа закрывал его и сбрасывал черновик.

## Исправление

- В `WizardShell.vue` Enter из текстовых полей фокусирует следующий видимый, доступный элемент ввода **текущего шага**. На последнем поле фокус переходит на «Далее», но шаг не отправляется автоматически. ИМЕ-композиция не перехватывается. Tab, кнопка «Далее» и Enter на самой кнопке работают как прежде.
- Регистрационный попап больше не закрывается кликом по фону.
- При явном закрытии крестиком или Escape, а также переходе из заполненной регистрации к входу, показывается фирменное подтверждение с выбором продолжить ввод либо сознательно сбросить форму. Пустая регистрация закрывается обычным образом.
- Пароли и остальные данные черновика не сохраняются в storage; до подтверждённого закрытия компоненты и значения остаются в памяти.
- Логин и восстановление доступа не меняют собственную семантику Enter и закрытия.

## Приёмочные сценарии

- Вписать фамилию → Enter → фокус на имени → Enter → на отчестве → Enter → фокус на «Далее» без смены шага.
- Клик по backdrop не закрывает регистрацию и не очищает ФИО или логин.
- После ввода данных Escape / крестик показывает подтверждение; отмена возвращает к введённой форме, подтверждение закрывает и очищает.
- При незаполненном черновике крестик / Escape закрывает сразу.
- Вход и восстановление продолжают работать обычным образом.
- Проверить mobile/desktop, сборку Vite и CI до влития в main.
