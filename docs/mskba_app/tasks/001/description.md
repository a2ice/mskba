# 001 — Основа темы и дизайн-системы

**Статус:** В работе · **Дата обновления:** 2026-10-08

## Цель

Подготовить изолированную `mskba_app` с принятым визуальным эталоном 002-03 и реальной возможностью постепенно добавлять экраны.

## Что сделано

- Подключены theme registration и локальное переключение `APP_THEME=mskba_app`.
- Добавлены Blade layout, fallback и Vite entry.
- Перенесены токены, CSS, шрифт Inter, SVG sprite, изображения и демонстрационный каталог.
- Production/default остаётся старой темой; приложение локально возвращает HTTP 200.

## Осталось проверить

- Соответствие актуального каталога принятому эталону на desktop и mobile.
- Правильную загрузку ресурсов, отсутствие регрессий и поведение в поддерживаемых viewport.
- Зафиксировать полноценную визуальную приёмку согласно протоколу #139.

## Критерии приёмки

Один набор токенов/asset-ов используется в каталоге и рабочей теме, сборка работает, готовность границ темы и её visual baseline подтверждена пользователем.
