# Мобильный параллакс фото карточки площадки

DEV first. Владелец 27.11.2026 предложил лёгкое вертикальное смещение фотографии при скролле в одноколоночной мобильной выдаче. Каталог площадок и SEO-подборки, обе темы; максимум 640 CSS px и только фактическая одна колонка. Фото масштабируется 1.10 вокруг верхнего центра внутри существующей обрезанной рамки. Верх фото на 85% высоты видимой области — смещение 0%; на 15% — −10% от высоты рамки. Плавная позиционная интерполяция без отдельного запуска анимации, обратный скролл идёт по той же кривой. Это стартовые параметры для визуальной приёмки. Не двигать карточку, избранное, текст или sticky toolbar. Список, карта, две колонки, другие каталоги и reduced motion не меняются. При pinch zoom эффект отключён.

Один общий модуль: пассивные слушатели, requestAnimationFrame, IntersectionObserver рядом с viewport, обработка новых карточек infinite scroll; без запросов, БД или миграций. При отсутствии необходимых API обычное статическое фото.

Приёмка: iPhone Safari, Android Chrome; скролл в обе стороны медленно и быстро, остановка, смена направления, отсутствие пустых краёв фото и изменения высоты, кнопка избранного, новые карточки, переход в карту/список, разворот и reduced motion. Проверить обе темы и SEO-подборку. Реальная визуальная приёмка обязательна; автоматический CI не заменяет её. MAIN — отдельно по согласованию.
