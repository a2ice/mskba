# MSKBA App Task 324 — Внешние холды и сквозная цепочка счетов

Дизайн и UI для обеих тем, приемка на dev.

- [x] В настройках аренды: один срок холда, источник его ручной проверки и комментарий.
- [x] В карточке аренды: форма подтверждения реального удержания, способ и дедлайн.
- [x] В карточке аренды: счета, статусы и действия по полномочиям.
- [x] В обоих дизайнах: шаблоны счетов global / venue / agent, ручные и автоматические.
- [x] Покупателю не показываются внутренние финансовые обязательства MSKBA и агента.
- [x] Постоплата и подтверждение реального получения — разные действия.
- [x] Явно обозначены три разных срока: подтверждение брони до окончания холда, оплата счёта покупателем в пределах холда, плановый расчёт по внутренним счетам (не продлевает холд).
- [x] После подтверждения брони дата внешнего холда показывается как историческая; задолженность по постоплате сохраняется и погашается позднее.
- [x] В Filament и публичном редакторе шаблонов указан смысл окна оплаты покупателем, а не финансовых расчётов с площадкой.
- [ ] Ручная приёмка новых подписей и пояснений на dev под покупателем, агентом и superadmin.
- [ ] Скриншоты desktop/mobile на dev и ручная приемка.
- [ ] Подтверждение соответствия UI Kit во всех интерактивных селектах и формах.

Бизнес-инвариант: с агентом **покупатель → агент → MSKBA → площадка**, без агента **покупатель → MSKBA → площадка**. Юридический статус финансовых документов требует отдельного согласования перед production.

Спецификация: [venue-rental-invoice-chain](../../../specification/venue-rental-invoice-chain.md).


### Дополнение 20.11.2026 — СБП и интерактивный счёт в переписке

- Карточка счёта в чате бронирования и связанном чате предзаявки: сумма, дедлайн, способ оплаты, реквизиты только уполномоченным сторонам.
- Действия в самой карточке: «Скопировать реквизиты», «Я оплатил», «Подтвердить получение», «Открыть счёт».
- Для СБП — отдельные поля банка, телефона/номера карты, комментария к переводу, инструкции по подтверждению; сохранённые зашифрованные профили реквизитов выставителя в пределах площадки.
- «Я оплатил» открывает диалог с обязательным номером операции для СБП и дополнительным комментарием, переводит счёт в `claimed`, но не `paid`.
- Реквизиты и номер операции не публикуются всем участникам переписки, а доступны только плательщику/получателю.
- Внешний банк не подключён, данные карт перед production требуют правовой/безопасностной приёмки.
- UI: существующие стили кнопок/диалогов, адаптивная карточка с переносом действий; обе темы; контролируемые поля формы счёта.
