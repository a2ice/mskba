# Каталог площадок — режим «На карте»

## Эталон UI Kit и гайдлайн

- Публичная светлая тема mskba_app, общий каталог layouts.category и toolbar components.catalog-toolbar: существующие иконки, состояния is-active, токены --surface, --line, --muted, --radius-control, без самодельных селектов или кнопок.
- Блок карты — существующий примитив panel в пределах основного container, с адаптивной высотой и отступами. Маркер — штатный venuePlacemark и CSS venue-pin.css; кластеры — существующая конфигурация Яндекс Карт.
- Референсы: docs/specification/ui-design-system.md (UI Kit, токены, клавиатура и адаптивность), прежний рабочий mskba_dark/js/features/default-category.js (перемещение скролла к карте).

## Поведение

- Только для /venues в переключателе убрать ссылку «Списком» и показать «На карте». Другие каталоги продолжают использовать карточки/список.
- Состояние view=map передаётся в GET-форму фильтров и сохраняется при сбросе/сортировке. Фильтрация search, type, operational_status, access работает на сервере через тот же ListVenuesHandler, что и карточки.
- Карту строить по всем площадкам текущей отфильтрованной выборки, не по четырём карточкам первой страницы. Нет координат — точку не показывать, без подмены координат; показать понятный empty state, если все точки отсутствуют.
- При переходе с длинного списка/карточек в view=map позиция прокрутки должна вернуть карту в видимую зону с учётом sticky header. Не делать плавный отложенный скролл на touch/Safari, сначала два кадра на рендер, затем создавать карту.
- Координатные границы и масштаб выбираются по фактическим точкам; единственная точка — локальный zoom 15. Точки кластеризуются, balloon предлагает переход на площадку или подходящий зал и избранное.

## Проверка

- GET /venues — четыре карточки с infinite-scroll, вид «Карточками» по умолчанию; GET /venues?view=map — карта со всеми найденными координатами без загрузчика карточек и sentinel.
- При смене поиска/типа/состояния/условий доступа проверять обновление точек, кластеров, ссылок на подходящий зал и отсутствие площадок вне фильтра.
- Проверить переключение после прокрутки далеко вниз (desktop и мобильный Safari), повторное открытие карты, адаптивность 390/768/1440, hover/focus/активную кнопку, zoom и balloon.
- Автоматические регрессии: VenueCatalogInfiniteTest, ShopCatalogControlsTest; PHP lint, JS syntax/Vite build, CI. Production не изменять, визуальная приёмка на dev.
