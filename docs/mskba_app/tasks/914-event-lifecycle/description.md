- UI Kit / Modal 1.1: native dialog, стандартный header с крестиком и drag affordance, обязательная причина >=10 символов, закрытие по завершённому жесту на фоне. Удаление обратимое, только организатор; история причин и персональные уведомления confirmed/tentative.

- Страница мероприятия и попап «Хочу здесь играть» используют общий шаблон участников/RSVP/чата, контроллер JS, стили и диалог подтверждения удаления сообщения. Эталон #916: 10 записей, before_id, сохранение позиции, автопрокрутка к новым, отметка изменения и дата, карандаш, подтверждение удаления, два RSVP, белый composer 5px и остаток символов; без лишних заголовков.
- Проверить desktop/mobile, доступность, обе темы, права, актуальный CI и deploy на main/dev. Ограничение секционных занятий и игр с результатами сохраняется.

## Единый composer и действия
- Общий `components.chat-composer`: передаваемые действия id/value/label/slot; event adapter отвечает за RSVP, generic disclosure menu — за открытие, закрытие и dispatch. Гамбургер непосредственно слева от отправки предназначен только для действий с сообщением. «Пойду»/«Не пойду» и «Подумаю» остаются отдельными кнопками над чатом с прежней логикой и доступом независимо от права писать. При редактировании в меню красный пункт «Удалить», штатное подтверждение сохраняется. В обычном режиме гамбургер виден, но не открывает пустую панель, пока не добавлены действия (например, вложения); действие не подменяет серверную авторизацию. При отсутствии права писать composer скрыт. В дальнейшем другие чаты подключают свой transport/permissions/action adapter; существующие личные чаты не мигрируются этим PR.
- UI: 44px hit target, 5px composer, токены темы, открытие вверх, Escape и клик вне, никаких дополнительных заголовков. Сохраняются прокрутка, 10 записей, версии, счётчик, статус действий и подтверждение удаления.

## Прямой вход с карточки площадки
- Карточка «Предстоящие мероприятия» открывает существующий попап «Мероприятие» сразу на выбранном событии, без промежуточного списка. «К мероприятию» ведёт на страницу, «Назад» — в существующий список. Связь по ID, с обычным href fallback без JS; detail panes включают все карточки, даже вне лимита 20. Из карточки и вводного текста убрана информация о бронировании; оставлено «Сбор участников». Новый попап не создаётся, используется общий чат.

- По уточнению владельца вводный абзац блока «Предстоящие мероприятия» удалён целиком; после заголовка сразу карточки.
