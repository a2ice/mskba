# #1036 — Общий фильтр настроенной аренды

DEV ONLY. Основание: согласованный универсальный конструктор SEO-посадочных (docs/tasks/seo-rental-1034/catalog-landings.md); предыдущий PR #1064 merged aa87dfd.

- В действующую компактную группу чекбоксов /venues добавляем «Аренда настроена» (нативный check-label из принятого UI Kit, без новых стилей, попапов и перестройки экрана). Legacy mskba_dark использует тот же partial и имеющийся check-label. Малое расширение принятого UI-паттерна; отдельная новая композиция не вводится.
- GET rental_configured=1 (nullable boolean); отсутствует/0 — обычная выдача. При включении выбирается реальная открытая зона с активной настроенной арендой и допустимым scope. Фильтры type/access/status/география работают в пересечении, не расширяют выборку. Даже без type/access ссылка ведёт на конкретную совпавшую зону. Не обещает свободные слоты и возможность оплаты; global rental feature flag и permissions остаются в действующем booking flow.
- Карта, list/cards, sort, pagination и fragment используют тот же handler; общий mobile dock учитывает активный rental_configured, legacy hidden GET и счётчик сохраняют значение. Сброс удаляет ограничение.
- Проверки: существующий RentalSeoInventoryTest дополнен HTTP-проверками выборки, вторичной зоны, карты, JSON, отсутствия эффекта от false, валидации и пустой выдачи; ранее покрытые приватность и совместимость обычного каталога сохраняются. Визуальная проверка тем, mobile/desktop и счётчика после dev deploy отдельно.
- Не меняем production, noindex, robots, sitemap, БД, тарифы, авторизацию и booking/payment. Ресурс Filament, маршруты/SEO-тексты — последующие этапы.
