# Задача 308 — действия редактора площадки в контекстном меню

## Цель
На публичной странице площадки и её зала не размещать административные кнопки среди пользовательских действий. Ссылка-карандаш рядом с H1 и крупная кнопка «Управление промокодами» не нужны в hero.

## UX / UI Kit
- Использовать существующий верхний контекстный бар под шапкой MSKBA App и его выпадающее меню «Действия», без нового компонента или CSS.
- Для владельца площадки или участника с реальным `VenueDetailsDTO.canEdit` добавить единственный пункт верхнего уровня «Редактировать» в «Действия». Пункт ведёт в `account.venues.edit`; при наличии возможности управления промокодами под ним отображаются два подпункта «Площадку» и «Промокоды».
- Для пользователя, имеющего только право на промокоды (без редактирования площадки), не терять доступ: отдельный пункт в «Действия» «Управление промокодами».
- Гость и пользователь без соответствующих прав не видят ни одного редакторского действия.
- Оставить существующие системные пункты контекстного меню («Помощь», «Поделиться» и др.) и основные пользовательские CTA («Расписание», «Хочу здесь играть»).
- Убрать иконку карандаша из `app-entity-heading` и промокодную кнопку из hero на общей странице и на странице выбранного зала.
- Пока редактор `venues.edit` не реализован в активной теме, системная заглушка должна показывать корректную навигацию: «Площадки / Школа №1794 / Редактирование» вместо «Страница». Наличие этой заглушки не считать готовым редактором.

## Регрессионные проверки
- Площадка и подстраница зала: видимость edit по соответствующим правам, ссылка и отсутствие дублирующих кнопок.
- Пользователь без прав, гость: нет редакторских ссылок.
- При наличии промокодного url управление остаётся доступным и не оказывается в hero.
- Заглушка editor route показывает название именно редактируемой площадки в breadcrumbs.
- Existing UI Kit: `docs/specification/ui-design-system.md`, desktop/mobile, без новых стилей и дополнительного eyebrow.

Изменения для `dev`, не для production без приёмки.


## Уточнение 06.11.2026 — согласованный UX

- Для пользователя с правом редактирования площадки в контекстном меню Действия — одна прямая ссылка «Редактировать» на account.venues.edit (как прежняя иконка-карандаш).
- У пункта нет вложенных действий «Площадку» или «Промокоды».
- «Управление промокодами» не возвращается отдельной кнопкой на публичную страницу и не выводится отдельным действием в контекстном меню; дальнейший доступ к нему предполагается из единого редактора площадки.
- Удалить бессмысленный пункт-заглушку «Найти» из подраздела контекстных действий площадок (не влиять на каталог, поиск и фильтры).
- Старое описание ветки выше отражает предыдущую реализацию; эти требования имеют приоритет для актуального интерфейса.

## Уточнение 07.11.2026 — источники права и единый вход в ЛК

- Контекстный бар MSKBA App использует существующее одноуровневое действие «Редактировать» (компонент UI Kit **context actions**). Новых элементов, CSS, цветов и состояний не добавлять.
- Публичная страница площадки и зал/корт: для пользователя с **действующим контрактом площадки**, явно предоставляющим `VenuePermissionEnum::EDIT`, ссылка ведёт на `account.venues.edit`. Проверять право контрактным сервисом, а не объединённым флагом `canEdit`.
- Для подтверждённого суперадмина **без** такого контракта ссылка ведёт в Filament `VenueResource::getUrl('edit')`, и только при наличии серверного разрешения на бэкофисное редактирование площадок. При наличии обоих видов доступа приоритет у контракта; простой статус суперадмина не создаёт контракт.
- Пользователь без действующего контракта EDIT и без бэкофисных прав не видит пункт, даже если является первоначальным создателем площадки. Существующий переход после создания площадки на редактор не изменять.
- Единственный канонический список принадлежащих пользователю площадок — `/account/contracts/venues` внутри «Мои контракты». Дублирующую незавершённую страницу `/account/venues/{alias}` не показывать; старые прямые URL перенаправлять на список. Из списка «Открыть» и имя площадки ведут на публичную страницу.
- Breadcrumbs редактора: **Главная / Аккаунт / Мои контракты / Мои площадки / Название площадки**. Ссылки «Мои контракты» и «Мои площадки» ведут на канонические списки; не использовать дублирующий обзор. Тот же предок навигации используется для старых форм модерации, расписания и условий.
- В `mskba_app` редактор пока остаётся заглушкой; создание полноценной формы — отдельная задача #634. Обновление пути не означает готовность редактора.

### Регрессия
- Действующий/недействующий контракт EDIT, отсутствие контракта, суперадмин с правом Filament, гость; проверить публичную площадку и подстраницу зоны.
- Карточки в «Моих контрактах» не содержат ссылки на старую страницу `account.venues.show`.
- Breadcrumbs редактора содержат все канонические уровни с корректными URL.
- Изменения только для `dev`; production не затрагивать.
