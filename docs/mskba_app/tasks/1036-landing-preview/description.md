Отдельный GET /backoffice/content/catalog-landings/{landingId}/preview в действующем auth + can:manage-content контуре, дополнительный Gate в сервисе. Не выдаём открытый preview через query, не активируем запись и общий feature flag.

Обычное применение фильтров или сброс ведёт в обычный каталог, не редактирует посадочную.
- Явное уведомление о сохранённом предпросмотре; HTML и JSON preview private/no-store, X-Robots-Tag noindex/nofollow/noarchive. Не меняем robots.txt, sitemap, глобальное включение landings, внешние сервисы, БД и booking.

Визуальная приёмка отдельно: кнопка в Filament, обе темы, ширины 360/390/768/1440, корректные блоки и фильтры. Использованы существующие UI компоненты, предпросмотр не заменяет изолированную UI Studio.
