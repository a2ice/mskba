# 341. Единое добавление в избранное после входа

Общий native dialog обеих тем повторяет окно избранного страницы площадки (без eyebrow, штатная ручка, крестик и кнопка). Гостевой клик не записывает избранное; только явное «Войти» сохраняет одно действие в sessionStorage, отмена очищает его. После входа используется явный идемпотентный add; при успехе показано информационное окно. Существующие гостевые записи и claim сохранены. Удаление не меняет сценарий. Проверки: PHP-регрессии, CI, desktop/mobile обеих тем и повтор действия после входа. Визуальная приёмка не проведена.
