# 014 — Обязательное завершение онбординга на странице приватности

**Решение принято 2026-10-09.** Вместо шестого шага Wizard оставляем успешную регистрацию с переходом на /account/privacy/distribution. Никаких дополнительных шагов в самом Wizard. Аккаунт и пароль сохраняются обычным способом до настройки приватности.

## Серверный контракт

- Уже имеются поля personal_data_distribution_required_at и personal_data_distribution_setup_completed_at. Если первое заполнено, а второе ещё нет, ограничиваем доступ к защищённым маршрутам до завершения настройки.
- На защищённых web-маршрутах (auth) GET перенаправляем на страницу приватности, остальные запросы не исполняем. Для запросов ожидающих JSON возвращаем 409 с redirect_url.
- Разрешены страница настройки (GET/PUT), выход и публичные юридические страницы. Избегаем redirect loop.
- Повторный вход перенаправляет в онбординг с безопасно сохранённой конечной ссылкой.
- Никакой публичности по умолчанию. Можно завершить настройку с полностью закрытым профилем; согласие на распространение данных отдельно и только добровольно.
- Legacy-пользователи без обязательного признака не ограничиваются.

## Позднее, отдельная работа

Общие настройки: кто видит профиль (select), аватар (checkbox), поиск (select), сообщения (select), а также характеристики для игрока. Вариант «Моим связям» потребует нового backend ACL по подтверждённым отношениям команд, секций, тренеров и игроков: текущий selected_users — это ручной список ID, а не «Мои связи». Не создаём фиктивный UI.

## Проверка реализации 2026-10-09

Middleware EnsurePersonalDataDistributionSetupCompleted подключён после
ResolveCanonicalUserSession ко всей группе web. Он применяется к
авторизованным маршрутам auth, но не к публичным страницам:
GET, POST, PATCH и другие действия не выполняются до завершения
настройки. Страница privacy distribution (GET/PUT) и logout
являются исключениями. JSON возвращает 409 с redirect_url;
HTML — перенаправление 303.

AuthController.login при повторном входе направляет на privacy
и запоминает безопасную целевую ссылку. После успешного завершения
сервер обновляет состояние текущей сессии и возвращает пользователя
на изначально запрошенную страницу.

PersonalDataDistributionConsentService больше не предлагает заранее
публичные категории новым пользователям. При полном закрытии
профиля согласие на распространение не требуется. Основная кнопка
страницы для первичной настройки: «Завершить регистрацию».

PHPUnit: 47 тестов / 341 утверждение PASS (включая auth,
intended redirects, согласия, MSKBA App и новую защиту).
Тесты выполнены с CACHE_STORE=array, чтобы локальные
Redis rate-limit счётчики не влияяли на PHPUnit.

Реализация не добавляет вариант «Моим связям» — его нельзя
симулировать через selected_users. Отдельная будущая задача
должна определить ACL и проверить связь по бизнес-данным.

Функциональную проверку в пользовательском браузере и
визуальную приёмку необходимо провести перед коммитом.
