# #1039 — Управление SEO-посадочными в Filament

DEV ONLY. Зависимости #1066/#1067 merged. Раздел «Контент → SEO-посадочные страницы» использует стандартные Filament Resource/List/Create/Edit, Sections, Select, Toggle, CodeEditor (как BuilderPageResource), существующее право manage-content. Не вводит новый UI Kit или собственную вёрстку. Доступ к панели дополнительно регулируется действующими правилами Filament.

Поля: внутреннее название, ЧПУ, H1, активность; город и зависимый округ; тип/состояние/доступ/настроенная аренда; два HTML-текста; Meta Title/Description; флаги индексации/sitemap (по умолчанию false). Текст проходит ContentBodySanitizer при сохранении, метаданные пишутся в существующий PageSeoSetting с новым entity type и читаются PageSeoResolver. Сохранение записи/метаданных транзакционное, проверка Gate и server validation, уникальные ограничения БД, понятная ошибка дубликата. Удаление намеренно пока отключено (деактивация вместо потери ЧПУ/метаданных). Не меняем существующие права и SEO других сущностей.

Публичный URL, FAQ/перелинковка, визуальный редактор и интеграция каталога — следующий этап; HTML CodeEditor выбран как существующий безопасный паттерн первого этапа. Активность и флаги пока не публикуют и не индексируют страницу. Внешние сервисы, robots/sitemap и main не меняются.

Приёмка: feature tests editor permissions/HTML/shared metadata/duplicate; после dev deploy проверить меню, создание/редактирование, смену города, ошибки дублирования, сохранение черновика и метатегов. Визуальная проверка стандартного Filament отдельно, публичный UI требует UI Studio по принятому регламенту. Не считать CI визуальной приёмкой.
