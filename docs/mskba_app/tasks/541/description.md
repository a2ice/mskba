# 541 — Публичные лиги и сезоны (первая итерация)

Продолжение PR #540. Выполняется в изолированной feature-ветке; до пользовательской приёмки админки не вливать в dev.

- Пункт «Лиги» в основной навигации.
- Каталог /leagues с поиском и фильтрами по статусу и сезону.
- Страница лиги: логотип, описание, статус, сезоны, постоянные активные команды, опубликованные турниры.
- Страница сезона: лига, даты при наличии, команды, турниры.
- Не показывать draft лиги/сезоны, unconfirmed турниры, soft-deleted записи; архивы оставить публичными для исторических данных.
- Использовать существующие доменные модели League и LeagueSeason, маршруты команд и турниров.
- Адаптивные страницы и доступная клавиатурная навигация в дизайн-системе MSKBA.

## Отложенные баннеры
Позже предусмотрена широкая обложка отдельно от логотипа/аватара для лиг, сезонов, команд, турниров, площадок и потенциально игроков. Кроп-редактор должен поддерживать загрузку, масштабирование, позиционирование и превью. Неизменный оригинал и параметры кропа хранятся отдельно; производные изображения генерируются по необходимости. Баннеры не реализуются в этой задаче.

## Приёмка
CI и тесты, проверка 404 для чужих/черновых сезонов, отсутствие публикации черновиков, архивные страницы, работа фильтров и ссылок, UX desktop/mobile, пустые состояния. До приёмки админки PR остаётся черновиком. Production не трогать.
