# 541 — Публичные лиги и сезоны (первая итерация)

Продолжение PR #540 и реализация публичных страниц после приёмки административных разделов лиг/сезонов. Изменения в изолированной ветке до зелёного CI.

- Пункт «Лиги» в основной навигации.
- Каталог /leagues с поиском и фильтрами по статусу и сезону.
- Страница лиги: логотип, описание, статус, сезоны, постоянные активные команды, опубликованные турниры.
- Страница сезона: лига, даты при наличии, команды, турниры.
- Не показывать draft лиги/сезоны, unconfirmed турниры, soft-deleted записи; архивы оставить публичными для исторических данных.
- Использовать существующие доменные модели League и LeagueSeason, маршруты команд и турниров.
- Адаптивные страницы и доступная клавиатурная навигация в дизайн-системе MSKBA.

## Баннеры
Общий медиасервис баннеров реализован в PR #545 и уже объединён с `dev`. Публичные страницы лиг и сезонов теперь показывают отдельно от логотипа баннер 3:1, если он загружен. Собственнику доступны ссылки на страницы управления баннерами лиги и сезона; управлять ими также можно в бэкофисе по соответствующим permissions. Оригиналы и параметры кадрирования хранятся отдельно.

## Приёмка
CI и тесты, проверка 404 для чужих/черновых сезонов, отсутствие публикации черновиков, архивные страницы, работа фильтров и ссылок, UX desktop/mobile, пустые состояния. Публичный PR объединять только после зелёного CI. Production не трогать.
