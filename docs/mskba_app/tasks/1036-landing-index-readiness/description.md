# #1036 — Редакционная готовность к индексации

DEV ONLY. После #1111 в существующей кнопке «Проверить выборку» добавляется SEO-чеклист сохранённой записи. Проверка только для manage-content; ничего не публикует и не изменяет.

Пункты: активность, непустая гостевая выборка, непустой текст над и под каталогом (после очистки HTML и пробельных символов), индивидуальные Meta Title / Description из PageSeoSetting, сохранённый флаг разрешения индексации. Отдельно показывается запрошенное включение в sitemap; это необязательный независимый флаг. Ориентир в 3 площадки остаётся рекомендацией. Заполненные поля не доказывают качество/уникальность текста и соответствие спросу; нужна редакционная приёмка.

Фактические meta robots и sitemap не меняются: все посадочные остаются noindex независимо от флагов и исключены из sitemap. Тесты в обеих темах на симулированных production/dev HTTP host, без сетевых обращений; dev X-Robots-Tag сохраняется. Будущий отдельный release gate — согласование владельца, проверка фактических production данных, активной непустой релевантной подборки, чистого canonical URL, отсутствия произвольных фасетов/черновиков и сохранение запрета dev; явное решение о включении. Никаких внешних отправок sitemap/индексации. Не меняем production, booking и БД. Стандартное уведомление Filament, без новых публичных компонентов. CI и ручная проверка уведомления после dev deploy.
