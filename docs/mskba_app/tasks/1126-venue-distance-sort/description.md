# #1126 — Сортировка площадок по удаленности

DEV ONLY; актуальный шаблон mskba_app, все его темы. Переиспользуются Modal 1.1, существующий catalog-toolbar и механизм getCurrentCoordinates. Новые стили, цвета и изменения общего UI Kit не нужны. В legacy-шаблоне, где нет этого меню, новый попап не подключается.

- После фактического получения координат от браузера (в том числе при уже выданном разрешении) показывается «По удаленности» и однократное предложение.
- «Да, отсортировать» сохраняет ответ и применяет sort=distance; «Сам решу-у» (также Escape) сохраняет ответ и открывает существующее меню. Обе кнопки используют текущие применённые фильтры, не отправляют черновик фильтров автоматически.
- Координаты в серверной сессии, стабильный порядок при пагинации, без передачи координат сортировки в URL/профиль. Выбор сохраняется в аккаунте или гостевой сессии.
- При отказе/недоступности геолокации штатный каталог работает; сортировка при отсутствии координат по названию. Сортировка не включает и не изменяет радиус.
- Приёмка: guest/user, отказ/разрешение/повторный визит, обе кнопки, открытие меню на desktop/mobile, список/карточки/SEO-коллекция, остальные фильтры, объекты без координат, вторая страница/fragment, отсутствие координат в URL. Светлая и тёмная темы, 1440/768/390/360, клавиатура и Escape. Визуальная проверка не заменяется CI.
