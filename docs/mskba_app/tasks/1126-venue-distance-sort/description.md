# #1126 — Сортировка площадок по удаленности

DEV ONLY; актуальный шаблон mskba_app, все его темы. Переиспользуются Modal 1.1, существующий catalog-toolbar и механизм getCurrentCoordinates. Новые стили, цвета и изменения общего UI Kit не нужны. В legacy-шаблоне, где нет этого меню, новый попап не подключается.

- «По удаленности» всегда видна в меню, независимо от разрешения. Геолокация запрашивается только при её выборе; при отказе, таймауте или недоступности открывается тот же адресный/картографический попап, что в фильтре «Рядом со мной».
- Подтвержденная точка (геолокация или ручной адрес/карта) заменяет origin сортировки в сессии; закрытие попапа без выбора оставляет прежнюю сортировку. Радиус и черновые фильтры не меняются; применённые фильтры сохраняются.
- Автоматический запрос и предложение «Да, отсортировать» / «Сам решу-у» сохранены, но отключены через data-auto-prompt="0". Сохранение прежнего ответа в БД/сессии не удаляется.
- Приёмка: отсутствие запроса при загрузке, выбор сортировки с разрешением/отказом, ручной адрес/карта/отмена, смена точки, независимость радиуса, пагинация, SEO-коллекции, mobile/desktop и обе темы. Без координат сортировка не активируется. Визуальная проверка не заменяется CI.
