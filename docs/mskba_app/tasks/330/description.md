# Задача 330 — Пароли: восстановление и управление (18.11.2026)

## Интерфейсы и требования
- Форма «Забыли пароль?» в общем Vue-диалоге авторизации: ввод выбранного ранее подтверждённого email или Telegram @username, единый публичный нейтральный ответ без раскрытия данных аккаунта; не создавать новый UI-паттерн и не показывать чужие контакты.
- ЛК → Настройки: самостоятельный блок «Пароль и безопасность» в действующей системе panel / app-settings-panel с метками, ошибками под полями, одной основной кнопкой. Для первого пароля без текущего; для смены с текущим.
- Filament → Пользователи → Редактирование: действие в заголовке с модальной формой, только подтверждённый superadmin, ввод собственного пароля для авторизации действия, два поля нового пароля, основание.

## Безопасность
- Общий PasswordVO для всех операций, синхронизация канонического аккаунта и связанных идентичностей.
- Запрет отправки неподтверждённым контактам, отсутствие сброса без SMTP/открытого приватного чата Telegram.
- Ограничение частоты запросов, нейтральный ответ о восстановлении; в аудит не попадают пароли.
- Во всех случаях менять remember_token; временный пароль после восстановления и действий superadmin.

## Приёмка
- Email / Telegram с подтверждением: смена только при принятой доставке, пользователь получает временный пароль.
- Неизвестный / неподтверждённый / неоднозначный контакт и заблокированный пользователь: старый пароль сохраняется.
- Пользователь может установить/сменить пароль в публичной части; администратор без роли superadmin не может установить его в Filament.
- Регрессионные тесты + CI, затем стандартный production deploy.
