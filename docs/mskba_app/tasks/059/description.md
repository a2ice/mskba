# 059 — Третья вкладка игрока «Игровые показатели»

## Цель и критерии приёмки
Перенести блок объективных показателей из «Игровые характеристики» в `/account/participation/player?tab=metrics`; оставить самооценку на game. Поддержать `tab=physical|game|metrics`, desktop/mobile навигацию и ACL; не смешивать объективные статистики с самооценкой.

## Технические границы
Серверный GET и существующие агрегаты без дублирования запросов; режимы пустых данных.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
Зарегистрирована, ожидает приёмки предшествующих задач.
