# Рейтинг площадки — выравнивание по первой строке

Целевая ветка: dev.

На публичной странице площадки и игровой зоны звезда и числовой рейтинг выравниваются по вертикальному центру первой строки H1 независимо от количества строк названия. Размер обоих элементов уменьшен на 25% относительно прежнего размера (на широком экране 44 → 33 px для числа); минимальная интерактивная область 44 × 44 px сохранена. Заполнение звезды, скрытие числа при отсутствии оценок, открытие попапа и авторизация не изменяются.

Проверка: одно- и многострочные названия, рейтинг 5.0 и отсутствие рейтинга, мобильная и десктопная ширина, открытие попапа оценки.
