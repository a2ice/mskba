# Добавление площадки: inline-валидация, крестик и метро — 14.11.2026

- Кнопка очистки адреса центрируется вертикально с помощью top:50%/translateY(-50%), а полю оставлено место справа.
- Для общей формы на странице и в диалоге создания площадки показываем inline-сообщение под каждым обязательным полем (включая зал/корт), aria-invalid, aria-describedby, красную границу и фокус/скролл к первой ошибке. Нативные ограничения HTML5 сохранены.
- При input/change снимаем конкретную ошибку и красную границу. Принятие адреса из подсказок или геолокации также сбрасывает ошибку. Без выбора подсказки отправка запрещена.
- Ошибки 422 от Laravel сопоставляются с фактическими полями; серверную проверку адреса, прав, дублей и условий не изменяем.
- Метро отображаем как существующий app-venue-metro__chip с круглой точкой цвета линии; источник цвета — проверенный lineColor (option data-line-color). В старой теме текстовый вывод не меняем.
- Проверить desktop/mobile, обязательные поля, ошибку адреса, ручное исправление, несколько линий метро и случай без метро.
