# 336 — Единое создание мероприятий и обсуждение в теме MSKBA App

**Дата:** 18.11.2026. **Статус:** интеграция в задаче 336, см. ../../../../docs/tasks/336/description.md.

## Сценарии

- Из каталога мероприятий кнопка «Создать мероприятие» открывает нативный диалог.
- Из страницы площадки этот же диалог открывается из боковой панели и общего выбора «Хочу здесь играть». Площадка установлена автоматически, но не заблокирована и может быть изменена.
- Гость видит вход/регистрацию и переход в штатный wizard; авторизованный пользователь — поля типа, названия, площадки, даты и времени, длительности, формата, лимита, публичности и описания. Текущий backend тот же, что и для полного создания.
- Клик снаружи закрывает диалог только при нажатии и отпускании на фоне. Значения не сбрасываются после закрытия и открытия в рамках текущей страницы. Клавиатура и Escape работают штатно.
- Селекты и кнопки используют стандартные классы и переменные тем; корректный responsive на телефонах, без потери breadcrumbs/sidebar/header/footer.
- На странице площадки отдельным списком показываются также будущие публичные Event без подтверждённой брони, но без окрашивания расписания как занятого.
- На странице самого мероприятия остаются штатные блоки и добавлены вкладки обсуждения и истории; ответ на участие отражается в счётчиках и истории, авторские удалённые сообщения остаются зачёркнутыми.

## Приёмка

Две точки входа, предвыбор площадки, открытые/приватные типы, сохранение формы при закрытии, ограничения 3/60 и 200 символов, защита гостевого/чужого чата; адаптивность 320–1920 px, сохранены стандартные элементы. Не создавать новую «группу интересов» с выборами администратора, не резервировать слот самим появлением Event. Тесты + зелёный CI до merge.

- Для mskba_app штатная обёртка select-control и chevron вокруг нативных селектов; тип/формат изменяют только соответствующие поля; публичная игра с отключёнными заявками не рассылается подписчикам.

- Короткий попап содержит явную ссылку «Расширенная форма» на прежний полный мастер, чтобы команда, Telegram и другие специализированные параметры не исчезли из доступного UI.
