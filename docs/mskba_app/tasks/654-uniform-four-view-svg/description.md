# Task 654 — Четыре SVG-ракурса формы MSKBA

## Контекст и референс

Существующая мастерская работала как двумерный схематичный рисунок формы с
захардкоженными «MSKBA» и «33». Референс пользователя (09.11.2026) задаёт
пропорции баскетбольного комплекта: майка без рукавов, U-образная горловина,
обработанные проймы, боковые панели, нижний подол, самостоятельные шорты с
эластичным поясом, двумя штанинами и небольшим номером на передней штанине.
В перспективе будет 3D, но текущий визуализатор должен оставаться SVG.

## Требования

1. Один живой SVG-предпросмотр, четыре ортографических ракурса:
   спереди, левый бок, правый бок, сзади. Правый бок использует
   отражённую геометрию левого, чтобы форма не имела несогласованных швов.
2. Пустой комплект по умолчанию — светлый серо-голубой без логотипа
   и вторичного цвета; новая модель не содержит служебных букв MSKBA.
3. Основной цвет обязателен, вторичный опционален. Контрастная отделка
   используется только по выбору пользователя. Номер 01–999; номер на
   майке и в меньшем размере на передней штанине. Автоматический контраст
   и ручная настройка цвета номера, обводки и её цвета.
4. Логотип является частью конфигурации формы: на груди маленький,
   на стороне носителя слева/справа (или нет); на спине над номером /
   под номером (или нет). Для аватара спереди запрещено показывать
   логотип, размещённый исключительно на спине.
5. Список размеров XS–XXL сохраняется; отдельный выбор размера
   масштабирующего предпросмотра работает без искажения пропорций.
   Рукава отключены до разработки отдельной выкройки.
6. Сохранить совместимость личных проектов, гостевого черновика,
   единой мастерской страницы, модального окна и коллекции.
7. Миграция, API-валидация и тесты; цвета и положение лого при
   AI-генерации личной формы берутся из её сохранённой конфигурации.

## UI и ограничения

Используются существующие цвета дизайн-системы, диалог, поля, карточки и
кнопки MSKBA App. Визуализатор остаётся чистым SVG (без bitmap внутри
контура формы и без новых runtime-зависимостей). Поверхностей/свечения
3D нет. Цель — аккуратный **художественный референс**, а не производственная
выкройка или обещание пиксельного совпадения с низкоразрешённой картинкой.

## Acceptance

- Все 4 ракурса переключаются мгновенно; размеры XS и XXL различимы;
  на мобильном нет переполнения/неактивных кнопок.
- Вторичный цвет можно снять. Контраст номера читаем на тёмной/светлой
  ткани и при включении/выключении обводки.
- 1 рендерится как 01, 9 как 09, 999 как 999; 0 и 1000 отвергаются API.
- Позиции логотипа показываются в соответствующих ракурсах;
  отсутствующий логотип не создаёт заглушки.
- Создание/редактирование проекта, повторное чтение, коллекция и
  гостевой черновик сохраняют новые настройки.
- CI, PHP lint, Vite build и feature tests проходят.
- Слияние только в dev; main/prod без изменений.
