# Единая тарифная сетка площадок и залов (23.11.2026)

## Задача и принятые решения

Нужен один визуальный редактор для Filament и кабинета владельца площадки, поддерживающий одновременно ручные и интегрированные тарифы. Диапазон — только визуальное объединение соседних минимальных тарифных шагов (RTC), а не новая независимая тарификация. Источник истины для расчёта: существующие цены по слотам, с отдельным слоем ручных переопределений для зала. Кнопки и формы используют существующую UI Kit палитру/контролы; всплывающий редактор не пересоздаёт независимые условия аренды.

## Интерфейс

1. Выбор площадки или зала и режима «недельный шаблон / конкретная дата».
2. Цена и источник каждого временного шага; соседние шаги с идентичными ценами группируются в раскрываемые диапазоны.
3. Из раскрытого диапазона можно изменить ровно один шаг через диалог. Массовый редактор задаёт интервал, дни недели, стоимость целого/половины зала и исключения внутри диапазона.
4. Очистка ручного переопределения возвращает унаследованный или импортированный тариф.
5. Filament → Площадки → Аренда / Залы → «Тарифная сетка» и кабинет площадки ведут в **одну** страницу с общими серверными контроллером и компонентом. Нет расходящихся интерфейсов.

## Данные, приоритет и защита импорта

- Weekly venue: venue_schedule_slot_prices; date venue: venue_calendar_slot_prices.
- Weekly/date court source: venue_court_slot_prices, venue_court_calendar_slot_prices (включая импорт).
- Manual court: venue_court_manual_slot_prices (day_of_week или date). **Эти записи не изменяются повторным применением снимка интеграции**.
- Разрешение эффективной цены: manual court date → manual court week → court calendar → court week → court base → venue calendar/week → venue base; минимальная платная стоимость площадки соблюдается.
- Для недельного шаблона и календаря все изменения записываются в минимальные слоты. Ограничение шага, цена ниже минимума, дублирующиеся исключения, права на управление и принадлежность зала проверяются на сервере. Запись атомарная, синхронизация работает независимо.
- Текущие подтверждённые бронирования и неизменяемые сохранённые расчёты не переписываются.

## Acceptance

1. Импорт с последовательными ценами 2 000 / 2 000 / 2 500 / 2 000 ₽ отображается диапазонами и локальным исключением; сохранение диапазона записывает правильное число шагов.
2. Повторный импорт заменяет исходные цены, но ручная корректировка остаётся, видна в попапе расписания и quote; очистка возвращает актуальное значение источника.
3. Выбор дня недели/даты, минимального шага и ограничения нижней цены.
4. Доступ владельца/управляющего к разрешённому залу; 403 при попытке редактировать чужую площадку.
5. UI проверен в обеих темах и по текущему MSKBA App UI Kit. После merge автоматический CI и main-deploy, если он разрешён конфигурацией окружения.
