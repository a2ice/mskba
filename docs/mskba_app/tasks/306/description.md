# Task 306 — фильтрация площадок по условиям конкретных залов

## Цель
Для площадки с крытым платным залом и бесплатным уличным кортом фильтр «Бесплатно» должен находить площадку, но вести посетителя на конкретный бесплатный корт.

## Backend
- Единый `VenueCourtDiscoveryAccess` агрегирует активные залы с `EffectiveCourtPolicy`.
- Категории `free`, `paid`, `approval` независимы; площадка может попадать в несколько.
- Неизвестная настройка оплаты не приравнивается к `false` — отдельно `unknown`.
- Закрытые или удалённые залы не должны считаться доступными.
- Ссылки формируются на public court routes; при нескольких совпадениях выбирается первый по порядку залов.
- Нет денормализованной копии флагов на Venue; не менять ценообразование и логику бронирования.

## UI Kit / интерфейс
- Используются существующие карточки каталога `catalog-item.blade.php`, классы `venue-catalog-item__access`, действующие icon classes и штатные ссылки; без новых CSS, цветов, модальных окон и layout primitives.
- На общей карточке, если условия смешаны, отображаются нейтральные подписи «Есть бесплатный доступ» / «Есть платные залы»; подтверждение и предварительная запись не смешиваются с оплатой.
- При фильтре «Бесплатно», «Платно» или «По подтверждению» карточка, CTA и balloon карты ведут прямо на выбранный подходящий зал, рядом указывается его название.
- Не дублировать информацию в картографическом JS: HTML-пэйлоад задаётся сервером, JS экранирует вывод и отображает подготовленную ссылку.

## Приёмка
- Школа №1794: уличный корт бесплатно, без записи и подтверждения; крытый платный с подтверждением.
- Площадка находится по фильтрам free и paid, соответствующие ссылки ведут на разные залы.
- Карта каталога и карточки/список совпадают.
- Перестановка залов, наследование nullable, ручное переопределение, закрытие, один зал, неизвестная оплата, user access.
- Feature/API/Blade tests, PHP/Vite, PostgreSQL 16/17, desktop/mobile визуальная приёмка.

Границы: главная карта / общий поисковый API / Telegram Mini App остаются в issue #624; эта задача ограничена `/venues` и картой каталога.
