**Статус:** на визуальной приёмке локально (2026-10-13). **Процесс:** без commit/push до визуальной приёмки.

## Согласованные изменения

- Модалка заявки об изменении подтверждённых данных: заголовок «Изменение данных», селектор по общему `select-control`, одна основная кнопка «Отправить заявку» и вторичная «Отмена» в неподвижном footer, без изменения маршрута, CSRF, native validation и данных формы.
- Группа sidebar «Мой MSKBA» → «Участие», через общий `AccountMenu`, без копирования в шаблоны или смены ссылок/доступов.
- Страница `/account/contacts`: вместо видимой текстовой метки канала Email/Telegram/VK/Телефон и префикса «:» — соответствующий значок из Tabler Icons Outline 3.46.0; для screen reader канал сохраняется в скрытой текстовой метке. Для типа OTHER — общий значок контакта.
- Исправить по приёмке #031 реальный success modal: единый зелёный градиент в правом нижнем углу, убрав конфликт старого CSS-фона; не изменять логику регистрации контакта.
- Не затрагивать `mskba_dark`, бизнес-логику, деплой или посторонние незакоммиченные изменения.
