# Площадки · Filament · Расписание и создание

## Интерфейс

- Общая неделя: один набор интервалов по умолчанию для Пн–Вс.
- Исключения по дням недели: указывается конкретный день; можно заменить интервалы или пометить выходным.
- Исключения по датам остались прежними и имеют приоритет над недельными.
- При редактировании существующих площадок наиболее частый график за семь дней становится базовым, все отличающиеся дни — исключениями.
- Дополнительных таблиц или миграций нет: перед сохранением набор разворачивается в существующие `venue_schedule_intervals`.
- Старый код, вызывающий `VenueBackofficeEditor::save()` с `weekly_intervals`, продолжает работать.

## Создание площадки

- Один первичный «Зал 1» уже создаётся автоматически при создании любой площадки, в том числе уличной; ручное добавление для создания не требуется.
- Для ошибок валидации на вкладках create/edit выводится постоянное уведомление с причиной вместо неинформативного отсутствия реакции.
- Проверены в тестах разворачивание расписания, исключения, обратное заполнение, создание без расписания и наличие единственного первичного зала.
