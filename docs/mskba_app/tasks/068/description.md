# MSKBA App 068 — изображения ракурсов лица вместо SVG

**Дата:** 30.10.2026. **Цель:** /account/participation/player, блок «Фотографии лица для генерации».

## Изменение

Вместо временных SVG-контуров используются существующие PNG-файлы из `public/images/blank/avatar/`:

- анфас: `front-male.png` / `front-female.png`;
- слева: `left-male.png` / `left-female.png`;
- справа: `right-male.png` / `right-female.png`.

В зависимости от сохранённого `personalProfile.gender` страницы игрока загружаются ровно три изображения одного пола. При отсутствии сохранённого значения сохраняется действующее визуальное поведение `Appearance::normalizeGender` — изображение male по умолчанию **без записи пола в профиль**.

PNG отображаются внутри существующих светло-голубых круглых кликабельных областей. Файловые input, подписи ракурсов, клавиатурный фокус, отображение имени выбранного файла и галочка выбранного файла остаются работоспособными. Серверные требования «анфас + хотя бы один профиль» не меняются.

## Критерии приёмки

1. У игрока с мужским полом отображаются `front-male`, `left-male`, `right-male`.
2. У игрока с женским полом отображаются `front-female`, `left-female`, `right-female`.
3. Нет SVG-заглушек, масштабирование и круглые рамки сохранены.
4. По нажатию на любой ракурс открывается загрузка файла, после выбора отображаются имя и галочка.
5. Сгенерированные аватары и основная фигурка слева не затронуты.
6. Полный CI → merge `dev` → подтверждённый SSH-деплой, без изменения `main`/production.
