# 043 — Две темы оформления MSKBA App

Статус: локальная реализация, проверка / визуальная приёмка впереди (2026-10-15).

## Контракт

- Единый renderer mskba_app и общие Blade/Vue компоненты. Палитры только CSS custom properties; никаких копий страниц.
- Системные arena_night («Ночная арена») и court_day («Светлый паркет»), неизменяемый slug, запрет удаления; системные темы нельзя снять с публикации.
- Filament → Дизайн → Темы оформления: создание, визуальные цвета, редактор переменных, preview, публикация и глобальная тема. История версий сохраняется автоматически, восстановление доступно менеджеру и само создаёт обратимую ревизию.
- Разрешения backoffice.theme.view / backoffice.theme.manage совместно с backoffice.access.
- Общая тема для гостей/пользователей без личного выбора. Личный выбор хранится у canonical identity, смена CSS без reload.
- Сервер выбирает тему до первого paint; CSS выдаётся версионированным URL с immutable cache.
- Валидируются HEX палитра и содержимое CSS: только один :root, переменные, без глобальных селекторов, URL и импортов.
- CSS компонентов обновляется через токены и общие light-mode адаптации. Нельзя нарушить top-layer modal и работу чатов.
- Локальная ветка feature/design-theme-manager-20261015, основание origin/dev a4abae34.

## Приёмка

- Миграция: встроенные темы, одна глобальная, nullable user preference, rollback.
- Filament: полномочия, CRUD, защита системных тем.
- User flow: guest, personal choice, default, disabled custom fallback.
- Desktop/mobile 320/390/768/1440, формы, сообщения, поповеры, модалки, header.
- Тесты PHP, Vite и реальный браузер. До визуальной приёмки статус не «Принято».
- Никаких push, PR, merge, deploy без отдельной команды.

## Premium refinement — Apple-inspired typography (2026-10-15)

Визуальная приёмка владельца **ещё впереди**; референс — принципы Apple Human Interface Guidelines, не копирование фирменной графики.

- **Основная светлая тема сохраняет Inter** до решения владельца. В Filament → Дизайн → Темы → Предпросмотр светлой темы можно мгновенно сравнить Inter, Onest и Manrope с кириллицей и включить/отключить лёгкий градиент крупного заголовка. Переключатели действуют только в предпросмотре и не пишут в базу.
- Self-host: `Onest MSKBA` (100–900) и `Manrope MSKBA` (200–800), WOFF2 Latin/Cyrillic, `font-display: swap`, настоящий локальный импорт Vite без CDN. Исходные файлы из Fontsource/font-files; отдельные лицензии SIL OFL 1.1 в `resources/themes/mskba_app/assets/fonts/premium/`.
- Деликатный холодно-графитовый градиент текста — только выбранные крупные заголовки разделов h1 и отдельные h2. Небольшие заголовки карточек h3, hero над фото и все обычные подписи остаются однотонными; `prefers-contrast: more` / forced-colors выключают градиент.
- Небольшой эффект полупрозрачного стекла — только шапка, контекстная навигация и выпадающие меню; контентные карточки по-прежнему белые и непрозрачные. При `prefers-reduced-transparency` подложка становится непрозрачной. Все эффекты ограничены `[data-appearance-mode="light"]` и не меняют «Ночную арену».
- В редактируемой группе CSS-токенов Filament появились `--light-display-font-family`, `--light-display-gloss-top`, `--light-display-gloss-bottom`, `--light-premium-chrome`, `--light-premium-menu`, `--light-premium-blur`, `--light-premium-shadow`.
- Миграция `2026_10_15_233000_add_court_day_premium_tokens.php` добавляет только отсутствующие параметры и оставляет индивидуальные исправления администратора без изменений; создаёт версию истории и безопасна при повторном запуске.
- Чеклист: build Vite и URL локальных шрифтов; Filament preview 390/768/1440; русские и английские заголовки; focus, модальные окна, меню и reduced-motion; тесты CSS / миграции / разрешений. После CI — автоматический deploy dev, не main/prod.

Источники вдохновения и открытых ресурсов: Apple Human Interface Guidelines, Fontsource Onest/Manrope. UI-иконки остаются принятой коллекцией Tabler; декоративные 3D-иллюстрации вынесены в отдельную потенциальную задачу.


## Theme controls: fonts, satin-metal context bar, sidebar palette and widget glow (2026-10-16)

- Filament → Дизайн → Темы: штатные Select для **основного текста** и **заголовков** у каждой темы. Доступны Inter, Onest, Manrope, Golos Text, Commissioner и Rubik; все лицензии SIL OFL и локальные Latin/Cyrillic WOFF2 включены в ресурсы.
- Отдельная группа цветов **бокового меню** (фон, текст, hover, активный фон/текст). Цвета не привязаны к общей палитре карточек; начальная светлая схема бело-серо-оранжевая. Тёмная тема по умолчанию сохраняет старый внешний вид и может использовать новые настройки при ручном выборе.
- Цвет и интенсивность **боковой подсветки виджетов** задаются у темы; индивидуальный `gradient_color` виджета по-прежнему имеет приоритет. Светлая тема восстанавливает `--surface-corner-layer` и использует слабый голубой фон `#BCDDF6` с альфа 20%, белая основная поверхность не заменяется.
- Контекстная панель под header — сдержанный серый сатин-металлик, полупрозрачный с размытием в обычном режиме; выпадающие меню оформлены аналогично. При `prefers-reduced-transparency: reduce` применяется полностью непрозрачный, но визуально различимый серый градиент. Настройки доступности не переопределяются.
- Предпросмотр темы: системный HTML-select заменён на стилизованный MSKBA dropdown (button + listbox; Enter/Escape/Arrow/Home/End/Tab, focus ring и click-outside).
- Хранение: поля цветов, шрифтов и glow в `design_themes` и `design_theme_revisions`, при изменениях создаётся ревизия, восстановление включает все параметры. URL версионного CSS меняется при обновлении. Удаление двух системных тем по-прежнему запрещено.
- Проверки: новые тесты рендера CSS/истории/предпросмотра/лицензий/миграций, полный CI, Vite, деплой на `dev`. `main` / production без изменений.
