# #1171 — Рейтинг карточек и двухнаправленная сортировка площадок

[Issue #1171](https://github.com/a2ice/mskba/issues/1171). DEV first. База 69817974e24b7a7251e8f3d118833b6f8279d057.

## Контракт
- Общий nullable rating по опубликованным отзывам площадки, включая карточки её зон. Одна десятичная цифра, прочерк без оценок, белые цифры на rgba(0,0,0,.25), 42×42px, левый верхний угол симметрично сердцу. Общий Blade partial и CSS. Каталог, соседние/похожие зоны, legacy, популярные на главной, данные и renderer карточки карты. Не менять глобальные кнопки избранного.
- Рейтинг / Название / Опубликовано / Удалённость. Название применяет текущее направление, треугольник переключает направление и сразу применяет; title описывает действие, вертикальный разделитель, активный ряд. Рейтинг первым, начальное направление по убыванию; default каталога по-прежнему название А–Я. Направления по условию запоминаются в sessionStorage после применения.
- Старые URL new/name_asc/name_desc/distance и новые old/rating_asc/rating_desc/distance_desc; Опубликовано пока использует created_at, отдельная дата первой публикации отсутствует. Подсказка «Сначала более ранние». Без координат/рейтинга в конце в обоих направлениях. Фильтры и вид сохраняются, сортировка до пагинации. Оба действия удалённости — прежняя геолокация по явному действию и ручной fallback.
- Общий toolbar opt-in только для площадок MSKBA App; другие каталоги не меняются. Рейтинг legacy поддержан; legacy-меню не изменялось.
- Публичные оценки читаются из БД агрегатом, без кеширования оценки в поисковом документе. Никаких миграций, изменений записи оценок или модерации.

## Приёмка
- PHP: рейтинги из опубликованных отзывов, оба направления, null в конце и вторая страница, старые sort URL, дата, расстояния.
- JS: обратная удалённость, отказ/ручной выбор, отмена, сохранение фильтров.
- Визуал на dev: 360/390/768/1440, светлая/тёмная палитры, карточки рядом/похожие/главная и карта, название и направление сортировки, sticky toolbar, клавиатура и подсказка. Изолированная визуальная приёмка пока не подтверждена; CI не заменяет браузерную проверку.
- Полный зелёный CI → merge только dev → проверить автодеплой и UI. Main не трогать.
