# 060 — Фильтры кабинета: «Найти» и «Сбросить»

## Цель и критерии приёмки
На `/account/subscriptions`, `/account/favorites` и подобных листингах привести формы фильтров к `/account/contracts`: отдельная кнопка «Найти», bordered/no-background «Сбросить», корректный submit, поиск, query-параметры, paginated response, адаптивность, доступность. Отмена фильтров не должна требовать reload там, где используется AJAX.

## Технические границы
Один общий стиль кнопки, без дублей селектов или endpoint.

## Процесс
CI (PHP, JavaScript, сборка frontend, PostgreSQL 16/17) → PR/merge в `dev` → проверка развёртывания → визуальная приёмка владельца. `main` не затрагиваем. Следующий этап выполняется после приёмки текущего.

## Статус
Зарегистрирована, ожидает приёмки предшествующих задач.
