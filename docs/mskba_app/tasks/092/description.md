# 092 — Совместимость печатной листовки с активной темой

Дата: 17.11.2026.

## Проблема

После перехода production с модуля `mskba_dark` на светлую тему `mskba_app` обязательная команда `acquisition:documents:smoke` останавливает релиз: в реестре печатных форм используется `theme::documents.acquisition-flyer-a4`, но Blade-шаблон листовки есть только в старой теме.

## Реализация

В тему `mskba_app` добавляется идентичная существующему доверенному шаблону `mskba_dark` копия `documents/acquisition-flyer-a4.blade.php`. Содержание листовки, вёрстка A4, палитра печатного артефакта и состав параметров остаются без изменений. На страницах сайта тема не меняется. Мы не добавляем fallback на внешние/редактируемые шаблоны и не отключаем обязательную диагностику PDF.

## Приёмка

CI/Blade/Vite зелёные; шаблон существует в обоих theme namespace; стандартный production deploy проходит реальную `acquisition:documents:smoke` с Gotenberg, затем HTTP, canonical/SEO и 51 исторический URL. Без изменений баз данных, прав пользователей и договорных записей. Дальнейшее выделение печатных шаблонов в общий namespace — отдельная задача и сейчас не требуется.
