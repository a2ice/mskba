# Аренда площадки — визард поиска по времени

Запрос 20.11.2026. Сначала дата и время МСК, опциональный диапазон; затем сводка и вкладки залов с привычным выбором слотов. На странице конкретного зала поиск предварительно ограничен им. Возврат сохраняет условия. Без eyebrow, общий Modal 1.1, Wizard 1.1, общий drag и scroll, footer с «Назад»; отдельный календарь при просмотре расписания остаётся без изменений.

Техническое ограничение: существующий PublicVenueDaySchedule принимает сегодня + 8 дней; не расширяем внешние интеграции и сетевую нагрузку в этой правке. Для одной даты ищем от указанного времени до конца дня. В диапазоне 23:59 означает включительно последний слот до полуночи (24:00 в API, 00:00 в UI). Все даты MSK. На смене даты на будущую время по умолчанию 00:00, при возврате на сегодня — исходный lead + 10 минут. Если default пересёк полночь — следующий день, 00:00, а реальные ограничения всё равно проверяет сервер.

Прайм: будни 18–22, выходные 10–21; сводка учитывает минутную долю реально бронируемых непрерывных интервалов и UNKNOWN/stale. Остаток ночных слотов не считается большим выбором. Розовая плашка группирует только непрерывные booked, не смешивает их с неизвестными. Реальный quote и booking остаются прежними. Пакетный read-only запрос на один зал — максимум 9 дней; ответ содержит только поля для сводки. При переключении дня/зала — свежий запрос полного расписания.
