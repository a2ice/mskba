# UI самостоятельной предзаявки аренды

Согласованный пользователем сценарий задачи [323](../../../tasks/323/description.md).
Новые общие визуальные примитивы не вводятся.

Использованы контракты [UI Kit](../../../specification/ui-design-system.md#интерактивный-ui-kit-тем-оформления--2026-10-19)
и раздела [компоненты и состояния](../../../specification/ui-design-system.md#компоненты-и-состояния):
`button primary/secondary`, `panel`, `field-group`, существующая композиция
`app-rental-pricing` и `app-rental-inbox`. Селекторы зала/области и календарь
переиспользуют существующую публичную quote-форму. Собственных select/CSS/modal
нет. Для mskba_dark используются её `btn`, `form-control`, `card`,
`venue-management-actions`; новая тема туда не переносится.

Действие «Предзаявка» отправляет выбранные параметры отдельному endpoint через
formaction; обычный расчёт и отправка брони сохранены. Есть заметка, пояснение
об отсутствии резервирования, список своих/доступных предзаявок, диалог,
приватные файлы, согласие/отказ и переход к обычной брони. Read-only пользователь
не получает форму сообщения, а пользователь без booking grant — предложение.

Визуальная приёмка **не выполнена**: нет рабочего Laravel runtime после отказа
установки зависимостей. До release проверить обе темы на 1440/390/360, длинные
имена/сообщения, keyboard focus, ошибки формы, права readonly, выбор зала и
календаря, обычный quote/booking, загрузку/скачивание файла. PHPUnit не заменяет
эту проверку. Модальные окна и CSS вне scope не изменялись.
