# Задача 070 — логотипы команд в таблице Filament

**Основание:** После успешного dev deploy предыдущих исправлений пользователь сообщил, что в таблице «Контент → Команды» не отображаются логотипы.

## Причина
В `TeamResource::table` `ImageColumn` получает `$record->logo?->publicUrl()` (готовый URL `/storage/teams/...`), хотя Filament обрабатывает state как storage-relative path и повторно строит ссылку через Storage. Из-за этого итоговый src не ведёт к реальному изображению.

## Решение
- Передавать `logo.path` (относительный путь в публичном disk) в `ImageColumn`, а не готовый URL.
- Явно использовать `->disk('public')`, показать нейтральную заглушку при отсутствии логотипа.
- Существующий `BackofficeTeamLogo` и его способы загрузки/удаления не менять.

## Критерии
1. Сохранённый WebP `teams/{id}/{uuid}.webp` отображается в таблице через URL `/storage/teams/...`.
2. При отсутствии логотипа видна заглушка, не иконка сломанной картинки.
3. В редакторе логотип продолжает работать.
4. CI зелёный, затем merge и подтверждённая выкладка на dev, production не затрагивать.
