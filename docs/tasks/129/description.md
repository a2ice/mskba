# 129 - Компактный выбор цветов и фон команды

## Оригинальное описание

Доработать настройки цветов команды: заменить широкие colorpicker на маленькие квадратные элементы, кнопку сохранения переименовать в «Применить», а действие сброса сделать компактной квадратной кнопкой с крестиком.

После успешного сохранения домашних цветов внешний фон страницы настроек команды должен использовать горизонтальный градиент от основного домашнего цвета к дополнительному домашнему цвету. Верхняя область под шапкой, breadcrumbs и действием «Назад» должна сохранять тёмный фон с запасом, чтобы навигация оставалась читаемой даже при белых или очень светлых командных цветах.

## Реализация

- colorpicker имеет компактный квадратный размер `38×38`;
- рядом показывается текущее HEX-значение либо «Не задан»;
- сброс выполняется квадратной кнопкой `×` размером `32×32`;
- кнопка формы называется «Применить»;
- пустой colorpicker по-прежнему не сохраняет техническое значение `#000000`;
- внешний `.site-content` страницы настроек получает горизонтальный градиент `home_primary → home_secondary`;
- если задан только один домашний цвет, он используется с обеих сторон и фон становится однотонным;
- если оба домашних цвета отсутствуют, сохраняется стандартный фон портала;
- поверх командного фона добавлена тёмная верхняя зона до 110 px и плавный переход до 170 px, поэтому breadcrumbs и «Назад» остаются на нейтральном фоне даже при светлой палитре;
- основной контент и sidebar сохраняют собственный тёмный фон и не меняют контрастность.

## Проверки

- добавлен feature-тест на компактные controls, текст «Применить» и генерацию безопасного домашнего градиента;
- требуется проверить итоговый PR diff и PHP-синтаксис обновлённого теста перед merge.
