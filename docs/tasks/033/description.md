# 033 - Исправить повторную геолокацию и сброс адресных данных

## Оригинальное описание

После определения адреса через «Я на площадке» и очистки поля повторное нажатие в Telegram не определяет геолокацию. При очистке или ручной корректировке адреса все связанные адресные значения также должны сбрасываться.

## Подробное описание

Telegram `LocationManager` нужно инициализировать только один раз: если manager уже имеет `isInited`, повторный запрос сразу вызывает `getLocation()`. Это предотвращает зависание Promise на клиентах, которые не вызывают callback повторного `init()`.

Любое пользовательское событие `input` инвалидирует структурированный адрес и сразу очищает выбранное метро, включая случай частичной корректировки, а не только полностью пустое поле. Крестик использует тот же полный сброс.

## Результат

- повторное определение геопозиции использует уже инициализированный Telegram LocationManager;
- первая инициализация по-прежнему проверяет доступность геолокации;
- ручное удаление или изменение адреса сбрасывает город, улицу, дом, индекс, координаты, признак выбранного адреса и метро;
- frontend-ассеты пересобраны.
