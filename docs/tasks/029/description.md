# 029 - Сделать поиск площадок по тегам регистронезависимым

## Оригинальное описание

Сделать поиск площадок по тегам независимым от регистра.

## Подробное описание

Поисковый запрос для ветки тегов должен нормализоваться тем же универсальным кириллическим транслитератором и slug-алгоритмом, которые используются при сохранении `VenueTag::slug`. Сопоставление выполняется по нормализованному slug, поэтому не зависит от регистра и не привязано к PostgreSQL-оператору `ILIKE`.

Остальные поля общего поиска сохраняют текущее поведение.

## Проверка

- тег находится запросом в нижнем регистре;
- тот же тег находится запросом в верхнем и смешанном регистре;
- кириллический запрос корректно сопоставляется с транслитерированным slug;
- фильтры видимости площадок продолжают применяться.

## Результат

- `SearchVenuesHandler` получает общий `CyrillicTransliterator` через DI;
- поисковый запрос преобразуется тем же способом, что slug тега;
- ветка тегов сопоставляет нормализованный запрос с `venue_tags.slug`;
- сравнение по исходному имени сохранено как fallback;
- feature-тест выполняет поиск сохранённого кириллического тега запросом в верхнем регистре.
