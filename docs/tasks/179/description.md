# 179 — Полноценная публичная страница спортивной секции

## Цель

Довести SportsSection от технической карточки до полноценной публичной страницы уровня площадки: общий `section-sidebar`, понятная запись в секцию, быстрый доступ к управлению и полноценная информация для игрока. Дополнительно добавить необязательную возрастную группу по году рождения.

## Согласованные инварианты

- публичная страница использует общий layout `section-sidebar`;
- понятные badge не получают дублирующих tooltip;
- CTA записи отражает фактическое состояние пользователя и секции;
- управляющий получает прямые ссылки на редактирование, заявки/набор, занятия и связанные команды;
- возрастная группа необязательна и задаётся одним из способов: без ограничения, один точный год или полный диапазон годов;
- точный год и диапазон одновременно храниться не могут;
- `is_recruiting = true` означает открытый приём заявок, поэтому публично одновременно могут показываться «Идёт набор» и «Принимает заявки»;
- в публичном списке тренеров показываются только действующие membership с активным контрактом и актуальным сроком действия;
- регулярное недельное расписание и booking-first подтверждение TrainingSession не входят в эту задачу и будут продолжены отдельной задачей после 179.

## Реализация

Реализовано в ветке `feature/179-section-public-page`, PR #194.

- публичная страница переведена на `section-sidebar`;
- добавлены блоки обзора, занятий, тренеров, площадки, стоимости, команд, фотографий и контактов;
- CTA записи и управления зависят от реального состояния пользователя, заявки и permissions;
- добавлены `target_year`, `target_year_from`, `target_year_to` и UI настройки аудитории;
- настройки набора сохраняют взаимоисключающие режимы точного года и диапазона;
- активный набор сохраняет инвариант открытого приёма заявок;
- публичный roster тренеров ограничен active-membership контрактом из `SportsSectionAccess`;
- Feature-тесты проверяют пользовательское поведение, а не косметический порядок CSS-классов.

Стабильный продуктовый контракт вынесен в `docs/project/sports-sections.md`.
