# 179 — Полноценная публичная страница спортивной секции

## Цель

Довести SportsSection от технической карточки до полноценной публичной страницы уровня площадки: общий `section-sidebar`, понятная запись в секцию, быстрый доступ к управлению и полноценная информация для игрока. Дополнительно добавить необязательную возрастную группу по году рождения.

## Согласованные инварианты

- публичная страница использует общий layout `section-sidebar`;
- понятные badge не получают дублирующих tooltip;
- CTA записи отражает фактическое состояние пользователя и секции;
- управляющий получает прямые ссылки на редактирование, заявки/набор, занятия и связанные команды;
- возрастная группа необязательна и задаётся одним из способов: без ограничения, один точный год или полный диапазон годов;
- точный год и диапазон одновременно храниться не могут;
- регулярное недельное расписание и booking-first подтверждение TrainingSession не входят в эту задачу и переносятся в Task 180.

## Реализация

В работе на ветке `feature/179-section-page`.
