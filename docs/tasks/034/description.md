# 034 - Перевести идентичность площадки на тип и географическую близость

## Оригинальное описание

Исключить название/alias из определения одинаковости площадок. Дубли определять по типу и близости координат, поскольку одна локация может содержать уличную площадку и спортивный зал. Адрес сделать обязательным. Alias оставить только для URL, используя стабильный ID.

## Подробное описание

Структурированный адрес, выбранность подсказки и координаты обязательны для создания и изменения паспортных данных площадки. Alias больше не блокирует одинаковые названия и не создаёт кандидатов дублей.

Для площадок одинакового типа вычисляется расстояние Haversine между адресными координатами. Радиус до 50 метров считается сильным конфликтом с уже подтверждённой площадкой и повторно проверяется в транзакции подтверждения. Радиус до 200 метров создаёт pending-кандидата для ручной модерации; расстояние и порог сохраняются в metadata.

Публичные и внутренние venue URL получают идентификатор `id-alias`. Старые alias-only ссылки временно поддерживаются как fallback, но новые ссылки строятся со стабильным ID.

## Проверка

- одинаковые названия одного типа по разным координатам разрешены;
- одинаковый тип в пределах 50 метров от подтверждённой площадки нельзя подтвердить;
- другой тип на тех же координатах разрешён;
- одинаковый тип в пределах 200 метров создаёт кандидата с расстоянием;
- создание и обновление требуют выбранный структурированный адрес и координаты;
- новые ссылки используют `id-alias`, старые alias URL остаются читаемыми;
- конкурентное подтверждение сериализуется блокировкой площадок одного типа.

## Результат

Добавлен общий сервис географической близости с настраиваемыми порогами 50/200 метров. Создание и изменение площадки требуют выбранный структурированный адрес с координатами; проверки имени, alias и точного текста адреса из идентичности удалены. Поиск кандидатов дублей переведён на одинаковый тип и расстояние, а подтверждение повторно проверяет сильный конфликт внутри транзакции с упорядоченной блокировкой площадок типа.

Новые ссылки формируются через стабильный идентификатор `id-alias`, при этом старые alias-only ссылки продолжают открываться. Покрыты сценарии одинаковых названий, разных типов в одной точке и географического конфликта.
