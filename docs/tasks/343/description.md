# 343 - Фильтр площадок по ближайшим мероприятиям на 1–14 дней

## Оригинальное описание

Фильтр площадок по ближайшим мероприятиям на 1–14 дней. Требования владельца от 20.11.2026.

## Подробное описание

На /venues добавить фильтр «Есть ближайшие мероприятия». При активации снизу появляется фирменный input slider как в профиле игрока, диапазон целых 1–14 дней. Default 7 дней — предложение, согласовать/проверить существующий паттерн. Учитывать будущие опубликованные доступные для просмотра мероприятия (не скрытые/черновые/отменённые/завершённые), не путать Event и вложенную Game. Учитывать timezone и точно определить границы периода при реализации. Применять EXISTS/единый query до пагинации, список и карта, совместимо с остальными фильтрами; исключить дубликаты площадок. Проверить крайние даты, пустую выдачу, режимы и сброс.

## Статус

Запланировано; реализация не начата. Перед реализацией сверить актуальный код и документацию, применять Task Workflow и GlobalRule5 с учётом отдельных ограничений.
