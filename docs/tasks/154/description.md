# Task 154 — sidebar и навигация страницы площадки

## Цель

Убрать дублирование навигации на публичной странице площадки и привести поведение sidebar к единому breakpoint `768px`.

## Требования

- на экранах шире `768px` показывать sidebar на самой странице и скрывать дополнительную навигацию внутри основного контента;
- на экранах `768px` и уже переносить sidebar в существующее мобильное сворачиваемое меню и не дублировать его на самой странице;
- на мобильном экране показывать контентную навигацию непосредственно над блоком «Игры и мероприятия»;
- убрать отдельную верхнюю mobile-sticky навигацию страницы площадки, чтобы на странице оставалась только одна контекстная навигация;
- переименовать секции sidebar: «Площадка» → «Навигация», «Состояние» → «Информация», «Управление» оставить без изменений;
- сделать три секции sidebar accordion: по умолчанию раскрыта «Навигация», при раскрытии другой секции ранее открытая схлопывается;
- на desktop sidebar должен работать через CSS `position: sticky` с отступом около `10px` от нижней границы header и естественно останавливаться у нижней границы родительской grid-колонки;
- сохранить существующий механизм `mobile-sidebar-navigation`, который переносит один и тот же DOM-узел sidebar в мобильное меню, а не клонирует его.

## Результат

Реализация выполняется в `feature/154`. Проверка включает полный CI и frontend build. После зелёного CI задача может быть влита в `main` по заранее данному пользователем разрешению.
