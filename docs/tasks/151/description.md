# 151 — Полировать заголовок и занятые слоты площадки

## Задача

На публичной странице площадки уменьшить заголовок примерно в 1.5 раза, визуально увеличить порог обрезания названия с 30 до 40 символов и около занятых слотов показывать тип публичного мероприятия ссылкой, открывающейся в новой вкладке.

Для игр к типу добавлять компактный формат из primary game, например `Игра 5×5`. Полное название мероприятия сохранять в tooltip ссылки.
