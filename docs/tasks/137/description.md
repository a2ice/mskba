# 137 — Добавить фильтр отменённых мероприятий

## Оригинальное описание

На странице мероприятий по умолчанию не показывать отменённые игры и добавить рядом с фильтром
«Показывать прошедшие» селект статуса: все, не отменённые, отменённые.

## Подробное описание

Отменённые мероприятия исключаются из предстоящего и прошедшего журналов независимо от того, является ли
текущий пользователь организатором. GET-фильтр `status=all|not_cancelled|cancelled` управляет статусной частью
выдачи и сохраняется в пагинации; значение по умолчанию — `not_cancelled`. Отмена больше не дублируется в UI
фильтра итога, а старый URL с `outcome=cancelled` нормализуется в статус `cancelled`.

## Статус

Выполнено.

## Результат

В быстрые фильтры журнала добавлен селект «Статус» со значениями «Все», «Не отменённые» и «Отменённые».
По умолчанию отменённые мероприятия исключаются и из предстоящей, и из прошедшей выдачи, в том числе для
организатора. `all` возвращает публичные отменённые записи вместе с остальными, а `cancelled` оставляет только
отменённые. Фильтр сохраняется в query string и защищён feature-тестом.
