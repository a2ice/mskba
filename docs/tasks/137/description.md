# 137 — Добавить фильтр отменённых мероприятий

## Оригинальное описание

На странице мероприятий по умолчанию не показывать отменённые игры и добавить рядом с фильтром
«Показывать прошедшие» переключатель «Показывать отменённые».

## Подробное описание

Отменённые мероприятия исключаются из предстоящего и прошедшего журналов независимо от того, является ли
текущий пользователь организатором. GET-флаг `show_cancelled=1` включает публичные отменённые мероприятия
вместе с остальной выдачей с сохранением фильтра в пагинации. Для прошедшего журнала выбор итога «Отменено»
также включает показ отменённых, чтобы фильтры не создавали заведомо пустую комбинацию.

## Статус

Выполнено.

## Результат

В быстрые фильтры журнала добавлен переключатель «Показывать отменённые». По умолчанию отменённые
мероприятия исключаются и из предстоящей, и из прошедшей выдачи, в том числе для организатора. Флаг
`show_cancelled=1` возвращает публичные отменённые записи, сохраняется в query string и учитывается счётчиком
активных фильтров. Прошедший итог «Отменено» включает показ автоматически. Поведение защищено feature-тестом.
