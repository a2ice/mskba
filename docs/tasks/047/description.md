# 047 - Перенести sidebar в мобильную панель навигации

## Оригинальное описание

На внутренних страницах sidebar с меню, фильтрами и дополнительными блоками не должен занимать место перед основным контентом в мобильной версии. Его нужно перенести в выпадающую навигационную панель и разделить её на взаимоисключающие секции «Главное меню» и содержимое sidebar.

## Подробное описание

На экранах до 768 пикселей общий sidebar layout переносит существующий DOM-узел sidebar в мобильную панель, не клонируя содержимое. Это сохраняет значения фильтров, идентификаторы элементов и подключённые обработчики. При возврате к desktop узел возвращается в исходную grid-позицию.

Мобильная панель получает accordion из двух секций в порядке: главное меню, затем контекстный sidebar. Если sidebar существует и непуст, при первом открытии панели раскрыта его секция, а главное меню свернуто. На страницах без sidebar раскрыто главное меню. Одновременно может быть открыта только одна секция. Переход по ссылке контекстного sidebar закрывает мобильную панель.

Desktop layout и tablet-компоновка шире 768 пикселей остаются без изменений.

## Проверка

- feature-проверка наличия общей accordion-разметки и метаданных sidebar;
- production-сборка Vite;
- полный backend test suite;
- `git diff --check`;
- mobile smoke test страниц с sidebar и без него.

## Результат

Общая мобильная навигация получила две взаимоисключающие accordion-секции: «Главное меню» и контекстную навигацию раздела. На страницах с непустым sidebar по умолчанию раскрывается контекстная секция; на главной и других страницах без sidebar — основное меню.

Sidebar переносится в панель как исходный DOM-узел и возвращается в grid при переходе на desktop. Ссылки sidebar закрывают мобильную панель после выбора. Специальное содержимое площадок, аккаунта и админки сохраняется целиком, включая фильтры, состояние и дополнительные блоки.

Проверки пройдены: 29 профильных feature-тестов, полный backend suite (208 тестов, 1202 assertions), production-сборка Vite, `git diff --check` и headless mobile DOM smoke test страниц с sidebar и без него.
