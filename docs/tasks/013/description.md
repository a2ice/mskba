# 013 - Улучшить UX wizard подтверждения аккаунта при уже выбранной роли

## Оригинальное описание

Пользователь попросил:

> переделаем немного wizard - в ситуации когда при подтверждении аккаунта роль уже есть, например, пользователь указывал ее при регистрации - мы все равно показываем первый шаг с кнопками управлеения "назад|далее" - думаю в данном случае это лишнее действие и можно переходить сразу ко второму шагу. это первое - еще я хочу чтобы на каждом шаге дальше первого - в шапке шага показывалась накомленная к текущему шагу информация - то есть например на шаге два - мы показываем то что пользователь уже выбрал на предыдущем шаге - 1, на шаге 3 - на 1 и 2.

## Подробное описание

Нужно улучшить UX wizard подтверждения аккаунта в теме `mskba_dark`.

Требования:

- если у пользователя уже есть роль участия, не показывать шаг выбора роли;
- при наличии роли wizard должен начинаться со следующего применимого шага;
- дату рождения и пол нужно показывать отдельными шагами;
- на шагах после выбора роли показывать накопленную информацию, выбранную на предыдущих шагах;
- summary должно обновляться на клиенте при изменении роли, даты рождения и пола;
- серверная валидация и финальный submit остаются источником доверия.

## Результат

Wizard подтверждения аккаунта теперь не показывает шаг выбора роли, если у пользователя уже есть роль участия.

Поведение:

- пользователь без роли начинает с шага выбора роли, как раньше;
- пользователь с ролью `player` или `coach` начинает с шага даты рождения, а затем переходит к отдельному шагу пола;
- пользователь с ролью без дополнительных требований начинает с шага имени;
- на последующих шагах есть summary-блок с накопленной информацией из предыдущих шагов: на шаге пола показываются роль и дата рождения, на шаге имени - роль, дата рождения и пол;
- summary обновляется на клиенте при изменении роли, даты рождения и пола;
- backend service `AccountConfirmationWizardService` теперь не включает шаг `participation_role`, если роль уже есть.

Обновлены продуктовая и техническая документация.
