# 092 - Регистрация участников турнира на месте

Добавить управляемую организатором регистрацию по постоянной ссылке и QR-коду. Авторизованный пользователь отправляет специальную заявку, а новый пользователь может быстро зарегистрироваться и выбрать роли. Ответственный видит источник заявки, характеристики игрока и при необходимости сразу назначает команду даже после начала турнира.
