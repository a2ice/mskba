# 222 — Унифицировать верхнее выравнивание горизонтальных строк форм

## Проблема

В горизонтальных form-row использовалось `align-items: end`. Если у одного
поля появляется helper/error текст снизу, соседние поля и actions смещаются
вниз относительно верхней границы строки.

На кошельке это проявилось одновременно в:

- «Перевести бонусы» — predictive recipient имеет служебную подпись;
- «Начислить бонусы» — поле суммы имеет постоянный helper text.

## Решение

В общий `form-controls.css` добавлен переиспользуемый pattern:

- `.form-row--top` — логические ячейки горизонтальной формы выравниваются по
  верхней границе;
- `.form-row__action` — action-кнопка остаётся на линии самого control,
  независимо от высоты helper/error текста соседнего поля;
- на мобильном stacked layout автоматически возвращается stretch и убирается
  desktop offset action.

Wallet использует общий pattern вместо локального `align-items: end`.

Не меняем глобально все существующие `display:flex/grid`: в проекте есть
headers, filters и декоративные layouts, где `center/end` является осознанным.
Новый pattern предназначен именно для горизонтальных строк полей формы и может
переиспользоваться при следующих правках таких строк.

## Проверка

- recipient и amount cells начинаются с одной верхней границы;
- helper predictive search не сдвигает amount/action вниз;
- bonus grant helper не сдвигает кнопку «Начислить»;
- на мобильном форма остаётся нормально stacked;
- frontend build и PHP tests.
