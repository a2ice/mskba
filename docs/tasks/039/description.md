# 039 - Перевести Telegram Mini App на общую мобильную главную

## Оригинальное описание

Не плодить отдельные Telegram-страницы и сценарии: использовать мобильную версию сайта с дополнительным верхним отступом Telegram. В мобильной шапке заменить поиск круглой кнопкой профиля: гость видит белую иконку, авторизованный пользователь — аватар или первые две буквы имени.

## Подробное описание

Маршрут `/telegram` переводится на общую страницу `welcome` и основной layout. Telegram-контекст ограничивается safe-area, автоматической авторизацией и обновлением профиля в шапке. Старый `/integrations/main` временно сохраняется как legacy-вариант, чтобы переход был обратимым и существующие AJAX-прототипы не удалялись до проверки общего сценария.

SDK Telegram загружается асинхронно. Для авторизации frontend использует `Telegram.WebApp.initData`, а при задержке SDK читает `tgWebAppData` из hash launch URL. Backend в любом случае проверяет подпись и срок данных. Это устраняет внешний SDK как блокирующую зависимость стартового рендера и как единственный источник `initData`.

Общий мобильный header показывает кнопку профиля вместо поиска. Авторизованное состояние использует доступное фото или Unicode-safe инициалы; Telegram AJAX-auth обновляет кнопку без перезагрузки.

## Проверка

- `/telegram` отдаёт общую главную и Telegram bootstrap-атрибуты;
- `/integrations/main` сохраняет legacy-интерфейс;
- обычная главная не запускает Telegram-auth;
- гостевой и авторизованный варианты мобильного профиля присутствуют в HTML;
- Telegram auth feature-тесты и полный тестовый набор проходят;
- frontend-ассеты собираются успешно.

## Результат

Основной Telegram-вход `/telegram` переведён на общую главную страницу и стандартный mobile header. Telegram-контекст добавляет верхний safe-area, асинхронный SDK и автоматическую авторизацию; legacy-интерфейс сохранён на `/integrations/main` для переходного периода.

Авторизация больше не зависит исключительно от готовности SDK: подписанная строка извлекается также из `tgWebAppData` launch URL и неизменно проверяется backend. Мобильный поиск в шапке заменён кнопкой профиля: гость видит белую иконку, авторизованный пользователь — Telegram/profile-фото или первые две Unicode-буквы имени. AJAX Telegram-auth обновляет элемент без перезагрузки.

Пройдено 188 тестов с 1058 assertions; PHP/JS syntax-check, `git diff --check` и production frontend build выполнены успешно.
