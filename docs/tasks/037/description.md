# 037 - Добавить статус в поиск площадок Telegram Mini App

## Оригинальное описание

Добавить в результаты поиска площадок badge статуса и фильтр по статусу; подтверждённые площадки отмечать зелёной галочкой.

## Подробное описание

В расширенные фильтры Telegram-поиска добавляется статус площадки. Значение валидируется как `VenueStatusEnum` и применяется после общего ограничения видимости, поэтому фильтр не раскрывает недоступные пользователю площадки.

JSON-результат содержит отображаемый статус и отдельный булев признак подтверждения. В заголовке карточки подтверждённой площадки показывается компактная зелёная галочка с текстовой подписью для вспомогательных технологий.

## Проверка

- статус присутствует среди расширенных фильтров;
- endpoint принимает допустимый статус и фильтрует только уже доступную пользователю выдачу;
- JSON содержит статус и признак подтверждения;
- подтверждённая карточка получает зелёную галочку;
- frontend-ассеты успешно собираются.

## Результат

В расширенные фильтры добавлен статус площадки, а endpoint поиска валидирует его через `VenueStatusEnum` и применяет поверх общей доступной выдачи. Ответ поиска теперь содержит статус и признак подтверждения; подтверждённые карточки отмечаются компактной зелёной галочкой с доступной подписью.

Feature-тест Telegram Mini App проверяет наличие фильтра, передачу статуса и новые поля JSON. Сборка frontend-ассетов выполнена успешно.
