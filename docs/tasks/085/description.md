# 085 - Добавить журнал игровых действий game_actions

## Оригинальное описание

Добавить отдельную таблицу `game_actions` для хранения последовательности игровых событий.

## Подробное описание

Текущая модель хранит только актуальный счёт и накопительную статистику игроков. Нужно добавить append-only журнал действий, чтобы сохранять порядок бросков и других изменений, определять последнюю активную сторону после перезагрузки live-страницы и подготовить источник для будущей play-by-play и realtime-трансляции.

Каждое действие относится к игре и получает монотонный номер `sequence` внутри игры. Действие может ссылаться на сторону, игрока и актора, содержит тип, количество очков, время и дополнительный JSON payload. Запись выполняется в одной транзакции с обновлением счёта и статистики.

## Проверка

- миграция создаёт таблицу и ограничения;
- явное действие статистики сохраняется вместе со snapshot;
- ручная коррекция счёта сохраняется отдельным действием;
- live-страница восстанавливает последнюю активную сторону;
- профильные feature-тесты и frontend build проходят.
