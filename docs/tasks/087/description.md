# 087 - Общий realtime-слой и live-обновление игры

## Цель

Подключить Laravel Reverb и Laravel Echo как общий транспорт realtime-доставки, первым вертикальным
срезом которого станет автоматическое обновление публичной страницы трансляции текущей Game.

Архитектура должна допускать дальнейшие приватные каналы уведомлений, toast, сообщений и обновлений
дашбордов без связывания этих bounded context с игровым UI.

## Решения

- HTTP snapshot остаётся источником истины; WebSocket сообщает о появлении новой ревизии.
- Публичная трансляция подписывается на публичный канал `game.live.{gameId}`.
- После сигнала клиент получает свежий snapshot, поэтому reconnect и пропущенные события не требуют
  воспроизведения всей истории сообщений.
- Broadcast публикуется синхронно после успешного commit; событие содержит только сигнал, а не состояние игры.
- Общий frontend transport управляет Echo, состоянием соединения и подписками; страница игры отвечает
  только за применение своего snapshot.
- Будущие пользовательские данные доставляются через приватные каналы с серверной авторизацией.

## Scope первой поставки

- Reverb/Echo dependencies и конфигурация local/production;
- процесс Reverb в Compose и WebSocket proxy в Nginx;
- публичное событие изменения live-состояния Game;
- JSON snapshot счёта, статуса, периода, составов, статистики и последнего игрового действия;
- автоматическое обновление live-страницы, reconnect и HTTP fallback;
- feature/unit проверки broadcast-контракта и snapshot;
- инструкции запуска и диагностики.

## Не входит

- пользовательские notification/message channels;
- presence channels;
- хранение истории WebSocket-сообщений;
- горизонтальное масштабирование Reverb (конфигурация должна его допускать позднее).

## Результат реализации

- Reverb установлен как отдельный Compose-процесс, а Nginx проксирует `/app` и `/apps` с WebSocket headers.
- Добавлен ленивый общий Echo transport с состояниями соединения и повторной синхронизацией.
- `EventChanged` инфраструктурно преобразуется в лёгкий синхронный broadcast `game.live.updated` после commit.
- Публичный HTTP snapshot версии 1 возвращает состояние игры и непрозрачную ревизию.
- Live-страница применяет счёт, активную сторону/период, статистику игроков, периодные срезы и последнее действие.
- При отсутствии Reverb или разрыве соединения используется HTTP fallback раз в десять секунд.
- Публичные и будущие приватные контракты разделены; wildcard origins не используются по умолчанию.
