# 006 - Разработать динамический partial breadcrumbs для разделов и подразделов

## Оригинальное описание

Разработать `partials.breadcrumbs` так, чтобы partial был динамическим. Например, для подраздела "Пользователи" раздела "Админка" по адресу `/admin/users` breadcrumbs должны показывать цепочку: `Главная / Админка / Пользователи`.

## Подробное описание

Нужно доработать partial `resources/themes/mskba_dark/views/partials/breadcrumbs.blade.php`, чтобы он формировал хлебные крошки как цепочку разделов текущей страницы, а не только как пару `Главная / текущая страница`.

Базовый ожидаемый результат:

- главная страница не показывает breadcrumbs;
- страница админки `/admin` показывает `Главная / Админка`;
- подраздел админки `/admin/users` показывает `Главная / Админка / Пользователи`;
- текущий пункт цепочки не является ссылкой;
- промежуточные пункты ведут на соответствующие разделы, если для них есть маршрут;
- существующие вызовы partial через `title` не должны ломаться.

На текущем этапе в проекте есть маршруты:

- `home` - главная;
- `account` - личный кабинет;
- `admin.index` - раздел админки;
- `admin.users` - подраздел пользователей в админке.

Реализация:

1. В partial оставить возможность явной передачи `breadcrumbs`, чтобы страницы могли задавать цепочку вручную.
2. Если `breadcrumbs` не передан, строить цепочку автоматически по имени текущего маршрута.
3. Человекочитаемые названия брать из метаданных маршрута `->defaults('breadcrumb', '...')`.
4. Для маршрута `admin.users` partial автоматически включает родительский `admin.index`, потому что имя маршрута разбирается по сегментам.
5. Для маршрутов без `breadcrumb` сохранить fallback на переданный `title` или дефолтное `Страница`.
6. Оставить визуальный стиль существующих breadcrumbs и при необходимости точечно поправить CSS под динамическую цепочку.
7. Обновить документацию задачи результатом выполнения.

Затронутые файлы:

- `resources/themes/mskba_dark/views/partials/breadcrumbs.blade.php`;
- `routes/web.php`;
- при необходимости `resources/themes/mskba_dark/css/app.css`;
- build-артефакты `public/build`, если меняется CSS;
- `docs/tasks/006/description.md`.

Проверки:

- `php artisan view:cache && php artisan view:clear`;
- `npm run build`, если будет изменен CSS или frontend build-артефакты.

## Результат выполнения

Partial `theme::partials.breadcrumbs` строит цепочку breadcrumbs динамически:

- для `admin.index` отображается `Главная / Админка`;
- для `admin.users` отображается `Главная / Админка / Пользователи`;
- для `account` отображается `Главная / Личный кабинет`;
- для новых route-name подразделов цепочка строится по сегментам имени маршрута, например `admin.settings` сможет включить `admin.index`;
- человекочитаемые названия задаются рядом с маршрутами через `->defaults('breadcrumb', '...')`;
- для неизвестных маршрутов и маршрутов без `breadcrumb` сохраняется fallback на переданный `title`;
- при необходимости страница может передать явный массив `breadcrumbs`;
- текущий пункт цепочки выводится без ссылки с `aria-current="page"`.

Добавлен feature-тест `Tests\Feature\BreadcrumbsTest`, который проверяет цепочку на странице `/admin/users`.
