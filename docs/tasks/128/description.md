# 128 - Цвета команды

## Оригинальное описание

Добавить в основные настройки команды четыре необязательных цвета сразу после логотипа: основной домашний, дополнительный домашний, основной гостевой и дополнительный гостевой.

Цвета должны храниться на самой команде в nullable JSON-поле.

## Подробное описание

В `teams.colors` хранится JSON только с реально заданными значениями. Поддерживаются ключи:

- `home_primary`;
- `home_secondary`;
- `away_primary`;
- `away_secondary`.

Каждое значение валидируется в формате `#RRGGBB` и нормализуется к нижнему регистру. Отдельные цвета могут отсутствовать. Если не задан ни один из четырёх цветов, `teams.colors` хранится как `NULL`.

В разделе «Основные настройки» сразу после логотипа расположен отдельный блок «Цвета команды» с нативными colorpicker. Рядом с каждым picker показывается текущее HEX-значение и доступно действие «Сбросить». Пустой цвет не подменяется значением `#000000`: чёрный используется только как техническое начальное состояние самого HTML color input, а фактическое поле остаётся пустым до выбора цвета.

Сохранение цветов вынесено в отдельный endpoint настроек команды и использует существующее право `team.settings.edit` / `EDIT_SETTINGS`.

## Результат

- добавлено nullable JSON-поле `teams.colors`;
- модель `Team` получила array cast для `colors`;
- добавлен endpoint `teams.settings.colors.update`;
- в настройки команды добавлены четыре colorpicker сразу после логотипа;
- поддерживаются частично заполненные наборы цветов;
- полная очистка переводит поле `colors` обратно в `NULL`;
- добавлена серверная валидация HEX `#RRGGBB`;
- добавлены feature-тесты сохранения, частичного набора, очистки и невалидного значения.
