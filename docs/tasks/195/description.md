# 195 — Унифицировать отображение tooltip для текста и визуальных маркеров

> **Актуализация 2026-09-21:** визуальная часть решения изменена по результатам эксплуатации. `title` теперь по умолчанию даёт только tooltip без `?` и без подчёркивания. Явный индикатор справки включается только через `data-tooltip-help`. Описание ниже сохранено как история первоначальной реализации; актуальный контракт — в `docs/specification.md`.

## Причина

В проекте накопилось несколько способов оформления `title`: где-то рядом появлялся `?`, где-то подчёркивание, где-то оба признака отсутствовали. Локальные `data-tooltip-variant="title"` и `data-tooltip-icon` использовались непоследовательно, поэтому одинаковые по смыслу подсказки выглядели по-разному.

## Инвариант

Tooltip с `title` должен оформляться по типу источника:

- читаемый текст — пунктирное подчёркивание самого текста **и** отдельная кнопка `?`;
- иконка, точка, swatch, badge/знак или другой компактный визуальный маркер — только tooltip на самом источнике, без `?` и без подчёркивания;
- icon-only источник определяется автоматически;
- если визуальный маркер содержит текст и поэтому неоднозначен для автоматического определения, используется `data-tooltip-visual`;
- `data-tooltip-icon` остаётся совместимым alias;
- `data-tooltip-variant="title"` больше не должен подавлять текстовое оформление;
- при необходимости явно форсировать текстовый режим можно использовать `data-tooltip-text`.

## Реализация

- общий enhancer `tooltips.js` разделяет источники на text/visual;
- text-source получает `.ui-tooltip-source--text`, содержимое `data-tooltip` и сгенерированную кнопку `?`;
- visual-source получает `.ui-tooltip-source--visual` и не создаёт дополнительную кнопку;
- для визуального источника без собственной доступности enhancer добавляет `aria-label` и keyboard focus;
- `label` считается интерактивным источником на touch, чтобы tooltip не блокировал выбор radio/checkbox;
- `MutationObserver` автоматически обрабатывает элементы с `title`, добавленные после загрузки страницы, и обновления существующего `title`;
- cleanup заголовка площадки учитывает новые классы и удаляет автоматически созданную кнопку, если tooltip после снятия усечения больше не нужен.

## Миграция текущего UI

Неоднозначные визуальные маркеры с читаемым DOM-текстом помечены `data-tooltip-visual` (badge статусов команды, сокращения турнирной таблицы, обязательность шага confirmation wizard, live audience). Ошибочные `data-tooltip-icon` сняты с обычного текстового label «Количество колец», booking-scope label и текстовых метаданных команды.

## Проверка

- `node --check resources/themes/mskba_dark/js/features/tooltips.js`;
- `npm run build`;
- CI проекта;
- desktop smoke: текстовый `title` показывает подчёркивание + `?`, icon/sign — только tooltip;
- touch smoke: отдельная `?` открывает текстовую подсказку, visual source открывается tap-ом только если он не является action-control, tap вне закрывает tooltip.
