# 150 — Поднять карту выбора площадки над вложенным location wizard

После возврата ссылки `На карте` на финальном шаге location mini-wizard popup карты открывался под двумя уже открытыми wizard-модалками.

Причина: базовый `.modal` использует `z-index: 320`, location mini-wizard — `345`, а map modal оставался на базовом уровне.

Нужно поднять только modal выбора площадки на карте выше вложенного wizard, не меняя глобальный порядок остальных popup.
