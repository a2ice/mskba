# 315 — Мультиканальная публикация материалов в Telegram, VK и Instagram

**Ранее этот пункт ошибочно дублировал номер 281** в `docs/tasks.md`.
Номер 281 закреплён за каталогом вознаграждений; задача публикации
перенумерована без изменения контракта старых PR/тикетов.

## Цель

Спроектировать единый pipeline публикации существующих редакционных
материалов MSKBA в Telegram, VK и Instagram с учётом политики доступа,
медиаданных, расписания, авторизации внешних аккаунтов, ошибок и аудита.
Не превращать этап в автоматический AI-скрейпинг из задач 282–284.

## Статус

План / вне ближайшего блока 302–311. Объём, API-доступ, права владельца
и модерацию контента согласовать отдельно. Нет основания считать
интеграции уже запущенными по наличию Telegram Mini App или новостей.
