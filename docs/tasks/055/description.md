# 055 - Расширить типы мероприятий и разрешить бронирование площадок без расписания

## Оригинальное описание

Добавить тип мероприятия «Игровая тренировка», подставлять конкретный тип в действие создания и форму в зависимости от текущего раздела, а площадку без заданных часов работы считать доступной в любое время.

Форма создания должна предлагать название из типа и текущей даты, старт через 30 минут и часовую длительность. Старт не может быть раньше чем через 30 минут, окончание — раньше чем через час после старта; пустое окончание рассчитывается автоматически. Под выбором площадки нужна заглушка будущего списка избранных площадок.

## Подробное описание

`EventTypeEnum` расширяется значением `game_training`. Список мероприятий передаёт выбранный фильтр в форму создания: подпись действия, заголовок формы и начальное значение изменяемого select соответствуют текущему типу. Без фильтра сохраняется общее действие «Создать мероприятие».

При открытии формы название формируется как `{Тип} - YYYYMMDD`, начало округляется вверх до минуты после текущего времени +30 минут, окончание устанавливается ещё через час. При смене типа автоматически созданное название обновляется, но введённый пользователем текст не перезаписывается. Сервер повторно проверяет минимальный горизонт старта и часовую длительность. Если окончание не передано, HTTP request и application handler независимо используют `starts_at + 1 час`, поэтому доменная бронь всегда остаётся конечным интервалом.

Подтверждённая физически активная площадка участвует в создании мероприятия независимо от наличия регулярного расписания. Отсутствующее или полностью пустое недельное расписание означает базовую доступность 24/7 с сохранением ограничения первой версии: мероприятие должно завершиться в тот же локальный день. Исключение даты может закрыть такой день или ограничить его заданными интервалами. При наличии хотя бы одного регулярного недельного интервала дни без интервалов считаются закрытыми. Проверка пересекающихся активных броней применяется во всех случаях.

Для PostgreSQL добавляется миграция ограничения допустимых значений `events.type`; SQLite-тесты продолжают использовать строковое представление enum.

## Проверки

- контекстная ссылка и предвыбранный тип в форме;
- создание «Игровой тренировки»;
- создание мероприятия на площадке без расписания;
- соблюдение исключений и пересечений броней;
- полный набор backend-тестов и сборка frontend-ассетов.

## Реализовано

- добавлен тип `game_training` с подписью «Игровая тренировка» во всех пользовательских и административных фильтрах;
- кнопка создания на странице выбранного типа получает предметную подпись и передаёт тип в форму;
- форма показывает предметный заголовок и предвыбирает тип в изменяемом select;
- форма предлагает контекстное название, старт через 30 минут и окончание ещё через час;
- backend запрещает слишком ранний старт и длительность менее часа, а отсутствующее окончание рассчитывает автоматически;
- ссылка «Избранные площадки» открывает модальную заглушку будущего функционала;
- подтверждённые активные площадки без расписания доступны для создания мероприятий;
- отсутствие недельных часов трактуется как 24/7, а закрывающие исключения, интервальные исключения и занятые брони сохраняют приоритет;
- добавлена обратимая PostgreSQL-миграция ограничения `events.type`;
- актуализированы продуктовая и техническая документация модуля.
