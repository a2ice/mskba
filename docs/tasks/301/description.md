# 301 — Управляемое закрепление основной шапки вместо показа от наведения к верхнему краю

## Требование
Убрать автоматическое раскрытие основной шапки при наведении указателя в верхние 18px экрана. Сохранить раскрытие на прокрутке вверх и скрытие при прокрутке вниз в обычном режиме.

На контекстной sticky-полосе, справа от кнопки «Действия», добавить компактный элемент со стрелкой вниз (44px hit area). По нажатию шапка появляется и фиксируется независимо от направления прокрутки; стрелка поворачивается на 180 градусов. Повторное нажатие возвращает режим автоскрытия и убирает закреплённую шапку на прокрученной странице. Переходы между страницами в рамках одной вкладки сохраняют предпочтение через sessionStorage; на главной, где контекстная полоса не выводится, остаётся безопасное автоматическое поведение без недоступного переключателя.

## Реализация
- `resources/themes/mskba_app/js/header.js`: удалены обработчики pointermove/top edge и hover lock; явный `pinned` с доступным `aria-pressed`, динамическим названием кнопки, sessionStorage и синхронизацией `--app-visible-header-height` / `--app-sticky-offset`. При снятии закрепления сбрасывается последнее намерение прокрутки и закрываются выпадающие меню.
- `resources/themes/mskba_app/views/partials/context-bar.blade.php`: кнопка со стрелкой после «Действия», доступна с клавиатуры.
- `resources/themes/mskba_app/css/context-bar.css`: невыпадающая компактная кнопка, поворот SVG на 180°, поддержка reduced motion, фокус.
- `tests/JavaScript/app-header-scroll.test.mjs`: проверены отсутствие hover reveal, upward scroll, закрепление/снятие, сохранение в пределах вкладки и страница без контекстной полосы.

## Приёмка
1. После прокрутки вниз навести мышь к верхнему краю — шапка не раскрывается.
2. Кликнуть стрелку вниз рядом с бургером — шапка опустится, стрелка повернётся вверх и останется видна при прокрутке вниз.
3. Нажать ещё раз — шапка скроется (кроме естественного положения в самом верху страницы) и снова будет появляться при прокрутке вверх.
4. Перейти на другую страницу с контекстной полосой — состояние закрепления сохраняется в текущей вкладке. На главной странице нет застрявшего режима без кнопки.
5. Оба оформления, desktop/mobile, клавиатура, prefers-reduced-motion; успешные CI, merge в dev, deploy_dev. Без изменений main/production.
