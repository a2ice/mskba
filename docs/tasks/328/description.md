# 328 — Группы навигации Filament и дашборд разделов

## Задача
После переноса на production админка `/backoffice` стала доступна, но в боковом меню почти все разноплановые разделы находятся в «Контент», а главная «Инфопанель» пустая.

Нужно сгруппировать все доступные администратору пункты по смыслу; по умолчанию группы закрыты, активная открывается автоматически, ручное раскрытие/сворачивание сохраняется. Главную переименовать в «Дашборд» и показать на ней те же группы и переходы.

## Структура
| Группа | Содержимое |
|---|---|
| Контент | Материалы и FAQ, разделы FAQ |
| Сайт и дизайн | Страницы, шаблоны, компоненты, темы, медиа, виджеты, стили |
| Пользователи и доступ | Пользователи, системные роли, специализации |
| Площадки | Площадки, удобства, модерация, дубли |
| География | Города, районы, линии и станции метро |
| Аренда и документы | Заявки, предзаявки, контракты, шаблоны и комиссии |
| Соревнования | Мероприятия, команды, лиги, турниры |
| Магазин | Категории, товары, типы, характеристики, теги |
| Лояльность | Акции, вознаграждения |
| Поддержка | Обращения, диалоги, пользователи операторского центра |
| Разработка | IDE и агентские инструменты (только в разрешённой среде) |

Скрытые служебные ресурсы и ресурсы без прав доступа не включаются в навигацию или дашборд.

## Техническая реализация
- Группы определены через нативные `NavigationGroup::make(...)->collapsed()` в `BackofficePanelProvider`; соответствующие `$navigationGroup` и `$navigationSort` у ресурсов приведены к единой структуре.
- Нативный Filament Dashboard заменён на `BackofficeDashboard` с заголовком и навигационным ярлыком «Дашборд» при сохранении прежнего маршрута `/backoffice`.
- Виджет `NavigationOverview` строит карточки из `Filament::getNavigation()` — того же, уже отфильтрованного по доступности набора пунктов, что и сайдбар. Никакой дублирующей карты URL или новых разрешений.
- Filament хранит открытые группы в `localStorage` и не учитывает активный раздел при последующей загрузке. Маленький изолированный скрипт синхронизирует исходное состояние с активным пунктом на первом открытии и после Livewire-навигации, оставляя ручные переключения внутри страницы.
- Собственные стили ограничены префиксом `mskba-bo-dashboard-` и не заменяют стандартные компоненты Filament.

## Проверка
- Проверить CI и `/backoffice` на dev / production.
- Дашборд содержит группы, отобранные в sidebar, и работает в светлой/тёмной теме на desktop/mobile.
- После перехода в ресурс открыта только его группа; на дашборде все закрыты; ручное управление действует до следующего перехода.
- Пользователь с ограниченными правами не получает ссылки на недоступные ресурсы. Developer tools не появляются в production.
- Никакие данные БД и существующие адреса ресурсов не изменяются.
