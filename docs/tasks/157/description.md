# Task 157 — статусы и приватность занятых слотов площадки

## Цель

Сделать список занятых слотов самодостаточным: каждый занятый слот должен объяснять, каким типом мероприятия или бронированием он занят и в каком состоянии находится бронь.

## Требования

- Не показывать автогенерируемое название Event в компактном списке занятых слотов.
- Если Event существует, показывать тип/формат (`Игра 5×5`, `Тренировка` и т. п.).
- Для `PUBLISHED + PUBLIC` Event тип/формат остаётся ссылкой в новой вкладке.
- Для приватного или ещё не опубликованного Event тип/формат показывается обычным текстом без ссылки.
- Если Event ещё не создан, показывать `Бронирование`.
- Для занимающих слот статусов `confirmed`, `pending`, `held` показывать только компактную иконку; текст статуса рядом с иконкой не выводить.
- Текст статуса показывать в tooltip при наведении непосредственно на status-icon через `data-tooltip-variant="title"`, без дополнительной иконки `?`.
- Status-icon не должна быть частью ссылки на Event и не должна иметь подчёркивания.
- Полное текстовое описание слота сохранять через `aria-label`, чтобы компактный визуальный UX не ухудшал доступность.
- Не ослаблять правила доступа к приватным/черновым мероприятиям.
