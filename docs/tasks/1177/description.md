# 1177 — Унификация публичных страниц участников и команд

[GitHub #1177](https://github.com/a2ice/mskba/issues/1177). Согласовано владельцем 28.11.2026. Только dev после визуальной приёмки, зелёного CI и проверки доставки. Main отдельно.

## Реализация (кандидат)
- Общая навигация участников, игроков, тренеров и команд для desktop/mobile.
- Компактные карточки с существующими placeholder-ассетами; gender-specific fallback только по доступному PROFILE_GENDER, иначе единый существующий default. У скрытого фото URL не выводится.
- Нативный users.show в mskba_app, роли/блоки и ссылки из PublicUserProfileService; сохранены канонизация, meta, собственный аккаунт и редактирование по правам. Контракт JSON preview не расширяется.
- Карточки участников: дополнительные сведения только по соответствующим ROLE/PROFILE и block permissions, вычисляются после pagination. Eligibility role catalog сохраняется (task 207).
- Команды: логотип, описание, состав по форматам через TeamLineupResolver, число вакансий отдельно от remainingSpots. Детали: состав, руководство, вакансии, опубликованные желаемые площадки, завершённые публичные игры, подтверждённые турниры, публичные лиги. Скрытый профиль участника команды не раскрывает имя/аватар.
- Сообщения: existing direct-message-dialog / access/send; UI CTA только при действующем доступе, блокировки и self учитываются; серверная проверка не заменяется. Контакты команды — капитаны/менеджеры, дедупликация по canonical user; один получатель — прямой popup. Заявки остаются на существующих маршрутах TeamSportsServiceProvider; состояния pending/awaiting/accepted/blocked не позволяют повторную отправку.
- Без миграций, без новых прав, без изменения процессов аренды/мероприятий.
