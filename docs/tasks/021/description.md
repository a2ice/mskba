# 021 - Запретить создание площадок с повторяющимся названием или адресом

## Оригинальное описание

Нужно запретить создавать площадки с уже существующим alias/названием. Сейчас для названия `test` добавляется `test-2`, `test-3` и так далее. Нельзя разрешать дубли `test`, `TeSt`, `TEST` и другие варианты, отличающиеся только регистром. Также нельзя добавить площадку с уже существующим адресом.

## Подробное описание

При создании площадки система должна:

- вычислять alias из названия и отказывать, если такой alias уже существует;
- считать варианты названия, приводящие к одному alias, дублями вне зависимости от регистра;
- не создавать суффиксированные alias вида `test-2`;
- отказывать при совпадении адреса с уже существующей площадкой;
- проверять адрес как для fallback `venues.raw_address`, так и для структурированного адреса `addresses.full_address`.

## Результат

Добавлен `VenueUniquenessChecker`, который:

- вычисляет alias из названия площадки без подбора суффиксов;
- проверяет существование alias без учета регистра;
- нормализует адресные строки перед сравнением;
- проверяет дубли в `venues.raw_address`, `addresses.full_address` и structured-only адресах по `city`, `street`, `building`.

`CreateVenueRequest` теперь возвращает validation error для дублей названия и адреса. `CreateAccountVenueHandler` дополнительно повторяет проверку перед сохранением, чтобы прямой вызов use case не вернул старое поведение с `test-2`.
