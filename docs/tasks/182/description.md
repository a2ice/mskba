# 182 - Закрепить выборочное чтение и актуальность навигации документации

## Оригинальное описание

Прочитать обязательные правила. Найти нужные разделы через оглавление и поиск. Читать только материалы текущей задачи и ее зависимостей. Расширять чтение при конкретной нехватке информации. Уже прочитанное перечитывать только при изменениях или потере нужного контекста.

При важном изменении поддерживать актуальность и консистентность проектной документации, включая все необходимые оглавления, ссылки и раскрытия, чтобы решение находилось при выборочном чтении.

## Подробное описание

Небольшая правка правил документации по прямому поручению пользователя. Планирование, реализация и проверка объединены по Task Workflow. Ветка: `docs/182`; исходная `main` чистая. Перед merge обнаружено, что номер 181 занят параллельной задачей в `origin/main`; эта задача перенумерована в 182.

План: добавить общий порядок чтения и правило актуальности в Agent Rules; уточнить входную инструкцию и Task Workflow; закрепить проверяемый путь к новым решениям в правилах документации и общей спецификации. Продуктовые сценарии и код не меняются.

## Результат

- GlobalRule2 задает обязательное и выборочное чтение, работу с зависимостями и условия перечитывания.
- GlobalRule3 требует актуальности содержания и навигации вместе с важным изменением.
- Правила документации описывают путь от оглавления к раскрытию, актуализацию зависимых описаний и входящих ссылок, основной источник темы и фиксацию несоответствий вне задачи в backlog.
- `AGENTS.md`, Task Workflow и Specification согласованы с новыми правилами.

## Проверки

Проверки документации: `git diff --check`, проверка добавленных локальных ссылок и якорей, просмотр diff на согласованность правил. Автотесты приложения и сборка не требуются для этой правки.

## Статус

Выполнено. По прямому поручению пользователя изменения закоммичены в `docs/182` (19ceeb69), влиты в актуальную `main` без конфликтов и задача отмечена выполненной после merge. Проверки документации прошли.
