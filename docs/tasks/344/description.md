# 344 - Предложение роли организатора в визарде создания мероприятия

## Оригинальное описание

Предложение роли организатора в визарде создания мероприятия. Требования владельца от 20.11.2026.

## Подробное описание

Если у пользователя нет продуктовой роли «Организатор мероприятий», в нижней части соответствующего шага визарда создания Event показать фирменный предвыбранный checkbox «Добавить мне роль „Организатор мероприятий“». Если роль есть — не показывать. Снятие флажка не препятствует созданию Event. Назначить роль только при успешном создании, идемпотентно, серверной операцией через текущую модель ролей; не выдавать системные права администрирования. Сохранить выбор при восстановлении формы после авторизации, для гостя проверить актуальную роль после входа. Не создавать роль при отмене/ошибке. Сверить текущий Event-first wizard Task 337 и активные PR, не нарушать механику предзаявок и Game.

Запланировано; реализация не начата. Перед реализацией сверить актуальный код и документацию, применять Task Workflow и GlobalRule5 с учётом отдельных ограничений.
