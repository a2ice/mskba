## r1
- Изолированный /uikit/rental-workflow. mskba_app, состояния normal/inquiry/conflict. Переключение ролей, четыре конфигурации, синтетические данные, локальная переписка, действия по заявке.
- Реальные app-message-workspace, app-messages, panel, button, mskba-modal, общий chat-actions-trigger. Локальные стили только внутри rental-studio. Ни Core, ни backend не изменяются.
- Восьмидневная сетка с 30-минутным шагом fixture, выбор интервала или вариантов, причины отказа, переход от уточнения к бронированию. Счета по звеньям в обратном порядке, оплата в прямом; локальная симуляция, не финансовый расчёт. Конфликт и истечение срока — демонстрационные команды.
- Email preview не отправляет письма; никаких API и записей в БД.
