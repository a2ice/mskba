# 059 - Разрешить перенос мероприятий между свободными площадками

## Оригинальное описание

Разрешить организатору мероприятия и `superadmin` менять площадку, начало и длительность мероприятия. В текущей итерации перенос доступен только между свободными площадками, которые не требуют оплаты и подтверждения бронирования.

## Подробное описание

Форма редактирования дополняется площадкой, началом и длительностью. Если эти значения меняются, application handler атомарно переносит связанную бронь вместе с мероприятием.

Перенос разрешён, только если исходная и целевая площадки имеют свободный доступ (`!requires_payment && !requires_booking_approval`). Для несвободных площадок паспортные поля мероприятия по-прежнему редактируются, но изменение брони недоступно до появления отдельного процесса согласования.

В транзакции площадки блокируются в стабильном порядке по `id`, затем блокируются мероприятие и его бронь. Новое время повторно проверяется по физическому статусу площадки, расписанию, исключениям и чужим активным броням. Собственная текущая бронь исключается из проверки пересечений. При любой ошибке старая бронь остаётся без изменений.

Начало перенесённого мероприятия должно быть не раньше чем через 15 минут, длительность выбирается от 30 минут до 8 часов с шагом 30 минут.

## Реализовано

- форма редактирования свободного мероприятия дополнена площадкой, началом и длительностью;
- перенос разрешён только между свободными подтверждёнными работающими площадками;
- мероприятие и бронь переносятся одной транзакцией;
- собственная бронь исключается из проверки пересечений;
- площадки блокируются по `id`, затем блокируются мероприятие и бронь;
- при конфликте или нарушении расписания прежняя бронь сохраняется;
- для несвободной площадки форма объясняет ограничение и оставляет доступными паспортные поля.
