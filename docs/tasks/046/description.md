# 046 - Повысить контрастность подсказок и placeholder в тёмной теме

## Оригинальное описание

Проверить текстовые подсказки и placeholder во всей основной тёмной теме, исправить недостаточный контраст на тёмном фоне и выполнить production deploy.

## Подробное описание

Ввести единые цветовые токены для вторичного текста, placeholder и недоступных значений. На уровне темы переопределить Bootstrap-переменные и общие классы `.text-muted` и `.form-text`, а также placeholder обычных полей, textarea, auth-форм и Tom Select. Частные информативные подписи должны использовать общий контрастный токен вместо случайных тёмных значений.

Изменение не должно затрагивать декоративно приглушённые элементы, например незаполненные звёзды рейтинга, и не должно менять семантику ошибок, предупреждений или disabled-контролов.

## Проверка

- поиск непереопределённых placeholder и вспомогательных Bootstrap-классов в основной теме;
- production-сборка Vite;
- `git diff --check`;
- визуальная проверка основных форм и production HTTP smoke test после deploy.

## Результат

Основная тёмная тема получила единые токены для вторичного текста, placeholder и disabled-значений. Bootstrap-подсказки `.text-muted` и `.form-text`, нативные placeholder во всех input/textarea, auth-форма и поле Tom Select теперь используют читаемые светлые оттенки с явной непрозрачностью. Подпись загрузки аватара также переведена на общий токен.

Декоративные приглушённые элементы и семантические цвета ошибок, предупреждений и успешных сообщений не изменялись. Проверки пройдены: production-сборка Vite, полный backend suite (208 тестов, 1197 assertions) и `git diff --check`.
