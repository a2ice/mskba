# 340 - Компактный cookie-баннер и проверка согласий гостей

## Оригинальное описание

Компактный cookie-баннер и проверка согласий гостей. Требования владельца от 20.11.2026.

## Подробное описание

Баннер показывать независимо от авторизации при отсутствии сохранённого действительного выбора. Изучить фактические технические/аналитические cookie, момент запуска Метрики и правовое основание. Не блокировать необходимые session/CSRF cookie; аналитические при необходимости согласия активировать только после него. Сохранить действие выбора между страницами и входом. Уменьшить шрифт, кнопки и вертикальные padding; opacity .9, hover/focus-within 1, плавный переход. Проверить desktop/mobile/TMA, доступность и safe area. Проверить фактическое поведение в чистой сессии. Источники: https://yandex.ru/legal/cookies_policy/ru/ ; https://sberbusiness.live/publications/cookie . Не считать юридический аудит выполненным без проверки фактического подключения.
