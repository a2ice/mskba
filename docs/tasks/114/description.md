# 114 - Сделать статусы дублей пользователей визуально понятными

## Оригинальное описание

В таблице дублей пользователей белые badge в колонке «Статус» плохо читаются и не позволяют быстро отличить результат обработки пары.

## Подробное описание

- убрать зависимость кнопки статуса от нативного светлого оформления Safari;
- различать состояния цветом: оранжевый для ожидающей проверки пары, зелёный для объединённой и красный для отклонённой;
- дополнить цвет точкой-индикатором, сохранив текстовую подпись как основной источник смысла;
- добавить кнопке доступное описание действия и заметный focus state;
- не менять бизнес-логику разрешения дублей и фильтрации списка.

## Проверка

- собрать frontend-ассеты;
- проверить Blade view cache;
- вручную проверить контраст и состояния `pending`, `merged`, `rejected` на desktop и mobile.

## Результат

- кнопки статуса больше не наследуют нативный светлый фон Safari;
- `pending`, `merged` и `rejected` различаются текстом, цветом и точкой-индикатором;
- кнопка получила доступное описание открываемого действия и заметное состояние клавиатурного фокуса;
- бизнес-логика и HTTP-контракты объединения дублей не изменялись.
