# 347 - Контекстные тултипы организаторов и игроков на мероприятиях

## Оригинальное описание

Контекстные тултипы организаторов и игроков на мероприятиях. Уточнения владельца в разговоре 20.11.2026.

## Подробное описание

Дополнение к задаче 345, не отдельная система рейтингов. На публичной странице мероприятия у организатора и игроков показывать компактный повторно используемый tooltip/popover по наведению, фокусу и touch. Организатор: рейтинг соответствующей роли, число реально проведённых мероприятий; игрок: рейтинг роли, краткая публичная информация и число сыгранных игр. Использовать существующие агрегаты/доменные статусы, не считать отменённые мероприятия или простые заявки как завершённые игры; отсутствие данных не равно нулевому рейтингу. Соблюдать настройки видимости, не раскрывать закрытые данные, избегать N+1. Не менять правила оценки из 345 без отдельного согласования.

Приёмка: разные роли, неизвестный рейтинг, пустая статистика, скрытый профиль, клавиатура/mobile; корректные числа из фактических завершённых игр и мероприятий.

## Общие UI-требования и релиз

[UI Kit и гайдлайн](../../specification/ui-design-system.md): штатные компоненты, модальные окна с заголовком, фирменными крестиком и иконкой перемещения, без eyebrow; если действий нет, не дублировать закрытие кнопкой в footer. Отдельная ветка, необходимые проверки/CI, merge в main и dev только своей правки, подтверждение деплоев и отчёт. Значимое обновление — system_update после подтверждённой production-доставки.
