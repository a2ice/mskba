# 117 — Первый полноценный SVG Player Character и конфигуратор внешности

## Цель

Заменить технический placeholder игрового персонажа на первую полноценную визуальную модель, с которой пользователю приятно взаимодействовать. Этот интерфейс рассматривается не только как настройка профиля, но и как будущая точка входа в воронку персонализации и заказа баскетбольной формы.

## Принципы

- не использовать набор готовых растров под каждую комбинацию;
- renderer остаётся заменяемым и state-driven;
- первая версия строится на inline SVG;
- анатомия не должна состоять из примитивных овалов: руки разделены на плечо/верхнюю часть руки, локоть, предплечье, кисть; ноги — на бедро, колено, голень, голеностоп/стопу;
- базовый стиль — упрощённо-реалистичный, а не фот реализм и не cartoon stick figure;
- все изменения внешности отображаются live;
- интерфейс должен быть достаточно качественным, чтобы пользователь хотел экспериментировать с образом.

## Возможности V1

- мужской / женский preset;
- 6 тонов кожи;
- gender-dependent наборы причёсок;
- 6 цветов волос;
- мужские варианты усов/бороды;
- 4 комплекта баскетбольной формы;
- сохранение выбранного appearance state в `player_profiles.extra.character` с версией конфигурации;
- сохранение существующего renderer-agnostic контракта и события `player-character:change`;
- рост/вес/body_type продолжают влиять на масштаб и пропорции фигуры;
- subtle idle animation отключается через `prefers-reduced-motion`.

## Persistence

Новая таблица пока не создаётся. Appearance хранится как versioned sub-document:

```json
{
  "character": {
    "version": 1,
    "gender": "male",
    "skin_tone": "warm",
    "hairstyle": "male_fade",
    "hair_color": "dark_brown",
    "facial_hair": "none",
    "uniform_kit": "mskba_home"
  }
}
```

При обновлении персонажа другие ключи `extra` должны сохраняться.

## Future-proofing

В дальнейшем renderer может быть расширен:

- новыми body presets;
- аксессуарами/equipment slots;
- формой команды;
- персональными цветами, номером и дизайном;
- несколькими poses;
- более сложной SVG-анимацией;
- при необходимости — заменён на Canvas/WebGL/Three.js без изменения формы данных и основного configurator UI.

## Acceptance criteria

- placeholder полностью заменён на SVG character;
- явно видны отдельные анатомические сегменты конечностей;
- male/female действительно меняют модель/доступные опции;
- skin tone, hair, facial hair и uniform переключаются live;
- женский preset не допускает мужские hairstyle/facial hair значения;
- appearance сохраняется и восстанавливается после reload;
- старые ключи `player_profiles.extra` не теряются;
- desktop/mobile layout не ломается;
- `AccountPlayerProfileTest`, character tests, Blade cache и frontend build проходят.
