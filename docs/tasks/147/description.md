# 147 — Финальная полировка location mini-wizard

## Цель

Исправить оставшиеся UX-регрессии вложенного location mini-wizard после Tasks 145–146.

## Scope

- В карточке завершённой настройки показывать выбранный район/округ и использовать текст «Локация установлена».
- Зафиксировать кнопку `Далее / Готово` у правого края footer mini-wizard даже когда `Пропустить` скрыта.
- Перенести действие «Текущая локация» внутрь первого шага mini-wizard.
- При успешной геолокации использовать существующую точку поиска и автоматически перейти к финальному шагу «Улица и площадка»; при ошибке показывать сообщение внутри mini-wizard.
- Не менять серверную географическую модель и существующую radius/discovery механику.
