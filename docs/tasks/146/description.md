# 146 — Исправить layout вложенного location mini-wizard и приоритет поиска метро

После Task 145 на production выявлены две UX-регрессии.

## Проблемы

1. Контент вложенного popup mini-wizard занимает только узкую левую колонку. Причина: после переноса `.home-event-location__mini` из `.home-event-location--conditional` во вложенный modal на него снова начинает действовать legacy-grid `150px minmax(0, 1fr)` из базового CSS.
2. Predictive-поиск метро сохраняет исходный порядок совпадений. Поэтому при запросе `сел` совпадение внутри слова (`Красносельская`) может оказаться выше совпадения с начала названия (`Селигерская`).

## Решение

- во вложенном modal принудительно переводить mini-wizard в одноколоночный полноширинный layout, не меняя основной popup;
- после формирования списка метро сортировать видимые варианты: сначала станции, название которых начинается с введённого фрагмента, затем остальные совпадения; внутри групп — по русскому алфавиту;
- не менять текущую группировку одноимённых станций по линиям и логику выбора/радиуса.
