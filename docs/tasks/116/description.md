# 116 - Уточнить масштаб сцены и влияние веса на Player Character

## Описание

Доработать foundation игрового персонажа на `/account/participation/player` без изменения backend/DB-контракта.

### Вертикальный safe-area сцены

- рабочая вертикальная область шкалы 0–250 см должна быть немного отступлена от физической рамки stage;
- использовать внутренний plot-area с запасом примерно по 10 px сверху и снизу;
- внутри plot-area должны находиться шкала, ось, линия фактического роста, фигура и линия пола;
- внешний контейнер по-прежнему представляет сцену 200 × 250 см;
- запас нужен для будущего renderer, где персонаж может стоять в полуповороте, а носки/кроссовки и другие выступающие детали не должны упираться в рамку;
- horizontal width marker и служебный badge могут использовать внешнюю безопасную область, не ломая шкалу.

### Вес + телосложение

Вес должен визуально влиять на placeholder совместно с выбранным телосложением.

- `body_type` задаёт базовые пропорции;
- `weight_kg` плавно модифицирует массу/ширину;
- при известном росте вес нормализуется относительно роста, чтобы одинаковый вес не выглядел одинаково у игрока 160 и 220 см;
- меняется не только общий контейнер по X, но также пропорции корпуса, рук и ног;
- изменение веса в форме должно сразу обновлять stage без сохранения страницы;
- raw contract `gender / height / weight / body-type / skin-tone / hairstyle` остаётся renderer-agnostic.

## Acceptance criteria

- шкала и фигура имеют верхний и нижний внутренний запас;
- отметки `250` и `0` больше не прижаты к border stage;
- линия пола расположена выше нижней рамки;
- при одинаковых росте и телосложении изменение веса даёт заметное изменение фигуры;
- при одинаковом весе, но другом росте ширина рассчитывается естественнее за счёт нормализации;
- изменение `body_type` продолжает заметно менять базовый тип фигуры;
- desktop/mobile layout Task 115 не ломается;
- schema/database не меняются.
