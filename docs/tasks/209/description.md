# Task 209 — Убрать избыточные tooltip и нейтрализовать `?`

## Проблема

После унификации tooltip любой `title` на читаемом тексте превращается в стандартный text-tooltip с пунктирным подчёркиванием и кнопкой `?`. На карточках команд встречались `title`, полностью повторяющие видимое содержимое (`1 участник`, `Тренер: …`, `Капитан: …`), из-за чего появлялись бессмысленные подсказки. Дополнительно все `?` постоянно были оранжевыми и визуально конкурировали с основным контентом.

## Решение

- Из team catalog удалены дублирующие `title` у количества участников, тренера и капитана; `aria-label` сохранён.
- Общий tooltip enhancer теперь страхует весь проект: text-tooltip не создаётся, если нормализованный `title` полностью совпадает с видимым текстом источника после удаления иконок/скрытых элементов.
- Если уже enhanced-элемент динамически получает такой дублирующий `title`, enhancer очищает прежний synthetic tooltip и generated `?`.
- Стандартный `?` по умолчанию полупрозрачно-белый: нейтральные border/background/text.
- Оранжевый акцент включается при hover/focus связанного text-source или самого tooltip trigger.
- Содержательные tooltip, где `title` объясняет или дополняет видимый текст, продолжают работать.

## Проверки

- contract test проверяет duplicate suppression helpers;
- contract test фиксирует neutral default color и source-hover accent selector;
- team catalog contract гарантирует отсутствие трёх конкретных дублирующих `title`.
