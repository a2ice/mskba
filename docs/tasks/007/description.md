# 007 - Добавить FAQ в главное меню и страницу первых шагов

## Оригинальное описание

Создать раздел FAQ в главном меню header в группе "Еще".

Маршруты:

- `/faq` - общий раздел FAQ;
- `/faq/welcome` - первые шаги.

Первым разделом FAQ должен быть `/faq/welcome`.

## Подробное описание

### Цель

Добавить пользовательский справочный раздел, куда можно вести пользователя из welcome-уведомления и из главного меню.

### Решение

FAQ реализуется как статический справочный раздел текущей темы:

- route `faq.index` для `/faq`;
- route `faq.welcome` для `/faq/welcome`;
- пункт "FAQ" в dropdown-группе "Еще";
- страница индекса FAQ со ссылкой на первые шаги;
- страница "Первые шаги" с базовым описанием дальнейших действий после регистрации.

Отдельный bounded context не вводится, потому что текущая задача добавляет справочные страницы, а не управляемую базу знаний.
