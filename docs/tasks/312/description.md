# 312 — Системный пользователь в Filament

Суперадминистратор может назначить или снять роль «Системный пользователь» в карточке пользователя. Назначение фиксируется в истории и отзывает персональные разрешения предыдущей роли.

Неподтверждённый системный пользователь может войти в Filament с индивидуальным разрешением «Вход в Filament /backoffice». Право входа и остальные разрешения назначаются персонально. Для выбора доступен набор операционных прав роли `admin`. При обновлении ранее не действовавшие назначения остаются выключенными. Блокировка закрывает вход. Правило подтверждения для других ролей сохраняется.

При отклонении изменения статуса Filament показывает причину и возвращает сохранённое значение в поле.

## Проверка на DEV

1. Под суперадминистратором назначить роль тестовому неподтверждённому аккаунту. Проверить запись в истории и отказ во входе до выдачи разрешения.
2. Выдать право входа и просмотр конструктора. В отдельной сессии открыть Filament и список компонентов, проверить отсутствие доступа к действиям, для которых права ещё не выданы.
3. Добавить нужные права CSS и JS, проверить действия в компоненте. Проверить назначение прав вне конструктора. Отозвать право входа и повторить запрос.
4. Подтвердить тестовый обычный аккаунт без проверенного основного контакта. Убедиться, что уведомление объясняет причину и статус остаётся прежним.
