# Task 292. Контактные каналы в настройках подписки

## Требование
- «Добавить Telegram» и «Добавить Email» открывают **тот же переиспользуемый диалог добавления контакта**, что и в кабинете, с заранее выбранным типом.
- Контакт подтверждается через действующий механизм (Telegram-бот / email-код); после успешного подтверждения проверка доступности обновляется без перезагрузки.
- Канал, который инфраструктура реально не поддерживает, **не выводить вообще** (пока нет SMS, не выводим телефон, его checkbox и «Добавить Телефон»).
- Для доступных каналов, требующих настройки, показывать краткое действие добавления вместо длинных объяснений. Недоступный по условиям, но технически поддерживаемый канал — disabled, рядом рабочая ссылка/кнопка.
- «Личные сообщения» выбраны по умолчанию, не должны неожиданно сбрасываться при обновлении состояния других контактов.
- Сервер повторно проверяет права и доступность канала.

## Приёмка
Открыть двухшаговую подписку, проверить Telegram и Email, модальное окно и подтверждение, исключение SMS и обработку ошибок.

## Порядок
После приёмки Task 291, отдельный PR, зелёный CI, dev и приёмка.
