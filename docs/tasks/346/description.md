# 346 - Наполнить подсекции главной: преимущества поиска площадок

## Оригинальное описание

Наполнить подсекции главной: преимущества поиска площадок. Уточнения владельца в разговоре 20.11.2026.

## Подробное описание

Дополнить подраздел «Площадки» на главной странице актуальным описанием возможностей портала: карта и поиск рядом со мной, фильтрация площадок с ближайшими мероприятиями, существующие фильтры. Проверить фактическую доступность возможностей из задач 342 и 343 в целевой ветке до публикации; не обещать недоступное. Сохранить текущую композицию и UI Kit, адаптивность, реальные ссылки/CTA к каталогу; не менять остальной hero без необходимости. Для остальных подсекций не придумывать неподтверждённые преимущества.

Приёмка: desktop/mobile, отсутствие переполнения, ссылки открывают ожидаемый каталог/режим; описания соответствуют фактическим фильтрам. При необходимости релиз после 342/343.

## Общие UI-требования и релиз

[UI Kit и гайдлайн](../../specification/ui-design-system.md): штатные компоненты, модальные окна с заголовком, фирменными крестиком и иконкой перемещения, без eyebrow; если действий нет, не дублировать закрытие кнопкой в footer. Отдельная ветка, необходимые проверки/CI, merge в main и dev только своей правки, подтверждение деплоев и отчёт. Значимое обновление — system_update после подтверждённой production-доставки.

## Статус

Запланировано; реализация не подтверждена.
