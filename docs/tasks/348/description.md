# 348 - Интересуются: пользователи площадки в ЛК и Filament

## Оригинальное описание

Интересуются: пользователи площадки в ЛК и Filament. Уточнения владельца в разговоре 20.11.2026.

## Подробное описание

В контуре конкретной площадки в ЛК по действующему контракту и в карточке площадки Filament добавить «Интересуются». Единая серверная выборка/права: избранное, активная игровая подписка с прямой привязкой, совпадение по условиям/географии; учитывать исключения и обязательные условия, дедуплицировать по каноническому пользователю, объяснять причины. Связано с 286, 288, 330, 339, 345; не дублировать matching, группы или подсистему сообщений. Показывать доступные публичные роли, рейтинги, игровую/организаторскую активность, фильтры по роли и активности. Для уполномоченного сотрудника — личное сообщение и персональное предложение/уведомление через существующий pipeline, с отдельными правами, настройками приватности и согласиями, rate limit и аудитом. Не раскрывать личности по одной подписке/избранному без допустимого согласия и не показывать персональные контакты/точный график; для остальных — агрегаты, как предусмотрено 288. Проверить, покрывает ли «Мои подписки» (339) сценарий «Мои интересы» (управление условиями, включёнными/исключёнными площадками); не создавать дублирующий раздел, если достаточно существующего. Не реализовывать весь коммерческий контур 288 в рамках этой задачи; расширение доступа к данным требует сверки privacy-модели и согласия пользователя.

Приёмка: оба интерфейса, scoped permissions и IDOR, совпадения/исключения/дубли, отсутствующие данные, запрет сообщения при блокировке/настройках, согласия и антиспам, пагинация и mobile.

## Общие UI-требования и релиз

[UI Kit и гайдлайн](../../specification/ui-design-system.md): штатные компоненты, модальные окна с заголовком, фирменными крестиком и иконкой перемещения, без eyebrow; если действий нет, не дублировать закрытие кнопкой в footer. Отдельная ветка, необходимые проверки/CI, merge в main и dev только своей правки, подтверждение деплоев и отчёт. Значимое обновление — system_update после подтверждённой production-доставки.
