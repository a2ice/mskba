# 044 - Добавить управление сохранёнными аватарами

## Оригинальное описание

Добавить удаление аватарки и выбор активной: под основным аватаром показывать маленькие превью, клик по превью устанавливает его активным.

## Подробное описание

В аккаунте отображаются до трёх сохранённых аватаров. Активный выделяется рамкой и полной непрозрачностью; остальные доступны для выбора. Каждый сохранённый файл можно удалить с подтверждением действия.

Выбор и удаление выполняются только владельцем профиля. Изменения сериализуются блокировкой профиля, чтобы параллельная загрузка, выбор и удаление не нарушали инвариант одного активного аватара. При удалении активного следующий новый по времени файл становится активным; при удалении последнего используется системная заглушка.

Явно удалённая Telegram-копия не должна восстанавливаться при следующей авторизации, пока URL исходного Telegram-аватара не изменился.

## Проверка

- feature-тест выбора активного аватара;
- feature-тест удаления активного аватара и физического файла;
- feature-тест запрета управления чужим аватаром;
- feature-тест запрета повторного импорта удалённой Telegram-копии;
- полный backend test suite и frontend production build.

## Результат

Под основным изображением добавлена галерея из трёх превью с выделением активного. Выбор и удаление реализованы отдельными HTTP-действиями и application handlers; все запросы ограничены профилем текущего пользователя и сериализуются через блокировку профиля. Удаление активного файла назначает следующий, удаляет физический файл и оставляет soft-delete tombstone для Telegram-синхронизации.

Проверки пройдены: профильные feature-тесты и полный backend suite (201 тест, 1157 assertions), production-сборка Vite и `git diff --check`.
