## Повторный запуск при необходимости

Открыть `.vscode/mcp.json` и нажать Start над `playwright` либо выбрать
`MCP: List Servers` → `playwright` → запуск. Подтвердить доверие, если VS Code
его запросит, и включить инструменты сервера в чате. Первый запуск через npx
может скачать пакет в npm cache; `package.json` приложения не меняется.
После переподключения проверить реальную доступность инструментов агенту.
Создание конфигурации само по себе не подтверждает запуск сервера в VS Code.
