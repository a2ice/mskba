# Дизайн-стенд 002

Изолированный визуальный образец принятого гайдлайна **1.0** (ревизия 3, 2026-09-06).
Не Vue-тема, не production
маршрут и не реализация компонентной библиотеки 004. Все события вымышлены;
формы, фильтры и диалог работают только в текущей странице, без API и сохранения.

## Открытие

URL запущенного стенда: http://127.0.0.1:8013/.

В локальных задачах VS Code добавлена `Preview theme design guideline`.
Для воспроизведения без этой локальной задачи: из корня `site` выполнить
`python3 -m http.server 8013 --bind 127.0.0.1 --directory docs/tasks/139/preview`.
Требуется Python 3; сервер должен отдавать только эту папку, не корень репозитория.
Остановить можно через завершение задачи или Ctrl+C в её терминале.
`.vscode/tasks.json` локален и не входит в commit.

## Зависимости и границы

- Две существующие иллюстрации берутся с `http://localhost:8000/images/`;
  для них требуется запущенное основное приложение. Новые assets не добавлены.
- Inter загружается с Google Fonts; без сети используется Arial. Это временная
  зависимость стенда; локальные лицензированные WOFF2 запланированы на 004.
- Bootstrap, Vue, Vite и бизнес-JavaScript приложения не подключаются.
- Загрузка файла только выбирает локальный файл; проверки размера/preview/upload
  ещё не реализованы. Native select не заменяет будущий predictive select.
- Кнопки действий показывают образец диалога/уведомления, не создают заявки.
- В header/footer используется предоставленный пользователем логотип:
  `public/images/logo-image.png` → `public/images/logo-mark-100.png` (98×100 px,
  21 278 bytes, RGBA). Исходник сохранён. Pillow: видимые границы alpha >8,
  дополнительно 4 px поля, crop `(303,24,1234,971)`, thumbnail 100×100 LANCZOS,
  PNG optimize. Отсекаются практически прозрачные поля, форма не искажается.
  В интерфейсе высота 40 px; соседняя надпись MSKBA сохранена.
- Все UI-иконки — [Tabler Icons Outline 3.46.0](icons/README.md), оригинальный
  локальный subset с MIT-лицензией. Ручные рисунки заменены в ревизии 2.
- Матрица всех будущих состояний описана в гайдлайне; стенд демонстрирует её часть.
