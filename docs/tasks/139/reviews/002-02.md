## Замечания → изменения

1. **Мяч и единая иконографика.** Все самодельные paths заменены на оригиналы
   Tabler Icons Outline 3.46.0, включая `ball-basketball`. Локальный subset из
   17 иконок и MIT-лицензия; [источники](../preview/icons/README.md).
   Проверено машинное совпадение каждого path с upstream закреплённой версии.
   Правило готового пакета добавлено по прямому указанию пользователя в
   [CaseRule12](../../../specification/agent-rules.md#caserule12---использовать-готовый-пакет-ui-иконок).
2. **Диалог.** Явное fixed-центрирование относительно viewport. Высота по контенту,
   минимум 300 px, максимум 95dvh; ширина до 560 px и не более 90vw, минимум
   300 px при достаточном окне. На слишком малом viewport лимит viewport важнее
   минимума. Header/close и footer не прокручиваются; body со своим scroll.
   Фон блокируется от прокрутки, клавиатурный цикл учитывает body.
3. **Градиент media-card.** Прозрачный → точный `--surface`, зона 25% высоты
   карточки. Hover/focus: 35% и дополнительная плотность, transition 240 ms;
   reduced motion — без transition. Последние 2 px непрозрачны для устранения
   светлого шва при дробных размерах. Бейдж остаётся над overlay, клики проходят.
4. **Компактная площадка.** Адрес 12/16, промежутки 4 px, текст 70 px по высоте,
   mobile-preview 72×72, desktop 88×88, вертикальные центры совпадают.
   Длинный текст может увеличивать строку, а не обрезается.
5. **Native select.** Системная стрелка скрыта через appearance; Tabler chevron-down
   20×20 отстоит на 16 px от края, для текста резервируется 48 px справа.
   SVG не перехватывает pointer events, сам select и dropdown остаются нативными.
   В forced-colors возвращается системное оформление стрелки.

## Браузерные результаты

Ширины: **320, 360, 390, 639, 640, 768, 1023, 1024, 1440**, высота 900.
Нет root overflow или видимых элементов main за viewport. Квадратные размеры
мяча сохраняются во всех видимых местах (22/24/32/36 px). Центры превью и текста
компактного ряда совпадают на каждой ширине. Console errors и failed requests
при наблюдаемой загрузке/обходе не зарегистрированы.

нативной прокрутки), фокус остаётся в body.

### Градиент и select

- Desktop-card: fade 115.19 → 161.26 px, то есть 25% → 35% внутренней высоты
  карточки; opacity дополнительного слоя 0 → 1. Координата body и высота карточки
  не меняются. Hover и focus дают одно состояние. Reduced motion: transition 0s.
- Select: фактический отступ стрелки 16 px, размер 20×20, pointer-events none.
  Выбор через штатное действие автоматизации `selectOption` меняет значение
  на «Спортивный зал». Forced-colors: SVG скрыт, appearance auto.
- **Не подтверждён** выбор внутри системного выпадающего меню клавиатурными
  событиями автоматизации: значение не изменилось. Нативный popup находится
  вне обычного DOM; это не считается пройденной ручной/кроссбраузерной проверкой.
  JS стенда не перехватывает клавиши select. Требуется ручная проверка на целевых ОС.

## Проверки файлов и ограничения

JS syntax, диагностика HTML/CSS/JS, git diff whitespace, SVG source/лицензия
проверены. Vite/PHPUnit не запускались: PHP и bundled assets не менялись.
CSS media-fade использует container query units (`cqw`) внутри карточки;
целевая браузерная матрица новой темы должна учитывать их поддержку.

Safari/Firefox, реальные iOS/Android/Telegram, экранная клавиатура, browser zoom
200% и системное меню select остаются отдельной проверкой. Desktop resize не
заменяет устройства. Стандартный CSS-подход не объявляется проверенным во всех
браузерах по одному запуску Chrome.
