## Предлагаемое визуальное решение

Чёрно-графитовая среда, оранжевое главное действие и смысловой акцент,
атмосферная фотография, тяжёлая кириллица Inter, многослойные карточки.
На desktop hero и ближайший матч стоят рядом; на mobile — вертикальный поток
с нижней навигацией. Ниже показаны формы, статусы, таблица и правила композиции.
Длина всего стенда объясняется каталогом образцов, а не предложением такого
размера будущей главной страницы. Точные значения и расширения языка референсов
предлагаются на согласование, не объявляются измеренными по скриншотам.

## Проверки и результаты

| Проверка | Результат |
| --- | --- |
| Ширины 320, 360, 390, 639, 640, 768, 1023, 1024, 1440 при высоте 900 | root overflow отсутствует; видимые элементы main не выходят за viewport |
| Основные снимки 1440×900, 390×844, 768×1024, 320×800 | сохранены; desktop/mobile первый экран дополнительно просмотрен визуально |
| Изображения и Inter | успешно загружены; broken images не обнаружены |
| Начальная загрузка и обход размеров | console/page errors, failed requests и HTTP ≥400 не зарегистрированы |
| Поиск/формат | 3×3 оставляет 1 событие; неизвестный запрос показывает empty; reset возвращает 2 события |
| Пустая форма | error виден, aria-invalid=true, focus на названии, error связан через aria-describedby |
| Заполненная форма | локальный success «Данные никуда не отправлены» |
| Checkbox / switch / radio | переключаются, выбор radio взаимоисключающий |
| Dialog | открытие, Tab/Shift+Tab, Esc, focus restore проверены |
| Toast | показ/закрытие; на 390 px находится выше нижней навигации |
| Reduced motion | animation-name spinner становится none |
| Длинные русские названия и кнопка | временные строки в DOM на 320/768/1024: root/element overflow не обнаружен |
| Reflow 720×450 | scrollWidth=clientWidth=705; не заменяет фактический browser zoom |

Исправлено по проверке: при native dialog Tab на границе списка уходил из его
DOM (в browser focus boundary). Добавлен явный цикл между кнопками статического
диалога. Повторный прямой цикл: cancel → confirm → close; обратный с close → confirm;
Esc возвращает focus на инициатор. Это решение для данного стенда, не универсальный
focus manager будущего Vue-компонента.

### Контраст

Расчёт WCAG relative luminance по фактическим CSS-токенам (не скриншоту):

| Пара | Минимальный коэффициент |
| --- | --- |
| text на четырёх основных поверхностях | 15.13:1 |
| muted на тех же поверхностях | 7.75:1 |
| faint на тех же поверхностях | 5.75:1 |
| accent на тех же поверхностях | 6.22:1 |
| control-line на тех же поверхностях | 3.75:1 |
| on-accent на default/hover/active primary | 5.93:1 |

Текстовые пары выше проходят 4.5:1; значимые границы — 3:1. Это не сертификат
WCAG всего экрана: фото, полупрозрачные и отдельные статусные поверхности требуют
контекстной проверки. Disabled и декоративные линии не включены в эти требования.

## Ограничения и непроверенное

- Фактический browser zoom 200% не проверен. Эксперимент `body.style.zoom=2`
  дал scrollWidth 1545 при clientWidth 1425: CSS zoom не переключает media queries
  как browser zoom, поэтому не считается пройденной проверкой. Отдельно проверен
  reflow на половине desktop viewport; реальную zoom-проверку ещё нужно выполнить.
- Нет проверки реального iOS/Android, Safari, экранной клавиатуры, screen reader
  и Telegram WebView/safe-area. Desktop resize не заменяет их.
- Не проверены сценарии отсутствия изображений/Google Fonts, истечения сессии,
  реальных запросов, повторной отправки и оплаты: это статический стенд без backend.
- Не все состояния будущей библиотеки реализованы; predictive select, tooltip,
  pagination, bottom sheet и upload workflow остаются контрактом этапа 004.
- Старый дефект B139-01 не исправлялся; toolbar данного стенда переносится отдельно.
- Vue/Vite build и PHPUnit не запускались: production assets и PHP не менялись.
  Проверены синтаксис JS, git diff и диагностика изменённых файлов.
