# 001-01 — Исходный браузерный baseline mskba_dark

## Статус и окружение

Дата: 2026-09-06. Шаг 001 принят пользователем ответом «да» с уточнением:
строго соблюдаем гайдлайн, сам стиль берём из скриншотов — современный application-like.
Это фиксация текущего интерфейса, не приёмка новой темы и не полный UX-аудит.
Гайдлайн новой темы ещё не утверждён: версия не применима.

- Ветка: `feature/139`; HEAD: `d2fcdf8e1dc351e5a95fc32f6c023945847f5830`.
- Незакоммичены документы задачи, MCP и настройки исключения служебных артефактов;
  код/стили приложения не менялись. База локальная, миграции применены ранее.
- URL: `http://localhost:8000`; текущая тема `mskba_dark`.
- Chrome `152.0.7977.82`, macOS, Playwright MCP, изолированный профиль, гость.
- Viewport в CSS px: 1440×900, 390×844, 360×800, 768×1024.
- Full-page screenshots сохранены для 1440 и 390; дополнительные снимки
  показывают tablet-каталог и раскрытое мобильное меню.
- Авторизация, платёжные действия, отправка форм и изменение предметных данных
  агентом не выполнялись. Обычные heartbeat/загрузка карты запускались самим сайтом.

## Сценарий и ожидания

Открыть страницы, дождаться загрузки и шрифтов, изменить viewport, проверить
доступность заголовка/навигации, сетевые ошибки, console/page errors и горизонтальные
границы. Сохранить полный документ для исходного сравнения. На странице площадки
отдельно проверить открытие меню, переключение вкладки и закрытие.

Ожидание: HTTP 200, отсутствие ошибок ресурсов/JavaScript, доступные controls
без обрезки, рабочие mobile-навигация и отображение карточки. Снимки показывают
фактическую старую тему, не желаемое оформление.

## Найденные особенности

### B139-01 — Поиск каталога обрезается на tablet

При 768×1024 `.catalog-toolbar__search` начинается на x = −8.77 px и имеет ширину
180 px. Родительский flex-toolbar остаётся внутри контента (x = 30.12…722.88),
но его содержимое не умещается. Повторная прямая загрузка при этом viewport
воспроизводит результат; это не только следствие resize.

Корневой `scrollWidth` при этом равен `clientWidth`: проверка только ширины документа
пропустила бы дефект. В текущем планировании старый CSS не исправлялся.
Владелец предотвращения регрессии: 002/004 — правила toolbar и компонентов,
007 — повторная проверка каталога на 768 px и соседних breakpoint.

### Допустимый внутренний overflow площадки

У мобильных вкладок `venue-mobile-sticky-nav` есть `overflow-x: auto` и собственная
ширина прокрутки; правые вкладки за viewport не означают расширение страницы.
Canvas Яндекс-карты шире экрана, но ограничен предком `ymaps…inner-panes` с
`overflow-x: hidden`; корневое переполнение отсутствует. Их не записываем
как дефекты только по bounding box дочернего элемента.

### Композиция и навигация

- Высота главной: 5218 px на desktop и 7811 px на 390 px; нынешняя композиция
  преимущественно длинная лендинговая, это исходная точка для нового app-home.
- Заголовки вкладки главной/каталога/входа содержат суффикс `Laravel`;
  при переносе нужно проверить единые brand/meta-настройки (003/010).
- На mobile странице площадки кнопка меню раскрывает контекстные вкладки;
  подтверждены смена «Меню площадки» на «Главное меню», выбранное состояние
  и закрытие меню. Полная клавиатурная ARIA-проверка пока не выполнялась.

## Ограничения

- Не проверены Safari, реальные iOS/Android и Telegram WebView.
- Resize desktop Chrome не воспроизводит touch, мобильную клавиатуру, DPR устройства
  или системные safe-area. Это responsive baseline, а не сертификация мобильной версии.
- Не проверены 200% zoom, все промежуточные ширины, контраст, все hover/focus/validation
  состояния, отправка форм, authenticated/admin permissions и полный booking-flow.
- Измерения геометрии и screenshots не заменяют пользовательскую оценку композиции;
  отдельная приёмка нового дизайна ещё предстоит после создания гайдлайна.
- Карта и данные могут меняться; LAB-площадка — текущий пример, не гарантированный
  стабильный fixture. Текущий URL и дату нужно учитывать при повторной проверке.

## Решение по шагу

001 принят как подготовительный шаг: охват, референсы, работающий браузер и
исходные материалы доступны. Найденный дефект старой темы остаётся в дальнейшей
матрице. Приёмка не распространяется на ещё не созданный дизайн или непроверенные
сценарии. Разрешён отдельный коммит 001 без push по ранее согласованному порядку.
