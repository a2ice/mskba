# 005 — Общий layout и навигация приложения

## Цель
Создать единый каркас всех новых экранов.

## Описание
Реализовать header, desktop navigation/sidebar, mobile bottom bar, область контента,
breadcrumbs/назад и слои модальных окон по гайдлайну. Отдельно согласовать состав
пунктов. Обеспечить active-состояния, прямые ссылки, Back/Forward, scroll restoration,
фокус при смене страницы и переходы на legacy. Не переписывать серверные правила меню.

## Статус
Запланирована. Зависимость: 004.

## Критерии приёмки
Каркас принят на desktop/mobile; клавиатура и sticky-панели не перекрывают контент.
Проверены reload, прямой вход и возврат между новой темой и legacy, нет двойных
обработчиков/подписок. Для включённого в объём Mini App проверен реальный WebView.

## Результат выполнения
Не выполнено. Ожидается визуальная приёмка layout до предметных страниц.
