# 001 — Границы, сценарии и визуальные референсы

## Цель
Зафиксировать объём первой версии и проверяемый визуальный ориентир.

## Описание
- Инвентаризировать текущие маршруты, страницы, компоненты и состояния.
- Разделить public/account/admin/Telegram: новая тема, временный legacy или вне объёма.
- Утвердить ключевые сценарии, порядок переноса, браузеры и участие Mini App.
- Разобрать презентацию: типографика, карточки, фотографии, навигация; отделить
  работающие функции от будущих возможностей. Получить доступные исходные assets.
- Сохранить исходные desktop/mobile-снимки текущего UI для сравнения.

## Статус
Принята пользователем 2026-09-06. MCP подключён, исходные проверки выполнены.
При приёмке уточнено: строгое соблюдение гайдлайна не означает строгий визуальный
стиль; современный application-like дизайн выводится из приложенных скриншотов.

## Критерии приёмки
Пользователь согласовал матрицу экранов, границы первой версии и референсы.
Все открытые решения из описания задачи имеют ответ либо владельца следующего шага.

## Результат выполнения
Собран фактический список GET-маршрутов и групп Blade-страниц. Подготовлены
[черновик охвата](../scope.md), [разбор референсов](../references.md) и
[отчёт о доступе к браузеру](../browser-access.md).
Приняты публичная часть + аккаунт, legacy-админка и условное откладывание нового UI
Mini App с сохранением совместимости. Исходников презентации нет; запрашивать новые
assets по мере необходимости с параметрами. Добавлена конфигурация Playwright MCP,
доступ инструментов подтверждён реальными вызовами.

В [отчёте 001-01](../reviews/001-01.md) зафиксированы четыре страницы на четырёх
размерах окна, 10 снимков и проверка мобильного меню. Ошибок console/network в
наблюдаемом интервале нет; найдено обрезание поиска каталога при 768 px.
Гайдлайн ещё не существует: baseline не является визуальным эталоном новой темы.
Проверки авторизованных экранов, Safari/устройств и подробных контрактов относятся
к последующим этапам; владельцы открытых решений указаны в `scope.md`.
Приёмка получена ответом «да» с уточнением визуального направления. Ограничения
baseline остаются явно задокументированными; следующий этап — гайдлайн 002.
