# 006 — Главная страница приложения

## Цель
Показать первый цельный экран в стиле презентации на основе принятой дизайн-системы.

## Описание
Согласовать композицию hero, быстрых действий, ближайших событий и остальных
сводных карточек. Использовать подготовленные сервером реальные данные и общие
компоненты. Декоративные изображения не должны ухудшать чтение и скорость загрузки.
Не выдавать макетные фильтры и будущие функции за работающие действия.

## Статус
Запланирована. Зависимость: 005.

## Критерии приёмки
Приняты desktop/mobile и состояния гость/пользователь/нет данных/ошибка.
Все действия ведут в существующий или перенесённый сценарий. Проверены
типографика, отношения отступов, responsive-изображения и бюджет загрузки из 003.

## Результат выполнения
Не выполнено. Главная старой темы остаётся без изменений.
