# 004 — Токены, компоненты и визуальный каталог

## Цель
Начать делать гайдлайн исполняемым через общие токены и компоненты действующей
темы `mskba_dark`, без глобальной переделки интерфейса.

## Описание
- Выбрать первый небольшой набор востребованных primitives текущей темы.
- Вынести для него токены и общие Blade/CSS/JS-компоненты без массовой замены
  существующей разметки.
- Поддерживать визуальный каталог: варианты, состояния, длинные тексты, образцы
  форм и композиции; не создавать параллельные компоненты только для каталога.
- Связать каждый образец с правилом гайдлайна и использовать те же компоненты на страницах.
- Применить набор на одной согласованной странице или одном сценарии и проверить
  доступность, responsive-состояния и отсутствие регрессий на соседних страницах.

## Статус
Требует новой декомпозиции после решения 2026-09-09. Зависимость: принятая 002;
отменённая архитектура отдельной Vue-темы 003 больше не является зависимостью.

## Критерии приёмки
Первый ограниченный набор компонентов и страница его применения визуально приняты
на desktop/mobile по общему протоколу; сборка проходит. У гайдлайна, токенов,
каталога и реально используемых компонентов нет расходящихся значений.
