# 007 — Каталог и страница площадки

## Цель
Проверить дизайн-систему на сквозном сценарии поиска и просмотра площадки.

## Описание
Перенести каталог, поиск/фильтры, list/map, карточку площадки, галерею,
характеристики и вход в доступные действия. Сохранить серверный visibility scope,
URL фильтров, пагинацию и правила предикативного выбора. Карта загружается по
необходимости, не дублирует источник результатов и обрабатывает недоступность провайдера.

## Статус
Запланирована. Зависимость: 006.

## Критерии приёмки
Поиск → карточка → назад сохраняет согласованное состояние. Приняты desktop/mobile,
длинный адрес, пустой результат, нет фото и ошибка карты. Доступ к закрытым данным
не расширился. Новые компоненты сначала приняты в каталоге 004.

## Результат выполнения
Не выполнено. Порядок проверки: отдельно каталог, отдельно карточка, затем весь flow.
