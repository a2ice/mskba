# 032 - Улучшить ввод адреса и отображение подсказок

## Оригинальное описание

Во всех полях адресных подсказок добавить крестик очистки в конце input, показывать адрес начиная с города без страны и отображать там же loading-индикатор между вводом текста и появлением подсказок. Loading и крестик должны сменять друг друга.

## Подробное описание

Расширить общий frontend-компонент `address-suggest`, чтобы обе формы площадки — обычная и Telegram — использовали одинаковую правую управляющую зону поля. При запросе подсказок показывается spinner, после завершения при непустом значении — кнопка очистки. Очистка сбрасывает видимый текст, структурированные поля адреса, выбранность подсказки, автоматически заполненное метро, ошибки и незавершённые запросы.

Yandex provider формирует пользовательский label из структурированных компонентов `город, улица, дом`, не включая страну. Страна остаётся отдельным полем DTO и продолжает участвовать в проверке допустимой географии.

## Проверка

- обычная и Telegram-формы содержат общий контрол очистки;
- spinner виден во время debounce и сетевого запроса;
- устаревший ответ не появляется после изменения или очистки поля;
- крестик очищает видимые и скрытые адресные данные и автозаполненное метро;
- ручной выбор и геолокация после заполнения показывают крестик;
- label Yandex-адреса начинается с города, страна в нём отсутствует.

## Результат

- обычная и Telegram-формы используют одинаковую обёртку поля и правый control;
- обе формы предлагают кнопку «Я на площадке» через общий reverse-geocoding сценарий;
- CSS-крестик сменяется анимированным spinner на время debounce и AJAX-запроса;
- очистка инвалидирует незавершённый запрос и сбрасывает текст, структуру адреса, ошибки и автозаполненное метро;
- программное заполнение Telegram-формы синхронизирует состояние control без очистки данных;
- Yandex provider формирует label в формате `город, улица, дом`, сохраняя страну отдельным значением DTO;
- feature-тесты проверяют наличие control в обеих формах, unit/feature-тесты — компактный label.
