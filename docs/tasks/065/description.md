# 065 - Автоматически регистрировать участников из Telegram-чата

## Оригинальное описание

Все пользователи основного Telegram-чата должны иметь возможность ответить «Пойду» или «Не пойду» в карточке мероприятия, даже если они ранее не открывали Mini App. Первый ответ должен безопасно создать облегчённый аккаунт портала, связать его с Telegram и сохранить выбор пользователя.

Необходимо также исправить зависание Telegram на состоянии «Загрузка…» после нажатия inline-кнопки.

## Подробное описание

Telegram сам передаёт доверенный идентификатор нажавшего пользователя в `callback_query.from.id`, поэтому пользовательские данные не включаются в `callback_data`. При первом ответе создаются пользователь, профиль, `TelegramAccount` и подтверждённый Telegram-контакт. Повторные callback и последующий вход через Mini App должны находить тот же аккаунт.

Ответ «Пойду» использует существующий сценарий присоединения к мероприятию. Ответ «Не пойду» сохраняется как осознанный отказ даже для пользователя, который ещё не был участником.

Поскольку Telegram не может подключиться к production webhook и сообщает `Connection timed out`, получение `callback_query` переводится на исходящий long polling через отдельный контейнер. Это позволяет использовать уже настроенное соединение с Bot API через фиксированный IP и не требует входящего соединения со стороны Telegram.

## Результат

Первый ответ пользователя в Telegram-карточке теперь безопасно создаёт облегчённый аккаунт, профиль, `TelegramAccount` и подтверждённый Telegram-контакт. «Пойду» записывает пользователя на мероприятие, «Не пойду» сохраняет статус отказа; повторные нажатия и последующий вход через Mini App переиспользуют тот же аккаунт.

Production-получение callback переведено с недоступного входящего webhook на отдельный long-polling контейнер. Offset обновлений хранится в Redis, callbacks передаются в основную очередь, а deployment автоматически удаляет webhook без потери ожидающих обновлений. Добавлены новый канал регистрации `telegram_chat`, миграция ограничения, обработка непредвиденных ошибок с ответом пользователю и feature-тесты автосоздания, отказа и polling transport.
