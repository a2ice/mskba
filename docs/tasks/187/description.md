# 187 — Сохранить заявку представителя и сканы при создании площадки

## Исходная задача

Выбор «Как представитель площадки» должен сохраняться постоянным черновиком заявки на управление. При создании можно загрузить сканы; позднее продолжить заявку и явно отправить её на проверку. Права владельца автоматически не выдаются.

## План

- Общий статус DRAFT заявки; submitted_at отсутствует до отправки.
- Частные JPG/PNG/PDF документы: до 10 файлов по 10 МБ, всего до 50 МБ. Загрузка необязательна и доступна только сценарию представителя.
- Создание площадки и черновика атомарно, файлы удаляются при ошибке сохранения.
- Заявитель сохраняет текст, добавляет и удаляет сканы в черновике; отправка использует существующие проверки полномочий и контакта, сохраняет ту же заявку и документы.
- Черновики не появляются у проверяющих, не создают переписку или уведомления.
- Документация и профильные проверки целостности, доступа, отказов загрузки и перехода статуса.

## Статус

Завершена и включена в main. PR #201: `73d47f8e`, полный GitHub CI [34972545258](https://github.com/a2ice/mskba/actions/runs/34972545258) прошёл, включая PHP suite и production build.

## Реализация

Постоянный draft и private документы, продолжение в редактировании и «Управлении», сохранение и отправка той же заявки, приватность до отправки и неизменяемость после неё. Сохраняются старые проверки отправки, переписка и рассмотрение; все начальные сканы учитываются в общей квоте вложений. Черновики и отменённые неотправленные заявки исключены из очередей проверяющих. Multipart-лимит PHP/nginx увеличен до 64 МБ, отдельный файл остаётся ограничен.

Документация: [Черновик заявки представителя](../../specification/venue-ownership-drafts.md), ссылки из главных документов и мастера обновлены. JS syntax, production build и Pint проходят; браузер недоступен, визуальная проверка не заявляется. PostgreSQL проверяется миграцией production deploy; локальный Docker недоступен.
