# 038 - Сделать мобильную sticky-навигацию страницы площадки

## Оригинальное описание

Сделать sidebar страницы площадки компактным на мобильных экранах и закрепить его наверху, сохранив навигацию и переключение активного раздела по мере прокрутки.

## Подробное описание

На ширине до 900 px первый навигационный блок sidebar преобразуется в горизонтальную прокручиваемую sticky-панель под основной шапкой. Блоки состояния и управления в мобильной панели скрываются, поскольку они не относятся к навигации по длинной странице. Существующая внутренняя anchor-панель контента на этой ширине скрывается, чтобы не показывать две одинаковые навигации.

Sidebar-ссылки подключаются к существующему `IntersectionObserver`. Он синхронизирует активное состояние desktop- и mobile-ссылок, наблюдает каждую целевую секцию один раз и при смене секции прокручивает горизонтальный список так, чтобы активный пункт оставался видимым.

Связанная мобильная навигация breadcrumbs также сохраняет полную цепочку: промежуточные пункты больше не скрываются CSS, а длинная цепочка и текущий пункт переносятся на несколько строк.

## Проверка

- страница содержит размеченную мобильную навигацию и общие anchor-ссылки;
- feature-тест страницы площадки проходит;
- frontend-ассеты успешно собираются;
- PHP-тесты релевантного сценария проходят;
- CSS и JS не создают вторую мобильную sticky-панель.
- на мобильной ширине breadcrumbs показывают все промежуточные пункты.

## Результат

На мобильных экранах sidebar страницы площадки стал компактной горизонтальной sticky-навигацией под основной шапкой. Дублирующая внутренняя навигация и второстепенные sidebar-блоки на этой ширине скрываются. Scroll-spy использует общие ссылки, наблюдает уникальные секции и автоматически удерживает активный пункт в видимой области панели. Breadcrumbs больше не скрывают промежуточные элементы и аккуратно переносят полную цепочку.

Feature-тест страницы площадки и сборка frontend-ассетов выполнены успешно.
