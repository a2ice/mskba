# Task 294. Избранное в шапке и realtime-счётчик

## Требование
- Слева от логина и аватара показать иконку сердца со счётчиком **активных избранных записей**; записи в корзине не учитывать.
- Использовать существующий паттерн счётчика сообщений/аватара, включая согласованный источник событий Reverb, первоначальную загрузку, переподключение и синхронизацию между вкладками.
- Клик по иконке у авторизованного пользователя ведёт в `/account/favorites`.
- Для гостя клик ведёт к авторизации; после успешного входа возвращает к избранному (использовать действующий безопасный redirect-пайплайн).
- Счётчик обновляется без ручной перезагрузки при добавлении, удалении и восстановлении избранного; корректен на мобильном и desktop, не перекрывает аватар и уведомления.
- Тесты прав доступа, cache invalidation, Reverb и доступности ссылки.

## Приёмка
Гость/авторизованный, две вкладки, добавление и удаление, корзина, Reverb reconnect, мобильная шапка.

## Порядок
После приёмки Task 293, отдельный PR, зелёный CI, dev и приёмка.
