# 002 — Tablet flow и demo кабинета

## Цель

Сделать внутренний mobile/tablet-first сценарий, которым агент реально может
пользоваться во время встречи с администрацией площадки.

## Работы

- экран начала визита: найти/создать площадку;
- безопасный demo/sandbox кабинета без доступа к чужим данным;
- показать реально работающие ключевые возможности;
- preview будущих возможностей визуально отличать от активных функций;
- фиксировать результат презентации;
- крупные CTA, минимум переходов и admin-терминов;
- не требовать аккаунт представителя до момента, когда он согласился подключаться.
