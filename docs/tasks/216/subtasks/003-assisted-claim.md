# 003 — Assisted auth, claim и съёмка документов

## Цель

Позволить представителю площадки завершить все свои действия прямо при агенте.

## Работы

- использовать существующий login/registration/social-login;
- работать с canonical user;
- при необходимости назначать participation role представителя площадки штатным способом;
- создать/использовать текущий `VenueOwnershipClaim`;
- дать агенту в рамках assisted flow фотографировать документ камерой планшета;
- загрузить фото/скан в private storage Task 187;
- сохранить evidence и отправить тот же claim в pending;
- явно различать applicant и actor, который физически загрузил документ;
- не просить представителя повторно загружать файлы после визита.

## Безопасность

Агент не получает пароль пользователя. Документ предоставляется представителем
площадки и лишь фиксируется агентом в системе.
