# 005 — Trial offer, аналитика и мотивационный фундамент

## Цель

Зафиксировать полевое предложение и данные, необходимые для оценки работы
агентов, не смешивая задачу с будущими Purchase/Finance сценариями.

## Работы

- configurable offer «3 месяца бесплатно»;
- сохранить применённый offer, start/end периода;
- не создавать фиктивные платежи/покупки до появления subscription/Purchase;
- базовые показатели: визиты, интерес, submitted claims, successful connections;
- группировка по agent;
- сохранять данные так, чтобы позже добавить commission/reward без миграции
  исторических фактов подключения.

## Граница

Начисление агенту денег/бонусов, расчёт комиссии и биллинг площадки — отдельные
задачи.
