# 227 — Упростить UX референсов лица игрока

## Цель

Убрать из пользовательского интерфейса технические подробности AI pipeline и сделать загрузку
ракурсов лица визуальной и понятной.

## Реализовано

- удалены служебные тексты про `private`, 512 px, нормализацию и внутренний порядок проверки;
- удалён служебный блок под сценой 2D/3D;
- подписи ракурсов сокращены до «Анфас», «Слева», «Справа»;
- вместо пиктограммы человека используется круг 50×50 px с плюсом;
- выбранное локальное фото показывается в круге сразу, до ответа backend;
- поверх неподтверждённого фото показывается loading overlay;
- при ошибке или отключённом AI локальный preview остаётся видимым до перезагрузки, но не считается сохранённым;
- после успешной AI-проверки preview переключается на приватно сохранённый нормализованный reference;
- подтверждённые reference доступны только владельцу через authenticated endpoint с `no-store`;
- кнопка «Сгенерировать 2D через AI» перенесена под карточки ракурсов и использует штатный `btn--primary`.

## Инвариант хранения

Оптимистичный preview во frontend не меняет backend-инвариант Task 225:
файл и Media-запись создаются только после успешной AI-проверки. Ошибка не сохраняет выбранный
локальный файл и не удаляет ранее подтверждённый reference.
