# 061 - Добавить фильтры журналов мероприятий

## Оригинальное описание

Добавить в шапку списков предстоящих и прошедших мероприятий фильтры по типу и датам. Для прошедших дополнительно добавить фильтр по итогу.

## Подробное описание

Фильтры работают через GET-параметры, комбинируются между собой и сохраняются в пагинации:

- `type` — тип одиночного мероприятия;
- `date_from` и `date_to` — включительные границы по дате начала в часовом поясе приложения;
- `outcome` только для `period=past`: `completed`, `cancelled` или `unmarked`.

«Итог не указан» означает закончившееся мероприятие без статуса `completed|cancelled`. Фильтрация не расширяет права видимости: гость видит только публичные записи, организатор дополнительно видит собственные.

## Результат

- в шапке обоих журналов добавлены комбинируемые фильтры по типу и диапазону дат;
- в журнале прошедших мероприятий добавлен фильтр по итогу;
- выбранные параметры сохраняются в ссылках раздела и пагинации;
- диапазон дат валидируется сервером и применяется по часовому поясу приложения;
- feature-тест покрывает фильтрацию обоих журналов и различает итоговые метки карточек от вариантов фильтра.
