# 140/007 — Диапазон дат поиска мероприятий

Статус: выполнено.

## Что реализовано

- шаг `4 · Когда` получает значения по умолчанию при открытии/search reset:
  - `Дата от` — текущий день в timezone приложения;
  - `Дата до` — текущий день + 7 дней;
- frontend не вычисляет календарную дату из timezone браузера: значения выдаёт backend, используя `config('app.timezone')`;
- lightweight homepage options endpoint дополнен полями:
  - `timezone`;
  - `default_date_from`;
  - `default_date_to`;
- если пользователь меняет начальную дату, `min` конечной даты синхронизируется с ней;
- конечная дата не может остаться раньше начальной: при таком изменении она приводится к начальной дате;
- значения восстанавливаются при повторном открытии popup и возврате на вкладку `Найти`;
- запрос к homepage options кэшируется внутри frontend-модуля, чтобы повторные reset не создавали лишних запросов;
- при недоступности lightweight config endpoint шаг остаётся рабочим и не блокирует поиск.

## Тесты

`HomeLocationOptionsControllerTest` дополнен фиксированным временем и проверяет:

- timezone `Europe/Moscow`;
- `default_date_from = 2026-09-07`;
- `default_date_to = 2026-09-14`.
