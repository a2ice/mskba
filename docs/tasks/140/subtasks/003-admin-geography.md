# 140/003 — Административный справочник географии

Статус: выполнено.

## Что реализовано

- добавлен admin-раздел `/admin/geography` — «Города и районы»;
- раздел доступен подтверждённым пользователям с ролью администратора или выше через общий `access-admin-panel`;
- добавлен пункт «Города и районы» в admin sidebar/dashboard navigation;
- реализовано создание, редактирование и удаление `City`;
- реализовано создание, редактирование, перенос между городами и удаление `District`;
- alias валидируется как стабильный lowercase latin slug (`a-z`, `0-9`, `-`);
- имя и alias города уникальны, имя и alias района уникальны в пределах города;
- город нельзя удалить, пока у него есть районы/округа или связанные адреса;
- район/округ нельзя удалить, пока он используется в адресах;
- район/округ нельзя перенести в другой город, пока он используется в адресах, чтобы не получить противоречие `addresses.city_id` / `addresses.district_id`;
- ограничения удаления продублированы на уровне БД через restrictive foreign keys;
- `City` и `District` подключены к существующему audit log;
- интерфейс показывает количество связанных адресов и блокирует очевидно недоступные удаления;
- добавлены feature-тесты CRUD и проверок целостности, а admin access coverage расширен новым разделом.

## Технические решения

Routes вынесены в отдельный `routes/admin-geography.php` и подключены в существующий массив web routes в `bootstrap/app.php`. Это не раздувает основной `routes/web.php` и следует уже существующему в проекте подходу с несколькими web route files.

Строковое `addresses.city` остаётся независимым snapshot-полем. Изменение имени города в справочнике не переписывает исторические строки адресов; каноническая связь определяется через `city_id`.
