# 318 — Публичный каталог лиг в светлой категории MSKBA App

## Оригинальное описание

Привести `/leagues` к тому же эталонному виду, что и публичный каталог «Площадки», вслед за переносом остальных шести каталогов в PR #691. После зелёного CI влить изменения в `dev`, не трогая production.

## Реализация

- Публичная страница `/leagues` наследует общий `theme::layouts.category` и использует разделённые desktop/mobile фильтры с UI Kit `select-control`.
- Сохраняются `q`, `status`, `season`, доступность только активных и архивных лиг, ссылки на записи и ограничение кнопки «Создать лигу» по правам пользователя.
- Добавлены стандартные режимы `cards`/`list` с сохранением query, единый toolbar, счётчик, пагинация, SEO canonical/meta и адаптивное оформление логотипа/заглушки.
- Детальные страницы лиги и сезона, backend-логика и production вне рамок.
