# 189 - Никнеймы и уточнение публичного профиля

## Оригинальное описание

Добавить редактируемый уникальный никнейм на `/account` с AJAX-сохранением и стандартной валидацией; строить публичные ссылки по никнейму с fallback на логин; использовать пользовательское описание роли при его наличии; соблюдать настройку приватности аватара даже для обязательного публичного профиля тренера.

## Подробное описание

- `nickname` хранится отдельно от технического `username` и может быть изменён или очищен.
- Допустимо 3–30 символов: первый символ — латинская буква, далее латинские буквы, цифры и `_`; значение нормализуется в lower-case.
- Никнейм не может совпадать с никнеймом или логином другой identity, чтобы `/users/{identifier}` оставался однозначным.
- Канонический адрес профиля: nickname → username → numeric id. Старый URL по username после появления nickname перенаправляет 301 на nickname.
- Поле на `/account` сохраняется PATCH/AJAX без перезагрузки и показывает локальный результат/ошибку.
- Для роли игрока заполненное «О себе как об игроке» заменяет стандартную подпись роли. Для остальных ролей пока используется стандартный текст, пока у них нет собственного публичного description-поля.
- Исключение публичного тренера открытой секции не отменяет `AVATAR`: при запрете фото возвращается стандартный аватар с tooltip «Отображение аватара запрещено в настройках профиля».

## Проверки

Добавлены feature-тесты на валидацию/коллизии никнейма, смену и очистку, канонический redirect, пользовательскую подпись игрока и приватность аватара публичного тренера. Frontend требует production build из-за нового `account-nickname.js`.
