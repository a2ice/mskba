# 316/005 — Production release gates и rollback

Статус: **запланирована**.

- CI/Deploy blocker для пробной индексации, списка missing URLs, broken canonical, 404/5xx, soft-404 шаблонов, пустого контента и отсутствующей Метрики.
- Автоматический аудит запускается против **закрытого prod-shaped стенда**, не подменяя текущий production.
- Предрелизный freeze и согласование плана, бэкап DB + media + nginx/env, проверка восстановления, точка rollback.
- Подготовить инструкции переключения app theme и переноса кода без подмены production данных; `php artisan migrate --force` только после успешного dry-run.
- Определить, какие миграции обратимы, и в случае ошибки использовать восстановление из backup/snapshot, а не слепой `migrate:rollback`.
- Только отдельное разрешение на `main` и production.

Приёмка: проверяемый release checklist и хотя бы одно тренировочное восстановление.
