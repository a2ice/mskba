# 002 — Тренерские contracts и ACL

## Цель

Расширить общий Contract scope секциями, добавить section access levels,
permissions, атомарное создание owner/head coach и безопасную смену head coach.

## Результат

Нет параллельного ACL; сервер проверяет confirmed coach, полномочия и принадлежность
membership выбранной секции.

## Статус

Выполнено.
