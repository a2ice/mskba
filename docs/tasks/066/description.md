# 066 - Открывать Telegram-карточку мероприятия внутри Mini App

## Оригинальное описание

Кнопка «Открыть мероприятие» в Telegram-карточке должна запускать Mini App, а не обычный встроенный браузер Telegram, и после авторизации открывать выбранное мероприятие. В сниппете нужно явно показывать тип активности и описание, а для игры и игровой тренировки использовать заголовок «Играем на {название площадки}».

## Подробное описание

Ссылка публикации строится как Telegram deep link основной Mini App с безопасным параметром `event_{id}`. Telegram передаёт параметр в подписанных `initData`, сервер разрешает только известный формат и возвращает относительный внутренний URL существующего мероприятия. После успешной Telegram-авторизации frontend переходит по этому URL внутри текущего WebView.

Произвольные URL и redirect-параметры от клиента не принимаются, поэтому механизм не создаёт open redirect. При неизвестном, некорректном или удалённом мероприятии Mini App остаётся на главной странице.

Карточка явно подписывает тип строкой «Тип активности: …» и показывает «Описание: …» либо прочерк для пустого описания. Для игры и игровой тренировки заголовок формируется по площадке как «Играем на …», для остальных типов сохраняется название мероприятия. Длинное описание ограничивается длиной сниппета, чтобы сообщение не превысило лимит Telegram.

## Результат

Telegram-карточка мероприятия формирует ссылку Main Mini App с параметром `event_{id}`. После проверки подписанных `initData` сервер разрешает параметр в относительный маршрут существующего мероприятия, а общий Telegram frontend автоматически открывает его в том же WebView.

Некорректные значения, внешние адреса и отсутствующие мероприятия не создают переход. Добавлены feature-тесты ссылки публикации, корректного назначения и отклонения неизвестного параметра.

Формат текста карточки дополнен явными полями типа активности и описания; игровые активности получили единый заголовок по выбранной площадке.
