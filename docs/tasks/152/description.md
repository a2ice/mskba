# 152 — Поднять preview площадки над wizard и добавить CTA при пустом поиске

## Задача

В conditional location mini-wizard ссылка `Посмотреть площадку` открывает preview modal под двумя уже открытыми wizard-модалками. Это тот же stacking-case, который был исправлен для modal карты в Task 150: вложенный preview должен быть третьим уровнем и находиться выше обоих wizard-слоёв.

На шаге результатов поиска мероприятий при пустой выдаче после текущего текста добавить фразу `или создайте своё мероприятие` и кнопку `Создать`, которая переключает текущий popup на соседнюю вкладку `Создать`, не закрывая основной modal.
