# 025 - Подключить Яндекс Метрику

## Оригинальное описание

Добавить Яндекс Метрику в head-шаблон сайта.

## Решение

- добавлен `YANDEX_METRIKA_ID` и соответствующая настройка `services.yandex_metrika.id`;
- JS-код счётчика вынесен в общий partial и подключён в `<head>` всех тем и Telegram Mini App;
- `noscript`-fallback вынесен в отдельный partial и подключён сразу после `<body>`;
- без ID, с нулевым или некорректным ID разметка Метрики не выводится, поэтому local/test окружения не отправляют аналитику;
- один и тот же счётчик используется независимо от выбранной темы.

## Включение

Указать положительный числовой ID счётчика в production `.env`:

```dotenv
YANDEX_METRIKA_ID=12345678
```

После изменения закэшированной конфигурации выполнить `php artisan config:cache` или штатный production deploy.

## Проверки

- отсутствие кода без ID;
- наличие JS и `noscript` на обычной и Telegram-страницах;
- отсутствие вывода и инъекции при некорректном ID.
