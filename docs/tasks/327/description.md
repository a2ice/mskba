# 327 — Системные обновления проекта в Content и агентский API

## Оригинальное описание

Создать единый журнал значимых изменений MSKBA: полная запись в административном разделе Content со ссылками на merged GitHub PR и проектную документацию, публичная версия в ленте новостей без внутренних технических ссылок. Сделать обязательным для всех исполнителей, включая ChatGPT и AI-агентов. Для авторизации агентских запросов к MSKBA использовать существующую системную учётную запись `dev`.

## Подробное описание

Утверждено пользователем 2026-11-18. Целевая архитектура и API-контракт описаны в [спецификации журнала](../../specification/project-updates.md).

## До появления API

Не выдавать черновик в документации или сообщение ChatGPT за опубликованную запись. Готовить краткое содержание и внутренние ссылки к задаче/PR, помечать как «ожидает записи в Content». Только после внедрения endpoint использовать сервисный `dev` с действительным защищённым токеном.
