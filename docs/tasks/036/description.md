# 036 - Предупреждать о подтверждённой площадке рядом при выборе адреса

## Оригинальное описание

При вводе и выборе адреса проверять наличие подтверждённой площадки по этому адресу или в ранее согласованном радиусе и показывать короткое предупреждение справа от кнопки «Я на площадке».

## Подробное описание

После выбора адресной подсказки или успешного обратного геокодирования frontend отправляет тип площадки и координаты в отдельный JSON endpoint. Endpoint использует общий `VenueProximityService` и сильный радиус из конфигурации — 50 метров по умолчанию. Конфликт учитывается только для подтверждённой площадки того же типа, в соответствии с предметным инвариантом дублей.

При конфликте рядом с кнопкой геолокации показывается короткое предупреждение. При очистке или ручном изменении адреса предупреждение сбрасывается; при изменении типа выбранная точка проверяется повторно. Проверка служит ранней UX-подсказкой, а серверные проверки создания и модерации остаются обязательными и не заменяются клиентом.

## Проверка

- endpoint находит подтверждённую площадку того же типа в радиусе 50 метров;
- площадка другого типа или удалённая точка не создаёт предупреждение;
- проверка запускается после выбора адреса, геолокации и изменения типа;
- предупреждение очищается вместе с адресом.

## Результат

Добавлен throttled JSON endpoint ранней проверки близости, переиспользующий предметный сервис и радиус 50 метров. Общий компонент адреса запускает проверку после выбора подсказки, геолокации и смены типа, отменяет устаревший результат при изменении адреса и показывает предупреждение справа от кнопки. При редактировании текущая площадка исключается из результата.
