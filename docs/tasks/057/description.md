# 057 - Исключить турнир из типов одиночного мероприятия

## Оригинальное описание

Турнир не является простым событием, а представляет список событий-игр. До отдельной реализации турниров убрать возможность создавать мероприятие типа «Турнир», удалить тип из enum и сократить описание формы создания до «Выберите площадку и свободное время.».

## Подробное описание

`Event` остаётся агрегатом одного мероприятия с одной бронью площадки. Турнир требует собственного жизненного цикла и связей с несколькими играми, поэтому значение `tournament` удаляется из `EventTypeEnum`, пользовательских фильтров, формы создания и PostgreSQL check constraint.

Для уже развёрнутой базы добавляется обратимая миграция, сужающая допустимые значения `events.type` до `game|training|game_training`. Миграция намеренно останавливается, если обнаружит существующие записи `tournament`, чтобы не удалять и не переклассифицировать предметные данные молча.

## Реализовано

- турнир удалён из enum одиночного мероприятия и связанных подписей действий;
- ссылка на турнир удалена из подменю мероприятий;
- создание `Event` с типом `tournament` запрещено серверной enum-валидацией;
- ограничение PostgreSQL синхронизировано обратимой миграцией;
- тексты каталога, админки и документация описывают только поддерживаемые типы;
- подзаголовок формы сокращён до «Выберите площадку и свободное время.»;
- добавлен regression-тест отсутствия турнира в форме и запрета его отправки вручную.
