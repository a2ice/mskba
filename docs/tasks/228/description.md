# 228 — Единый конфигуратор персонажа игрока

## Цель

Собрать настройки 2D/3D-персонажа в один понятный блок «Персонаж» и подготовить
текущие параметры для платной AI-генерации.

## Реализовано

- отдельная карточка «Референсы лица» убрана: блок «Лицо» теперь первый внутри «Персонаж»;
- рост, вес, сложение и женский параметр объёма груди находятся в общем контуре персонажа;
- ручные настройки тона кожи, причёски, волос и бороды показываются только в режиме 3D beta;
- выбор команды перенесён внутрь блока «Форма»;
- добавлены кроссовки: белые / чёрные;
- добавлен сворачиваемый блок «Атрибуты»:
  - налокотник слева;
  - налокотник справа;
  - оба налокотника;
  - напульсники;
  - наколенники;
  - повязка;
- кнопка генерации называется «Сгенерировать»;
- текущие несохранённые настройки формы передаются в generation payload;
- backend проверяет выбранную команду против фактического активного player membership;
- shoes/attributes сохраняются в character extra и имеют версию схемы 4;
- для 3D белые/чёрные кроссовки сразу меняют материалы обуви;
- дефолтный 2D placeholder заменён на `body-male.png` / `body-female.png`;
- placeholder-мужчина отображается на шкале как 195 см, женщина — 175 см, ширина auto;
- после успешной генерации placeholder заменяется результатом AI и снова следует фактическому росту.

## Generation preflight

Порядок до внешнего AI-вызова:

1. Pricing разрешает актуальную цену `avatar_generation`;
2. требуется подтверждённый анфас + слева или справа;
3. проверяется доступный баланс пользователя;
4. проверяется выбранная команда (если передана);
5. вызывается внутренний `PlayerCharacterAiGateway`.

Таким образом provider не вызывается при незавершённом пользовательском вводе или
недостаточном балансе.

## Ограничения

- спортивные атрибуты пока передаются в AI payload и сохраняются, но отдельные 3D meshes
  для них ещё не созданы;
- реальный AI provider и списание средств остаются отдельным следующим этапом.
