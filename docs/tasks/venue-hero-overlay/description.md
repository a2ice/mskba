# Venue hero overlay — responsive follow-up

## Goal

Улучшить адаптив публичной страницы площадки в промежуточном диапазоне ширин, где двухколоночный hero уже неудобен, а мобильный layout ещё не нужен.

## Requirements

- в диапазоне 769–1100px держать `.venue-hero` в одну колонку;
- не выводить информационный блок отдельной строкой под фото, а накладывать `.venue-hero__summary` поверх правой части изображения;
- использовать горизонтальный градиент справа налево: от тёмного к прозрачному;
- сохранить кликабельность ссылок и читаемость информации поверх изображения;
- на телефонах до 768px оставить обычный stacked-layout без overlay;
- рядом с пятью звёздами рейтинга не показывать числовое значение;
- точное дробное значение рейтинга оставлять только в tooltip/aria-label;
- заполнение звёзд продолжать считать по точному значению рейтинга.
