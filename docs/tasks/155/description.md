# Task 155 — responsive polish публичной страницы площадки

## Оригинальное описание

После Task 154 выяснилось, что breakpoint 768px слишком поздний для двухколоночной страницы площадки: sidebar начинает заметно сжимать основной контент. Также требуется вернуть sticky-поведение горизонтальной навигации и скорректировать представление рейтинга в heading.

## Требования

- переключать публичную страницу площадки из двухколоночного режима в широкий одноколоночный режим уже на viewport 1024px и меньше;
- горизонтальную навигацию по разделам показывать в этом режиме и снова фиксировать у нижней границы шапки при прокрутке;
- блок действий heading переносить на отдельную строку раньше, вместо чрезмерного сжатия заголовка и рейтинга;
- не заменять пять звёзд рейтинга одной компактной звездой;
- сохранять пять звёзд и обычную кнопку бронирования в переносимом блоке действий;
- видимое числовое значение рейтинга округлять до целого;
- точное дробное значение сохранять в tooltip/aria-label рейтинга;
- не менять бизнес-логику рейтинга и заполнение звёзд: заполнение остаётся рассчитанным по точному значению.

## Результат

Реализуется в ветке `fix/155`. Проверка включает CI, PHP tests и frontend build.
