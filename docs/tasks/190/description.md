Статус: выполнено, PR #204 вмержен в `main`.

## Цель

Убрать общий placeholder `dmitry_olsen` из `/account` и предлагать каждому пользователю свободный никнейм.

## Правила

- сначала строится персональный вариант из имени и фамилии: lower-case, транслитерация в латиницу, разделитель `_`, максимум 30 символов;
- персональный вариант предлагается только если он не конфликтует с nickname или username другой identity;
- если персональный вариант занят или корректно не строится, используется нейтральная база `court_king`;
- если `court_king` занят, выбирается первый свободный цифровой вариант: `court_king1`, `court_king2`, …; после прямых суффиксов поддерживаются варианты вида `court_king_1000` … `court_king_9999`;
- это только подсказка placeholder: фактическое сохранение повторно проходит серверную валидацию и проверку уникальности.
