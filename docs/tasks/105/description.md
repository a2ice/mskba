# 105 — Унифицировать формирование участников самостоятельных и турнирных игр

Самостоятельная игра должна использовать общие с турнирными матчами правила, экраны и сервисы управления составом с минимальными отличиями.

Для самостоятельной игры поддерживаются два режима:

- готовые команды: при создании указываются обе команды либо ни одной; организатор может приглашать команды, а команды — подавать заявки, если настройка включена и стороны ещё не утверждены;
- отдельные игроки: участники подают заявки, после чего организатор формирует две сбалансированные команды по механике balanced-турнира.

Турнирный матч получает команды из расписания турнира. У самостоятельной игры команды можно утвердить, заменить и переутвердить до фактического начала игры. Основные параметры игры также редактируются до начала.

Участием команды в самостоятельных и турнирных играх управляет владелец команды либо активный участник с глобальным правом «Управлять участием команды в играх». Назначать это право может владелец или участник с правом управления правами команды.

## Критерии готовности

- единые доменные правила и переиспользуемые UI-компоненты не дублируют турнирную механику;
- заявки и приглашения защищены авторизацией, транзакциями и стабильным порядком блокировок;
- нельзя указать только одну готовую команду или одну команду с обеих сторон;
- после начала игры состав и основные настройки изменять нельзя;
- ключевые переходы статусов и конкурентные сценарии покрыты тестами;
- продуктовая и техническая документация актуализированы.
