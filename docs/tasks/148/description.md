# Task 148 — Геолокация: улица, районы и predictive площадок

## Контекст

После переноса географии во вложенный mini-wizard нужны три небольшие UX-доработки финального шага.

## Scope

- после успешного определения текущей геопозиции использовать улицу из reverse geocode и автоматически подтвердить её через существующие Яндекс-подсказки;
- не выбирать площадку автоматически, а только сразу показывать подходящие площадки по установленной улице/радиусу;
- крестик поля площадки закрывает/очищает текущую выдачу, а следующий focus/click по пустому полю снова показывает варианты по установленной улице;
- служебный район `Другие территории` всегда показывать последним пунктом списка районов;
- серверную модель географии и discovery не менять.
