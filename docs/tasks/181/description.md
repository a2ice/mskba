# 181 — Полировка публичной страницы спортивной секции

## Цель

Закрыть UX-замечания после визуальной проверки Task 179: понятнее показать основную площадку, убрать дублирование recruitment-состояний и добавить необязимую вместимость секции.

## Согласованные правила

- термин `Площадка` на публичной странице секции заменяется на `Основная площадка`;
- основная площадка является default/желаемой площадкой секции, но конкретные занятия могут проходить в других местах;
- название основной площадки открывает существующий системный preview Venue; при известных координатах preview показывает карту с одной точкой;
- `Идёт набор` и `Принимает заявки` не показываются одновременно: `is_recruiting` имеет приоритет как усиленное состояние открытого приёма;
- `Идёт набор` получает pulse-анимацию по мотивам online-индикатора главной страницы с поддержкой `prefers-reduced-motion`;
- у секции есть необязательный `trainee_capacity`;
- при заданной вместимости recruitment badge показывает `active_trainees_count / trainee_capacity`, например `Идёт набор 1/15`;
- формат `1/15` означает «занято / всего»;
- вместимость на этом этапе информационная и сама по себе не блокирует подачу или принятие заявки.

## Реализация

Работа ведётся в ветке `feature/181-section-public-polish`.

Проверки должны покрыть сохранение вместимости, взаимоисключающий recruitment badge, счётчик вместимости и открытие общего preview основной площадки.
