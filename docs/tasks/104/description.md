# Задача 104. Площадка по умолчанию для турнира

Добавить к турниру необязательную подтверждённую площадку по умолчанию. При назначении новой игры турнира площадка должна быть предварительно выбрана, но организатор может заменить её для конкретной игры.

Выбор площадки у турнира не создаёт бронь, не изменяет уже назначенные игры и не подменяет фактическую площадку при переносе игры.
