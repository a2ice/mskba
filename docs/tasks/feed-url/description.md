# Перенос публичной ленты с /news на /feed

Публичная лента материалов переносится с `/news` на `/feed` без изменения внутренних route names `news.index` и `news.show`.

- `route('news.index')` должен генерировать `/feed`;
- `route('news.show', $alias)` должен генерировать `/feed/{alias}`;
- старые `/news` и `/news/{alias}` сохраняются как legacy routes и отвечают HTTP 301 на соответствующий `/feed` URL;
- query string при редиректе сохраняется;
- canonical URL материалов указывает непосредственно на `/feed/{alias}`;
- старые URL следует сохранять как постоянные redirects, чтобы внешние ссылки и поисковые сигналы переносились на новые адреса.
