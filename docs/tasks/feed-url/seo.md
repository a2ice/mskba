# SEO notes

Для постоянного переноса URL используется server-side HTTP 301. Канонические внутренние ссылки сразу ведут на `/feed`, поэтому пользователи и поисковые роботы не проходят лишний redirect hop при обычной навигации.

Legacy `/news` redirects не удаляются после переиндексации и могут оставаться постоянно для сохранения внешних ссылок.
