# Task 122 — Player Character male visual refinement

## Оригинальное описание

Точечно довести UI и мужскую procedural 3D-модель Player Character после Tasks 118–121: убрать POC/debug UI и линию роста, улучшить плечевой пояс, баскетбольную форму и шорты, реально подключить мужские причёски, не нарушив метрический контракт сцены 200 × 250 см.

## Подробное описание

- Сохранить literal viewport: X = 200 см, Y = 250 см, пол = 0 см.
- Рост человека измерять от нижней точки обуви до анатомической макушки головы; волосы не входят в `height_cm` и не участвуют в нормализации роста.
- Рост/вес/телосложение должны менять морфологию без изменения заданной высоты.
- Убрать горизонтальную линию роста. Оставить интерактивную оранжевую точку, позиционируемую проекцией той же Three.js камеры; tooltip доступен hover/focus и tap.
- Удалить пользовательские POC/debug подписи и остатки SVG runtime/include. При ошибке показывать только короткое пользовательское сообщение.
- Перестроить переход шея → трапеции → плечо → дельта → рука на непрерывном path loft без видимых шарниров.
- Пересобрать шорты как устойчивую систему из тазовой части и двух вертикальных loft-штанин без twisted/disconnected geometry.
- Сделать отдельную oversize basketball jersey: длинный свободный низ, front/back верх с armholes и плечевыми перемычками; майка перекрывает пояс шорт.
- Реализовать объёмные мужские `male_bald`, `male_buzz`, `male_fade`, `male_short`, `male_curls` с существующим `hairColor`.
- Бороды, женская procedural-модель, анимации, аксессуары и новый persistence в задачу не входят.

## Результат

Будет заполнено после реализации и проверки.
