# 303 — Конструктор тарифных правил: условия, формула, скидки

## Цель
Добавить на страницу «Цены» площадки (и залов с наследованием) управляемые условия: название, описание, активность, формула, приоритет, область действия и версия. Пример: аренда от 120 минут = скидка 30%.

## Объём
- Безопасный declarative DSL/визуальный конструктор, НЕ произвольный PHP/JS/eval. Условия: длительность, конкретная дата, день недели, интервалы времени, зона/зал, область аренды, сумма/количество шагов; операции percent discount, fixed discount, surcharge, fixed total, minimum amount (при необходимости).
- Приоритеты, взаимоисключение/совместимость и stop-processing, временная активность, конфликты и инспектор расчёта.
- Правила от Venue по умолчанию наследуются VenueCourt, поддержать явное выключение/добавление правила залом без копирования всей конфигурации.
- Версионирование и журнал аудита, published vs draft, защита от отрицательных значений/циклических правил/неоднозначного порядка. Применять к сумме RTC до расчёта комиссий (Task 304).
- Внешние цены не означают автоматически право предоставить скидку: сохранять источник и того, кто покрывает снижение.

## Acceptance
Feature/PostgreSQL: 2 часа -> 30%, 90 мин -> нет, разные цены RTC, совпадающие правила, дата, наследование, disabled, rounding, price floor, immutable quote и защита от инъекций. UI в гайдлайне, responsive.

## Готовность
PR -> CI green -> merge dev -> dev deploy -> сценарии проверки для пользователя -> приёмка до 304. main/prod не менять.
