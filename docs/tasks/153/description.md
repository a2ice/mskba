# Task 153 — регрессии верхнего блока площадки

## Цель

Закрыть две небольшие регрессии публичной страницы площадки перед следующим этапом рефакторинга layout/sidebar.

## Требования

- tooltip полного названия площадки показывается только когда название действительно длиннее 40 символов и визуально обрезано;
- возле занятого слота показывать ссылку на связанное публичное мероприятие в новой вкладке;
- не раскрывать приватные мероприятия и черновики;
- поддержать переходный booking-first контур, где Event может ссылаться на booking через `events.booking_id`, даже если обратный `venue_bookings.event_id` отсутствует у старых/переходных данных;
- для игры сохранять подпись с форматом (`Игра 5×5`, `Игра 3×3` и т. п.).
