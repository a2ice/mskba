# Task 144 — Подсветить переход «Далее» после выбора и закрывать popup кнопкой «Назад» на первом шаге

## Контекст

В homepage popup-wizard пользователь выбирает вариант карточкой, после чего следующий ожидаемый шаг — кнопка `Далее` в общем footer. На визуально насыщенном экране связь между совершённым выбором и дальнейшим действием не всегда очевидна.

Дополнительно на первом шаге основного wizard кнопка `Назад` сейчас заблокирована, хотя естественное действие для неё — выйти из popup.

## Требования

- После фактической смены выбора кликом по карточке привлечь внимание к общей кнопке `Далее`.
- Не запускать эффект при повторном клике по уже выбранной карточке.
- Кнопка должна плавно увеличиться до `scale(1.1)` за `0.35s` и вернуться к `scale(1)` ещё за `0.35s`.
- Одновременно по кнопке проходит световой блик слева направо и обратно справа налево.
- Блик реализовать через `::before`, привязанный к кнопке через `position: relative`; ширина полосы — около `35%`, высота — `100%`, наклон вправо около `15deg`.
- Эффект должен работать через общий navigation-компонент и поддерживать динамически создаваемые карточки nested location wizard.
- Уважать `prefers-reduced-motion`.
- На первом шаге основного popup-wizard кнопка `Назад` активна и закрывает popup. На остальных шагах она сохраняет обычную семантику перехода назад; nested location wizard продолжает перехватывать footer по своему контракту.

## Вне scope

- Изменение логики переходов между шагами.
- Автоматический переход вперёд сразу после выбора.
- Изменение внешнего вида карточек выбора.
