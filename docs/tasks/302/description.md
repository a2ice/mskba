# 302 — Главная DEV: плавный выход Venues V3 и стабильный первый кадр

## Оригинальное описание

Исправить рывок при переходе от закреплённой композиции с двумя игроками и судьёй к обычной прокрутке. Убрать скачок персонажей при первой установке координат JavaScript.

## Область и план

Только опубликованные CSS/JS компонента `venues-scene-v3` на DEV. Источник истины — Filament. Сохранить исходную графику, пики, длинные правые секции, отдельные слои и единственный мяч. Публикация через существующий API bridge с точными SHA и заменами. Production не меняется.

UI: уникальная существующая композиция главной; новые примитивы/формы не вводятся. Существующий DOM, типографика и CTA сохраняются. Контракт движения описан в [Venues V3](../../page-builder/filament-home/venues-v3-motion.md).

## Изменение

- Вместо умножения смещения на smoothstep интегрируется smoothstep скорости. Переход длиной 250 px центрирован на достижении верхом последней секции верхней границы окна; скорость 0→1 без превышения 1.
- Локальное движение персонажей достигает пиков до начала общего выхода. Расчёт учитывает реальное положение последней секции, включая её CSS-смещение.
- Начало входной анимации ограничено исходной позицией сцены в документе: при scrollY=0 прогресс равен нулю, как в статическом CSS.
- CSS белого игрока использует startY=15%, как JS. Desktop-геометрия доступна до установки JS-класса. Mobile/reduced-motion используют прежнюю пиковую позу с первого кадра.
- Изображения не скрываются на время загрузки JS; LQIP не меняется.

## Проверки

Локально: синтаксис JS; численная проверка реального контроллера на 1363×936, 1440×900 и 1920×1080, монотонность и скорость ≤1×, точное линейное продолжение, пики до выхода, обратная прокрутка, mobile/reduced-motion. Проверки API bridge: 10/10.

Ожидается: подтверждение актуальных API-версий, публикация CSS и JS отдельными запросами, визуальная проверка в облачном браузере. До успешной публикации задача не считается исправленной на сайте.
