# 188 — Публичный профиль и карточки тренеров секции

## Задача

B043: публичный профиль /users/{username}, ролевые страницы и независимая приватность блоков игрока. Карточка тренера секции показывает действующий аватар и открывает попап с базовыми сведениями и ссылкой в новой вкладке.

## План

- Единая проекция публичных данных для страниц и API попапа, без сериализации внутренних моделей.
- Публичный минимум действующего тренера открытой секции: имя, аватар, роль и открытые секции. Контакты и прочие роли не раскрываются этим исключением.
- Приватность профиля, аватара, каждой роли, характеристик, команд, игр и турниров; выбранные пользователи и владелец учитываются общей службой доступа.
- Защита от раскрытия закрытых событий, черновиков, заблокированных пользователей и отозванного участия.
- Профильные проверки, документация, CI и включение в main.

## Статус

Реализация завершена в feature/188, ожидает полного GitHub CI и включения в main.

## Проверки

Профильный прогон: 56 тестов, 378 assertions — публичный профиль, независимая приватность ролей/блоков, выбранный посетитель, обязательный минимум тренера, истечение контракта, отключение роли, блокировка/удаление, аватары, участники секций и запрет заявки организатора. После итоговых изменений отдельный прогон PublicUserProfileTest: 11 тестов, 58 assertions. Production build, Pint, JS syntax и diff check проходят. Браузер недоступен, визуальная проверка не заявляется. Полный suite выполняется GitHub CI перед main.
