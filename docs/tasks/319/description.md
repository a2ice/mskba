# 319 - Подтверждение игрока и единый попап подтверждений

## Оригинальное описание

Ввести подтверждённого игрока независимо от подтверждения аккаунта. Подтверждение аккаунта, игрока и будущих ролей должно открывать единый попап со списком принимаемых данных и предупреждением о защите. У подтверждённого игрока рост и год «Играю с» изменяются через заявку с обязательной причиной; вес и телосложение свободно редактируются. Право редактирования своих подтверждённых данных используется общее.

## Реализация

- `user_participation_roles.confirmed_at` отдельно от `User.status`; проверка сохранённых обязательных параметров игрока.
- Универсальный Blade-диалог и JS для подтверждения аккаунта, игрока, будущих ролей.
- Защита `height_cm` и `experience_started_year` на сервере, свободное изменение других полей.
- `profile_change_requests.scope` для независимых `account` и `player` заявок; та же очередь, права модерации, треды, уведомления, отмена/блокировка/одобрение, проверка snapshot при решении.
- Использование общего `identity.profile.self_edit`, без нового permission.
- Доработка экрана игрока в теме `mskba_app`, списка заявок для администраторов и документации.

## Приёмка

Проверить оба попапа подтверждения, серверные обязательные поля, запрет прямого изменения подтверждённых характеристик, разрешённые обычные изменения, общую модерацию и независимость заявок `account/player`. Проверить desktop/mobile по UI Kit. Запустить PHPUnit feature-тесты, миграции и Vite build. Принятие пользователем на `dev` и вывод в production выполняются отдельно.
