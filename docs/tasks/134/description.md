# 134 — Добавить желаемые площадки команды

## Оригинальное описание

Сделать связь между командой и площадкой двух типов: подтверждённая и желаемая.
Подтверждённую связь оставить для будущего flow, а желаемую разрешить устанавливать ответственным
лицам команды.

## Подробное описание

Постоянная команда может выбрать несколько подтверждённых площадок как желаемые. Связь
хранит тип `desired|confirmed`, но текущий UI создаёт и удаляет только `desired`. Пара комана–площадка
уникальна, чтобы будущее подтверждение было переходом типа, а не второй параллельной связью.

Управление доступно создателю и участникам с договорным правом `team.venues.manage`. Выбор
площадки использует общий predictive search. Желаемые площадки видны на публичной странице команды.

## Статус

Выполнено.

## Результат

Добавлена типизированная связь комана–площадка, отдельное договное право управления,
страница с predictive search и публичный список желаемых площадок. Unique constraint и транзакционная
блокировка команды защищают от дублей, а `confirmed`-связь нельзя удалить через текущий UI.
