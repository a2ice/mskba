# 320 - Уведомления о переводах и настройки аккаунта

## Оригинальное описание

Исправить toast и уведомления по подтверждённым каналам при переводе средств другому пользователю. На странице настроек объединить главную страницу и оформление сайта в компактную плашку «Базовые настройки» (два поля в ряд), добавить отдельную плашку «Уведомления». После зелёного CI влить PR в dev.

## Реализация

- Финансовое уведомление получателю получает системную категорию доставки; перевод и повторное списание не меняются.
- Email-доставка выбирает подтверждённый адрес канонического аккаунта: предпочтительно основной, иначе другой подтверждённый. На неподтверждённые адреса рассылки нет.
- Reverb остаётся основным механизмом toast, а активная вкладка дополнительно синхронизируется с сервером при недоступности realtime и периодически при подключении.
- В теме `mskba_app` объединены параметры главной страницы и оформления, добавлены отдельные настройки каналов email и Telegram с сохранением существующей модели `UserNotificationSetting`.
- На сайте in-app уведомления остаются включёнными; доставка в Telegram возможна только при подтверждённой привязке и доступном личном чате с ботом.
- Применены тесты сохранения настроек, выбора подтверждённого email и категории уведомления о переводе.

## Приёмка

PR в `dev` после успешного CI; функциональная проверка на dev пользователем.
