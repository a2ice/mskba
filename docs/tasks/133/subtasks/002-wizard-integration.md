# 002 — Интеграция event wizard

## Цель

Исключить создание неподтверждаемых legacy draft-мероприятий на коммерческих площадках.

## Краткое описание

Разделить свободный и rental-сценарии в application layer: для активной политики выполнить quote/request и сохранить intent, для свободного доступа оставить атомарное создание, а при отсутствии обязательной коммерческой настройки вернуть понятную ошибку.
