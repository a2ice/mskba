# 003 — UI, документация и проверка

## Цель

Сделать новый жизненный цикл понятным пользователю и защитить критические сценарии проверками.

## Краткое описание

Обновить сообщения wizard и страницы брони, продуктовую и техническую документацию; добавить feature/integration-тесты идемпотентности, сохранения игровых настроек, Telegram и запрета legacy pending-gap.

## Статус

Выполнено.

## Результат выполнения

В wizard добавлены пояснения booking-first сценария, цена аренды и переход к заявке.
Обновлена продуктовая и техническая документация; feature-тесты защищают
идемпотентность, перенос настроек игры, Telegram-публикации и запрет
неподтверждаемого legacy draft.
