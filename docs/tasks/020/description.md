# 020 - Исправить видимость неподтвержденных площадок в публичном списке

## Оригинальное описание

Отображение площадки `venues/{alias}` происходит по условиям видимости: actor/owner для неподтвержденных площадок. Но на страницу площадок `/venues` в список площадок такие неподтвержденные площадки попадают для пользователей, которым карточка недоступна.

## Подробное описание

Список `/venues` должен показывать:

- подтвержденные площадки для всех;
- неподтвержденные площадки только actor-создателю, bootstrap-владельцу или пользователю с договорным доступом.

Прямой просмотр `/venues/{alias}` уже применяет корректную проверку доступа через `VenueAccessResolver::canView()`. Проблема находится в query-логике формирования списка actor-доступных площадок.

## Результат

Исправлена группировка условий в `VenueAccessResolver::actorOwnedVenueIdsFor()`: проверка совпадения `user_id` или `user_fingerprint_id` теперь применяется именно к `creatorActor` текущей площадки, а не отрывается от relation-ограничения через верхнеуровневый `orWhere`.

Добавлены feature-тесты:

- guest-создатель видит свою неподтвержденную площадку в `/venues`;
- другой guest actor с другим fingerprint не видит эту площадку в `/venues` и получает forbidden на карточке;
- direct use case не возвращает неподтвержденную площадку другого actor.
