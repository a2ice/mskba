# 135 — Добавить вакансии и набор в команды

## Оригинальное описание

Добавить функционал «команда hiring», чтобы пользователи могли фильтровать команды, которые нуждаются
в доборе, и подавать заявки на вступление. Для конкретной потребности команда может необязательно указать
амплуа, опыт, пол, свободное описание и количество требуемых игроков.

## Подробное описание

Отдельная hiring-сущность хранит вакансию постоянной команды. Вакансия имеет активное/закрытое
состояние, количество мест и необязательные критерии. Общий флаг `accepts_join_requests` остаётся отдельным
правилом приёма заявок. Каталог умеет отбирать команды с активными вакансиями, а публичная страница
показывает условия набора и позволяет авторизованному неучастнику подать заявку на выбранную вакансию.

С Task 176 действует единый бизнес-инвариант: активная/reopened `TeamHiringPosition` возможна только при
`accepts_join_requests = true`. Открытие или повторное открытие вакансии автоматически включает общий приём
заявок, а выключить его при наличии активных вакансий нельзя. Целевая заявка на вакансию также проходит
через глобальный gate и больше не обходит закрытый приём заявок. Migration Task 176 исправляет legacy-команды
с активными вакансиями, включая им `accepts_join_requests`.

## Статус

Выполнено. Инвариант активного набора уточнён и усилен в Task 176.

## Результат

Добавлены отдельные hiring-вакансии с количеством мест, амплуа, минимальным опытом, полом и описанием.
Каталог фильтрует команды с активным набором, а публичная страница показывает критерии и принимает целевую заявку.
Принятие атомарно занимает место и автоматически закрывает заполненную вакансию. Начиная с Task 176 активная
вакансия означает открытый общий приём заявок; закрытая команда не принимает ни общую, ни целевую заявку.
