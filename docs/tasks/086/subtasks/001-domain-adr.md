# 001 - Доменный глоссарий и ADR

## Цель

Утвердить термины, границы агрегатов, ownership данных и заменить противоречащие решения задачи 084.

## Статус

Завершено на уровне проектирования.

## Работы

- описать Event, Game, Training, OpenTraining, GameTraining, Tournament и TournamentMatch;
- закрыть решения D01–D14;
- определить основную Game игрового Event и внутренние Game тренировки;
- пометить прежний Event/Game ADR как superseded, не удаляя историю решения;
- обновить продуктовую и техническую документацию после утверждения.

## Приёмка

- у каждого поля и lifecycle есть один владелец;
- нет двух разумных трактовок самостоятельной и турнирной игры;
- открытые продуктовые вопросы явно перечислены и согласованы.

## Результат

Принят [ADR Event, Game и Tournament](../../../specification/event-game-tournament-architecture.md),
прежний ADR задачи 084 помечен как заменённый. Продуктовый flow вынесен в
[Мероприятия, игры и турниры](../../../project/events-games-tournaments.md).
