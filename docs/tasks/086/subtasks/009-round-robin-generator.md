# 009 - Генератор «каждый с каждым»

## Цель

Генерировать туры и матчи без преждевременного создания Event, Booking и Game.

## Статус

Реализовано и локально проверено 2026-08-08. Следующий срез — 010, назначение матча и бронирование.

## Работы

- чистый deterministic generator;
- один и два круга;
- bye для нечётного количества команд;
- preview до сохранения;
- атомарная запись round/sequence;
- безопасная повторная генерация до назначения игр.

## Приёмка

- каждая пара встречается нужное число раз;
- команда играет не более одного матча в туре;
- одинаковый ввод даёт одинаковый результат;
- назначенные и завершённые матчи нельзя разрушить regeneration.

## Реализация

- чистый `RoundRobinGenerator` использует circle method и стабильный порядок TournamentEntry;
- для нечётного количества сторон автоматически добавляется bye без создания фиктивного entry;
- второй круг повторяет пары с переставленными сторонами;
- preview возвращает туры, пары и fingerprint активных entries, не изменяя базу;
- apply под блокировкой Tournament повторно генерирует схему на сервере, проверяет ACL и fingerprint;
- существующая неназначенная схема заменяется атомарно, sequence пересобирается без разрывов;
- если хотя бы один TournamentMatch уже связан с Game, regeneration отклоняется;
- интерфейс предупреждает перед заменой существующей схемы.

Проверено: профильный и смежный регресс `65 tests / 637 assertions`, Pint и production Vite build.
