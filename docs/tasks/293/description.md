# Task 293. Перемещение попапов (drag-and-drop)

## Требование
- Инвентаризировать все типы попапов: нативный dialog, Vue и переиспользуемые wizard, избежать точечных несовместимых реализаций.
- Общий механизм перетаскивания за заголовок (не за крестик, кнопки и поля), с сохранением фокуса и доступности.
- Пока идёт drag, временно убирать backdrop-filter blur с подложки для возможности видеть страницу под попапом; после release/cancel возвращать прежний эффект.
- Ограничить перемещение видимой областью, учитывать resize, скролл и мобильные touch/pointer events, закрытие и повторное открытие. Модальное поведение и блокировка действий с фоном сохраняются.
- Учесть reduced-motion, клавиатуру и запрет случайного клика по контролам при перетаскивании.

## Реализация: один контроллер на оба интерфейса

- Модуль `resources/themes/mskba_app/js/modal-dragging.js` подключён в обоих JS entrypoint. Он обнаруживает открытые окна динамически, включая Vue и окна, создаваемые после загрузки.
- Поддерживаются два общих shell: `dialog.mskba-modal` (контакты, подписки, авторизация, юридические документы и т. д.) и `.modal.is-open > .modal__dialog` (старый shell с minimize/restore); дополнительно карта площадки `dialog.app-venue-overlay` и нативный редактор цен `dialog.account-venue-price-dialog`.
- Кнопки, ссылки, поля ввода и другие интерактивные элементы в заголовке не являются drag-handle. Порог 5px предотвращает случайное перемещение при обычном клике. Работают Pointer Events (мышь/касание), `pointercancel` и `Escape`.
- Перемещение доступно и с клавиатуры: `Alt + стрелки`, `Alt + Shift + стрелки` для большего шага; фокус на заголовке не пропадает.
- CSS-перемещением управляется **только поверхность**, не backdrop. В процессе активного drag снимается именно `backdrop-filter`, **не затемнение**, в том числе для нескольких открытых модальных окон; после release/cancel/blur — восстановление.
- Позиция ограничивается `visualViewport`, при resize/zoom пересчитывается, при закрытии или сворачивании сбрасывается. Не меняются URL, значения форм, события закрытия, браузерная top layer, блокировка фона и focus-trap.
- Специальные старые overlay с собственным DOM, например медиа-lightbox/день площадки/Telegram mini-app вне общего shell, не подменяются вслепую: их жизненный цикл нужно отдельно валидировать до подключения, чтобы не сломать свайпы и жесты.

## Приёмка
Проверить мышью и touch на нескольких попапах, отпускание за пределами, возврат blur, закрытие/открытие, отсутствие смещения после resize.
