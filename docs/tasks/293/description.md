# Task 293. Перемещение попапов (drag-and-drop)

## Требование
- Инвентаризировать все типы попапов: нативный dialog, Vue и переиспользуемые wizard, избежать точечных несовместимых реализаций.
- Общий механизм перетаскивания за заголовок (не за крестик, кнопки и поля), с сохранением фокуса и доступности.
- Пока идёт drag, временно убирать backdrop-filter blur с подложки для возможности видеть страницу под попапом; после release/cancel возвращать прежний эффект.
- Ограничить перемещение видимой областью, учитывать resize, скролл и мобильные touch/pointer events, закрытие и повторное открытие. Модальное поведение и блокировка действий с фоном сохраняются.
- Учесть reduced-motion, клавиатуру и запрет случайного клика по контролам при перетаскивании.

## Приёмка
Проверить мышью и touch на нескольких попапах, отпускание за пределами, возврат blur, закрытие/открытие, отсутствие смещения после resize.

## Порядок
После приёмки Task 292, отдельный PR, зелёный CI, dev и приёмка.
