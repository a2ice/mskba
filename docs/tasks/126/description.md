# 126 — Исправить pipeline Blender-модели игрового персонажа

## Оригинальное описание

На production Blender/MPFB-модель игрока отображается как разрушенная low-poly фигура. Нужно
определить причину, восстановить корректную геометрию и продолжить развитие 3D-персонажа.

## Диагностика

Исходный `mskba-male-base-test-clean.glb` содержит 14 517 вершин, 26 756 треугольников,
нормали и UV. В Task 125 в приложение попала отдельная `trimesh`-копия: 640 вершин,
1 799 треугольников, без нормалей и UV и с разрушенной топологией. Агрессивное упрощение,
а не метрическая камера Three.js, создало ложные поверхности между ногами и грубый силуэт.

Попытка перенести clean export через `feature/126` была незавершённой: пяти фрагментов
недостаточно для payload, они не образуют валидный gzip, а renderer импортировал только три.

## Решение

- clean GLB хранится как самостоятельный Vite asset и загружается `GLTFLoader.loadAsync()`;
- base64-фрагменты, ручная распаковка и зависимость от `DecompressionStream` удаляются;
- Three.js и GLTFLoader устанавливаются как локальная pinned npm-зависимость вместо production
  import с `esm.sh`;
- существующая единая XYZ-нормализация сохраняет физический рост и пропорции модели;
- integrity test проверяет GLB v2, размер геометрии, normals, UV и метрические bounds, чтобы
  повреждённая low-poly копия не вернулась незаметно.

## Границы этапа

Текущий clean GLB остаётся статической базой без skeleton, animations, morph targets и материалов.
На этом этапе skin tone задаётся renderer-материалом, а вес, телосложение, причёска и форма ещё не
меняют mesh. Для модульной кастомизации следующий authored asset должен иметь согласованные имена
mesh/material slots, rig и отдельные morph targets либо сменные части.

Визуально приложенный export имеет выраженные женские пропорции торса, несмотря на male-название.
Это свойство исходной геометрии и должно быть отдельно исправлено в параметрах MPFB/Blender;
renderer не должен компенсировать его неравномерным масштабированием.

## Критерии готовности

- production-quality clean geometry отображается без ложной поверхности между ногами;
- модель высотой 185 см стоит на отметке 0 и достигает отметки 185 см;
- GLB и Three.js обслуживаются приложением без стороннего CDN;
- изменение роста сохраняет пропорции благодаря uniform scale;
- asset integrity, существующие Player Character tests, Blade compile и Vite build проходят;
- desktop и mobile WebGL-представления проверены в локальном браузере.

## Статус

В работе в `feature/126`.
