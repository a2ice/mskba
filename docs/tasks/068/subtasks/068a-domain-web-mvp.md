# 068A — доменная основа и web MVP

Статус: реализовано, ожидает пользовательскую проверку.

Состав:

- агрегат `CoordinationSession` и один poll первой итерации;
- текстовые варианты, одиночный и множественный выбор;
- один изменяемый ballot на пользователя;
- настройка, разрешающая либо запрещающая изменение ballot после первого ответа;
- анонимное или открытое отображение состава голосов;
- ручное и автоматическое закрытие;
- явное решение создателя без автоматического создания мероприятия;
- Gate будущего операционного права `coordination.create`;
- web-страницы списка, создания и голосования;
- постоянное действие «Создать опрос»: для гостя открывает общую
  авторизацию/регистрацию и продолжает сценарий на форме создания;
- модель нескольких Telegram-чатов и публикаций без фактической доставки.

Не входит:

- редакторы типизированных дат, времени и площадок;
- предложения вариантов;
- публикация и синхронизация Telegram;
- цепочки нескольких poll;
- создание `Event` и брони.

Результат:

- 9 feature-тестов, включая smoke-render web-страниц, гостевой auth redirect и
  анонимное/открытое отображение голосов;
- 75 assertions;
- полный набор проекта: 279 тестов и 1725 assertions;
- production frontend build выполнен успешно.
