# 068C — переход к мероприятию

Статус: запланировано.

- явное действие организатора после закрытия;
- возможность не принимать ничью или неоднозначный результат;
- сбор точных параметров мероприятия из принятых решений;
- повторная проверка всех инвариантов `Event` и `Booking`;
- идемпотентное создание мероприятия отдельным application handler.
