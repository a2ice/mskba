# 068E — персональные операционные права

Статус: реализовано.

## Реализовано

- постоянный snapshot в `user_operational_permissions`;
- все поддерживаемые и добавленные в будущем права разрешены при отсутствии
  строки snapshot;
- подтверждённый `admin+` может менять права только пользователя с более низкой
  системной ролью и не самого себя;
- управление доступно в таблице `/admin/users`;
- создание и изменение строк snapshot автоматически попадает в общий аудит;
- `UserOperationalPermissionChecker` читает постоянное хранилище, поэтому
  существующий Gate `coordination-create` не изменил HTTP-контракт.

## Конкурентный доступ

Изменение набора прав блокирует строку целевого пользователя. Роль повторно
проверяется уже после получения блокировки, а весь актуальный enum permissions
записывается в одной транзакции. Это не позволяет двум администраторам оставить
частично сохранённый набор.
