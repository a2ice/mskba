# 063 - Перевести итоговую сводку сайта на Redis

## Оригинальное описание

На главном экране и в мобильной панели заменить статические значения «игр сегодня» и «онлайн» реальными показателями через Redis. В количество игр включать мероприятия типов «Игра» и «Игровая тренировка».

## Подробное описание

Сводка состоит из разных по природе показателей:

- количество опубликованных или завершённых игр и игровых тренировок за текущий московский день кешируется по модели cache-aside;
- online presence авторизованных пользователей хранится в Redis Sorted Set с timestamp последней активности;
- знаменатель online-показателя равен количеству незаблокированных и неудалённых пользователей.

Web middleware отмечает активность авторизованного пользователя на обычных запросах. Frontend heartbeat обновляет сводку на открытой странице без перезагрузки. Один пользователь учитывается один раз независимо от числа вкладок. При изменении мероприятий и пользователей связанные кеш-ключи инвалидируются после завершения транзакции.

Для тестового `array` cache store предусмотрен совместимый fallback presence. Ошибка Redis не должна приводить к ошибке страницы.

## Результат

- статические значения удалены из desktop и mobile UI;
- добавлен кешируемый суточный счётчик игр и игровых тренировок;
- добавлен Redis presence и heartbeat;
- добавлена динамическая русская форма слова «игра»;
- добавлены feature-тесты расчёта событий, уникальности online-пользователей и истечения presence.
