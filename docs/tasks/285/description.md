# 285 — Site Media Library в Filament

## Оригинальное описание

Полноценное управление изображениями сайта из Filament, без GitHub Actions/VDS деплоя на каждое изменение. Папки, загрузка, сжатие, метаданные, копируемые URL, замена и откат двух версий, применение в Page Builder и перенос текущих файлов Hero Slider.

## Подробное описание

DEV-only. Реализация раздела «Контент → Медиафайлы» и «Папки медиа» на базе общего Media, логического SiteMediaAsset, UUID-ссылки и двух физических Media-версий. При замене старый URL остаётся стабильным.

Hero Slider получает дополнительные selectable library UUID поля, сохранённые legacy FileUpload значения остаются валидными. Идемпотентная команда site-media:import-hero (--apply) инвентаризирует и импортирует ссылки из current draft/published Page Builder и /images. Команда не переписывает опубликованные HTML/CSS/JS и не удаляет исходники. После DEV QA — отдельно подтверждённая замена старых путей в кодовых редакторах и публикация.

## Проверки и этапы

1. Проверить схему, права, CRUD/rollback и защиту опубликованных ссылок.
2. CI/Pint, тесты, PHP/Blade, миграции, браузерный DEV smoke.
3. Прогнать import-hero (dry-run, затем --apply) на DEV; зафиксировать найденные/пропущенные изображения.
4. Сравнить Hero desktop/tablet/mobile, включая полупрозрачные PNG и спрайты.
5. Main/production не менять.
