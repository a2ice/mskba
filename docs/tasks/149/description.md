# 149 — Вернуть выбор площадки на карте в location mini-wizard

## Задача

На финальном шаге nested location mini-wizard под полем выбора площадки вернуть стандартную ссылку `На карте` из общего predictive venue selector.

Карта должна открываться в существующем popup выбора площадки и использовать те же активные фильтры, что и predictive-поиск: город/район/улица либо GPS/метро + радиус.

Выбор площадки на карте остаётся явным действием пользователя и использует существующий `venue_id` flow.
