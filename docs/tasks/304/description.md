# 304 — Комиссии MSKBA и партнёров в серверном расчёте

## Цель
Ввести версионируемые коммерческие правила площадки и залов: глобальная комиссия MSKBA, overrides, вознаграждение коммерческого агента/партнёра и итоговая стоимость quote. Не путать коммерческого агента с browser/AI-исполнителем.

## Объём
- Источник цены, цена после тарифных правил, MSKBA fee, partner fee/share, источник выплаты (плательщик/за счёт владельца/из комиссии), net allocations; избегать двойного учёта.
- Наследование портала -> площадка -> зал; явное 0 сохраняется, валюты/minor units, фиксированное/процентное начисление, ограничения и порядок округления.
- Полный pricing breakdown и версии правил в неизменяемом VenueBookingQuote snapshot; UI показывает честную конечную сумму.
- Не начислять реальные деньги, не инициировать платежи, пока нет подтверждённого расчётного контура; исторические брони не перерасчитывать.
- Отдельно конфигурировать источник покрытия скидок, запретить необеспеченные обещанные внешнему поставщику цены.

## Acceptance
Unit/feature/PostgreSQL кейсы: комиссии 0/percent/fixed, агент с долей комиссии, split source, скидка + комиссии, venue/court override, rounding, rollback, immutable snapshots. Все изменения аудируются. CI/deploy/ручная приёмка.
