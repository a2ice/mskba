# 001 - Тестирование task workflow

## Оригинальное описание

Тестирование task workflow - метод `AuthController@restore` должен возвращать текст "Восстановление пароля пока не реализовано. Сорян, но мы работаем над этим! Прямо сейчас!!!"

## Подробное описание

Нужно проверить task workflow на небольшой пользовательской доработке: метод `AuthController@restore`, который вызывается маршрутом восстановления доступа, должен вернуть пользователю JSON-ответ с сообщением:

```text
Восстановление пароля пока не реализовано. Сорян, но мы работаем над этим! Прямо сейчас!!!
```

Затронутый пользовательский сценарий: восстановление доступа из auth flow. Это временное состояние функции: восстановление пароля еще не реализовано, но пользователь должен получить понятное сообщение вместо ошибки или пустого ответа.

Ожидаемые изменения:

- найти `AuthController@restore`;
- реализовать возврат указанного текста;
- добавить или обновить feature-тест на `POST /auth/restore`;
- при необходимости актуализировать продуктовую документацию по регистрации и входу.

Релевантные документы:

- `docs/project.md`;
- `docs/project/registratsiya-i-vhod.md`;
- `docs/specification.md`;
- `docs/specification/protsess-raboty-s-zadachami.md`;
- `docs/specification/vedenie-dokumentatsii.md`.

Проверки:

- запустить релевантный feature-тест, если возможно;
- при необходимости запустить `composer test` или `make test`.

## Результат выполнения

Метод `AuthController@restore` возвращает JSON response со статусом `501`, статусом `not_implemented` и текстом сообщения:

```text
Восстановление пароля пока не реализовано. Сорян, но мы работаем над этим! Прямо сейчас!!!
```

Добавлен feature-тест на `POST /auth/restore`, проверяющий JSON-контракт ответа. Продуктовая документация по регистрации и входу дополнена временным состоянием восстановления доступа.
