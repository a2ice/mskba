# 332 — Два варианта баннера площадки

## Цель
Настраивать оформление страницы отдельной площадки из Filament, не меняя фотографии залов и баннеры других сущностей.

## Поведение
- **Плашка** (по умолчанию): прежний широкоформатный баннер 3:1 над контентом.
- **Фиксированный фон**: изображение заполняет видимую область окна через `position:fixed; inset:0; object-fit:cover` и остаётся на месте при прокрутке.
- В фоновом режиме над изображением размещён неинтерактивный слой с произвольным CSS-фоном, исходно `rgba(0,0,0,0.5)`. Администратор может указать белое засветление `rgba(255,255,255,0.5)`, любой другой цвет или градиент без проверки CSS-синтаксиса.
- Карточки, вкладки, расписание и формы остаются поверх изображения и сохраняют интерактивность; попапы продолжают использовать штатный верхний слой.
- Отсутствующий баннер не выводится; все старые площадки сохраняют режим плашки.
- Поддержаны обе публичные темы площадки. Баннеры лиг, сезонов, команд и профилей не изменяются.
- Режим и CSS-наложение изменяются в Filament через основную форму площадки. Загрузка и кадрирование из ЛК сохраняют существующую модерацию.
- Устранён регресс: прежний sibling-селектор менял `position:sticky` панели `.app-venue-page__anchors` на `relative`. Теперь `position:relative` применён только к hero, columns и venue-show; навигация сохраняет свою фиксируемую геометрию и `z-index:18`.
- Новый nullable столбец `banner_overlay_color` сохраняет строку как есть. У старых записей `NULL` означает использование прежней настройки `banner_overlay_opacity`. Значение передаётся через escaped data-атрибут и применяется одной командой `style.setProperty`, а не вставляется непосредственно в inline-style.

## Приёмка
Проверить оба режима, сохранение строк CSS без преобразований, светлые и тёмные наложения, legacy-значения процентов и восстановление sticky-навигации, прокрутку desktop/mobile, отсутствие горизонтального скролла, интерактивность карточек и попапов, неизменность остальных баннеров и безопасную миграцию.
