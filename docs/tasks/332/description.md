# 332 — Два варианта баннера площадки

## Цель
Настраивать оформление страницы отдельной площадки из Filament, не меняя фотографии залов и баннеры других сущностей.

## Поведение
- **Плашка** (по умолчанию): прежний широкоформатный баннер 3:1 над контентом.
- **Фиксированный фон**: изображение заполняет видимую область окна через `position:fixed; inset:0; object-fit:cover` и остаётся на месте при прокрутке.
- В фоновом режиме поверх изображения находится неинтерактивный тёмный слой с непрозрачностью 0–100%, по умолчанию 50% (`rgba(0,0,0,.5)`).
- Карточки, вкладки, расписание и формы остаются поверх изображения и сохраняют интерактивность; попапы продолжают использовать штатный верхний слой.
- Отсутствующий баннер не выводится; все старые площадки сохраняют режим плашки.
- Поддержаны обе публичные темы площадки. Баннеры лиг, сезонов, команд и профилей не изменяются.
- Режим и затемнение изменяются в Filament через основную форму площадки. Загрузка и кадрирование из ЛК сохраняют существующую модерацию.

## Приёмка
Проверить оба режима, сохранение 50% и значений 0–100%, прокрутку desktop/mobile, отсутствие горизонтального скролла, интерактивность карточек и попапов, неизменность остальных баннеров и безопасную миграцию.
