# 317 — Источник страницы реферального приглашения

## Оригинальное описание

Доработать существующую реферальную ссылку MSKBA, добавив `source_page`, чтобы после регистрации приглашённого пользователя было видно, с какой страницы пригласивший отправил ссылку (например, из попапа пополнения баланса на странице игрока). Полную историю посещений не собирать.

## Реализация

- Добавить необязательный `source_page` в `referral_attributions` с обратимой миграцией.
- Сохранять параметр `source_page` из ссылки `/r/{username}` в `referral.pending` и переносить его в атрибуцию при первом входе нового пользователя.
- В существующем попапе «Пригласить друга» формировать ссылку с текущим путём страницы; копирование и системная отправка через share/email используют ту же ссылку.
- Разрешать только локальный относительный путь, не сохранять query/fragment и внешние адреса.
- Показывать значение в карточке пользователя Filament, вкладка «Общее».
- Старые ссылки без параметра остаются работоспособными (`source_page = null`); механизм начисления наград не меняется.

## Проверка

- Feature: новая ссылка `/r/{username}?source_page=...` → первая авторизация приглашённого → `referral_attributions.source_page`.
- Feature: старая ссылка без параметра и внешний `source_page` не ломают атрибуцию; внешние URL не сохраняются.
- PHP lint, `git diff --check`; при наличии рабочего окружения профильный PHPUnit.
- Ручной smoke: открыть профиль игрока → пополнить баланс → «Пригласить друга» → скопировать ссылку и проверить `source_page`.
