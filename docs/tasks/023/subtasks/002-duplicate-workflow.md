# 002 - Переписать duplicate workflow

## Цель

Убрать использование `VenueStatusEnum::DUPLICATE` из поиска, отображения и merge дублей.

## Краткое описание

Дубль определяется через `canonical_venue_id` и строки `venue_duplicates`, а не через жизненный статус площадки.

## Статус

Выполнено.

## Результат выполнения

Merge дублей больше не пишет `status = duplicate`: дубль определяется через `canonical_venue_id`, а жизненный статус площадки остается независимым. Тесты duplicate workflow обновлены под новую инварианту.

Поиск и проверки дублей дополнительно ограничены типом площадки. Совпадающие название и адрес не связывают площадки разных типов, поэтому спортивный зал и уличная площадка одной школы могут существовать отдельно.

Генерация alias новых площадок использует общий `App\Support\Text\CyrillicTransliterator` с явной таблицей русской транслитерации. Компонент не зависит от Venue и может переиспользоваться другими модулями; результат не зависит от версии внутреннего transliterator Laravel.
