# 002 - Переписать duplicate workflow

## Цель

Убрать использование `VenueStatusEnum::DUPLICATE` из поиска, отображения и merge дублей.

## Краткое описание

Дубль определяется через `canonical_venue_id` и строки `venue_duplicates`, а не через жизненный статус площадки.

## Статус

Выполнено.

## Результат выполнения

Merge дублей больше не пишет `status = duplicate`: дубль определяется через `canonical_venue_id`, а жизненный статус площадки остается независимым. Тесты duplicate workflow обновлены под новую инварианту.
