# 342 - Фильтр площадок «Рядом со мной»

## Оригинальное описание

Фильтр площадок «Рядом со мной». Требования владельца от 20.11.2026.

## Подробное описание

На /venues после фильтра названия добавить «Рядом со мной». Только по явному действию запросить геолокацию устройства; при отказе, ошибке, отсутствии API или таймауте — штатный попап выбора адреса с предиктивным вводом и переключением «На карте», установкой точки и радиуса. Дать возможность изменить выбранную точку. После подтверждения фильтр выбран, под ним фирменный range-slider радиуса; изменение радиуса, точки и применение — согласно общему контракту фильтров. Отмена выбора не активирует новый некорректный фильтр. Одинаковая серверная фильтрация списка/карточек и карты до пагинации/limit, совместимость остальных фильтров, пустое состояние и сброс. Использовать общий географический поиск Task 143 (Haversine, координаты), предиктивный адрес и существующую карту, не дублировать. Диапазон и default радиуса согласовать/сверить с имеющимися настройками: Task 143 описывает 1/3/5/10 км, default 3 км; 1–30 км, default 5 км — возможный новый вариант, не утверждён. Не сохранять координаты в профиль без отдельного действия. Проверить права браузера, fallback, touch, границы радиуса, обе выдачи.

## Статус

Запланировано; реализация не начата. Перед реализацией сверить актуальный код и документацию, применять Task Workflow и GlobalRule5 с учётом отдельных ограничений.

## Частичная реализация

Добавлен серверный фильтр координат и радиуса в единый ListVenuesHandler; расстояние переиспользует VenueProximityService, фильтрация предшествует пагинации и построению карты. HTTP-валидация требует цельный набор координаты/радиус, допустимый радиус 1–10 км. Добавлена регрессия. UI, выбор адреса/карты, проверки и публикация остаются открытыми; задача не завершена.

## UI (черновик)

Общий компонент обеих тем; точка выбирается по явному запросу геолокации либо через штатный predictive адрес/Яндекс Карты. При отмене исходное состояние сохраняется, координаты не записываются в профиль. Радиус 1–10 км, по умолчанию 3 км, изменяется перед применением общей формы. Необходимо подтвердить CI и визуальную проверку обеих тем до merge.
