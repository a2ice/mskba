# Task 290. Подпись сердечка для записи в корзине

## Проблема
При наличии записи избранного с `trashed_at != null` на сердечке появляется текст «Восстановить из корзины». В публичном каталоге это лишняя внутренняя подробность.

## Требование
- На сердечке при состояниях `none` и `trashed` одинаковые `aria-label` и `title`: **«Добавить в избранное»**.
- В состоянии `active`: **«Убрать из избранного»**, при этом вид заполненного сердечка и `aria-pressed=true` остаются.
- Сохраняем существующий backend toggle: `trashed` → `active`, никаких повторных записей.
- В самом кабинете /account/favorites вкладка «Корзина» и действие «Восстановить» остаются без изменений.

## Приёмка на dev
1. Добавить площадку в избранное, затем убрать сердечком, оказавшись в состоянии `trashed`.
2. Навести на сердечко и проверить: «Добавить в избранное», а не «Восстановить из корзины».
3. Повторно нажать и убедиться, что площадка снова активна в избранном и сердечко заполнено.
4. Проверить подпись для новой площадки и для площадки уже в активном избранном.
5. Зелёный CI → один squash merge в `dev` → ручная приёмка пользователя перед Task 291.

## Статус
В работе. Отмечать выполненной только после согласованной приёмки (включая политику реестра задач для `main`).
