# Task 204 — Мета-информация пользователя и редактирование операционных прав

## Цель

Сделать superadmin-страницу пользователя полезной для диагностики технических аккаунтов и убрать разрыв между просмотром и редактированием операционных прав.

## Реализация

- На вкладке «Общая информация» добавлен блок «Мета-информация регистрации».
- Показываются:
  - канал регистрации;
  - дата создания и первый вход;
  - состав canonical identity;
  - связанные локальные alias-аккаунты;
  - Telegram ID, username, имя, язык и последняя авторизация;
  - VK ID, имя и последняя авторизация;
  - до пяти первых связанных acquisition visits: кампания, канал, source/medium, persona, дата визита и landing.
- Telegram/VK ищутся по всем `identityIds()`, а не только по canonical user, потому что после merge provider account может оставаться на alias.
- На вкладке «Роли» операционные права редактируются прямо на странице переключателями и сохраняются существующим `AdminUpdateUserOperationalPermissionsHandler`.
- Сохранение из user editor возвращает обратно на вкладку «Роли»; popup в общей таблице пользователей сохраняет прежний redirect.

## Безопасность

Страница редактирования пользователя по-прежнему доступна только через `can:manage-users-as-superadmin`. Изменение операционных прав дополнительно проходит существующий gate `manage-user-operational-permissions` и application-level проверку иерархии ролей.

## Проверки

Добавлены feature tests на:
- отображение Telegram metadata, находящейся на alias canonical identity;
- форму операционных прав на вкладке «Роли»;
- сохранение прав и возврат на ту же вкладку.
