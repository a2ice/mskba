# 194 — Компактный social-login в popup авторизации

## Причина

На мобильном popup «Вход в аккаунт» блок быстрого входа занимал слишком много высоты: Telegram и VK выводились отдельными вертикальными секциями, каждая со своим разделителем.

## Решение

- В popup классической авторизации social-провайдеры собираются в общий блок.
- Telegram и VK показываются в одной строке двумя равными колонками с gap 12 px.
- Первая группа начинается разделителем «или быстрый вход через».
- Провайдеры группируются по два. Если появится третий вариант входа, он автоматически уйдёт в следующую группу, перед которой появится отдельный разделитель «или»; одиночная кнопка в такой группе занимает всю ширину.
- Существующие Telegram/VK partial остаются обратно совместимыми для inline-login и умеют отключать собственные разделители при встраивании в grid.
- На очень узких экранах уменьшаются внутренние отступы и шрифт social-кнопок, но двухколоночная композиция сохраняется.

## Проверка

Добавлен feature regression-check разметки popup при одновременно включённых Telegram и VK. Production deploy дополнительно выполняет frontend build и HTTP health-check.
