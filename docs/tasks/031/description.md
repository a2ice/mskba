# 031 - Добавить создание площадки по текущей геопозиции

## Оригинальное описание

Находясь непосредственно на площадке, пользователь должен иметь возможность определить текущую точку и подставить её при создании площадки в Telegram Mini App.

## Подробное описание

Добавить в поле адреса Telegram-формы кнопку «Я на площадке». Только после явного нажатия браузер запрашивает разрешение на геолокацию и передаёт полученные координаты в защищённый rate limit-ом backend endpoint обратного геокодирования.

Backend преобразует координаты через Yandex Geocoder в тот же структурированный адресный DTO, который используется обычными подсказками, проверяет допустимую страну и подбирает ближайшее метро. Клиент заполняет адрес, координаты, структурированные поля и метро как выбранную адресную подсказку. Пользователь видит найденный адрес и может проверить либо заменить его вручную перед созданием.

## Проверка

- кнопка присутствует в Telegram-формах создания и редактирования;
- геолокация запрашивается только по нажатию;
- найденный адрес проходит общий backend mapping и автоматически заполняет метро;
- отсутствие разрешения, координат или результата показывает понятное сообщение без очистки введённых данных;
- endpoint валидирует диапазон координат и ограничивает частоту запросов;
- сценарий создания площадки продолжает требовать подтверждённый структурированный адрес.

## Результат

- в обе Telegram-формы площадки добавлена кнопка «Я на площадке» с явным запросом разрешения устройства;
- реализован rate-limited endpoint обратного геокодирования координат;
- Yandex provider и общий адресный сервис поддерживают reverse geocoding через существующий DTO;
- найденный адрес заполняет те же структурированные поля и ближайшее метро, что ручная подсказка;
- ошибки разрешения, геолокации и геокодирования показываются рядом с адресом без потери введённых данных;
- добавлены unit и feature-тесты провайдера, общего mapping-а и валидации endpoint.
