# 048 - Исправить sticky-навигацию площадки в Telegram Mini App

## Оригинальное описание

На странице площадки в Telegram Mini App внутренняя навигация по секциям не фиксируется под шапкой либо использует неверно рассчитанную высоту отступа. Исправить прямо в `main` и задеплоить.

## Подробное описание

Оставить полный sidebar площадки в общей мобильной панели, но вернуть на саму страницу отдельную компактную горизонтальную навигацию по якорным секциям. Она располагается после breadcrumbs, фиксируется непосредственно под реальной нижней границей fixed-шапки и учитывает Telegram safe-area.

Фактическая высота шапки публикуется в общем CSS-токене и обновляется при load, resize и через существующий Telegram ResizeObserver. Scroll offset секций учитывает одновременно высоту шапки и sticky-навигации.

## Проверка

- профильные feature-тесты страницы площадки и Telegram-контекста;
- production-сборка Vite;
- полный backend test suite;
- `git diff --check`;
- mobile/Telegram smoke test после deploy.

## Результат

Мобильная страница площадки получила отдельную горизонтальную sticky-навигацию по разделам. Её верхняя позиция вычисляется от фактической высоты шапки, включая Telegram safe-area, а якорные секции прокручиваются с соответствующим динамическим отступом. Общий sidebar со статусом и управлением остаётся внутри мобильного меню.
