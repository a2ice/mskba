# 008 - Wizard подтверждения аккаунта

## Оригинальное описание

Если аккаунт не подтвержден (`unconfirmed`), то на странице `/account` снизу добавляется кнопка "Подтвердить аккаунт".

Кнопка ведет на страницу wizard подтверждения профиля с обязательными шагами `(О)` и шагами, которые можно пропустить `(Н)`.

Первые шаги:

- если роль участия не установлена - установить роль `(О)`;
- далее проверяется условие по роли, у каждой роли будет свое или не будет вообще;
- для роли "игрок" следующим шагом необходимо заполнить дату рождения и пол `(О)`;
- для роли "тренер" тоже необходимо заполнить дату рождения и пол `(О)`;
- следующий шаг - "Представьтесь пожалуйста"; ФИО необязательны и могут быть пропущены `(Н)`.

## Подробное описание

### Цель

Добавить первый flow подтверждения аккаунта, который переводит пользователя от статуса `unconfirmed` к `confirmed` после выполнения обязательных шагов.

### Решение

Wizard относится к `Identity`, потому что работает со статусом пользователя, базовым профилем и ролями участия.

Первая итерация:

- показывает кнопку подтверждения на `/account` для пользователя со статусом `unconfirmed`;
- добавляет страницу `/account/confirmation`;
- вычисляет шаги по текущему состоянию пользователя;
- поддерживает обязательные и необязательные шаги на уровне модели wizard;
- реализует обязательные шаги выбора роли, даты рождения/пола для игрока и тренера;
- оставляет ФИО необязательным шагом, который можно пропустить;
- дает пошаговую клиентскую навигацию вперед/назад;
- пересчитывает зависимые шаги на клиенте при выборе роли;
- сохраняет данные одним финальным submit всего wizard;
- при финальном submit переводит пользователя в `confirmed`, когда все обязательные шаги выполнены.

### Ограничения первой итерации

- необязательные шаги пока не добавляются;
- детальные role-specific правила есть только для `player` и `coach`;
- отдельная админская модерация подтверждения аккаунта не вводится.
