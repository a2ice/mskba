# 103 - Упростить управление дублями пользователей и объединить способы подтверждения контактов

## Оригинальное описание

Сделать таблицу дублей пользователей компактнее, перенести подробности и действия в модальное окно, убрать значок подсказки из пользовательского badge в шапке и объединить Telegram/VK ID с разделом контактов аккаунта.

## Подробное описание

- оставить в таблице дублей только пару пользователей, краткие доказательства, score и кликабельный статус;
- показывать полную информацию, выбор canonical user, подтверждения и действия merge/reject в модальном окне;
- обеспечить таблице безопасный горизонтальный скролл на узких экранах;
- убрать tooltip-знак вопроса у badge текущего пользователя в шапке;
- убрать отдельные пункты Telegram и VK ID из меню аккаунта;
- представить привязку Telegram и VK ID в разделе «Контакты» как подтверждённые способы связи и входа;
- сохранить отдельные identity-модели и существующие безопасные OAuth/Telegram-механизмы, не подменяя их ручным вводом контакта;
- перенаправлять старые страницы Telegram/VK ID в единый раздел контактов.
- при успешном входе или привязке через Telegram/VK ID создавать либо восстанавливать соответствующий подтверждённый контакт и отправлять уведомление только при его первом подтверждении.
- при входе или привязке VK ID переносить доступные данные профиля и аватар симметрично Telegram, сохраняя приоритет ручных изменений.

## Проверка

- целевые feature-тесты контактов, Telegram/VK ID и объединения пользователей;
- сборка frontend-ассетов;
- ручная проверка модального окна и адаптивности таблицы.

## Результат

- таблица дублей сведена к четырём основным колонкам, а подробности и решения перенесены в широкое модальное окно статуса;
- Telegram и VK ID объединены в разделе «Контакты» как подтверждённые способы связи и входа, при этом защищённые identity-модели и существующие сценарии авторизации сохранены;
- старые страницы привязки перенаправляют в единый раздел, отдельные пункты меню удалены;
- знак вопроса у badge пользователя убран без потери доступного текстового обозначения;
- добавлены регрессионные тесты единого интерфейса контактов и legacy-редиректов;
- вход и привязка VK ID синхронизируют подтверждённый VK-контакт по неизменяемому provider ID симметрично Telegram, без повторных уведомлений при последующих входах;
- VK ID заполняет только пустые имя, фамилию, пол и полную дату рождения; внешний аватар сохраняется локально фоновой задачей, не заменяет ручной и учитывает явное удаление прежней копии;
- проверено целевыми feature-тестами, кэшированием Blade, frontend-сборкой и `git diff --check`;
- полный regression-suite: `538 passed`, `3653 assertions` (PHPUnit с лимитом памяти 512 МБ).
