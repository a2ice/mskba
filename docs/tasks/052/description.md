# 052 - Требовать аккаунт для создания и управления площадками

## Оригинальное описание

Запретить создание площадки без аккаунта и сделать вход в сценарий максимально коротким: при попытке добавить площадку предложить вход или регистрацию, после успешной регистрации автоматически авторизовать пользователя и вернуть его к созданию площадки. Пункт «Мои площадки» должен зависеть от фактического доступа к площадкам, а страница должна соответствовать текущему стилю сайта.

## Подробное описание

Создание, редактирование, модерация, фотографии и удаление площадки требуют авторизованного пользователя. Подтверждение аккаунта и специальная роль участия для первоначального добавления не требуются.

`Actor` остаётся каноническим источником атрибуции и аудита. Browser fingerprint используется для security- и аналитических сценариев, но не предоставляет права на площадку. Гостевое владение площадкой и последующее закрепление через `ActorClaim` удаляются: в рабочих базах проекта таких площадок нет, а сохранение переходной ветки неоправданно усложняет модель доступа.

После регистрации пользователь автоматически входит в аккаунт, сессия регенерируется, а ответ возвращает безопасный внутренний URL продолжения сценария. Страница «Мои площадки» показывает площадки, созданные пользователем или доступные ему по действующему membership contract. Пункт аккаунта отображается при наличии хотя бы одной такой площадки независимо от роли участия и статуса подтверждения пользователя.

Список и внутренняя страница площадки используют компоненты текущей темы. Статус выводится единым контрастным индикатором с отдельными состояниями «Не подтверждён», «Подтверждён» и «Заблокирован»; действия используют только канонические `btn--*` классы темы.
