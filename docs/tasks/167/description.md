# Task 167 — Ближайшие площадки на публичной карте

## Задача

Заменить заглушку «Площадки рядом» в адресном блоке публичной страницы площадки на интерактивный сценарий внутри существующей Яндекс Карты.

## Реализация

- сервер выбирает до шести ближайших подтверждённых площадок с координатами;
- выборка использует общий версионируемый `VenueSearchCache`, поэтому не создаёт отдельный полный SQL-запрос при каждом открытии страницы;
- текущая площадка остаётся оранжевой точкой, соседние показываются синими;
- после включения слоя карта подбирает границы, включающие текущую и соседние точки;
- повторное нажатие скрывает соседние точки и возвращает исходный центр и масштаб;
- клик по соседней точке открывает существующий общий popup-превью площадки;
- неподтверждённые площадки в публичный набор не попадают;
- если координаты или соседние площадки отсутствуют, действие недоступно и не открывает фиктивную заглушку.

## Связанное уточнение модели залов

Во время проверки Task 164 устранена оставшаяся зависимость разрешений конкретного зала от `allows_whole`/`allows_halves` родительской booking policy. Эти поля задают начальные значения новому залу, а после создания источником истины для области аренды становится `VenueCourt`. Общие сроки, шаг времени, цены и включение rental-flow по-прежнему задаются политикой площадки. Настройка зала и превращение quote в заявку теперь блокируют строки в одинаковом порядке `venue → court`, поэтому устаревший quote не может обойти только что отключённую область аренды и конкурентные операции не создают противоположный порядок захвата блокировок.
