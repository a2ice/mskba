# 035 - Упростить обычное создание площадки до первого шага

## Оригинальное описание

Сделать добавление площадки в обычной версии таким же двухэтапным, как в Telegram: сначала запросить только название, тип и обязательный адрес с возможностью определить текущую точку, а после создания перейти к полной форме редактирования.

## Подробное описание

Публичная страница создания переиспользует общую venue-форму в компактном режиме. В первом шаге видимыми остаются название, тип, адрес, кнопка «Я на площадке», вычисленное ближайшее метро и действия формы. Метро автоматически передаётся компонентом адресных подсказок, но не редактируется на первом шаге. Список адресных подсказок позиционируется абсолютным слоем относительно input и раскрывается поверх следующих элементов формы. Описания и теги заполняются уже на странице редактирования.

После успешного создания обычный HTML-сценарий перенаправляет пользователя на `/venues/{id}-{alias}/edit`. Telegram JSON-сценарий остаётся без изменений.

## Проверка

- на странице создания видны только три предметных поля первого шага;
- адрес можно выбрать из подсказки или определить кнопкой «Я на площадке»;
- после успешного создания выполняется переход на страницу редактирования созданной площадки;
- полноценная форма редактирования по-прежнему содержит метро, описания и теги.

## Результат

Обычная страница создания переведена в компактный режим общей формы. Пользователь видит название, тип, адрес, определение текущей точки и автоматически найденное метро; само metro-поле остаётся скрытым. Адресные подсказки раскрываются поверх кнопки геолокации. После создания HTML-сценарий открывает страницу редактирования через устойчивый `id-alias`, а JSON-ответ Telegram не изменён.
