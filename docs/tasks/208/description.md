# Task 208 — Контекст «Участники» в sidebar каталога команд

## Проблема

После переноса ссылки «Команды» внутрь группы «Участники» переход `/participants` → «Команды» визуально полностью заменял sidebar: пользователь видел уже только локальную группу «Команды». Это создавало ощущение перехода в несвязанную навигацию.

## Решение

На `/teams` перед локальной группой «Команды» добавлена закрытая accordion-секция «Участники». Внутри повторяется родительская навигация:

- Игроки → `/players`;
- Тренеры → `/coaches`;
- Все участники → `/participants`;
- Команды → `/teams`.

Начальное состояние:

1. «Участники» — закрыта;
2. «Команды» — открыта;
3. «Фильтры» — закрыта.

При раскрытии одной секции остальные закрываются, как и раньше.

## Технически

- `default-category` получил optional `category-pre-navigation`;
- participant navigation partial теперь можно переиспользовать без переноса query-state из каталога команд;
- accordion JS теперь уважает серверно заданную открытую секцию вместо правила «всегда открыть первый DOM item»;
- остальные default-category consumers сохраняют прежнее поведение.

## Проверки

Feature test каталога команд проверяет:
- наличие родительской participant navigation;
- порядок accordion sections;
- закрытое состояние «Участники»;
- открытое состояние «Команды».
