# Task 145 — Полировка location mini-wizard

## Цель

Закрыть UX-замечания после Task 143 по вложенному выбору локации в homepage wizard поиска мероприятий.

## Scope

- показывать цвет линии метро корректным цветным маркером;
- не показывать одинаковую станцию отдельными строками для разных линий, сохраняя исходные варианты линий в данных;
- добавить в predictive input метро стандартный clear-control и loading-state;
- выбирать Москву по умолчанию при входе в ручной location flow;
- корректно очищать выбранный город/район при возврате к placeholder;
- сделать активную обводку mini-wizard спокойнее;
- вынести активные шаги mini-wizard в отдельный modal поверх основного popup, чтобы не раздувать высоту основного wizard;
- сохранить общий radius/location state и существующие фильтры discovery.

## UX-контракт

Вторичный modal используется только во время активной настройки. После завершения он закрывается, а в основном popup остаётся компактная сводка локации. Если вторичный modal закрыт до завершения, прогресс сохраняется и показывается действие «Продолжить».
