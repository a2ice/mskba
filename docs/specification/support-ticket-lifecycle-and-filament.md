# MSKBA — обращения техподдержки: жизненный цикл и Filament

## Filament
- В административной панели сохраняется бренд MSKBA · Управление. В заголовке
  вкладки браузера применяется отдельный префикс:
  Управление - [название раздела] - MSKBA, включая переходы Livewire.
- В навигации Filament группа Дизайн содержит Стили кнопок.
- Группа Обращения содержит Техподдержка: таблица с поиском, фильтром
  Открыто/Закрыто и read-only карточкой. Из Filament нельзя создавать,
  закрывать, возобновлять, удалять или редактировать обращения.
- Доступ: только подтверждённый административный персонал с входом в
  Filament и отдельным support.ticket.handle. Ограничения ретроактивной
  выдачи доступа, исключений и отзыва прав соблюдаются через
  SupportTicketAccess::visible() и canRead(). Не используются JOIN
  всех обращений с участниками.

## Закрытие
- Только текущий главный ответственный поддержки может закрыть открытое
  обращение, при наличии действующего разрешения и доступа к треду.
- В диалоге закрытия три значения enum:
  - resolved (по умолчанию) — Вопрос решён;
  - no_longer_relevant — Не актуально;
  - other — Другая причина + обязательное описание до 1000 символов.
- Код причины, описание, пользователь и время сохраняются на обращении.
  В request_thread_events создаётся отдельное событие support_closed
  с actor_user_id и метаданными причины.
- Старые вызовы POST без поля reason совместимы и означают resolved.

## Возобновление
- Закрытое обращение может возобновить его главный ответственный, если
  право и доступ к треду сохранены. Если главный отсутствует после отзыва
  полномочий, уполномоченный сотрудник с доступом может возобновить
  обращение, одновременно приняв главенство.
- Текущие реквизиты закрытия очищаются, а прежние события остаются
  неизменными в журнале. Создаётся событие support_reopened.
- Отправка сообщений остаётся недоступной, пока обращение закрыто.

## История сообщений
- Сообщения и события support_closed / support_reopened объединяются
  в хронологическую ленту с ограниченной keyset-пагинацией без тяжёлых JOIN.
- Системные блоки показывают Система MSKBA, действие, автора, код причины
  в человекочитаемом виде и описание, если оно задано.
- Из Filament доступен только просмотр последних 50 записей; для полной
  истории используется портал. Права проверяются до загрузки истории.
