# Page Builder — компактные редакторы CSS и JS

## Управление в Filament

В редакторах **Страницы / Шаблоны / Компоненты** сверху доступны две
компактные кнопки **CSS** и **JS**. Код редактируется в модальных окнах;
связанные с ним действия находятся внизу соответствующего окна.

* CSS: «Сохранить и опубликовать», «Откатить CSS» (если есть предыдущая
  версия), «Отмена». Если публикации страницы ещё не было, вместо
  публикации сохраняется CSS-черновик. Если у редактора есть `css.edit`,
  но нет `css.publish`, он может сохранять черновик без публикации.
* JS: «Сохранить и опубликовать», «Отключить JS» (если включён),
  «Откатить JS» (после второй различающейся публикации), «Отмена».
  Публикация JS **одновременно включает** его. Откат восстанавливает
  предыдущую версию и включает её.
* Без права редактирования доступен только просмотр исходника. Без
  `css.publish` / `js.publish` нельзя публиковать, откатывать и отключать
  код даже прямыми вызовами Livewire.
* Общая верхняя кнопка «Опубликовать» убрана. Низ страницы сохраняет
  «Сохранить» и «Сохранить и опубликовать» для HTML/компоновки/SEO.

## Семантика CSS и защита черновиков

Отдельная публикация CSS обновляет **только** `draft_css`,
`published_css` и независимый `previous_css`. Она не публикует
незавершённые изменения HTML, Hero Slider, маршрутизации или SEO.
Черновик CSS не появляется на публичном сайте до публикации.
Весь CSS по-прежнему проходит существующую проверку `PageBuilderMarkup`.

## Семантика JS

Используется одна транзакция для сохранения черновика, публикации и
включения. Состояние хранится в существующих двух слотах: текущий и
предыдущий опубликованные JS. Файлы JS при публикации не создаются,
исполняемое содержимое выдаётся по URL с SHA-256.

Отключение JS прекращает **новое подключение** скрипта и отдачу его
URL. Уже запущенный JS в открытой вкладке браузера не остановится
без обновления вкладки.

Изолированный JS preview endpoint остаётся в коде, но из компактного
интерфейса убрана отдельная кнопка «Песочница». Возврат этого действия
можно рассмотреть позже при необходимости.

## Взаимодействие с другими PR

Изменения внесены отдельным PR против `dev`.
Параллельный PR #364 меняет `BuilderComponentResource.php` (навигация и
слои слайдера). Конфликт с ним проверять после обновления `dev`:
при слиянии следует сохранить оба независимых набора изменений.

Ни `UserOperationalPermissionEnum`, ни сервис управления правами,
ни `BackofficePanelProvider` в этом PR не меняются.

## Ограничение высоты CSS/JS-редакторов

Модальные редакторы CSS/JavaScript в Page Builder (страницы, шаблоны,
компоненты) и в «Темы оформления» используют общий стиль панели Filament:
окно ограничено `95dvh` (`95vh` как fallback). CodeMirror получает
собственную прокручиваемую область для длинного файла; заголовок и
панель действий не уезжают за пределы экрана.

Для особенно небольших экранов тело модального окна может отдельно
прокручиваться, чтобы избежать обрезания кнопок или селектора версий.
CSS подключается из `resources/views/filament/backoffice/code-editor-styles.blade.php`
и не затрагивает публичную страницу или хранящиеся в Filament CSS/JS.
Логика публикации/отката и права доступа не меняются.
