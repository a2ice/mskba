# Операторский центр MSKBA

**Статус (16.10.2026):** этапы 1 и 2 реализованы в `dev` (PR #336 и #340); live-индикация присутствия в Filament дополнена PR #342, #346 и #347. GitHub CI/CD `dev` проверен. Ручная двухпользовательская браузерная приёмка ещё требуется. Production не затронут.

## Права и переписка

- `operator.presence.view` — присутствие и текущая безопасная страница; независимо от права на диалог.
- `operator.session_history.view` — ограниченная история переходов **текущей сессии**.
- `operator.conversation.handle` совместно с `backoffice.access` — инициирование/обслуживание назначенных сервисных операторских диалогов даже с пользователями офлайн. Другие операторы не получают доступ к переписке.
- `operator.marketing.send` не даёт права отправки рекламы до отдельного внедрения согласий, opt-out и частотных ограничений; этап 3 отложен. `operator.audience.filter` не требуется.

Операторская переписка использует существующую инфраструктуру уведомлений и приватного Reverb. Тексты сообщений и пути пользователя не пересылаются через broadcast-события. Сервер перепроверяет права на каждом HTTP/Livewire запросе и при подписке на приватный канал. Права контекстов команд и площадок вне этой задачи.

## Присутствие: Redis и точный смысл временных полей

`OperatorActivityService` хранит только безопасный путь страницы и временные Unix timestamps в Redis (UTC, секунды); IP, query string, hash, cookie, токены и полные приватные URL не сохраняются. Не использовать присутствие для авторизации.

- `operator-activity:current:{userId}` содержит `session` (SHA-256 идентификатора сессии), `path`, **`entered_at`** и **`at`**, TTL 7200 секунд. `path` проходит `safePath()`: запросы/фрагменты удалены, чувствительные маршруты сокращены; точные разрешённые ссылки на диалоги `operator|support|direct` допускаются.
- `entered_at` — момент входа на **текущий безопасный путь**. Меняется при смене `safePath`, не сбрасывается обычным heartbeat и сохраняется при возобновлении онлайна на том же пути. При смене нескольких приватных URL, свёрнутых `safePath` в одну безопасную категорию, новый вход намеренно не отслеживается.
- `at` — **последний успешный heartbeat**. Он обновляется и при неизменном пути. Онлайн-статус вычисляется на сервере из `at`: текущий timestamp не старше `operator_activity.online_seconds` (по умолчанию 150 секунд). После прекращения heartbeat статус станет «Офлайн» только после этого порога и очередного обновления видимого интерфейса; это не мгновенное обнаружение закрытия вкладки.
- Для Redis-записей, созданных до появления `entered_at`, чтение временно использует `at` как fallback; поэтому при самом первом показе старой записи «время перехода» приблизительное, пока запись не обновится. Никаких SQL-миграций не требуется.
- `operator-activity:history:{userId}:{sessionHash}` хранит до 100 безопасных переходов текущей сессии, TTL 2 часа. При logout активное состояние и его история удаляются.

### Синхронизация и отображение

Клиентский heartbeat отправляется обычно раз в 60 секунд; переходы SPA инициируют более раннюю отправку с ограничением минимум 3,5 секунды, а HTTP endpoint имеет throttle 20 запросов в минуту. При изменении безопасного пути или возвращении онлайн после паузы сервер публикует **только** `{changed:true}` на приватный `operator-presence.{userId}`. Подписываться может лишь уполномоченный оператор с назначенным диалогом и правами `backoffice.access`, `operator.conversation.handle`, `operator.presence.view`.

Filament Livewire получает реальное состояние через авторизованный запрос, а не по WebSocket payload. При смене страницы и новом состоянии «Онлайн» Reverb инициирует обновление; `wire:poll.visible.12s` остаётся резервом для offline (истечение 150 секунд без событий) и потери WebSocket. При возврате браузерной вкладки обновление запускается по `visibilitychange`/`focus`. Периодические heartbeat без смены страницы **не генерируют Reverb-событий**.

В операторском диалоге отображается статус «Онлайн/Офлайн», текущая или последняя безопасная страница и **время входа на неё (`entered_at`) в `Europe/Moscow` / МСК**, независимо от `APP_TIMEZONE` сервера (он может быть UTC). HTML `datetime` содержит ISO 8601 с часовым смещением; `at` не показывается вместо времени перехода. Статус и путь пересчитываются вместе при каждом обновлении Livewire. Проверка `operator.presence.view` не даёт утечь странице оператору без отдельного права.
