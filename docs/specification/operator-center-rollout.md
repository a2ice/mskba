# Операторский центр MSKBA

Статус: разработка начата, изменения только в ветке `feat/operator-presence-stage1`.

Этап 1: отдельные критичные глобальные permissions; Redis heartbeat присутствия и история переходов только в пределах активной сессии, с TTL и ограничением размера; список пользователей онлайн/офлайн в Filament.

Этап 2: операторские диалоги, доступные для любого зарегистрированного пользователя независимо от онлайн-статуса; серверная проверка роли на каждом запросе; доставка офлайн-сообщений через существующие уведомления.

Этап 3: рекламный тип сообщений только при соответствующем согласии, ограничениях частоты и отдельном разрешении. **Нельзя включать маркетинговые отправки до проверки согласий.**

Права контекстов команд/площадок не затрагиваются. Production не изменять без отдельного решения.
