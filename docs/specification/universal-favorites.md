# MSKBA — Универсальное избранное (первый инкремент, 2026-10-24)

## Контекст и UX
В задаче 286 («Хочу здесь играть») добавлено независимое действие **«Добавить в избранное»** над информационным блоком модального окна. Это не `PlayIntent`, не бронь и не заявка, работает без логина и не требует регистрации. В зарегистрированном кабинете `/account/favorites` предусмотрены фильтры по типам сущностей, список активного избранного и «Корзина».

## Модель данных
Таблица `favorites`: `user_id` **или** `guest_token_hash`, `entity_type` (`venue/event/team`), `entity_id`, `trashed_at`, timestamps. Универсальные polymorphic references реализованы короткими стабильными типами, без доверия к переданным извне именам Eloquent-классов. Ограничения уникальности: `user_id + type + id` и `guest_token_hash + type + id`. Типы регистрируются в `FavoriteTargetRegistry`, где проверяются публичность/доступность и URL; список поддерживаемых типов расширяется централизованно.

- Пока разрешены публичные подтверждённые `Venue`, публичные опубликованные/завершённые `Event` и активные постоянные `Team`; закрытый/неактивный объект добавить нельзя.
- Смена состояния **active → trashed → active** сохраняет исходную запись; физическое удаление из корзины не входит в инкремент. Если объект перестал быть доступным, показывать нейтральную недоступную запись, без ссылки и приватных данных.
- Для гостей сервер создаёт криптографически случайный opaque token, записывает только его SHA-256, передаёт сам токен в **HttpOnly, SameSite=Lax, secure-на-HTTPS, Laravel-encrypted cookie**, срок 90 дней. Cookie — не ID пользователя. При очистке cookie/смене браузера гостевое избранное нельзя восстановить до входа; явно не обещать синхронизацию между устройствами.
- На первом запросе после авторизации middleware `ClaimGuestFavorites` безопасно переносит записи в канонический аккаунт в транзакции и удаляет guest cookie. Если запись уже есть у пользователя, active гостя может восстановить пользовательскую trashed; active аккаунта не заменяется trashed гостя. Повторная обработка не создаёт дублей.
- Избранное является персональным пользовательским выбором. Оно не влияет на статистику спроса, рекомендации игр, уведомления, маркетинговые согласия или права доступа. Никакой персональной информации владелец площадки не получает.

## API
- `GET /favorites/status?type=venue&id=N` — доступно гостю.
- `POST /favorites/toggle` — CSRF-protected гостевой/пользовательский add/trash/restore, только allowlisted types и публичные объекты.
- `GET /account/favorites/items?type=all|venue|event|team&state=active|trashed` — приватный, только auth.
- `GET /account/favorites` — страница кабинета в светлой `mskba_app`.
