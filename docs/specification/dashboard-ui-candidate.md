# Динамические виджеты — UI Studio, ревизия 1

Epic #1073. Base SHA: 530c20b55c45dbfe8ea5e6258dd40dba1726a7da.
Case: dynamic-dashboard. Кодовый шаблон mskba_app. Кандидат, не интегрирован в приложение.

- Используются существующие panel, app-dashboard-grid, app-dashboard-widget, app-dashboard-widget__actions и button secondary; локальные CSS для строк данных, баланса и состояний.
- Реальный будущий Blade-представитель dashboard-dynamic-content использует DTO total/items/summary. UI Studio подключает его с фиксированными синтетическими fixtures; ссылки и повтор запроса локальные, не выполняют API.
- Состояния: данные, пустые списки, загрузка, ошибка, отзыв доступа (без данных), длинные строки. При реальном отзыве прав каталог должен убрать виджет; переходный placeholder не содержит сохранённых данных.
- Матрица проверки: все опубликованные темы mskba_app (включая светлую/тёмную), 1440/768/390/360, клавиатура/focus, перенос длинных строк, пустые и ошибочные данные. Legacy шаблоны не затронуты.
- Настройки ширины и порядка остаются в существующей оболочке дашборда; эта ревизия проверяет содержимое. Включение, сохранение пользовательских настроек, актуализация по Reverb, реальное поведение retry и исчезновение при отзыве прав — интеграционный этап.
- Статус: исходники кандидата подготовлены, отдельный Studio runtime и theme snapshot не проверены; hash темы и визуальная приёмка не подтверждены. Не публиковать dynamic-виджеты до принятой ревизии.
