# Виджеты личного кабинета: единые кнопки, изображения и отложенные обновления

## Filament

- Вкладка «Содержимое»: текстовые и статусные HTML-поля без отдельной ссылки/надписи кнопки.
- Вкладка «Действия»: единственный редактор стандартных кнопок. Существующие
  колонки link_url и link_label оставлены как legacy-проекция первой кнопки,
  но не служат входом в Filament.
- Вкладка «Изображение»: HTTP(S) URL для всех типов виджетов, в том числе
  HTML/CSS/JS. Расположение слева/справа (grid) или сверху/снизу, ширина
  25/50/75/100, gap 0–64px (10 по умолчанию).
- Доли grid делят ширину после вычета gap: 25fr/75fr. При 100%
  применяется вертикальная композиция, чтобы текст не исчезал.
  На мобильных устройствах боковые композиции перестраиваются вертикально.
- Вкладка «Размещение»: задержка обновления 0–60 с, default 5 с;
  значение 0 означает мгновенную замену.

## Обновление

- Reverb посылает существующую публичную инвалидацию без пользовательских данных.
- Клиент делает авторизованный запрос HTML и сравнивает хэш версии виджета.
  При изменении и положительной задержке старый DOM остаётся видимым,
  справа снизу появляется таймер, по истечении которого контент заменяется.
  Уведомления, восстановление фокуса, Reverb reconnect и polling не
  перезапускают действующий отсчёт. Динамические счётчики без правки
  виджета по-прежнему обновляются сразу.
- При удалении, отключении и исключении из аудитории карточка удаляется
  немедленно: приватность важнее задержки.
- При первой загрузке страницы показывается актуальная версия без паузы.
- Filament сохраняет last_edit_at и отклоняет повторные сохранения в течение
  задержки в транзакции с row lock. Кнопка сохранения также блокируется
  в UI с обратным отсчётом.

## Миграция

Для прежних виджетов значения по умолчанию:
image_position=top, image_width_percent=100, image_gap_px=10,
refresh_delay_seconds=5, last_edit_at=NULL. Существующие действия,
контент, аудитории, права и HTML-sandbox сохраняются.
