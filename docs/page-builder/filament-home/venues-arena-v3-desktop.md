# Главная DEV — Arena v3: desktop-композиция и единый мяч

## Область изменения

Только staging (https://dev.mskba.ru), только существующий опубликованный
Filament-компонент `venues-scene-v3` и включённый JS страницы «Главная».
Более ранний `venues-scene`, шаблон страницы, production и `main` не затрагиваются.

До утверждения адаптивной композиции изменения геометрии активны только
на ширинах **от 1100 px**. На меньших экранах сохраняется прежний Hero-мяч
без второй стадии перехода к шутеру.

## Источник графики и движения

Изображения остаются в Filament Site Media Library, папка
«Home venue section»: `arena`, `court`, `bench`, `hoop-arena`,
`player-shooting`, `player-defending`.
UUID/URL изображений и тексты/CTA/иконки справа не переписываются.

В новой композиции тренер/запасные/площадка/арена находятся позади Hero;
бросающий игрок №23 — справа от текстового блока; защитник №2 может
перекрывать нижнюю кромку Hero поднятой рукой. Внутри foreground размещена
обёртка `mskba-v3-venues__shooter-frame` с маркером
`mskba-venues-scene__ball-target`. Этот marker двигается вместе с шутером.

CSS для однократной публикации: 
`resources/page-builder/venues-scene-v3-desktop-hotfix.css`.
Он не подключается глобально: установщик один раз добавляет его к
**существующему** CSS компонента, после чего стили снова редактируются
исключительно в Filament.

JS мяча остаётся единственным опубликованным скриптом страницы,
переиспользует один DOM-узел `.mskba-rolling-ball`.
Профиль Desktop: `from [255,440]`, `to [760,890]`,
затем вторая scroll-зависимая фаза до маркера кисти шутера.
Размер/яркость/спрайт первого этапа не меняются. При движении назад
тот же DOM-узел возвращается в Hero.

## Разовая публикация из GitHub Actions

Команда `php artisan mskba:venues-arena-v3:desktop --check` выполняет
только проверки. `--apply` выполняет атомарное обновление через DB-транзакцию.
`deploy_dev` запускает обе команды после миграций и импорта Site Media.

Установщик обязан завершиться без изменений, если:

- среда не `APP_ENV=staging` и `APP_URL=https://dev.mskba.ru`;
- главная не ссылается на опубликованный `venues-scene-v3`;
- не найдены шесть требуемых изображений в Filament;
- HTML компонента или JS мяча отличаются от ожидаемой структуры;
- у компонента или JS есть неопубликованные изменения;
- обнаружено частичное применение исправления.

Перед публикацией в `page_builder_revisions` сохраняются отдельные
снимки `venues_v3_desktop_backup` (HTML/CSS компонента) и
`venues_v3_ball_js_backup` (все поля JS страницы). Затем стандартный
`PageBuilderPublisher` создаёт очередную публикацию компонента;
JS страницы обновляется с ротацией `previous_js` и записью аудита.

Маркер `[mskba-venues-v3:desktop-20261102-installed]` в описании
компонента предотвращает **любое повторное применение** при последующих
деплоях, даже если редактор изменил CSS/HTML/JS вручную.

## Проверки

1. На desktop 1440/1920: фон арены начинается за Hero, но не перекрывает
   его текст/ссылки; foreground-рука защитника проходит перед нижним краем
   Hero без обрезки; шутер справа от текста.
2. Проверить работающие CTA, четыре иконки, карту, турниры, footer.
3. Прокрутка вниз и вверх: мяч продолжает движение из Hero в сторону
   кисти шутера **без второго мяча или скачка**.
4. Tablet 768/1024 и mobile 360/390: нет новой стадии, нет лишнего скролла.
5. Если визуальная регистрация мяча неточна, менять в Filament CSS
   `left/top` маркера относительно шутера; настройки второго этапа
   не должны затрагивать начало движения Hero.

## Откат

При визуальном дефекте в Filament: в компоненте восстановить прежнюю
редакцию HTML, выполнить «Откатить CSS»; в JS главной использовать
«Откатить JS и включить». Внутренние исходные записи также сохранены
в `page_builder_revisions` как `venues_v3_desktop_backup` и
`venues_v3_ball_js_backup`.

Если проблема проявилась до успешной публикации, команда сама прекращает
работу без частичных изменений. Откат Git-коммита **не откатывает БД**.
Никогда не переносить этот однократный staging-компонент в `main` до
отдельной приёмки и переноса конфигурации в production.
