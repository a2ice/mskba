# Вложенные компоненты Page Builder

Композиция строится штатными плейсхолдерами в HTML Page Builder, **не** автоматической JS-инъекцией.

Пример:

В HTML главной опубликованный компонент сцены:
```html
<mskba-component name="home-venues-scene"></mskba-component>
```

В опубликованном HTML компонента сцены:
```html
<section class="mskba-v3-story__section--uniforms" id="venues-story-uniforms">
  <div class="mskba-v3-story__body-content">
    <mskba-component name="home-venues-section-form"></mskba-component>
  </div>
</section>
```

В опубликованном HTML компонента формы:
```html
<div class="tabs-wrapper">
  <mskba-component name="home-venues-section-form-workshop"></mskba-component>
</div>
```

## Контракт рендеринга

- PageBuilderRenderer раскрывает ссылки на опубликованные компоненты рекурсивно (до восьми уровней). Можно повторно использовать один и тот же компонент в разных местах; внутри своей же цепочки компонент не может ссылаться на себя.
- HTML каждого уровня отдельно санитизируется; после этого уже безопасный HTML вложенного компонента вставляется в безопасный родительский фрагмент. В публичном режиме неизвестные и неопубликованные компоненты не раскрываются, в preview выводится диагностическое сообщение.
- CSS вложенных компонентов собирается один раз на страницу, после CSS родителя и страницы, в общем \`@scope (.mskba-page-builder)\`. Опубликованный/включённый JavaScript вложенных компонентов тоже попадает в список ресурсов страницы ровно один раз. JS черновиков не выполняется.
- Для переключателей разрешены \`<button type="button">\`, \`aria-label\`, \`aria-pressed\`, \`aria-controls\`, \`data-tab-name\`. Сервер принудительно ставит \`type="button"\`, удаляет встроенные \`on*\`-обработчики и по-прежнему запрещает inline \`<script>\`, SVG, iframe и произвольное inline-\`style\`.
- Компонент и каждый вложенный дочерний компонент **нужно опубликовать отдельно**. HTML, CSS и JS компонента в Filament остаются источником истины; Git нужен только для рендерера и системной защиты.
- Не вкладывайте один \`<mskba-component>\` непосредственно в другой тег \`<mskba-component>\` в одной HTML-строке: компонентная иерархия задаётся содержимым отдельных компонентов, а не slot (исключение — Hero Slider).

## Приёмка

1. Компонент главной → компонент «Форма» → компонент «Мастерская»: HTML, классы, атрибуты вкладок и CSS/JS присутствуют в DOM.
2. Отсутствующий и неопубликованный дочерний компонент не раскрывается публично; в редакторском preview видна диагностика.
3. Циклические ссылки и более восьми уровней вложенности не приводят к бесконечной рекурсии.
4. Вложенные кнопки не вызывают отправку форм и не могут выполнять inline-обработчики событий.
5. CSS/JS не дублируются при повторном использовании одного компонента.
