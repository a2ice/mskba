# Магазин MSKBA — каталог без покупки

Публичный адрес: /shop. На первом этапе магазин работает только как каталог:
товары можно находить, фильтровать и изучать, но без оформления заказа и оплаты.

## Навигация

- Неограниченное дерево категорий; товар может находиться в нескольких категориях.
- Раздел /shop поддерживает обе темы: `mskba_dark` на общем шаблоне
  каталога и активную `mskba_app` в её собственном дизайне. В обоих случаях:
  закреплённый сайдбар с деревом категорий и фильтрами, поиск, карточки/список,
  мобильные фильтры и пагинация.
- Фильтры: тип товара, наличие, цена от/до, цвет, размер, тег, сортировка.
- Открывать можно только опубликованные товары, принадлежащие хотя бы одной
  публичной категории; скрытие родителя скрывает его ветку.

## Типы и характеристики

- «Категория» — место товара в навигации.
- «Тип товара» — один основной предметный тип, определяющий набор характеристик.
  Например, тип «Баскетбольная форма» определяет цвет, размер, материал, сезон и комплектацию.
- Характеристики — общий справочник для повторного использования разными типами.
- Автоматического наследования характеристик от родительских категорий НЕТ.
  Категория может предлагать тип по умолчанию при создании товара; сам товар
  сохраняет выбранный тип независимо от других категорий.
- Варианты SKU по цвету/размеру с собственными остатками и ценами — будущий этап,
  сейчас цвет и размер являются характеристиками базовой карточки.

## Первая демонстрационная карточка

«Одежда → Форма», образец Ozon 5041196075 по скриншоту от 10.11.2026:
чёрная баскетбольная форма (майка и шорты), размер 58 RU, мужская/женская,
на любой сезон, цена 1 018 ₽, зачёркнутая цена 2 651 ₽.
Цена 967 ₽ по Ozon Банку не является общей ценой.
Фотография получена из присланного пользователем скриншота, с исходными водяными знаками.
Наличие товара на складе MSKBA неизвестно («Наличие уточняется»).
Источник остаётся ссылкой на Ozon, без заказа на MSKBA.

## Выравнивание с каталогом площадок (2026-11-11)

- Каталог товаров использует ту же компоновку, что и площадки: sticky фильтры слева,
  компактные карточки и переключение «Карточки / Списком» справа.
- Кнопка «Добавить товар» открывает пока страницу-заглушку /shop/create.
- Категории свёрнуты по умолчанию, раскрывается только выбранная ветка.
- Избранное товаров сохраняется в существующей системе избранного MSKBA.
