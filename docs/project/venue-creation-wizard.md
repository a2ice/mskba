## Сценарии

На `/venues/create` пользователь сначала выбирает один из вариантов:

- «Я представитель площадки» — владелец или уполномоченный представитель. Для подтверждения управления понадобится скан документа о полномочиях; его можно прикрепить после добавления.
- «Хочу добавить площадку в каталог» — пользователь делится известным местом для баскетбола. Представлять площадку и подтверждать полномочия документами не требуется.

## Данные и публикация

Следующий шаг содержит название, тип, условия оплаты и бронирования, выбор адреса из подсказки либо по текущему местоположению. Данные сохраняются при переходе назад и при ошибке отправки. Если JavaScript недоступен, оба шага доступны как обычная форма.

После создания пользователь переходит к полному редактированию: фото, описание, теги и другие сведения можно дополнить перед отправкой на модерацию. Оба сценария создают неподтвержденную площадку и проходят существующую проверку дублей. Гостю сначала показывается общая авторизация; заблокированный аккаунт не может создать площадку.

## Подтверждение управления

На странице редактирования сразу после создания представитель видит отдельный переход «Подтвердить управление». Раздел «Управление» на странице площадки остается доступной точкой продолжения позже.

Подтверждение проходит через существующую заявку на управление: описать основание полномочий, затем прикрепить документ в переписке по заявке. Для подачи заявки требуется подтвержденный аккаунт или основной контакт. Выбор сценария в мастере не создает заявку автоматически и не подтверждает владельца; права определяются существующими правилами авторства и договорного доступа.
