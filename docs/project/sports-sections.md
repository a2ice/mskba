# Спортивные секции

Документ фиксирует стабильное пользовательское поведение контура спортивных секций (`SportsSection`).

## Публичная страница

Активная секция имеет полноценную публичную страницу на общем layout `section-sidebar`. Страница предназначена одновременно для потенциального участника и для пользователя с правами управления секцией.

Публичная часть может содержать:

- обзор секции с описанием и фотографией;
- направление и формат тренировок;
- состояние набора;
- целевой год рождения;
- число активных занимающихся и, если задано, вместимость секции;
- ближайшие подтверждённые занятия;
- действующих тренеров;
- основную площадку и зал;
- стоимость и активные тарифы;
- связанные постоянные команды;
- фотографии;
- публичные контакты.

В списке тренеров показываются только пользователи с действующей membership секции: membership должна относиться к секции, её контракт должен быть активным и находиться в допустимом временном интервале. Отключённый тренер не остаётся на публичной странице.

## Запись и набор

У секции два связанных признака:

- `accepts_trainee_requests` — секция принимает заявки;
- `is_recruiting` — секция находится в режиме активного набора.

Активный набор является усиленным состоянием открытого приёма заявок: `is_recruiting = true` означает, что `accepts_trainee_requests` также должен быть включён. В публичном UI эти признаки не дублируются двумя badge: при активном наборе показывается только «Идёт набор», иначе при открытом приёме — только «Принимает заявки». Активный набор получает заметный pulse-акцент; обычный приём заявок остаётся статичным.

У секции может быть необязательный `trainee_capacity` — количество мест. Это информационный лимит, а не автоматический запрет на заявку или приём. Если лимит задан, recruitment badge показывает число активных подтверждённых участников относительно вместимости: например `Идёт набор 1/15` или `Принимает заявки 1/15`. Формат означает «занято / всего».

CTA зависит от состояния пользователя:

- гость при открытом приёме видит «Записаться» и сначала проходит авторизацию с возвратом на страницу секции;
- подтверждённый активный игрок без текущей заявки может подать заявку;
- при существующей заявке показывается состояние «Заявка на рассмотрении» и доступна отмена;
- активный участник секции видит состояние «Вы уже занимаетесь»;
- пользователь, не подходящий под требования записи, получает недоступное состояние и пояснение;
- при закрытом приёме явно показывается «Набор закрыт».

## Возрастная аудитория

Ограничение по году рождения необязательно. Поддерживаются три режима:

- без ограничения;
- один точный год рождения;
- полный диапазон `от`–`до`.

Точный год и диапазон взаимоисключающие. Для диапазона нижняя граница не может быть больше верхней. На публичной странице отсутствие ограничения отображается явно.

Возрастная аудитория пока является информационным параметром секции и настройки набора; она не заменяет проверку подтверждённого активного профиля игрока при подаче заявки.

## Основная площадка

`primary_venue` на уровне SportsSection — основная/желаемая площадка секции по умолчанию, а не гарантия, что каждое занятие проводится именно там. Поэтому публичный UI использует формулировку «Основная площадка» и поясняет, что занятия могут проводиться и на других площадках.

Название основной площадки кликабельно и открывает общий системный preview площадки. Если у площадки есть координаты, preview дополнительно показывает карту с её точкой. Отдельная ссылка ведёт на полноценную публичную страницу Venue.

Конкретное `TrainingSession` в будущем может наследовать площадку секции как default и переопределять её для конкретного занятия; подтверждение фактической площадки относится к booking-first lifecycle занятия.

## Управление

Пользователь с соответствующими permissions получает на публичной странице быстрые переходы к управлению секцией. Действия разделяются по правам: редактирование секции, заявки и набор, занятия, связанные команды.

Публичное наличие секции не даёт прав управления само по себе: права определяются активными contract memberships и permissions.

## Занятия

Публичная страница показывает только будущие подтверждённые `TrainingSession`. Если занятие связано с публичным мероприятием, пользователь может перейти на его страницу.

Регулярное недельное расписание и полный booking-first lifecycle создания/подтверждения занятий не являются частью этого контракта и развиваются отдельными задачами.
