# Поиск мероприятий на главной

## Назначение

Главная страница MSKBA даёт быстрый вход в поиск баскетбольной активности через popup `Мероприятия -> Найти`. Пользователь может подобрать игру, тренировку, игровую тренировку или турнир, не уходя в отдельный каталог на каждом промежуточном шаге.

## Пользовательский flow

Поиск состоит из пяти последовательных шагов:

1. `Тип`;
2. `Параметры`;
3. `Где`;
4. `Когда`;
5. `Результаты`.

Выбор варианта и переход дальше разделены. Нажатие на карточку или option только сохраняет выбор; основной wizard меняет шаг по кнопкам `Назад`, `Пропустить` и `Далее`. Это позволяет спокойно проверить выбранные значения до продолжения.

На последнем шаге `Далее` меняется на `Готово`.

## Тип и параметры

По умолчанию выбран вариант `Не важно`, поэтому пользователь может сразу искать все доступные виды активности.

Для игры можно дополнительно уточнить:

- формат `Баскетбол 5×5`, `Стритбол 3×3` или `Стритбол 1×1`;
- способ формирования сторон: `Готовые команды` или `Отдельные игроки`.

Для турнира доступны тот же выбор формата и порядок набора:

- `Открытая лига` — набор может продолжаться во время турнира;
- `Фиксированный состав` — пул участников фиксируется до проведения.

Для тренировки и игровой тренировки дополнительных фильтров пока нет, поэтому шаг можно пропустить.

## Локация

На шаге `Где` пользователь выбирает `Не важно` либо `Указать локацию`.

При уточнении локации открывается вложенный flow:

1. город;
2. район / округ;
3. метро;
4. улица и площадка.

Можно использовать кнопку `Текущая локация`. После разрешения браузера система определяет координаты, преобразует их в адрес и старается заполнить известные город, район и метро. Если геопозиция недоступна, ручной выбор остаётся доступным.

Города и районы берутся из управляемого справочника MSKBA. На первом этапе в нём заведены Москва и Химки. Для Москвы второй уровень отображается как округа, для Химок — как районы/территории.

Улица подсказывается через Yandex с учётом выбранного города. Площадка выбирается существующим predictive-поиском MSKBA. Если пользователь меняет улицу, ранее выбранная площадка очищается, чтобы не сохранить противоречивую комбинацию фильтров.

Выбранные части локации показываются редактируемыми badges: к нужному подпункту можно вернуться без полного сброса wizard.

## Даты

По умолчанию поиск охватывает период от текущего дня до семи дней вперёд. Пользователь может изменить обе даты; конечная дата не может быть раньше начальной.

## Результаты

Результаты появляются пятым шагом внутри того же popup. В одной временной ленте показываются подходящие:

- игры;
- тренировки;
- игровые тренировки;
- турниры.

В выдачу попадают только публичные опубликованные мероприятия и подтверждённые турниры. Карточка показывает название, тип, дату или период, площадку, адрес и применимые игровые параметры.

Во время поиска показывается общий индикатор загрузки MSKBA. Если результатов нет, пользователь получает понятный empty-state и может вернуться к фильтрам. При ошибке можно повторить запрос кнопкой `Обновить`.

Кнопка `Назад` на результатах возвращает к датам. После изменения любого предыдущего фильтра новый переход на результаты запускает поиск заново.

## Площадки

Popup `Площадки` использует тот же общий нижний navigation footer, чтобы поведение `Назад / Далее` было одинаковым. Глубокая переработка содержимого поиска площадок в этот flow не входит.
